## 杯內雙溫度計

使用者指出溫度計放入水中比下方讀數更直覺，核可每杯一支同刻度溫度計、液泡浸水不碰杯底或杯壁、杯口小夾固定、液柱升降搭配小型即時讀值，並移除下方讀數欄。

- 兩支均為 0–80°C，每小格 1°C、每 20°C 標數字，刻度印在玻璃本體內；共用相同像素與溫度的線性換算。
- 液泡中心在場景 y=320、外半徑 15，水面約 y=210–215、內杯底約 y=350；液泡保留浸水及離底間隙。透明杯口小夾支撐，沒有新增電熱板或大支架。
- 讀值放在液柱頂端旁，隨液柱上下移動；每次由同一水溫狀態更新液柱、彎月面、讀值、熱傳箭頭。初始 A=60°C、B=10°C。
- 下方觀察欄整體移除，780px 面板寬度、場景原圖、三種環境、暖橙箭頭、操作按鈕及前後人物對話保留；手機仍以兩杯上下排列。
- SVG 提供各杯溫標、範圍及目前讀值的可讀名稱，吸放熱狀態以讀屏說明保留。

本機共 12 項全數通過（含外層），含原三環境與操作回歸、每支 81 條刻度的校準、同溫度同高度、液柱／讀值同步、液泡浸水與離底位置、鍵盤、減少動態、320–1440px 七種寬度、真實手機觸控、第二區獨立播放與小測；沒有 JavaScript 或 HTTP 錯誤。第 2–6 區及小測的 HTML 雜湊保持相同。

人工檢視三環境與手機實際瀏覽器畫面，確認玻璃管、固定夾、液泡、刻度、數字與 A／B 標示互不遮擋；持久化畫面為 `thermometer-room.webp`、`thermometer-fridge.webp`、`thermometer-hot.webp`、`thermometer-mobile.webp`。這是依使用者後續核可變更的呈現，取代最初示意圖中的固定觀察欄，沒有製作尚未核可的流光方案。
