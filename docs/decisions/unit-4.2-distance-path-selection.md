# 4.2 虛像對照的光段與總光路選取

日期：2026-11-06。依使用者要求，點選「反射前2公尺」時，只連亮上圖小熊到鏡面的2公尺；鏡後2公尺是反射光反向延長線，不與反射前光段連亮。鏡後標示仍可獨立選取，但不會連亮下方實際路程算式。下圖2公尺仍與真熊到原鏡面位置的算式互相對應；兩個情境的選取相互獨立。

兩張圖各自的「5公尺」改為可操作按鈕：上圖沿小熊→反射點→眼睛顯示整段實際反射光路；下圖沿真熊→眼睛顯示直達光路。金色高亮置於原藍色光線後方，保留原方向箭頭；鏡後虛線不納入上圖實際光路。按鈕提供鍵盤操作及焦點提示。

點擊對照區或其旁的空白處，解除兩個情境的選取及整段亮線；點選其他距離或總路徑按鈕時仍可切換。光線、物像位置及2／3／5公尺幾何數值保持。
