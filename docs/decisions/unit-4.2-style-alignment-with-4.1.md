# 4.2 共用外觀以4.1為標準

日期：2026-11-05。使用者要求對齊卡片、編號牌、標題留白、副標、頭像及頁寬。

- 以當次同步後的4.1實際樣式為準：桌機頁寬上限1120px，導覽250px／欄距34px；1100px以下為205px／24px，760px以下為單欄，頁寬上限620px及兩側12px。
- 六區卡片採20px圓角、淺白底、灰綠邊框及共用陰影；外框不再內縮，標頭分隔線與正文同寬。標頭25／28／21px內距、74px編號欄及16px欄距；900px以下水平內距21px，700px以下改18px內距、48px編號欄及10px欄距。
- 編號牌桌機50×50px，700px以下40×40px；主標題、上方留白及副標字級／行高／顏色／8px間距均直接對照4.1。第三區原有獨立h2字級與窄版外框內距不再覆蓋共用外觀。
- 教學區角色頭像為48px。小測依4.1的獨立規格保留44px頭像，並同步其外框、問號牌、標頭字級、副標及正文留白；潛望鏡內部任務配置不變。
- 共用外觀集中於`units/4/parts/4.2/assets/lesson-layout.css`，在活動專用樣式後載入；活動內容、既有ID與控制器不重構。頁面主題色同步共用紙色；窄版錨點預留110px，避免固定路線列蓋住標題。
- 整份body HTML逐字保留，包含已核可的開場、主圖、副標與說明、角色對話、器材、SVG與腳本。沒有新增套件、服務或光學模型變更。

版面驗證以新增的`tests/unit-4.2-style-alignment.test.cjs`逐項比較4.1的computed style，另以既有反射、虛像、物距、三鏡及潛望鏡專項確認可用寬度變更後的主要活動。詳細結果記於修訂檢查紀錄。
