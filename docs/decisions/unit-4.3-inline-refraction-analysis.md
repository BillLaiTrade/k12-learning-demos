# 第三／四區以常駐解析取代放大（2026-11-03）

使用者核可用角度扇形、原方向延長線與轉向箭頭連結折射方向和角度，要求取代原放大功能、保持原照片質感並與上方操作聯動；隨後一併授權兩區0–90°、第四區移除下半部殘留水面，以及箱框內嵌式介質切換。

## 決定

- 保留共用單光源控制器與主圖；刪除第三／四區熱點、放大視窗與相關開關事件。下方採永久完整解析，上方手動播放，兩者同步角度與介質，動畫進度不影響解析的可讀性。
- 分析圖共用原照片木紋與介質取樣、法線、同色角度扇形與實際黃光箭頭。灰虛線清楚標為原方向延長線，綠色彎箭頭示意相對該方向的偏轉；0°、全反射、掠射不顯示不適用的參考線。
- 引入單光源專用共用模型，兩區同為0–90°且同角度光源座標一致。保留原發光速率。超過水／玻璃至空氣臨界角時顯示全反射，使用紫色反射角與藍色入射角相等；不計算不存在的折射角。90°明確標示掠射，不產生穿越光。精確臨界角為模型極限，原生滑桿以1°調整。
- 第四區下半部包含兩側與底板一起以清空氣表面覆蓋；手機底框照片從不含液體的框帶取樣。按鍵位於原位置，以凹槽、內陰影、上下框唇遮擋呈現嵌入，保留水與玻璃雙選項、焦點與44px觸控區。
- 第五區原本的A／B獨立操作、放大與0–35°限制保持；舊出射模型保留其依賴關係，不進行無關重構。

## 驗證

完整模型角域、精確臨界角及兩側、前緣連續與有限值；瀏覽器驗證常駐圖解、特殊狀態、同構圖、箭頭時序、暫停／續播、切換競態／重試、鍵盤／拖曳／原生手機及八種視窗。另核對原照片未改、其他學習區與第五區回歸，公開部署成功後核對檔案雜湊與實際畫面。未新增依賴；未把此次修訂視為最終核可。
