# 單元 2.3 規劃決定：空氣

**狀態：已確認規劃範圍；尚未製作學習頁面**  
**確認日期：2026-10-27**

## 定位

2.3 是第二單元的獨立學習段，主題為空氣的組成與相關性質。2.1 只先以空氣作為混合物例子；2.3 再探究空氣由哪些氣體組成、各成分有何特性，以及支持這些認識的實驗證據。

## 已確認的學習小節

1. **空氣是空的嗎？** 回顧空氣占有空間，並連結 2.1 已學的混合物概念。
2. **空氣裡有哪些氣體？** 認識乾燥空氣主要由氮氣和氧氣組成，約分別占 78% 和 21%，其他氣體約占 1%；水氣和二氧化碳等屬於含量會變動的氣體。比例採約數，並說明水氣不列入乾燥空氣比例圖。
3. **空氣中的氧氣約占多少？** 透過封閉裝置中氧氣逐漸被消耗，觀察氣體體積或水面變化，估計氧氣約占原空氣體積的五分之一。學生需能說明觀察證據支持的結論；比例為估計值，不要求精密測量。
4. **空氣中的氣體有什麼不同特性？** 比較氮氣、氧氣及變動氣體的特性，例如氧氣能助燃但本身不燃燒、水氣含量會隨環境改變；最後用組成與實驗證據說明空氣為混合物。

## 實驗規劃目標

- 核心問題：空氣中的氧氣大約占多少？
- 核心證據：封閉裝置中氧氣被消耗後，氣體體積或水面出現變化。
- 預期結論：氧氣約占空氣體積的五分之一。
- 實驗的具體裝置、材料與操作步驟尚未定案。此規劃不代表已確認康軒某一版課本使用相同的實驗配置。

## 課綱對應與範圍

- **Fa-IV-3**：大氣主要成分為氮氣和氧氣，並含有水氣、二氧化碳等變動氣體。2.3 以組成比例、變動成分與重要氣體特性承接此項內容。
- **Ab-IV-4**：依能否用物理方法分離區分純物質和混合物。2.3 回扣空氣是由多種氣體組成的混合物；分類概念主要在 2.1 建立。
- **Fa-IV-4**（大氣可由溫度變化分層）不列入目前 2.3 規劃範圍。

## 後續工作
