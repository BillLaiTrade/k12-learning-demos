# 4.3 第三、第四區操作與標示修訂

日期：2026-11-03。使用者集中提出回饋後授權一次修改，範圍為第三、第四區共通標示／光源位置／介質選擇，以及第三區動畫加快、第四區新增A拖曳。

- 移除兩區的「實驗全景」與圖內播放／光源狀態標籤，保留操作列開關與下方即時狀態，避免相同訊息重複。
- 空氣、水、玻璃改為深色較粗字搭配貼合文字的淡色小底牌。主圖字體維持至少約15px，近拍沿用可讀字級，不新增大塊說明卡。
- 介質切換移除重複標頭，以較小淡色分段選項、勾選與淺色選中底表示水／玻璃，保留原生按鈕、aria-pressed、載入競態與失敗重試。
- 光源沿原光線向外移，目標距介面300個示意單位；接近垂直時限制垂直位置，避免光源超出水槽。第三區上方源垂直距離最多230，第四區上／下方分別最多230／250，入射點與折射角不變。
- 第三區空氣示意速率由0.13調為0.24單位/ms，預設45°水槽完整光路約由5秒縮至3秒；水／玻璃沿用相對速率。因光源距離隨角度受限，進入介面的時間由實際入射段長度計算，保留連續前緣、暫停／繼續、重播及離屏暫停。
- 第四區A、B都能滑鼠／原生觸控拖曳與鍵盤調角；拖A先求空氣側角度，再依既有折射率回推下方角度，維持0–35°範圍及同一光路。另一端同步對準，5px門檻區分點擊與拖曳，拖曳不改兩燈開關。
- 第四區器材置於獨立清晰前景，放大時仍保留其全景位置並可拖動，避免又被近拍裁切拉回中央或藏在窗後。光線端點依各視圖實際投影對準器材鏡片；紅藍中心線重合，方向相反。
- 中央局部放大、角度細引線、兩種介質、零度例外、焦點還原及手機同屏操作保持，其他學習區與照片／共用光學模型不變。

檢查補充兩端在水／玻璃、開窗／關窗下的拖曳，A原生觸控、兩視圖光線端點對位、外移邊界、動態入射時間、加快後的播放與原有回歸。仍為第四階段修訂，待使用者檢視，不宣稱外部驗收或單元最終核可。

補驗發現共用減少動態樣式會對所有元素套用極短過場，讓SVG路徑與器材變換的繪製值暫時落後模型。兩區光學SVG子元素明確設定無過場，確保拖曳與光線即時同步；背景濾鏡淡化仍保留。端點測試使用實際亮燈路徑與器材的螢幕投影，並檢查幾何元素沒有過場。
