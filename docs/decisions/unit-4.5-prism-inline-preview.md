# 4.5 第一區：減少側偏、內嵌白幕、移除器材標籤

日期：2026-11-02。使用者要求減少過於側偏的光路，並仿照4.4第三區把白幕正面放進操作畫面右側；後續明確要求移除遮住器材的「放入光路／拖曳底座／移開光路」三個標籤。

原60° N-BK7的參考最小偏向約38.65°，無法僅靠轉動而大幅減小。本輪改為30°等腰三角柱並重算光路，兩折射面邊長50mm、柱高40mm；準直白光、1×5mm狹縫與x=300mm白幕平面保持。參考偏向16.229854°、落點z=-87.3276mm；固定幕範圍調為z=-165至25mm，使色帶靠近幕面中央，也容納移開時的直射光。色散包絡隨新條件變窄：380–780nm約5.1364×5mm，400–700nm約4.2685×5mm；近看15×10mm，兩軸同倍率。科學圖及來源文件同步更新，不把示意線任意改成較小角度。

預覽置於同一操作舞台右上，採4.4的白幕正面／放大查看方式；放大用同模型原生對話框，支援Escape與焦點回復。浮動標籤全部移除，改用實際玻璃／底座的3D點選範圍拖曳，保留外部按鈕與鍵盤。小尺寸舞台讓器材位於預覽下方，核對玻璃與白幕不被預覽遮住。

只修第一區，其他區與唯一小測內容保持；仍屬第四階段待使用者檢視。幾何光學、理想準直與顯示色域／曝光限制保留，未宣稱實驗照片精準值。不新增套件或服務。
