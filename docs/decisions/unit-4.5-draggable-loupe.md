# 4.5 放大鏡改為直接拖曳

2026-11-05（臺北）。使用者要求可拖曳的放大鏡，取代點圖片後在另一處顯示放大內容。

鏡面及鏡柄皆可用滑鼠、觸控或筆直接拖曳；保留抓取偏移，鏡身跟隨移動，3×3像素、中央金框、右側單一色塊、RGB、同色數量及兩圖同步更新。以requestAnimationFrame合併移動事件，放開前套用最後位置並保留；原圖與處理圖都可拖。鏡面取樣來自原始／處理後圖片，沿用既有RGB與分組規則。

取消原圖單擊換選；快速觀察按鈕與方向鍵仍可定位。鏡面提供grab／grabbing及鍵盤焦點，取代先前透傳指標。正常位置鏡面中心對準取樣點；邊緣鏡身自動內縮以免裁掉鏡柄，取樣框和短線指出實際位置，拖出圖面仍可取到邊界像素。

使用pointer capture持續追蹤圖面外的指標；只接受主要指標及左鍵。放開解除捕獲，Escape、pointercancel、lostpointercapture、失焦、頁面隱藏、視窗尺寸／模式改變均取消並回復拖曳前的選取、位置及RGB草稿。不在觸控拖曳時捲動頁面，鏡外維持原頁面捲動。拖動期間經過其他顏色又回到起始同色組時保留原本調色，不因暫時取樣遺失。

未更動RGB計算、圖片、三模式、同色群組及第一小測；未加依賴。16項模型及29項介面檢查（含外層）涵蓋鏡面／鏡柄抓取偏移、移動中更新、放開保留、原圖／處理圖、取消／捕獲／失焦／模式切換／resize、圖外邊界、原調色保留、CDP真實觸控與捲動、七視窗及既有觀察室回歸。模型抓取偏移檢查使用1e-12容差處理浮點誤差。

前輪固定角落、點圖定位的規格保留歷史，由本決策取代。完成後依既有授權推送及驗證原生GitHub Pages，保存公開操作與檔案比對。
