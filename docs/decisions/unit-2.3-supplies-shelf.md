# 2.3 第六區：常駐材料區，逐件取用直接操作

2026-11-02。使用者希望不再先挑選材料、按開始才操作，而是物品本來就放在材料區，點選後來到操作桌再使用。本輪以此取代原第一步選材，沿用direct-1的真正器材拖曳、接近提示及複合操作；快取版本更新為supplies-1。

材料區與操作桌同時顯示，初始空桌，12件物品全部可取用。點大理石盤、錐形瓶、集氣瓶、水槽或工具，對應的同一件器材才出現在桌上；不用選齊、不做選材對錯檢查，沒有「選好了，開始操作」。重複點選只找到原物件，不複製、不清除水量、組裝、石塊及氣體。取用後可直接拖曳，已裝妥的塞子與漏斗維持原位置；手機取用時對準器材。

雙氧水及二氧化錳同樣可以放到桌上、拖曳嘗試。用在反應瓶時說明它們屬於前面的製氧材料，不生成本次二氧化碳，不鎖住整個操作流程。未上桌的容器與材料不顯示、不作接近目標，也不能被隱形填水或組裝。原點選／鍵盤輔助仍預設收起。

「重做實驗」保留已取用物品，重建空的實驗狀態；「清空操作桌」回到空桌，材料區繼續常駐可取用。唯一小測、科學反應／液封、導管進出與封存規則維持，第一至第五區不改。仍為第四階段製作修訂，非外部驗收或最終核可。
