# 5.3 第三區旋鈕各自控制（2026-11-06）

使用者指出點單杯卻啟動兩杯，核可修正各旋鈕只加熱各自那杯，並保留清楚命名的「兩杯一起開始」。A／B各自維護加熱時間與運行旗標，共用一個更新迴圈；後點另一杯不推進／重設先啟動杯。各到1,000cal停熱，兩杯都完成才更新紀錄並揭示歸納。

未啟動杯保留20°C、0cal與靜止燈號／攪拌／指針，完成杯保留終點。可單獨、先後、錯開加熱；重點完成或中斷杯只將該杯回到20°C重做，另一杯保留。整組按鈕將兩杯回到20°C同步啟動；有杯加熱時禁用整組重設及換量，未運行杯旋鈕仍可用。換區／背景停止活動杯，不自動續熱；重新加熱只重做選定杯。歷史紀錄保留，同條件不重複新增。
