# 4.4 第四區：讓圖卡跨過焦點

2026-11-03依使用者要求，從第三區的F外／F內比較接續，讓學生能親自跨越F判斷放大鏡條件。

- 圖卡改為0.3F至2F，拖曳、位置尺、刻度與鍵盤使用相同範圍。F由不可操作的參照改為可到達位置，另有1.5F／2F刻度。木軌與初始取景同步延伸，避免器材離開底座。
- 初次載入即開啟輔助光路，HTML及初始化一致，按鈕顯示「隱藏輔助光路」。既有切換觀察列保留光路偏好的行為保持。
- 觀察表保留五項內容，再加入「剛好在焦點」及「移到焦距外」兩列。尺下狀態與收尾對話明確收束正立放大虛像的條件；開始對話連接上一區的比較。
- F內使用原有虛像與角度投影，反向延長線及透明像位置不變。F上各物點出射平行光，沒有有限像距，但放鬆的眼睛仍可觀察像在無窮遠的圖案；用角度公式的有限極限繪製，不以空白冒充看不見，也不除以無窮遠。
- F外沿用同一薄透鏡公式形成倒立實像；主圖改用三條有限孔徑代表光線觀察正向會聚，F內維持入固定瞳孔的代表線。F外及F不畫反向虛線或虛像圖案，相關按鈕暫停使用。標籤顯示真正的實像距離。接近F的像可能非常遠，標籤固定於可見區並標示「視野外」及真實距離；避免把操作相機追到近無窮遠，明確開啟延長線時只對8F內的虛像作完整取景。
- 眼睛仍固定於1.7F；本區所有F外條件的實像位置都在2F以外，因此眼睛位於會聚點之前。正常眼睛無法清楚調節會聚入眼光，右欄顯示未解析光斑，尺下狀態說明原因，不延用清晰正立虛像。光斑為狀態示意，不是實際視網膜或眼睛調節計算，不能泛化為所有眼睛位置都看不到實像。
- 屏幕仍限0.45F至1.4F，在眼睛之前。F內比較保持；F／F外時文案改成相應成像條件與真正像距，不再把所有光斑稱為虛像。若要將F外實像接在屏幕上，可銜接第三區的完整屏幕範圍。

檢查包含F前後0.001F邊界、平行出射、真實會聚位置、非有限狀態不流入canvas／3D座標、F內像素恢復、預設光路及偏好、七列／刻度／鍵盤／原生觸控、七寬度四狀態與整課回歸。正式頁不提供測試全域API。
