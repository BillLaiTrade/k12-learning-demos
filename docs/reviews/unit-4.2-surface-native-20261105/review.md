# 第一區輔助反射圖解：材質剖面與原生播放

對照單元2.3水杯實驗、3.2傳聲圖及4.2第二／第五區，改進字級層級、圖像留白、材料厚度、邊緣高光與結果標示。光滑／粗糙以淡綠／淡藍對照，粗糙起伏保留放大示意說明；不加入第二區的法線／量角內容。

光路以Web Animations API的線條縮放及箭頭平移播放，兩側24個效果共用起始時間。取消逐幀SVG改寫及移動光點的陰影濾鏡；播放階段只有必要的狀態更新。減少動態偏好保留離散入射／接觸／反射階段，沒有移動／縮放。

`native-playback.json`記錄實際SVG像素變化、原生效果數及時間軸推進；獨立真實時鐘頁面量測幾何／樣式／子節點的DOM改寫數為0。這是動畫成本檢查，不是跨裝置FPS保證。`surface-rays.json`保存實際光路；驗證相同入射方向、局部平面反射規律、端點相接、平滑反射平行／粗糙反射分散及不穿過其他表面。

上方3D程式、主實驗figure與其CSS完全保留；第二區至小測內容相同，見`preservation.json`。移除「正在探索第幾段／正在進行單元小測」及其更新程式；1440與390寬的第一區、第三區、小測跳轉仍更新導覽與閱讀進度，沒有頁面錯誤。
