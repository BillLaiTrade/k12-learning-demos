# 第三區字卡閱讀停留與平順交接

2026-11-01。使用者希望右側逐步切換時，左側字卡的消失與換字更平順，避免還在閱讀就突然換掉。

新增oxygen-captions.mjs，正常互動只保留同一個字卡p，跟隨目前操作的drawing。原句完整顯示後先停留2.6–3.6秒（按字數），再260ms淡出，透明時換成最新句子，340ms淡入。快速到來的中間短句合併為最新提示，不累積過期訊息。自動連播700ms收尾不閃現讀不完的完成句；手動完成及封存結果仍可平順換成完成提示。右側步驟與原物理時間不延遲。

原生Web Animations同時承載閱讀停留與淡入淡出，播放暫停、器材視窗、Escape、分頁隱藏、離區及其他播放器均暫停它；返回／關閉不自動恢復。動畫自然完成後可完成最後字卡；重播／手動選步取消舊轉場並顯示所選操作，使用generation避免晚到回呼。減少動態偏好仍保留閱讀停留，但直接換字。無JS原七張字卡與八場景保持。SVG title與輔助狀態仍即時反映真正操作；畫面資料以data-caption-message與視覺字卡data-scene-note分開。

最終本機58項全通過（字卡10、材料10、器材9、操作11、連播10、物理8；零失敗／取消／略過）。新專項以原生Animation的duration／currentTime／finish核對閱讀時間、真實中途opacity、短句合併、同張字卡跨步、淡出與淡入各自暫停、介紹／背景／其他播放器、快速切步取消、完成後更新／重播、桌機及320／390手機、減少動態與無JS。已目視淡出中間影格與桌機／手機新句畫面，transitions.json保存兩個中間透明度。首次標記重名及測試把按鈕過渡算入字卡動畫的問題均已修正後重跑全套。
