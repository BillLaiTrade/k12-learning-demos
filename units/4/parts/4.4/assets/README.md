# 第九區顯微鏡資產

`microscope-studio.mjs/css` 呈現完整成像與兩個局部近看入口。預設及重設顯示整台顯微鏡；近看物鏡或目鏡時，完整關係線保留並突出對應範圍，可返回完整成像。近看入口位於實線、虛線區段框上方，分別標為物鏡成像與目鏡觀察；兩個區段名稱按鈕、鏡頭標籤及下方分工卡共用切換，保留輔助光路與物點偏好；初次載入與重設均開啟輔助光路。

`microscope-model.mjs` 使用單元既有 Three.js 製作直立式立體剖面，材質環境由程式生成。光路與正常字形的 HTML 標籤依同一相機投影；位置小圖為同模型的全貌快照與取景範圍。模型不可用時，SVG 備用剖面仍支援近看及返回。

`microscope-optics.mjs` 依既有 `optics.mjs` 的兩透鏡配置計算連續代表光線。物鏡近看呈現中間實像，目鏡近看及完整成像呈現目鏡的虛像。同一個中間像示意框持續存在，依觀察範圍標示為物鏡的實像或目鏡觀察的物體；比較圖把物鏡形成的中間像原樣帶入目鏡觀察。光學位置及參數不隨取景變動。

`microscope-specimen.mjs` 共用草履蟲固定玻片的輪廓、單側口溝及內部構造，提供比較窗、中間像放大示意、備用剖面與載物臺材質。物鏡成像整體旋轉180°，目鏡不再翻轉；顏色、構造及大小為教學示意。介面直接使用「中間像」，沒有額外代號或重複結論卡。

關係線以兩個上、下邊緣對齊的完整框線分別包住左三項與右三項；中間像只出現一次，位於兩框的交集。區別使用實線／虛線與框線位置，不依賴顏色；共用區域採淡紋理，不增加額外說明句。

關係圖的五個節點各有圖像：草履蟲原物、凸透鏡、倒立的中間實像、凸透鏡及透過目鏡所見的放大虛像。三個標本圖像共用 `specimenGraphic()`，中間實像與最終虛像方向一致且均相對原物旋轉180°。虛像使用清楚圖案與虛線字樣標示，不以模糊或透明度暗示光學性質。

兩張分工卡收進工作區底部，精簡為標題與焦距條件；卡片、區段名稱及主圖鏡頭入口共用選取狀態。近看時對應範圍框加入淡底色，該範圍三個節點的名稱加深，唯一中間像在任一局部近看均亮起；返回全貌或重設後清除局部強調。
