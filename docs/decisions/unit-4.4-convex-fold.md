# 4.4 第二區：凸透鏡折射說明收合

2026-11-07，依使用者核可示意圖製作，先修正示意圖第二介面直行參考線的物理錯誤。

- 現有立體器材、木質光軌、鏡片材料及主要操作保留。新增「重新觀察」恢復視角與光路，不更動器材位置。
- 下方分為「上方的光，為什麼往下會聚？」與「下方的光，為什麼往上會聚？」。使用原生 details / summary，預設收合、各自開關，支援鍵盤。
- 每圖使用主圖同一組球面與 Snell 折射資料，呈現①入玻璃、②出玻璃、會聚到同一 F 的連續光路。沒有沿用生成圖片中的曲率或直行參考線。
- 深色虛線是各介面的法線；淺色點線只是假如光不轉向的直行參考，不是實際光線。①沿水平入射方向；②沿已在玻璃內折射的方向延伸，所以上方圖②點線向右下、下方圖②點線向右上。
- SVG 使用等比例投影，維持法線與曲面垂直，也不誇張折射角。綠色彎箭頭是轉向提示，不作為光路。
- 「放大折射處」切換同一圖的觀察範圍，不改變角度；可返回完整光路。手機保持可讀尺寸並於圖內左右捲動，有明確提示，整頁不橫向溢出。
- 刪除原本兩個介面切換按鈕與長段文字，統一結論只保留上、下光線會聚於同一焦點。

驗證涵蓋：兩圖參考線與實際入射方向一致、主圖光路不變、兩個收合獨立、放大標籤不被裁切、光路切換同步、滑鼠／鍵盤／觸控、七種寬度、WebGL 失敗時仍有可操作說明。公開發布成功另以 Pages 工作與公開實測確認。
