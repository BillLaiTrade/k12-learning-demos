# 2.1 波的傳播素材

- `dialogue-character-avatars.png` 沿用 3.1／3.2 頁面的小葵與阿公頭像，顯示九段學習內容中的對話。
- 頭像圖由本專案既有的 `parts/3.1/assets/dialogue-character-avatars.png` 共用；左半為小葵，右半為阿公。頁面以 CSS 裁切對應半幅。
- `wave-rope-texture.png` 是繩波圖共用的編織繩紋理來源；三張圖都使用同一素材。
- `wave-rope-texture-clean.png` 是從來源圖裁切出的乾淨中央區域，用來避開透明去背邊緣的雜色，並填入第一、二、三張繩波圖。
