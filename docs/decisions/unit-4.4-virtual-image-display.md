# 4.4 第三區虛像呈現

2026-11-03依使用者核可示意實作。F內不能只顯示「屏幕接不到」：主圖需明確顯示同側、比圖卡更遠、正立放大的虛像。

- 位置與倍率唯一來源為既有薄透鏡模型。預設物距0.5F，像距−F，倍率+2；拖動圖卡連續更新，沒有離散替代圖案。
- 虛像使用原圖案的透明貼圖與虛線輪廓，沒有白板、實體邊框、底座、陰影或器材拖曳命中。為避免斜看時圖案過薄，只繞垂直軸面向觀察方向；中央上／下物點仍留在模型的世界座標，與延長線交點一致。
- 實際折射光為向前的實線；F內每個物點保留兩條代表光線，向後延伸為無箭頭虛線。虛線交點與虛像本體使用同一位置、倍率。關閉光路不移除虛像。
- 右側與3D屏幕繼續使用實際接收面的同一投影canvas，不能把虛像貼到白紙上冒充實像。
- 水平顯示比例每F由1.4增至2.1，光軌、器材、焦點及光路同步。初始聚焦主要器材區，縮小可看完整長軌；觀察列明確選取及容器尺寸改變才重新取景，尺拖曳／旋轉不重設相機距離。
- 虛像接近F時會遠離透鏡且變大，不裁改計算的位置或倍率；超出視野以位置標記保留正確圖卡側距離。三條已移除的操作提示不恢復。

檢查：純模型驗連續位置、倍率與共線；瀏覽器驗世界座標、實際渲染像素、切換狀態、屏幕投影不變、縮放旋轉、十尺寸及觸控。測試觀察介面只透過攔截模組注入，正式頁面無測試全域API。
