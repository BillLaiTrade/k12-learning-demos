# 4.3 先完成整頁基本版，再逐區優化

日期：2026-11-01。使用者已核可七區製作方式，要求以基本版本為後續優化基準。

採六個教學互動區加一個結尾小測，依序為介質光速、垂直入射、射入較慢介質、射回空氣、光路可逆、視深與理解檢核。每區沿用小葵／阿公對話，共用頭像；桌機以左側探索導覽配主內容卡片，手機改橫向導覽與單欄。單元入口開啟 4.3，其餘規劃中頁面不改。

光線採 SVG 幾何模型，保留滑桿、鍵盤和拖曳操作。動畫需手動開始，光速比較使用同距離與相同比例慢動作。視深以固定物體與入眼折射線求局部虛像位置。學生只比較方向，不新增司乃耳公式、臨界角與全反射計算。模型範圍及檢查方式見單元 README。

基本版實作與工程檢查不代表完整單元通過外部驗收或使用者最終核可。後續依使用者檢視逐區優化。
