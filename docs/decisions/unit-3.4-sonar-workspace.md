# 3.4 第四區：同屏聲納工作區

日期：2026-11-01（臺北時間）。依使用者核可示意圖 `exec-90452f4d-edbb-4b9c-81f7-3b8573827b37.png` 製作。維持第四階段供檢視。

原版海洋、測深圖、計算及紀錄縱向堆疊，使用者須上下滑動才能對照。桌機改為左側海洋／測深圖、右側本次測深／累積紀錄；聲速、時間、接收狀態與發聲／暫停集中於上方工具列。保留既有船、海床與共用角色；完整對話和模型限制移至下方預設收合的「探測說明與人物對話」，短操作提示常駐。

紀錄每頁四筆；新探測自動顯示其所在頁。翻頁不重播、不改當前計算、不刪除測點；探測中也可翻閱舊紀錄，回波抵達後維持所選頁。清除重設至第一頁並取消舊排程。海洋保留全部標記，測深圖仍依全部完成紀錄排序，重複位置取最新完成值；未完成測點不洩漏深度。

海洋與圖表共用左欄全寬，圖表以實際像素尺寸投影，水平位置對應原場景0–1000。ResizeObserver在換寬時重畫，字體和點大小不隨縮放變細。深度軸保持0–2250公尺，圖中僅連接已測點，標註點間為直線估計；不讀真實海床填補空白。

760px以下改上下排列，維持44px操作尺寸與不橫向溢出。桌機／筆電以實際視窗斷言核心全部可見，未用內層捲軸壓縮。桌機核心高度約587px、1024px寬約626px；包含標頭後仍可在1440×900、1366×768、1280×720、1024×768內同屏檢視。手機以可讀性優先，不宣稱同屏。

模型、聲音及拖曳／點船／箭頭／鍵盤控制保持：1500m/s，約150–2250m，0.20–3.00秒真實往返。未增加動畫倍率、預置測點或新套件。`echo.mjs`只更新聲納模組快取版本，其他播放器邏輯保持。

本機34項通過：聲納15、船隻7、整課10、測深圖模型2（含各外層）。新增同屏／水平對齊、四筆分頁及探測中換頁、手機實際觸控換頁；原聲音排程／最末輸出、暫停續播、清除、跨區、啟音失敗及延遲取消保持通過。已開圖檢視桌機與390px／320px。證據見 `docs/reviews/unit-3.4-sonar-workspace/`；公開確認另記於規劃repo。

## 2026-11-01 人物對話直接顯示

使用者指出人物對話不應被折疊。三段既有對話移出details，保留在操作區下方常駐顯示；只有模型條件保留收合，標題改為「模型說明」。不以預設open代替移出，使用者收合模型時不會隱藏人物。操作區位置、尺寸、工具列分組與各項互動保持。現有阿公對話已引導換位置、比較時間及累積測點，不另加F07建議的重複提示。這段取代本文最初「完整對話和模型限制一起收合」的安排。驗證見`docs/reviews/unit-3.4-sonar-dialogue-visible/`。
