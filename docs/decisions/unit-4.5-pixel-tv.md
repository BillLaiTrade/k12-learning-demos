# 4.5 第二個小測：像素電視三任務

2026-11-04（臺北）。使用者要求保留現有六題小測，另做簡易電視實作，依三張核可示意圖及後續五級按鈕討論開始製作。此指示取代早期唯一小測規格，不新增第六個教學區。

## 學習與操作

任務1調出指定色：左邊目前顏色、右邊目標，RGB各0～4級點選，不用滑桿。目標只呈現顏色與名稱，不給級數；可換目標繼續試調。

任務2補一格：4×4實作與完整目標並列，其餘15格一樣，只有第2列第3格為未填色。先調色，再按填入缺格；錯誤可修正，不會自動改其餘格。修好後仍能返回改動或重設本題。

任務3逐格重建：8×8實作從64個null空格開始，右邊是完整小狐狸目標，每格都要手動設定並填入。黑色[0,0,0]是已填值，與灰色點格未設定分開。選格可用點按、方向鍵、列／格選單或下一個空格；Enter等效填入。目標金框與實作選格對應，並有選取格目標色塊，讓手機不需精準點極小格。

三任務可任意往返，共用目前調色，已填畫面與回饋保留於本次頁面瀏覽。任務2／3可帶出選取格目標色回任務1試調，帶回後仍須按填入；不直接複製目標級數。檢查只指出差異或未填位置，不自動補圖、不提供配色答案。重設只清本任務畫面，保留其他任務與調色；重新整理回初始狀態。不儲存學生資料、不計總分、不做逐關鎖定。

## 顯色與呈現

以理想RGB發光螢幕示意，各通道級數除4成線性強度，再用共同sRGB轉換顯示；相同設定的通道一起提高形成灰階。共125種設定組合，目標、目前色、已填像素與合看預覽共用同一函數，子像素只保留自身通道，0級為黑。通道控制值不同於第三區650／530／460nm的輻射功率，不更動原光譜模型，也不當實測面板光譜或亮度。

所有目標由同套五級設定產生，確保可達；橙[4,1,0]、米白[4,4,3]等非原色保留。驗證比較同模型的離散設定，未設定格使用null。CSS畫電視框，DOM畫真正可操作格子，不把生成示意圖貼成操作背景；無新套件、圖像素材或WebGL需求。

桌機與手機都保留實作／目標對照，手機提供至少44px高的列／格選單與級數按鈕，免依賴小像素命中。原五區及第一小測整段保持，主程式獨立載入新模組，失敗不阻擋原內容。無JS可讀初始題意及色塊，操作停用。

模型與瀏覽器驗證包括125設定、黑／空格、單格與全圖判定、真正顯色、雙向試調帶回、64格逐一完成、狀態保存與重設範圍、鍵盤／手機、七尺寸及模組失敗／無JS；另回歸整課與第一小測。實際結果與公開部署保存主專案review，維持第四階段、待使用者檢視。
