# 4.4 第三區立體成像與物距比較

2026-11-02。使用者先核可分析方向，再看過示意圖，明確指示按圖製作。維持第四階段修訂，第三區保留已核可的「先對焦，再改物距比較」整合安排，不新增學習區或測驗。

沿用共用人物、卡頭、導覽標題與前兩區的器材風格。立體成像台包括發光圖卡、固定凸透鏡與白色屏幕；投影直接畫在接收面，正面視角仍是同一片屏幕。第一階段固定圖卡與鏡片，只移屏幕；第二階段解鎖圖卡，提供較遠、兩倍焦距、較近代表位置，但不自動對焦或搬動屏幕。階段切換保留器材與紀錄。無拉霸或整體重設按鈕。

物體與屏幕可拖曳底座，保留抓取偏移；鍵盤及移近／移遠按鈕提供替代與微調。鏡片固定以維持控制條件。空白處轉動視角，滾輪／雙指縮放；取消手勢後不繼續移動。器材名稱跟隨投影位置，窄螢幕避讓；F／2F依相同焦距與光軌位置標記。

沿用既有理想薄透鏡模型，獨立imaging-optics模組計算實像、屏幕平面倍率、有限孔徑造成的散開，以及超出軌道／屏幕狀態。投影用同一幾何的孔徑取樣，失焦連續變化，不將放大像縮小填入；超出接收面直接裁切。輔助線在薄透鏡主平面折轉，未逐面模擬玻璃折射；明確與第二區雙曲面折射的教學目標區別。模糊未模擬繞射、像差或實際光度，判定清楚容許正負1.5公分模型距離。

醒目光路按鈕在圖內，可追蹤上端／下端／合看；正面視角暫不顯示立體線，避免遮蔽投影，返回實驗台保留光路選擇。清楚像紀錄保存實際屏幕畫面，固定相同比例與範圍，不限制放大倍率。相同物距可更新，新增第四筆不刪舊紀錄，刪除由學生明確操作。

WebGL無法啟動時仍顯示相同屏幕投影，移動、階段與紀錄按鈕可用。沿用4.1既有Three.js，無新增套件或服務。第一、第二及第四至十區HTML與既有專屬資產保持，證據見[交付紀錄](../reviews/unit-4.4-imaging-3d-20261102/review.md)。
