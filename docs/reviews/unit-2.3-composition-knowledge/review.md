# 2.3 第二區整合氣體知識、四教學＋一小測

日期：2026-10-31（臺北時間）。使用者先要求評估，核可整合與編排方案後指示製作；已同步main並保留其他2.1工作。

## 核可架構與實作

01杯子／空氣占空間→02組成分類與氣體知識→03氧氣實驗（原04）→04二氧化碳實驗（原06）→05唯一小測（原07）。原03氮氣／05氬氣介紹移入第二區，新增氧氣介紹，不保留獨立導覽。

第二區主圖及全部比例／分類常駐，下方一個滿寬面板切換氮／氧／氬：名稱／化學式、約數占比與三項性質為主，下方用途小圖。預設氮氣，原生點色格／名稱與Enter／空白／觸控確認才換介紹；滑過及焦點只突出圖形，換排列不清除介紹。點空白可清除圖形選取，但正在讀的知識保留；閱讀面板本身不清除選取。

斜紋合併格先顯示氬氣＋其餘成分與明確選項，不自動當純氬；其餘只作多種成分短註，不等同二氧化碳、不額外做一張二氧化碳知識卡。選項所在短註隱藏時，焦點轉到對應可見圖例。無JS三份氣體知識與圖片依序顯示，提示與輔助切換按鈕隱藏。

沿用原字體、配色、標頭與小葵／阿公。氮78%、氧21%、氬0.93%皆為全部乾燥空氣約數；氧氣明確區分本身不可燃但助燃，並介紹不易溶水、無色無臭及呼吸／供氧。新增生成鋼瓶／面罩照片 `oxygen-supply-example.webp`（960×640、38,086 bytes），原PNG保留工作區generated_images；用途參考，不是實測照片或操作指引。原氮／氬小圖沿用，無新套件或字型。

兩實驗的裝置、四步及木條／石灰水觀察內容保留，只重編與調整開場。氧氣控制器依裝置找所屬區塊，避免舊編號依賴；小測判定保留，回看目標更新為s2／s3／s4。`preservation.json`核對第一區、兩實驗從裝置起的內容及小測body完全未改；`anchors.json`核對五個區塊、全部內部連結與ARIA引用無缺漏／重複。
