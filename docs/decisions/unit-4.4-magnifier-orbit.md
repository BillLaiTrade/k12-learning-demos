# 4.4 第四區旋轉與縮放分離

2026-11-02。使用者回報沒有使用滾輪，僅拖曳實驗台畫面就會自行放大縮小。已重現：原本updateCamera每次依新角度迴圈求取景距離，同一次50px拖曳可令距離由11.3898變為12.7976模型單位，屬於非預期的自動縮放。

將自動取景移到初始化與容器尺寸變動時，並用固定初始方向計算基準距離。一般更新只依旋轉角度與既有縮放倍數放置相機；拖曳空白、鍵盤旋轉、移動器材、光路開關及屏幕切換不重新配距。滾輪與雙指手勢仍可明確縮放，縮放後再旋轉保持所選距離。正面看屏幕為既有的明確視角切換，返回後恢復原本旋轉觀察距離。

此修正不消除不同角度的正常透視與遮擋；不再為了把不同角度塞滿畫面而自動拉近拉遠。右側固定眼睛視角與光學條件保持，器材尺寸與位置不因旋轉改變。既有七寬度仍在容器真正改變時自動取景。

原專項新增相機至固定中心的距離與FOV不變量，涵蓋滑鼠旋轉、58次多角度／上下鍵盤旋轉、縮放後再旋轉、屏幕切換，以及手機單指旋轉與雙指縮放；另保留右側影像像素、拖曳、光路、七寬度與備援。舊程式先以相同距離斷言重現失敗，修正後本機與公開重驗。最新證據見[交付紀錄](../reviews/unit-4.4-magnifier-orbit-20261102/review.md)，維持第四階段。
