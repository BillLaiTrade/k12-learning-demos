# 2.3 第三區：點擊修正與說明刪除（2026-10-30）

使用者回報點擊無反應，並要求移除「保存效果仍與密封、水分及溫度等條件有關。」；本次不改其他學習區塊。

## 重現與修正

- 減少動態模式下，舊程式按下後直接返回原本完成畫面，因此無可見反應。改為保留充氣前、充氮排氣、封口的階段靜態畫面，停用平滑插值與裝飾動畫。
- 圖片 decode 拒絕時，舊程式會永久停用按鈕。移除解碼作為啟用互動的前置條件，讓 CSS 自行載入圖片；不支援 IntersectionObserver 時仍能點擊。
- 以上為可重現的程式路徑，未確認使用者實際裝置符合哪一項；原始及修正後輸出見 reproduction.log、after-fix.log。
- 移除指定句子與專屬樣式，更新資源版本以避免快取舊腳本；不改充氮效果的科學界線。

## 驗證

- 本機 Chromium：第三區與整頁合計 18 項通過，見 browser-tests.log。
- 正常播放、重點擊、鍵盤暫停／繼續、離場暫停、手機觸控、初始減少動態及 decode 失敗回歸均通過。
- 七種寬度 1440／1280／1024／800／768／390／320px，初始和播放中均在內容欄內；左側參照影像雜湊保持相同。
- 桌機與手機截圖人工檢視，指定句子已移除；減少動態截圖可見充氮排氣階段。
- 測試時凍結時鐘、以明確時間推進，避免截圖耗時讓階段斷言偶發跳過封口階段。
