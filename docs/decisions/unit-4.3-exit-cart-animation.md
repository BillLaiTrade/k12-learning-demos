# 第四區由慢到快的小車類比

2026-11-03。依使用者要求，第四區也加入與第三區一致的小車動畫，對應上方水／玻璃、下方空氣。

- 沿用第三區圖文排版、輪胎／車軸、法線、軌跡與方向箭頭；第四區地面上下交換，上粗糙、下平滑，並明列兩區域對應的介質及光速快慢。
- 第四區上方介質名稱跟隨既有水／玻璃切換；下方固定空氣。類比速度固定70→100示意單位／秒、初始斜角30°，先跨界的左輪先加速，車軸偏離法線；雙輪進入後角度保持，速度相同。示意比例不冒充水／玻璃的真實光速，不與上方實驗入射角聯動。
- 兩區沿用同一小車初始化函式，但進度、按鈕及事件各自獨立。第三區初始40°及100→55的動畫保持；第二區程式與全部光學控制／模型不變。
- 一般展開自播、減少動態時手動，完成可重播；收合／離屏／隱藏停止保留進度，可繼續；無閒置動畫迴圈。手機單欄，光不受摩擦的限制說明保持。

檢查跨界前後的角度、速度與停止條件、材質標示、兩動畫獨立、七寬度、鍵盤／觸控及原有實驗。同視窗配置與其他區保持。維持第四階段修訂，待使用者檢視，非外部驗收或最終核可。
