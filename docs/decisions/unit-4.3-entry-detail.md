# 4.3 第三區：單一案例與入射點放大

2026-11-02。使用者指出重點應是光斜著進入另一介質時的現象與規則，水為主要案例，玻璃只供切換驗證；核可`exec-1013c901-98ad-4bce-9734-e668a1a73c62.png`的單一實驗＋入射點放大示意圖後授權製作。

- 預設空氣→水，水／玻璃切換同一裝置；取消雙槽並排與「同時發射」，保留點燈與發射光束、調角度及暫停續播。這項核可取代先前雙槽單側選擇的設計。
- 寫實全景提供操作脈絡；放大圖集中呈現介面、法線、入射角、折射角與規則。兩視圖使用同一座標系和每幀完全相同的光路資料，放大圖透過viewBox裁切，沒有獨立的假角度或任意轉折。
- 1254方形底圖共用外框與界面位置，入射點(650,570)，放大區以該點為中心、大小320×240。兩圖法線均穿過入射點，角度由既有代表折射率計算；45°對應32.0°／28.1°，0°則光路重合。全景中綠色小框定位入射點，連接線依實際DOM版位投影至放大圖；手機堆疊時省略連接線。
- 規則放在放大圖內，隨角度與介質同步更新；0°明示不偏折與角度相等。詳細機制仍預設收合，沒有增加額外小測或重複結論區。
- 發射動畫保持連續光束與代表速度比，僅供看見穿越過程，非實際秒數。滑桿、鍵盤、拖曳、點燈、重播、暫停及離屏／隱藏暫停保留，拖曳不誤觸發射。
- 切換介質保留角度，已有光路顯示新介質的靜態預覽，未發射保持待命。載入按選擇序號提交，快速切換不受舊回應覆蓋；失敗可重試或選另一種介質。
- 其他五教學區、小測、第一二區的程式與圖片、共用光學及課程腳本保持。只更新第三區模型／控制器／樣式／內容與相應測試，不新增套件。
