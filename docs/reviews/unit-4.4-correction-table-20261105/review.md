# 比較表切換檢查

- 三種眼睛的未矯正、合適鏡片、矯正結果皆能切換，上方按鈕、主光路、視網膜清晰度及表格按鈕狀態同步。
- 戴取鏡片不改變同一模型的視網膜位置；切換表格保留光路開關及上／下物點偏好。
- 上方手動選擇不合適鏡片時，該列的未矯正及合適鏡片按鈕均不誤標為選取；由上方選擇適當鏡片時，表格鏡片與結果按鈕同步選取。
- 原生Enter、Space及手機觸控皆可操作；點選鏡片欄的留白仍套用矯正條件。
- 第八區瀏覽器套件9項全數通過。窄版結果文字分行後以另開瀏覽器重新確認1440、390、320px全部表格條件、內層文字點選、無橫向溢出及所有表格按鈕至少44px高。
- 實際檢視桌面整區、桌面表格、390px整區及320px表格，沒有裁切或單字孤立換行。模型、上方控制與其他學習區的程式保持原有功能。
