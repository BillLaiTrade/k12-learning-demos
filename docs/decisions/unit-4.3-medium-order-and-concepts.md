# 4.3 第四區介質上下交換、畫面內選擇與重點說明

日期：2026-11-03。使用者先要求逐項記錄，最後明確授權一次修改四項回饋。

1. 第四區與第三區均由上方向下射入，改為水／玻璃在上、空氣在下。用既有慢→快幾何旋轉180°，入射角仍是水／玻璃側0–35°，折射角仍由同一光學模型求得。器材邊框保持正向，只於光學畫面內交換介質表面；兩視圖共用相同材料及界面。文字、扇形、角弧、引線、方向箭頭、鍵盤與原生拖曳均依新方向呈現。
2. 水／玻璃同時顯示，用原生按鈕與aria-pressed標出當前選項；切換位置依使用者最後一項修正，放到操作畫面內的中央下方，貼近底部橫框。第三至第五區一致。讀屏組名標示目前介質，載入失敗關窗時焦點回選中按鈕；切換競態與重試保留。
3. 第三／四區在整個實驗操作下方另設全寬、常駐重點區塊，以明顯邊框／標題、介質快慢流程、先後進入的波前轉向原因、角度比較與目前讀值，解釋快→慢偏向法線／慢→快偏離法線。兩角從法線量起，斜射條件與0°例外明示。原小車比喻仍為補充，不把主要原因折疊。
4. 平板／手機內容寬度不超過700px時，為操作畫面下方保留52px讓選項可以正常點選，維持原光學圖比例與光源邊界。檢查0°時第五區光源中央位置也不被遮住。

新增純模型檢查以光路斜率獨立量測入射／折射角、折射定律、拖曳逆算與邊界。瀏覽器覆蓋水／玻璃、0°／小角／35°、主圖與近拍真實光線端點、上下介質與角度角色、說明區塊的位置及常駐／即時更新、三區八種視窗選項可見且不擋器材，並保留動畫、A／B拖曳、圖片競態／重試及整課回歸，共56項（含外層）。第一、二、六區及小測、共用光學、照片原檔保持；沒有新增依賴，維持第四階段，待使用者檢視。
