# 2.3 滿水杯上提保水與逐步排水（2026-10-29）

## 問題與修正

- 使用者指出已完全進水的杯子上提後又像空杯，與操作不符。
- 第一個原因是杯內水圖層從固定的SVG y=130才開始畫，導致高於槽面的水柱漏畫；現在水填色與水紋涵蓋整個杯子，再按實際水面與杯內輪廓裁切。
- 第二個原因是杯口露出時直接套用平衡水面，沒有保留實際水量及排水過程。新增水量狀態與 `advanceCup`，杯口未露出時保留滿水水柱；露出後依時間逐步進氣、排水，不能一幀清空。杯口全露出時畫出回流到槽面的水流。
- 杯口偏上時，低於較低杯緣的水可保留，不強制把杯內水面拉到槽面或清空。濕紙狀態持續，上提不自動改變角度。
- 排水使用便於觀察的示意速率，不是實驗流量；仍省略表面張力、飛濺與三維流場。
- HTML與三份杯子模組同步至 `cup-lab-6`；未新增面板、放大功能或圖上註解。
