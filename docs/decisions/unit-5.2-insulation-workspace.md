# 5.2 第六區同屏觀察工作區

2026-11-06（臺北）。使用者指出第六區瓶體、曲線及控制需上下捲動，先要求示意圖，再明確核可`exec-80ef7270-0d8a-49e2-b39f-add98ccb46cc.png`並要求依圖修改。原圖保存在本輪review的approved-mockup.png，不以此圖代替真正互動。

## 核可安排

- 課文提供「展開同屏觀察」。原活動移到原生dialog中，頂部保留第六區標題、副標及「返回課文」；左側並排兩瓶與傳熱圖例，右側為同時鐘曲線、目前發現與保溫重點。
- 比較模式與共同條件置頂，開始／停續／重來、唯讀進度與狀態集中底部；詳細原理收合，展開成補充閱讀面板。原課文操作前後對話保留，返回即可閱讀。
- 使用同一份DOM與同一活動狀態，不複製瓶體、曲線、控制或計時。展開／返回不改比較條件或進度；Escape及返回鍵關閉，恢復課文位置與入口焦點，背景頁面不可操作。
- 桌機／筆電以1366×768及1280×720為主，另查1440×900及1024×768；主畫面與控制無須捲動。瓶體依場景高度與兩欄寬度等比例縮放，連標註都須在可見範圍內，不靠裁切或縮小正文字體湊高度。
- 低於900px採可閱讀的縱向內容，手機保留上下瓶組、視窗內捲動與底部控制。這不是宣稱320px也能同時顯示所有圖像。

兩組比較、原照片、反射層遮罩、氣體／固體／輻射路徑、定性曲線計算及時間策略保持。進度條只表示既有觀察窗進度，不能拖動，不代表熱量百分比或熱傳停止。前五區與原小測保持，無新套件或服務。仍為第4階段製作／修訂，待實際成果檢視。
