# 2.3 動畫依步驟顯示器材

2026-11-04（臺北時間）。依使用者要求，第三、第四區只有「認識材料」完整呈現材料；操作動畫收起當步尚未使用或已用完的物品。本決策取代前次將待用器材放在桌面後側的規則，前次圖集裁切修正繼續保留。

- 製氧準備集氣位置時，顯示水槽、集氣瓶及當下使用的玻璃片／導管；加入二氧化錳時聚焦錐形瓶、粉末與藥匙。加入大理石時只呈現錐形瓶、石頭及正在使用的鑷子。
- 組裝後保留反應及導氣裝置，避免連接中的器材無故消失；倒液試藥瓶、空碟及鑷子用完後收起。玻璃片於使用時取出，封存後留在瓶口。
- 收起只控制呈現與可點選範圍，不清除水、固體、氣體或已完成的操作。返回材料介紹仍能查看完整清單。
- 主圖調整取景以聚焦當步動作，畫面高度維持；手機近景及十三個無 JavaScript 代表畫面同步。固定玻璃管形狀、橡皮管長度、液封、反應與播放時間維持。
- 此規則只適用教學動畫；第六區學生自行擺放的材料不會自動收起。

驗證包含逐步器材與點選範圍、用完收起與封存再取用、完整材料介紹、組裝管長與液封、桌機／手機／無 JavaScript、器材介紹互動、完整製氣集氣及小測回歸。
