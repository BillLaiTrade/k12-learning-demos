# 第一區連續反射亮光

每道光以同一條完整折線承載短尾跡亮光。接觸前後不等待、不切換兩條線，也沒有固定接觸閃光；三層亮光在反射點自然折轉，兩側六道光同步。原本的方向示意淡化保留，完成後恢復完整圖解；移除三階段提示。原生動畫沒有逐幀JS改寫或SVG濾鏡。

一般與減少動態都只有手動播放一次，時間分別為3400／4200毫秒；減少動態的光暈較淡。保留重播、原生觸控，Esc可停止；偏好變更與離頁會結束舊播放。延遲的偏好事件只在模式不符時取消，不誤取消已按最新模式開始的新播放。

最終第一區針對性回歸9項（含外層）全部通過，命令：

```sh
CHROMIUM_PATH=/usr/bin/chromium node --test \
 --test-skip-pattern='實際像素|自由拖曳保留|恢復上下|回到正面重設|自由實驗常駐' \
 tests/unit-4.2-reflection-stage.test.cjs
```

`checks.json`在42%、46%、50%、54%記錄實際dash位置，證明接觸前後每個相同時間間隔沿路徑前進距離一致，同一段亮光同時跨在表面兩側。25%與35%的圖像像素不同，排除只切換整條線。一般／減少動態皆驗證完成、重播、停止；真實時間播放18個有效SVG效果共用起點，幾何／樣式的逐幀DOM改寫為0。

其他檢查包括相同照射條件、四種開關、反射幾何、六寬度、手機原生拖曳後再播放及無JS／無WebGL備援。主實驗、光學模型、靜態示意與第二區以後未改動，見`preservation.json`。圖像為實際SVG／頁面擷取，不是生成動畫。
