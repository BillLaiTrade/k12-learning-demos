# 3.4 第五區：播放完成後回到乾淨房間

2026-11-01（臺北時間）。使用者提供兩張結尾畫面，明確要求「結尾的畫面應該是乾淨的而不是有一堆波」。此指示取代先前完成後保留代表波前的安排；對應全課盤點F10。F06測點疊字尚未核可。

原完成狀態把畫面跳回1.05秒，切材料又改成該時刻的暫停狀態，因此結束後會持續出現多條反射波。改為自然完成時清空波線，時間保持6秒；房間、角色與材料選擇保留。完成後加入或移除材料仍為完成狀態、波線維持空白、暫停鍵停用，不重啟音源；只有明確按拍手／語音才重新發聲。

播放中仍可暫停，同一時刻切換材料比較波線深淺與粗細；沒有改波前模型、幾何、材料係數、6秒觀察時長、80倍視覺示意或音檔。更新完成狀態及收合說明，移除保留結尾代表畫面的過時描述；其他文案與布局保持。
