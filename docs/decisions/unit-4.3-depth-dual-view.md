# 第六區：同步側面光路與第一人稱視野

2026-11-03。使用者先要求檢視一至五區風格、分析第六區，再核可雙視角示意圖並授權製作。

## 教學定位

第六區是折射的生活應用教學，承接第四區水到空氣偏離法線，新增「入眼方向與視位置」的連結。初始即提供可見硬幣、完整光路、反向延長線與核心結論；無需預測作答或開始播放即可閱讀比較。互動用於加深理解，唯一理解檢核仍是結尾第七區。

## 共用狀態與兩個視角

- 左側為水槽剖面：固定槽底硬幣、可移動觀看位置、實際折射光與小瞳孔附近的反向延長線。金色箭頭由硬幣指向眼睛；橘色虛線是輔助線，沒有傳播箭頭。遮擋時光路止於槽壁／槽緣，不虛構抵達眼睛的光。
- 右側為同一觀看位置的針孔視野，以Canvas逐像素追跡空氣→水的反向光線，求取槽底、硬幣或槽壁交點。這是繪圖算法，不把眼睛當成實際光源；右圖沒有第二顆眼睛、虛像硬幣或光路疊圖。
- 兩邊共用水深40–100公分、觀看位置距前側40–170公分；預設70公分、距前側80公分。觀看目標區域固定，不自動追蹤硬幣。調水位不移動槽底硬幣；移動觀看位置才改變相機位置。
- 右圖硬幣的像素由真正的幾何交點產生，不以某個滑桿閾值切換顯示。槽口及2.1公分槽緣、前側不透光槽壁造成實際遮擋；例如同在距前側130公分處，水深40公分看不到，100公分可見。模型假設在展開說明交代，不模擬透過槽壁的另一組折射。
- 左圖局部視位置來自兩條小瞳孔光線的交點，不宣稱所有大角度光線有同一虛像，也不給出視深一律為實深3/4的公式。硬幣尺寸與材質為辨識示意，不作尺寸量測。

## 操作與畫面

單一共用控制列提供水位、觀看位置、重播光路與重設；眼睛可拖曳或以方向鍵／Home／End操作，觸控範圍至少44px。可隱藏光路與輔助線，右側視野不受影響。不新增放大、暫停或強制作答。

重播是手動慢動作，由硬幣沿折射路徑前進，再顯示判斷視位置的輔助線；右側維持目前物理視野。離開本區或頁面隱藏時保留進度，返回繼續，完成即停止動畫迴圈。減少動態偏好時直接保留完整圖解。

桌面左右並排、窄內容欄上下排列，不縮小整張桌面截圖。左圖文字至少13.5px；控制、核心結論與原因解說保持HTML可讀。Canvas備有文字描述，無JavaScript仍可讀到概念。材質圖載入失敗提供簡化材質及重試，幾何互動仍可用。

沿用既有oblique-entry-water照片的木紋、水色取樣；硬幣與槽體由SVG／Canvas繪製。核可示意圖僅留作版面對照，沒有直接貼成互動背景。無外部套件、服務或個資。

模型、控制器及樣式分別為depth-model.mjs、depth-observer.mjs、depth-lab.mjs、depth-lab.css；移除lesson.mjs的舊視深處理，前五區與小測控制保持。檢查及畫面見docs/reviews/unit-4.3-depth-dual/。維持第四階段，待使用者檢視，非最終驗收。
