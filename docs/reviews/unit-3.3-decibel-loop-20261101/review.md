# 第七區放大圖片與持續循環

2026-11-01，依使用者要求將圖片優先，桌機圖片／介紹欄由 1.2:1 改為 2.3:1；圖高由至少 285px 增至 360px（中型螢幕 310px）。標題上限約 23px，分貝主數字上限 48px；手機圖比例由 2:1 改為 16:9，分貝數字降至 37.6px。原始四張場景圖與十二份 WAV 未修改。

錄音改為原生 AudioBufferSourceNode.loop，在同一來源持續循環；沿用原成品淡入淡出邊界及音量階梯，不以 onended 新建來源。圖片／播放鍵仍可重播，播放中換情境持續循環，按停止才結束；離區、隱藏分頁、其他區或小測音源活動時仍停止，停止後切情境不自動起音。

本輪執行 unit-3.3-decibel-audio、unit-3.3-decibel、unit-3.3 三檔，涵蓋十二來源原始 PCM／雜湊／音量、全部來源 loop、真實音訊時鐘超過耳語兩個完整週期後仍播放且未建立新來源、停止／重播／換場景、取消／重試／離區／隱藏／跨音源、手機觸控、六種寬度的圖像比重與緊湊數字，以及情境帶與整頁小測回歸。18 項全部通過，0 失敗／略過，結果見 tests.log，畫面見 desktop.png／mobile.png。

第一輪固定牆鐘等待在音訊時鐘尚未跨過兩週期時提早斷言，已改為等待 AudioContext.currentTime 實際前進後再核對，沒有調整播放功能來配合測試。公開部署及公開操作結果另存課程 repo 的本輪公開確認紀錄。
