# 4.3 全面再檢查：11項核可決策

2026-11-05（臺北）。本輪重新盤點六區與唯一四層小測，使用者逐項選擇，11項皆採A；全部決定後統一修改、總測試及檢視。與前輪18項分開記錄。

| 項目 | 核可做法 |
| --- | --- |
| 1 | 統一兩圖與提示的可見性判定，保留部分看見，避免預覽與精細畫面改變判定 |
| 2 | 按發射後先將實驗圖與必要控制帶回可見範圍，再開始播放 |
| 3 | 只有順序真正改變才清除判定；選取卡片、放回原位或按到移動邊界，保留原結果 |
| 4 | 補充小車自動離屏或切頁暫停後返回續播；主動收合保持停止，重新展開不自動續播 |
| 5 | 保留排序，重播期間暫藏作答回饋，光路與角度完整顯示後恢復；期間若排序改變則清除舊回饋 |
| 6 | 小測就近補上同一束光斜射與各層介面互相平行的比較條件；作答前不直接揭示角度與光速規則，規則留於作答回饋 |
| 7 | 第四區以斜射且發生折射時限定偏離法線的結論，保留0度不偏折說明，不增加全反射內容 |
| 8 | 第五區保留紅藍雙光，在開關或圖例附近短註顏色僅用來區分前進方向 |
| 9 | 第三四區保留固定小車原理解釋，就近標明固定斜射類比與上圖設定獨立，不讓小車同步主圖參數 |
| 10 | 第二至四區改用小車兩輪同時或先後變速的白話類比，不額外引入波前；保留小車只是類比、光不是受到摩擦的說明 |
| 11 | 第六區從硬幣沒動，加水後還會被槽壁擋住嗎切入，將觀察接回看似與實際位置差別，改寫現有短對話與結論，不增加長段落 |

維持桌電／筆電正式範圍，不改手機專用排版。保留六區、唯一四層小測、首題與換題隨機、代表折射率、角度範圍、約兩秒加放水、固定觀看方向／倍率、原PNG與共用人物素材。不增加全反射內容、額外測驗或長說明區。

第六區可見性以真實硬幣半徑和連續槽緣交點判斷；剛露出的實際光線用同一反向追跡器取樣，並非另外繪製硬幣。所有可見文字與左圖使用同一幾何狀態。

四步：同步基準／決策 → 狀態與判定修正 → 短提示與對話 → 模型、互動、桌電／筆電、公開檢查。維持第四階段，非整單元外審或最終核可。
