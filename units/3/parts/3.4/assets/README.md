## 模型與播放

第一區已依核可示意改為木製反射板與實體器材場景，見下方最新規格。第2–3區維持牆面反射、340m/s；第4區水中1500m/s。聲速是題給近似，非實測。第二、三區按模型秒數播放，第四區動畫放慢8倍，提示音配合各區動畫，不是實際傳播錄音。公式限近似同位置發射／接收、固定目標、往返同介質；聲納為垂直探頭到海底的距離。

第5區相同650Hz短合成音比較：單次回聲延遲0.65秒、相對增益0.55；密集反射採延遲 `[0,.07,.13,.21,.31,.44,.59,.77,.98,1.22]` 秒，直接聲增益1，其餘為 `0.62*exp(-i*0.22)`。這是教學用的接收事件／路徑示意，不是房間聲學實測。

第6區用同一語音與相同延遲，比較處理前／後；吸音處理後只有反射增益改為 `0.62*exp(-i*0.65)`，直接聲不變。不用整體降低音量冒充吸音。圖中吸音區域對應上下兩條示意反射路徑的接觸面；材料不代表產品或真實係數。兩區圖表表示短音的到達紀錄，非整段語音的振幅波形。

第一至三區須點喇叭或按鈕後才播放聲音，已依最新核可呈現移除開關；其餘區聲音仍預設關閉。Web Audio採固定輸出，第一區保留無聲回報修正後的強度，聲音大小由使用者裝置調整，詳見下方最新紀錄，沒有啟用麥克風。跨區播放先暫停舊區，改條件或重來停止該區音效；分頁隱藏／離頁停止，返回不自動播放。減少動態偏好仍允許學生主動播放科學示意，可隨時暫停；沒有自動背景動畫。

聲納距離收合會同時隱藏圖上距離、答案及帶數值的深度控制；可由往返時間推得結果。顯示答案或取消收合即可再讀距離。
