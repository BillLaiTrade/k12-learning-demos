# 顯微鏡操作與畫面整合

將步驟切換與當前說明移入 `.micro-workspace`，主圖及觀看窗縮整為可同時檢視的高度，原光學計算及互動狀態不變。

- 顯微鏡既有四項瀏覽器測試通過，涵蓋立體／備用顯示、步驟、光路、物點偏好與重設。
- 實際檢查 1440×900、1366×768、1024×768、760×900、390×844、320×844，三步控制、工具、模型、觀看窗、狀態皆在同一視窗外框內；開啟光路時仍低於裝置視窗高度，無水平溢出或文字裁切。
- 桌面與手機實際查看截圖，控制與成像畫面可同時看到。截圖時停用平滑捲動並固定觀察框位置，排除擷取過程中的暫時裁切；另以整個手機可視畫面確認底部狀態可見。
