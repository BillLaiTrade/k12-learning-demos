# 桌面與背景直接接收暫停／續播點擊

2026-11-01，使用者回報字幕能控制，但主圖桌面／背景沒有反應。本輪針對第三區擺好集氣位置重現與強化背景命中，第四區同步採相同行為。

舊背景點擊目標為SVG共用use實例，字幕則是普通HTML。純顯示use改為不攔截指標，主圖及手機近景各加入透明背景命中區，放在真正器材熱區下方。背景自身直接呼叫既有手勢檢查與播放切換，並停止向外重複冒泡，確保一次點選只切換一次。保留選字、拖曳、捲動、右鍵排除與器材介紹優先；材料預覽／已完成仍不由背景自行起播。

初輪僅設定裝飾圖層不接收事件，手機仍有失敗。診斷顯示elementFromPoint命中背景，但原生觸控事件會被調整到附近導管按鈕；加入背景自身的直接點擊事件後，主圖暫停與近景續播都確實命中background-hit，不再彈出器材介紹。before-routing、after-decorative-routing、mobile-routing保存對應事件證據，未將初輪失敗稱為通過。

新增三個準備時點、四個桌面／房間背景位置的原生滑鼠檢查：播放中點選暫停、等待不前進、再點原進度續播且不開器材視窗。手機主圖背景測點也由角落移至真正的房間背景。最終canvas-tap、equipment與co2三套37項（含外層）全部通過，失敗／取消／跳過均0，包含觸控與近景、捲動、器材優先、像素暫停及第四區。見local-tests.tap。兩份樣式與兩個主控制器／器材模組快取版本已更新。
