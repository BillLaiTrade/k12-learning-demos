# 第六區固定視野角與縮放倍率

2026-11-04。使用者指出眼睛沿導軌遠離時，箱子後緣反而像靠近。確認原因為前輪依槽口重新取景：垂直視野角隨觀看位置從約47°縮為18°，放大抵銷距離感。使用者核可改為固定視角與縮放倍率。

右圖採固定29°向下方向、56°垂直視野角；拖曳時只平移相機原點，仍與左圖眼睛位置相同。視野不隨觀看位置、水位或硬幣可見狀態改變，沒有額外自動變焦、跟隨目標或CSS縮放。56°保留最近位置可見的硬幣周緣；遠離時槽緣投影與硬幣自然縮小，畫面留出的桌面隨距離增加。

這取代前輪「依槽口遠近緣填滿畫面」的做法；不修改箱體／硬幣尺寸、折射率、遮擋、世界座標或觀看位置範圍。左側導軌、相對位置、工具列、空槽起始、加水示範、直接拖曳、鍵盤、原生觸控、離屏續播與材質保持。
