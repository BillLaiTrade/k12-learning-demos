# 2.3 空氣：初稿互動與素材

- `air-model.mjs`：校正後氣體體積、水位／壓差／管位、共用實驗狀態、乾濕空氣比例及獨立小測判定；杯子模型由此轉出 `cup-lab-model.mjs`。內部水面高於槽面時，不把壓力差當成零；對齊後才保存 79.0 mL。
- `air.js`：以 SVG 繪製器材及氣體示意，處理共用播放時鐘、暫停／回看、記錄、對照、重設與各區操作。第02–04區共用同一資料來源，小測150→120 mL為獨立示例。
- `air.css`：沿用展示站綠色、紙色、對話頭像及垂直學習路線。人物使用根目錄 `shared-assets/characters/dialogue-character-avatars.png`，未新增副本。
- 器材圖由程式繪製；圖中氣體透明，圖表顏色只用於分類。幾何與數據是教學模型，不是真實實驗紀錄或實物製造圖。
- `air-story-opening.webp`：2026-10-29 依使用者要求補上的開場情境插圖。以共用人物頭像及 1.1 核可插圖為造型與畫風參考，使用圖像生成工具製作，轉存為 WebP；小葵為棕髮雙丸子頭、米白連帽上衣與深色背帶，阿公為白髮、圓框眼鏡、無鬍子及白袍。場景是花圃旁拿起空透明杯、準備使用水槽觀察，屬故事插圖，不是真實實驗照片。原始生成圖保留在工作區 `generated_images/`，頁面只載入本地 WebP，不依賴外站圖片。
- 頁首依 2.2 置於獨立 `header.masthead`，標題與圖片下方才開始「探索路線＋教材」兩欄。頁首及教材共用最大1160px的容器，文字／圖片為 `0.9fr／1.1fr`、28px欄距，680px以下改為上下排列。圖片長寬比16:9，手機圖框與容器齊寬；探索路線在手機亦位於完整開場之後。
- 結尾 `#s8` 參照 1.1、1.2 的獨立「單元小測」版型，左側導覽也直接標示「單元小測」。維持一份整合檢核及原有資料判定，不新增第二個測驗。
- 依據：`BillLaiTrade/k12` 的 `docs/product/units/4-matter-separation-and-aqueous-solutions/4.3-teaching-and-interaction-spec.md`。來源為 NOAA JetStream 空氣組成、RSC／Nuffield 鋼絲絨耗氧及 RSC 氧氣木條觀察教案，正式頁尾提供連結。

## 第一區「紙團潛水」改版

- 依使用者核可的版面示意圖製作，對照圖與實作畫面保留在 `docs/reviews/unit-2.3-cup-lab/`。
- `cup-lab-model.mjs`：杯高10、槽內水深15.2的剖面示意；外側水面為 y=0。旋轉後以水平線裁切杯內多邊形，計算空氣空間與水面；氣體連到杯口較高處時才逸出，逸出量不因回正而補回。紙團是否沾水依其位置與水面相交決定，濕紙狀態持續至換乾紙。數值是內部幾何單位，不向學生宣稱真實量測。
- `cup-lab-view.mjs`：器材、水槽、透明杯、紙團、圖上標示、杯口放大及兩次觀察共用同一套繪圖與幾何。氣泡自杯口上浮，杯內水面維持水平。
- `cup-lab.mjs`／`cup-lab.css`：垂直入水、傾斜、暫停／繼續、局部放大、拖曳／鍵盤／自由控制、重做及歷史觀察回看。比較區在學生完成觀察後展開；回看舊狀態不改寫目前紙團是否沾濕。
- `cup-water-caustics.webp`：圖像生成工具製作的水中光紋材質，用於器材插圖；不是實測照片或獨立反應影片。`cup-paper.webp`：依核可示意圖生成的透明背景白紙團素材，濕紙色澤由同一素材加濕潤色調呈現。兩個生成原檔保留在工作區，頁面只載入本地WebP。
- 教學模型假設：側面剖視、杯子由外力固定、近似等溫，忽略表面張力、氣體溶解及飛濺；空氣不染色，氣泡不代表可計數的氣體比例。減少動態模式以相同狀態和氣泡停格呈現。
