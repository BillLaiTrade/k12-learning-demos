# 4.5：真正的主圖放大鏡與選中色旁的 RGB 編輯

2026-11-05（臺北）。依使用者本輪累計四項核可修訂，沿用看像素／改同色像素／看整幅圖。

## 主圖與選中格

主圖新增真正有圓形鏡框、鏡柄的局部放大鏡。Canvas讀取同一圖片的附近3×3像素，中央金框為選中格；原圖鏡面讀原值，結果圖鏡面讀處理後值。虛線接回原圖的取樣框，鏡身置於較遠角落避免擋住取樣點，ResizeObserver同步尺寸；鏡面透傳指標，不攔住原圖點選。可點主圖或用方向鍵微調；邊緣超出原圖留空，鏡框及鏡柄不裁切。無JS時以同資料的九個色塊提供靜態鏡面。

右側取消九宮格與鄰格按鈕，只呈現一個較大的選中格合成色。其下是原本RGB組成；第二／三步在同一張面板下方直接編輯，避免捲回頁面上方找開關。第一步附「調整這個顏色」按鈕，直接帶目前選取進第二步。切模式不偷偷換選白雲。

## 同色範圍一致

兩圖用相同金色輪廓、同一資料及固定說明位置標同色範圍，可統一切換顯示；關掉標示不改RGB數值。保持原圖RGB完全相同分組，不模糊合併色名或不同陰影。海面快速點重新取樣為RGB(0,96,240)，共有37格，取代原本只有4格的代表點；白色仍352格。圖片與原始RGB陣列保持不變，只有快速選點的metadata改動，建置腳本可重建。

## RGB 控制與語意

右側先明示調整對象及影響幾格，再呈現即時單色及原始RGB，緊接「在這裡調整RGB」。紅／綠／藍各有0～255整數輸入與0關閉／128中／255最亮按鈕；沒有配目標色、猜配方或填圖任務。使用者可直接觀察變色。非法輸入不套用，離開欄位回最後有效值。

第二步數值是新顏色的RGB，包含可以增加原本為0的通道；整組直接改成新RGB，其餘像素原樣。換選不同原色就從新組原值開始，只換到同色格保留調整，避免取樣已變色畫面後併錯群組。

第三步數值是整圖各通道強度，0關閉、255保留原強度，每個像素數值以原值×控制值÷255後取整數。面板明確標「RGB強度」及意義，並另顯選中像素的實際目前RGB。這是圖片通道比例示意，不將sRGB數字視為光功率。兩種模式各自保留、還原從原圖算，不累積誤差。第一步始終讀原圖，刷新回第一步白雲。

14項模型、24項活動檢查（含外層）驗證實際鏡面像素、同色與整圖數值、原值保留／還原、兩圖輪廓、輸入邊界、七視窗三模式、觸控／鍵盤、獨立載入／失敗重載／無JS及第一小測不受影響。初輪極窄尺寸鏡面覆蓋取樣點，已依尺寸縮小鏡身並為鏡柄留白，最終檢查通過。五學習區、第一小測、圖片及共用素材不改，沒有新增依賴。上輪純開關與右側九宮格為歷史，由本節取代。
