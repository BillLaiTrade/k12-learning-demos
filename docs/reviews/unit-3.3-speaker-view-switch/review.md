# 3.3第二區：正／側面切換與直接振幅動畫

## 製作

- 共用「正面／側面」原生按鈕，同步切換左右。預設正面，每個比較區一次只顯示一個喇叭視圖；切換不重播、不中斷聲音、不清除波形、不重設頻率，鍵盤與觸控均可操作。
- 正面保留既有木殼圖片及獨立振膜動畫。側面重繪為可動畫SVG：木紋箱體、支架、磁鐵固定；音圈、紙盆、防塵帽同相位平移，懸邊連接固定支架與動態膜緣。使用共同暖色桌面背景，材質由向量漸層與木紋呈現。
- 以同一膜緣點對照平衡0及兩個極限位置。向內−A／向外+A虛線輪廓與兩段等長A箭頭直接相連；移除獨立圓點、抽象數值及原放大窗，不將峰到峰2A當作振幅。A是共同示意尺度，非公尺或實測位移。
- 沿用2秒播放對應10毫秒振動紀錄的200倍放慢顯示。200Hz畫面每秒1次、400Hz每秒2次、800Hz每秒4次；聲音維持實際200～800Hz與既有14倍共同增益。兩側放大位移±44SVG單位，頻率不改振幅。只播放被選的一側，左右聲音不重疊；停止歸位、調頻停止及離開區塊停止沿用。
- 桌機／筆電保留左右比較；600px以下上下排列同尺度圖，避免側面文字擠在過窄的兩欄。保留七區全寬卡片、原知識對話、時間波形及小測，不重加原先刪除的三行操作說明。
