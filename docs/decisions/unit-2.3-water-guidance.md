# 2.3 錐形瓶加清水的引導語氣

2026-11-04（臺北時間）。使用者明確指出：雖然加水後再加稀鹽酸仍可能產氣，加清水仍是本次實驗的錯誤步驟；提示不可鼓勵學生以追加稀鹽酸接續這個做法。

依此移除「若已有大理石，可裝好器材後加入稀鹽酸，不必只因加水就清空。」。錐形瓶已有清水時，保留「單加清水不會產生二氧化碳、不能代替稀鹽酸、會稀釋酸」的提醒。倒水當下與反應中的同類「不必清空」說法也移除，改為指向清水用於準備水槽與集氣瓶。

本輪修訂取代舊決策中鼓勵沿用錐形瓶內清水繼續補酸的提示語氣。水槽中的乾淨清水是否可沿用仍依既有狀態判斷。只修改文案，容器仍接受錯誤操作，沒有改變實際產氣或成果判定。
