# 5.1 第三學習區塊：雙刻度溫度計核對

2026-10-28：初版依使用者核可的 A 方案與示意圖製作。使用者再核可三項修訂：補上一般公式、改成降溫／升溫及數字搭配單位的控制、量程延伸至 −40°C，強調 −40°C＝−40°F。

## 最新外觀與功能

| 項目 | 實作及核對 |
| --- | --- |
| 版型與人物 | 維持前後各兩句對話、桌機左溫度計／右換算操作，手機上下排列；角色使用專案共用頭像。 |
| 量程與刻度 | 攝氏 −40–100°C 共 141 條每度刻線，華氏 −40–212°F 共 253 條。每 1°C 間距為每 1°F 的 1.8 倍。−40 在兩側同高；0°C／32°F 與 100°C／212°F 也同高。華氏重新選取標數位置，避免 32 與 40 過近。 |
| 公式 | 在大字讀數上方加入一般公式，下方保留代入計算。依已套用輸入的單位顯示攝氏→華氏或反向通式。 |
| 按鈕 | 點按每次 1°C；長按連續改變。實際滑鼠與觸控檢查放開後不繼續變動。捕獲指標後拖出按鈕放開也會停止；取消、失去捕獲、視窗失焦及頁面隱藏停止計時器。到界限停用對應按鈕。 |
| 數字與單位 | 單一外框內左側輸入數字、右側選攝氏／華氏，旁邊為設定溫度按鈕；Enter 亦能送出。選單改變不轉換正在輸入的數字，套用時才依所選單位解讀。空白或超出量程顯示短提示，原液面保持不變。 |
| 精度 | 內部保留換算值，讀數顯示至一位小數，需四捨五入時使用 ≈。例如 100°F 對應約 37.8°C；反向代入式同步。 |
| 重要溫度 | 新增 −40° 同值點捷徑，另保留冰點、室內示例、體溫參考及沸點，共五個。手機以三欄排列，複合輸入框和設定按鈕分行。 |
