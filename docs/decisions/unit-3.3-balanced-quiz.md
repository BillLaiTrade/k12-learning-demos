# 3.3 小測版面平衡與控制分組

2026-11-03，使用者核可三點優化：平衡波形與右側控制高度、整合音色切換、簡化步驟標題裝飾。

- 音色切換移入控制區，依序為音色、頻率與振幅。桌面與波形並排；手機保留波形後再調整的閱讀順序。
- 桌面波形利用既有控制區高度伸展，時間軸接近控制卡底緣；保留原10毫秒時間窗、相對振幅、真實訊號與波形比例規則。
- 移除三步驟標題底色與內距，保留淡綠編號與深綠粗體；控制卡淡綠標頭及3.2外框與小測標頭樣式保持。
- 三區結構、175px等寬靠右主按鈕、第一區換題、比較結果、手機換行及音訊模型保持。版面HTML移動音色控制並更新CSS版本。

沿用小測專項與整頁檢查，涵蓋桌面／手機、配對、音訊／波形、換題、重試、結果與觸控。樣式比較保留3.2框架及標題字級／色彩，依本次核可移除步驟標題底色比對。

公開檢查另揭露既有圖片初始化競態：小測先於第五區圖片初始化時，複製到空容器。小測現會在來源尚空時觀察圖片載入，補上當前題目圖像；換題時取消前一筆觀察，避免舊題圖片覆蓋。新增延遲圖片模組、期間換題、載入後核對當前器材及未自動播放的回歸；波形與音訊模型保持。更新控制器及入口查詢版本。
