# 4.4 透鏡如何形成影像？

依使用者核可的十區腳本製作：九個互動教學區與一個結尾小測。製作前實際分析 1.1、1.2、2.1、2.2 的教學邏輯、器材細節、版面及標題連動，分析與完成檢查記在 [review.md](../../../../docs/reviews/unit-4.4-basic-20261101/review.md)。

## 結構與模型

2026-11-02 第一區已依核可示意改為可旋轉、縮放的立體針孔實驗台。本輪接續使用者四項回饋：圖卡、孔板、屏幕都可直接沿軌拖曳，背景調亮，小孔增加雙面亮邊與定位標籤，輔助光路改為畫面內醒目按鈕。沒有距離拉霸；三件器材按鈕均支援選取與方向鍵／Home／End。各器材獨立移動，鄰近底座及軌道端點限制移動範圍，像與光路依三者相對距離計算。依使用者最新指示移除「重設位置」及「重設視角」，工具列保留光路、孔口近看與屏幕正面觀察。

輔助光路預設關閉，可分別追蹤上下端；「近看穿孔光路」觀看同一孔板並開啟光路，使用沿相同直線細分的立體輔助線，避免近看時遠端在相機後方而看不清入射段；「正面看屏幕」僅改變相機。孔口、光路寬度、柔化及亮度為教學示意。背景與器材較原版明亮，仍維持發光圖卡亮於投影。像超出接收面時依實際面積裁切並提示，不把大像自動縮小。第2–10區HTML逐段雜湊保持相同。

- `assets/pinhole-optics.mjs`：三維直線投影、三件器材動態位置限制及定性亮度。
- `assets/pinhole-3d.mjs`、`pinhole-3d.css`：第一區獨立渲染與操作，直接引用4.1既有Three.js，不新增套件；孔板具有真實開孔，接收面與像共用同一片屏幕。

- `index.html`：可閱讀的逐區內容、共用人物對話、完整提問導覽、九區閱讀位置及獨立小測。
- `assets/lesson.css`：沿用 4.3／2.2 的頁面殼層與卡頭尺寸，再加入本課的工作台、光路、控制與觀察窗；未修改共用或其他單元樣式。
- `assets/optics.mjs`：小孔相似三角形、理想薄透鏡光路、眼睛及兩段眼鏡作用、兩透鏡顯微鏡的純計算。公式用於保持模型正確，學生不必計算。
- `assets/lesson.mjs`：由計算結果更新光路、投影模糊、像的特徵、物距紀錄、調節與矯正，以及導覽和小測。第二至九區保留各自重設；第一區已移除重設按鈕。
- `assets/lens-studio-cover.webp`：本課生成的情境插圖，沿用共用人物設定；不作光學幾何證據。共用頭像仍直接引用 `shared-assets/characters`。

同一上下不對稱圖案貫穿 01–06。屏幕不跟隨物體自動對焦，只有清楚成像才可留比較紀錄。焦點邊界不繪製無限值；虛像使用有圖例的輔助延長線，眼睛觀察與屏幕比較分開。放大鏡與凹透鏡的觀察光束實際通過圖中眼睛的瞳孔範圍。

眼睛以等效透鏡表示角膜和水晶體的總作用，固定視網膜，分別追蹤兩個物點；各點各自成像而非整物匯成單點。眼鏡用兩段傳播與折射計算；顯微鏡物鏡焦距60、物距80，形成像距240的中間像，目鏡位於300且焦距100，中間像在目鏡焦距內。距離是製作者的模型參數，不作學生必背數值。

## 執行檢查

在展示庫根目錄執行，沿用既有 Node、Playwright、Chromium，不新增依賴：

```sh
node tests/unit-4.4-optics.test.mjs
node tests/unit-4.4-pinhole-optics.test.mjs
CHROMIUM_PATH=/usr/bin/chromium node tests/unit-4.4-pinhole-3d.test.cjs
CHROMIUM_PATH=/usr/bin/chromium node tests/unit-4.4.test.cjs
```

完整四檔共52項：透鏡模型8、針孔模型10、立體專項11、整課23（瀏覽器含主項）。前輪四項回饋執行受影響的後三檔共44項；透鏡純模型未改，不重跑。涵蓋實際像素上下對應、移動後光路與接收面、三件器材滑鼠／鍵盤／原生觸控拖曳及界限、孔口近看、畫面內光路按鈕、旋轉、縮放、取消手勢、七種寬度、十區導覽及2.2計算樣式比較。31與47項為改版前兩輪的歷史總數。

`PINHOLE_URL`可指定公開4.4網址（不帶hash），`PINHOLE_CAPTURE_DIR`另存第一區證據。立體專項以測試期間模組攔截讀取實際場景；正式模組不暴露測試API。光學模型用獨立幾何關係核對，沒有把畫面狀態文字當成成像證據。瀏覽器使用SwiftShader驗WebGL；不代表Safari實機。詳見[本輪紀錄](../../../../docs/reviews/unit-4.4-pinhole-3d-20261102/review.md)。

`LENS_URL` 可指定公開課程完整網址（不帶hash），`LENS_CAPTURE_DIR` 指定證據目錄。公開測試使用環境提供的 HTTPS 代理；需允許本機 socket 與 Chromium 程序。`#s1`–`#s10` 為十區錨點，`#unit-quiz` 為小測入口別名。

七寬度包括1440、1366、1024、820、760、390、320。窄螢幕完整光路可以在各自圖框左右捲動，不讓頁面本身橫向溢出。觸控由Chromium模擬，不宣稱Safari實機或外部驗收。

本機檢查已全數通過；公開發布與重驗結果另見檢查紀錄。仍為第四階段基本版製作／修訂，沒有新增完整單元外部驗收或最終核可。

2026-11-02接續移除第一區兩個重設按鈕，改跑立體11與整課23共34項瀏覽器檢查；模型未改。各測試情境以重新載入建立初始狀態，不新增產品重設入口。
