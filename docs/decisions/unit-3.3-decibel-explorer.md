# 3.3第七區採十二情境分貝探索帶

2026-10-31。使用者後續核可「上方一張大場景＋參考數字與介紹，下方可點選滑動的分貝情境帶」示意圖，要求涵蓋更多情境並製作精美圖片。此核可取代unit-3.3-static-decibel.md的三例靜態安排。

以同一OSHA Figure3的20～130dBA、每10dBA一例共十二例建立情境帶；不將各來源的條件混合成假實驗。四個原圖sheet各三張橫向插圖，由SVG視窗及clipPath切換。保留共用小葵／阿公頭像、2.1全寬卡片與兩則分貝知識框；不加播放或麥克風。

情境帶整數讀值用最近參考切換，游標73dBA時上方仍是約70dBA的教室情境。所選讀值、來源典型值與現場實測明確區分；不是固定場所聲級。四個有距離的來源條件顯示換算約值，其他例不虛構距離。來源、生成資訊與畫面見docs/reviews/unit-3.3-decibel-explorer/。

滑鼠與觸控支援點選和拖動，鍵盤有方向鍵／Home／End／Page及Shift細調。一次只呈現一張大圖；圖片解碼失敗不留錯誤配圖，重新選取可重試，慢載完成不覆蓋後來選擇。第一至六區模型及唯一單元小測保持。
