# 5.2 第四區：讓學生追蹤流體本身

2026-11-05。使用者要求先統一5.1／5.2格式，再推進5.2製作。沿用已核可六區順序及水／空氣對照，不新增教學範圍；前三區已有互動，本輪從第四區接續精修。

- 開場承接鍋底加熱與水上層變熱的日常疑問；阿公以水會移動回應，不念介面操作指令。
- 將原「同一方框只換底色」分成水槽與房間剖面，分別顯示底部加熱器、暖氣機。流線是流體路徑示意，小箭頭跟隨流動；暖冷色只是相對狀態，不是兩種固定身分的粒子或數字測溫。
- 不將整個觀察當成CFD：12個圓點沿定性路線循環，顏色隨路線位置變化，沒有聲稱量測流速、溫度或固定流路。維持下方受熱／向周圍散熱、室溫附近條件。
- 提示鄰近操作；同一時鐘帶動動畫與逐步觀察。完整一圈後呈現結尾對話，再銜接太陽與地球間的輻射疑問；不預先說「熱只往上跑」。暫停凍結示意，重來保留媒介、清除發現；換媒介則停止並清回起點。
- 新增獨立第四區腳本與樣式；其餘五區與小測HTML保留，從共用腳本刪除的只有舊對流程式。既有輻射／保溫／小測同時檢查，不因拆分互相控制。
