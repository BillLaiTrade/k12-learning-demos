# 4.3 每次載入隨機首題檢查

2026-11-05（臺北時間）。既有小單元局部修訂，依使用者要求讓四種介質每次載入隨機。範圍見[決策](../../decisions/unit-4.3-random-first-question.md)。基準為9c2668f0，維持第四階段製作／修訂。

## 修改與教學意義

原本首題固定為甲、丙、丁、乙由快到慢，40度入射，只有後續換題才洗牌。現在首次載入即從24種介質排列洗牌抽題，也隨機選36／40度；重播不變題，換題抽下一題。同輪24種排序不重複、跨輪不連續重複。重新載入獨立抽樣，未加入個人識別或持久儲存。

材質與代表折射率綁定，四筆角度、光路、正確排序及錯誤提示由當題模型計算。六個教學區、所有原圖片及材料代表值保持，見preservation.json。頁面與控制器的模組快取版本一併更新。
