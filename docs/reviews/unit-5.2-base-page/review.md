# 5.2 整頁基礎初稿

## 使用者指示

先建立公開學習頁，格式與排版依 5.1：開場敘事、側邊完整題目導覽、六區編號／標題／摘要、操作前後真實角色對話及結尾小測。後續由使用者逐區指導優化；先前靜態設計預覽不再作為主要學習入口。

## 本輪交付

- 新增 `units/5/parts/5.2/index.html` 與本地樣式／腳本，單元 5 入口的 5.2 改為可點選。
- 六區皆有原生 SVG 的簡化內容及基本操作：水與環境溫差、雙金屬熱平衡、材料傳導比較、水／空氣對流、輻射遮擋與保溫設計比較。
- 一個保冷水壺小測，整合熱傳方向與三種路徑；提供未完成、需再觀察及完成回饋。
- 開場不放對話框；各區操作前後使用既有共用頭像。5.1 及其他既有學習頁原檔未修改。
- 目前器材與動畫為基礎呈現；精緻插圖、操作節奏與台詞留待逐區優化，未宣告完整單元核可。

## 檢視方式

以實際 Chromium 手動瀏覽流程並擷取畫面，沒有新增或執行測試套件。檢視桌機、1024／768／390／320px；觀察開始／暫停與切換條件、同溫、材料色帶、水與空氣、遮擋板、保溫選項及小測未完成／完成回饋。JavaScript 語法與 git 差異格式另行核對。詳細限制見資產 README。
