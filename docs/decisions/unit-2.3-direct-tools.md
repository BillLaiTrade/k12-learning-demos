# 2.3 第六區：直接拖動桌上器材

2026-11-02。使用者要求接手尚未提交的 direct-1 改版；新環境沒有取得原檔案，已先同步兩個 repo 最新 main，再從公開的桌上實作小測接續製作。保留唯一小測、12件選材與製氧混淆物、第1至5區及其他單元工作，仍為第四階段。

點工具會把真正器材放到實驗桌；拖的是同一件照片／玻璃器材，沒有與器材分離的幽靈縮圖。鑷子夾石後留在桌上，可直接送至瓶口；清水瓶可接續為水槽及集氣瓶加水。有效接近位置顯示即將執行的動作，放開或在約220ms內保持穩定即可開始。路過時持續移動會重置停靠時間，空白處只放下工具；取消、Escape、失去指標捕捉、離頁及切到其他實驗均清除拖曳。

玻璃片可直接蓋上或從瓶口拖開；集氣瓶拖向水槽會先抬高、保持蓋片、倒置並由上方入水，向上拖出則先離水再扶正。雙孔塞、薊頭漏斗與稀鹽酸沿用接近操作。導管出口直接拖動，先退出瓶口下方才能橫移，進入時再向上插入；固定玻璃不伸縮，橡皮管維持弧長。原點選與鍵盤操作保留於預設收起的「輔助操作」內。

手機從器材本體開始觸控拖曳，不交給瀏覽器捲動手勢；空白處仍可滑動桌面。拖到左右邊緣會自動捲動，有有效接近提示時停止，提示保留在可見範圍。動作開始對準目標，用完對準仍可拿取的工具；玻璃片蓋上遭拒時會移至安全停放位置，避免擋住導管出口。

操作與動畫共用狀態，從目前工具位置接續。大理石從盤中減少、由瓶口放入；酸液從真正試藥瓶口經漏斗加入，接觸固體才反應。保留液封、實際出口位置、排氣、原有空氣、水位、瓶內餘水氣泡、未遮口失水與未封口CO2流失的規則；先撤管、水下蓋片、封口取出扶正才完成。錯誤可修正，不以唯一背誦順序評分。
