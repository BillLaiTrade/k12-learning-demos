# 3.4 聲納累積測點連成已測輪廓

2026-10-31（臺北時間）。依使用者希望A/B/C/D累積連線、取樣越密越接近海床的要求製作，維持第四階段。

- 至少兩個不同位置收到回波後，畫出橘色「已測輪廓」，放在場景與測點的獨立圖層；測點及字母顯示在線上方，船與聲波維持。
- 線依左右位置排序，紀錄表仍按發聲順序A/B/C…排列，來回移船不會形成折返交叉線。
- 輪廓只讀取已完成紀錄的x與depth；相鄰測點以直線連接，未測處不查詢真實地形或延伸到測區之外。頁面短註說明點間是估計、加密可描出細節。
- 同位置重測保留每一列與字母，輪廓使用該位置最新完成值，避免零長度／重複頂點。探測中仍保留前一次完整輪廓；清除時刪除全部紀錄、測點與連線，舊回波取消機制保持。
- `sonar-profile.mjs`只接收測量資料及深度投影常數；不依真實地形函數補點，不以平滑效果掩蓋稀疏取樣。原地形、計時、音訊、人物及其他五區保持。

驗證包括打亂測量順序、等待中排除、同位置重測、資料不變、使用刻意不同於真實地形的測量值，以及加入海山測點後改善粗測估計；瀏覽器同時查線的實際SVG座標、表格順序、清除與暫停。
