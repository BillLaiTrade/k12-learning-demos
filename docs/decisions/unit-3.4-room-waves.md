# 第五區：生活中的聲音反射（2026-11-01）

使用者經逐步討論核可生成圖 `exec-8b1aa812-b616-467b-ac08-cba30ec2f08b.png` 後，明確指示製作、檢查功能與畫面。合併原第五／六區，成為五教學＋一小測；保留前四區和共用角色。

## 教學與版面

標題「找找生活中聲音反射的蹤影」，由海底探測轉回日常房間。單一俯視空教室，小葵自己發聲／聆聽；阿公只在共用對話欄。先拍一下手，再可說一句話，之後切換吸音材料。吸音是觀察後的改善，不把術語「殘響」「拖尾」當必要新知。

木地板為獨立生成材質 `room-floor.webp`，牆、材料、共用小葵頭像和動態波前為獨立SVG層；不把核可整張示意圖貼入介面。圖與控制連續滿寬排列，窄螢幕控制2×2，材料初始關閉。

## 波前模型

`room-wave-model.mjs` 管理6×3.6m水平房間、偏心聲源(1.65,1.9)m、343m/s及80倍慢動作。以矩形鏡像聲源計算反射圓的曲率及到達；波前裁切在室內，沒有折線箭頭。畫面只呈現至第三階代表反射與有限波前，避免線條過密；不能當完整三維聲場或干涉模擬。

左、上兩面牆由壓力反射係數0.88改成0.35；碰到這些表面的反射才減弱，右／下保持原係數，源波、半徑和傳播速度保持。數值是教學假設，不是假造材料實測係數。近左牆往返約9.62ms，遠右牆約25.36ms，在80倍動畫分別約0.77／2.03秒返回。

## 音訊與時序

`build-room-wave-audio.py` 由相同水平模型加高度2.6m計算三維鏡像聲源至22階，包含地板、天花板，近嘴接收點與聲源約0.18m。拍手為固定亂數種子的10ms衰減短促聲，語音沿用本課離線合成檔。未將2.57m遠場量測音訊冒充自聽，無骨傳導或個人聽覺還原宣稱。

每組前後使用相同原音、直接聲、位置及共用輸出縮放，不各自整段正規化、不拉長聽覺延遲；原音時間維持，畫面是慢動作且語音取代表波前，明示兩者不逐波同步。使用者主動發聲時才播放；初始不出聲、不設聲音勾選或音量滑桿。

新增控制器透過 `echo.mjs` 既有 active/pause 介面與其他區互斥。開始／繼續等待音訊準備，暫停凍結時間並取消源，續播保留音訊offset；重發、改材料、切區及背景會取消舊排程。材料切換回到ready，等再次發聲，不偷偷自動播放。載入失敗清除待啟動觀察且可重試。

## 範圍與驗證

單元小測最後一項改問吸音後仍有部分反射；保留測距與比較紀錄題型。實際聽感不保證巨大清晰度改變，學生可依波前視覺觀察吸音作用。研究依據含dEchorate (2021)與教室量測，只校正合理尺度與效果方向，未冒稱本模型經真人／裝置聽覺驗證。
