# 5.1 素材與第一區塊故事插圖

## 2026-10-27：第一學習區塊

使用者核可以精緻的連續情境插圖講述手感的限制，本輪只修改 `#card-01`。

- `touch-story-before.webp`：小葵兩隻手分別接觸冷水與溫水，中間的室溫水尚未碰觸。
- `touch-story-after.webp`：相同人物、視角、桌面與水杯配置，兩隻手改放入中央同一杯室溫水。
- 兩幅圖以既有 `temperature-story-opening.webp` 的角色與畫風為參照生成；第二幅以第一幅編修，維持場景連續性。原始圖為 1536 × 1024 PNG，交付以 WebP 編碼，尺寸及構圖保持不變。圖片不含文字，水杯標示、對話與說明均由 HTML 提供。
- 阿公為無鬍子的白髮、圓眼鏡角色；小葵的衣著與浣熊背包延續既有設定。對話頭像繼續引用根目錄共用素材。
- 冷熱感受採「可能」的定性說明，不宣稱每個人感受一致，不把感覺變成溫度讀值。此區不加入假想的觸覺操作、評分或測量數值。
- 教學順序為先前接觸不同 → 同一杯水可能感覺不同 → 手感不能代替測量 → 引出下一區的溫度計原理。

- 依使用者回饋改為桌機左右雙格漫畫，縮小插圖與間距；窄視窗以小幅直向兩格呈現，保留原圖與對話。
- 再依回饋將每格改為左圖右文的小漫畫，插圖寬度約為前版一半，縮短說明並保留先後情境與感覺差異。
- 最新依使用者指示移除第一區全部補充段落、人物對話及結論，僅保留兩個步驟標題和兩幅圖片；替代文字保留場景描述，小幅圖片尺寸維持約 195px 寬。
- 更正前次過度精簡：恢復每格小葵與阿公的共用頭像對話，保留兩個步驟標題，移除額外敘述與結論。桌機插圖寬度由約 193px 增至約 390px，面積約四倍；窄視窗直向閱讀。
- 依最新更正對齊 3.1／3.2：前段小葵／阿公對話 → 兩幅故事圖 → 後段小葵／阿公對話。四句既有對話逐字保留，移出圖框；兩圖改為全寬直向排列，每幅桌機實測 796px 寬，是先前 193px 小圖的約四倍寬度，圖片不裁切。
