# 4.3 四層介質名牌字型

2026-11-05（臺北）。依使用者截圖，僅改善小測名牌「介質甲／乙／丙／丁」的文字外觀。

採明確繁體中文無襯線字型順序：Noto Sans TC、PingFang TC、Microsoft JhengHei、Noto Sans CJK TC，最後sans-serif；字重500、字距0.04em，移除淺色描邊，禁止合成字重。沿用系統字型，不新增網路字型、依賴或授權負擔。

只對.rank-medium-name生效，不改名牌形狀／材質／位置／字級、最快最慢標記、排序卡片、光路、角度、模型或文案。更新CSS版本，完成桌面走讀、實際正確排序及公開確認。維持第四階段，非整單元最終核可。
