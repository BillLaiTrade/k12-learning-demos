# 第三區：鏡後虛像常駐與雙視圖（2026-10-28）

## 核可與範圍

使用者先要求分析第三區，指出左圖初始看不到鏡後的虛像。依現有版型生成並校正光線共線的示意圖後，使用者明確核可，要求將新版更新到原公開連結。

- 以 `approved-layout.webp` 為版型對照：左側光路圖約 1.9 倍寬，右側鏡前景象較窄；沿用原有小葵及小熊素材、橘色對話、淺藍面板和綠色按鈕。
- 初始直接顯示實物與淡色虛像。虛像取同一側面素材沿鏡面反射，與實物同大、等高、等距；右圖鏡中像清晰不透明。
- 三個同色鼻尖標記連結左右視圖。只保留「看光怎麼走／隱藏光路」與「移除小熊／放回小熊」；移除與放回位置固定，不增加填答或重設。
- 正常模式先顯示實線，650 ms 後加入反向延長虛線，之後保留供閱讀；減少動態直接顯示完整圖。隱藏光路後仍看見虛像。移除後實物／像／光路一起消失，放回後虛像立即恢復。
- 桌面左右並列，手機上下排列。說明區精簡為核可圖的重點文字。第四區維持物距量測。

## 物理關係

鏡面 x=540，鼻尖 S=(345,300)，虛像鼻尖 I=(735,300)，眼位 E=(173,121)。反射點 M 由 E–I 直線與鏡面的交點計算，約為 (540,237.891459)。

實線依 S→M→E 前進；藍色虛線為 M→I，與 E–M 共線。檢查鏡射對稱、同高、入射及反射斜率互為相反數，以及反射線與延長線的斜率相同。圖上的單條代表光線用於解釋方向，不宣稱單條線可以獨立定位三維像點；整體虛像位置由平面鏡對稱關係呈現。半透明只表示分析圖中的虛像位置，不暗示鏡中像看起來模糊。移除物體不單獨證明虛像。

概念依據沿用專案既有核對：[OpenStax 2.1 Images Formed by Plane Mirrors](https://openstax.org/books/university-physics-volume-3/pages/2-1-images-formed-by-plane-mirrors)。
