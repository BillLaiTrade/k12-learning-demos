# 4.5 第一、二區圖解辨識、白幕對位與顯色修正

日期：2026-11-04（臺北）。使用者逐項指出兩次折射圖質感不足、上下色塊不容易對位、藍光偏紫，以及色散圖像一條藍線／近看缺乏連結；明確要求合併修正。沿用前輪兩區分工與操作，不增加其他區內容。

## 四項修正

1. 圖解改為低彩度深綠光學墊、細玻璃稜邊／高光／投影、柔和光束核心、界面編號與較清楚標示。桌機與手機各有構圖，手機改為上下主圖／近看，避免縮字；法線仍垂直實際玻璃面。
2. 預覽的白光參照與當前單色光加同一落點虛線。兩列使用同一幕面坐標與倍率，標記取自有限狹縫光斑中心、以DOM疊加，不修改光學畫布的像素。白光狀態不標單一落點。補充色帶由有寬度的各色光斑疊加，不能用可見色塊邊界作逐色精確對位；不把光斑移到色帶中看起來同色的位置。
3. 原曝光把460nm藍光的正紅通道留在中亮、藍通道截到最大，顯得偏紫。新增prism-display的統一亮度壓縮：先對負通道作顯示色域裁切，再以共同係數壓縮各正通道，保留通道比例與強弱順序，加中性背景。所有光源、像素與主圖白幕共用曲線／曝光，不單獨替藍光換色或改波長。3D光路／燈口及平面備援也採同一光譜顯色來源；物理光譜、能量與折射計算保持。
4. 主圖以混合顯示呈現幾乎重疊的色光，不讓最後畫的藍線遮住全部。明確標出A取樣框、同名A標記與虛線，連到放大的同一段出射光；近看紅／綠／藍各有名稱、箭頭與可辨識間距。取樣框包含三條光路，近看兩軸採相同倍率，偏折角度不變，不拉大真實角差。

## 架構與驗證

保留30°N-BK7、白光D65與650／530／460nm、1×5mm狹縫、15×10mm預覽及原幕面；不動三稜鏡操作、原兩區教學分工、第三至六區或唯一小測。prism-optics僅顯示部分使用新映射，prism-studio及precision-prism沿用幾何並統一顯色／對位。四張SVG由同一模型生成，無新套件／服務。圖解色光為代表、顏色與亮度為顯示近似，不作校準照度量測。

新增顯色3項，涵蓋正色通道比例、亮度單調／中性背景、藍不偏紫及三色坐標不改。圖解4項更新為桌機／手機四張圖：生成一致、均勻投影、法線／交點、三色順序、A區取樣對應／等軸倍率與可辨識間距。原光學7項回歸；整課35項增加上下標記同坐標、切回白光隱藏標記、實際藍光畫布不偏紫，保留3D／預覽像素一致、七寬度、手機／備援及無JS。實際執行結果與公開內容另存主專案review。
