# 4.4 凸、凹分區與後段10區整合

2026-11-02。使用者先核可凸、凹透鏡分區，再明確選擇「採10區整合排列（建議）」：屏幕對焦＋物距共用一台分階段實驗；近視／遠視＋眼鏡共用同一眼睛；顯微鏡獨立。整體維持九個教學區與唯一四題小測。

目前順序：針孔→凸鏡平行光→對焦與物距→放大鏡→凹鏡平行光→凹鏡成像→眼睛調節→屈光狀態與矯正→顯微鏡→小測。第一區HTML及三份專屬資產逐位元相同，見preservation.json。

新增凸／凹獨立的雙球面折射模型及響應式剖面，主圖和近看使用同一鏡片與光路，修正原凹鏡輪廓和出射線裁切。反向延長線僅凹鏡可選、預設關閉；主圖手機不再使用600px最小寬度。這輪完成結構及基本互動，未把兩區改成3D。

第三區以一台先固定物體對焦，再開放物距比較；屏幕不自動移動，只有清楚像可紀錄。第八區先比較正常／近視／遠視，再直接加入合適鏡片；正常成像不需矯正、換模型先撤舊鏡片。第九區顯微鏡有自己的重設。導覽、標頭與四題回看同步更新，回看分別為s1／s3／s4／s8。

本機新模型6與整課23共29項全過，輸出為local-model.txt與local-browser.txt。涵蓋厚薄、球面交點、兩介面折射關係、真會聚／虛延長、完整取景、實際近看、按鈕對比、兩組合併狀態連動、紀錄與撤鏡、獨立顯微鏡、四題回看、七寬度、原生觸控與2.2格式比對。第一輪自動化已過，但人工畫面發現延長線選取鈕白底白字，已修正並加對比斷言；最終23項重跑全過。主圖與手機近看已人工檢視。
