### 垂直入水與杯口旋轉

- 初次拖曳整段只改變深度，水平位移不改變杯子位置或角度；完整浸入且放開後，才開放新的一次杯口旋轉。
- 抓杯身維持上下移動；抓杯口則固定深度，以繞杯身中心的指標角度旋轉，支援左右各125°，滑鼠與觸控採相同規則。首次入水解鎖後不再因深度變淺而鎖回；上提或下放維持原角度，角度由拖動杯口、左右方向鍵或觀察主按鈕的明確旋轉操作改變。換乾紙重做後重新鎖定首次垂直入水。
- 「自由移動杯子」面板、深度／角度滑桿、杯口朝下與往上提按鈕及其事件已移除；學生直接拖杯身上下移動、拖杯口旋轉，保留方向鍵操作。
- 水槽及材質圖層不攔截杯口事件，旋轉用透明命中區加大手機操作範圍；不增加可見標籤或控制把手。

- 滿水倒杯上提且杯口仍浸在水中時，杯內水繼續保留，包括高於槽面的水柱；繪圖不再把杯內水裁在固定高度以下。杯口一側露出後才進氣並逐步排水；杯口全部露出時顯示水流回槽面的水柱。排水速率是可觀察的示意速度，不是實驗流量。杯口偏上時，低於較低杯緣的水可保留，不把水強制清空或一律拉到槽面。已濕紙團不變乾，拖曳角度也不會自動改變。
