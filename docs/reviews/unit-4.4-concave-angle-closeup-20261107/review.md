# 第五區單一介面折射角比較

日期：2026-11-07（Asia/Taipei）

採用較外側的平行光作為主圖與局部圖共同的示範光。主圖強調橘紅色光線並標示目前折射位置；光源高度與取景同步調整。局部圖將目前表面的法線轉成水平，每次只顯示一個介面，用橘、藍角弧和數字比較入射與折射角。進入玻璃約 16.3° → 10.8°；離開玻璃約 22.6° → 35.1°，均依同一組兩次 Snell 折射計算。

- 12 項光學測試通過，含外側光角度增加、兩個介面折射定律、預設模型相容性。
- 15 項瀏覽器互動檢查通過，含主圖／局部位置一致、單一介面、兩組角弧、切換時相機不變，以及既有第六區功能與備用畫面。
- 最終 1440、390、320 像素視窗各檢查兩個介面，共六組通過；SVG 文字未裁切、主圖光路端點在視野內、關閉光路會隱藏角弧與比較列。
- 已人工檢視桌面兩個介面及手機畫面。第五區以外 HTML 保留；共用模型預設光線高度仍為 1.2，僅第五區選用 2.25。
