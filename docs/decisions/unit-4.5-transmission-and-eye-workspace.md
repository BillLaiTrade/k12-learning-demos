# 4.5 第五、六區：透射與入眼光路的集中操作

日期：2026-11-03（臺北）。使用者指示先檢視最新第四區，再接續第五、六區優化；維持第四階段，非外部驗收或最終核可。

第四區以最新六區版本檢視，既有色卡／照明專項及視窗專項共22項通過，涵蓋20種組合、14組視窗尺寸、實際3D與手機操作。保留第四區內容。

第五、六區延續第四區的閱讀順序：正式角色引導、上方三欄色光對照、滿寬器材與右上接收預覽、集中選項、隨操作更新的小葵觀察。移除重複結果框，不加入逐區計分、額外放大或新依賴。版面使用自然頁面高度，窄版按鈕至少44px，器材與預覽避讓；新增的樣式限於第五、六區。

- 第五區保持先固定白光換色片、再固定色片換照明。模式按鈕與狀態文字明示固定條件；停用不能改的選項，切回換色片時恢復白光、保留色片。沿用四種色片及四種照明的原反射／透射模型，結果、色條與白幕共用狀態；很暗不描述為被色片染成另一種色光。
- 第六區保持綠色色卡反射／綠色色片透射與遮光板。遮擋只改收到的光，光源及離開物體的光保持；移開可恢復，切換情境保留遮擋狀態。兩種情境的3D輔助線皆終止於實際遮光板入射面。平面備援以眼睛取代白幕，反射觀察者與光源同側、透射在另一側；遮板垂直於該段光路，光線在遮板停止。預覽的灰色遮擋提示不代表物體改變顏色。

純光學數值及第一至四區／唯一小測保持。驗證包含16種色片照明組合、逐色守恆、真實3D光線與遮板交點、八種視窗的器材／預覽避讓、鍵盤及手機原生點按／拖曳取消、WebGL備援與整課回歸。指令見tests/README.md，執行結果與公開發布紀錄保存於主專案本輪review。
