# 4.4 局部格式對齊檢查

本次只調整4.4的共用格式。以4.1為參照，確認頁寬、字型、頁面配色、卡頭及正文留白、頭像、編號牌與一般按鈕的共同數值在1440、1024、390、320px一致（format.json）。使用Tab鍵實際移至重設按鈕，金色焦點顯示正確。

既有整頁回歸23項全數通過：九區操作、唯一小測、七種尺寸、完整標題與導覽、鍵盤、原生觸控、素材與瀏覽器錯誤。沒有水平捲動、被截斷的標題／副標或重複ID。

實際檢視桌面頁首與首區、桌面第七區、1024px焦距內虛像、390px第八區與320px首區截圖。模型與標籤完整，右側觀察窗和操作項目未互相遮擋。

preservation.json確認HTML除CSS快取版本外逐字相同，沒有修改執行腳本或個別實驗樣式。4.2與其他頁面未納入本輪修改。
