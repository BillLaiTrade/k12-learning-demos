# 第九區：完整成像與局部近看

日期：2026-11-05

核可示意圖的兩個畫面共用同一操作視窗。以完整成像為主體，兩個近看入口選擇物鏡或目鏡所涵蓋的範圍，移除並列三步驟的編號及切換方式。

## 呈現與操作

- 初次載入及重設均顯示完整顯微鏡、完整光路與最終虛像比較，兩個近看按鈕均為未選取。
- 固定呈現「原物 → 物鏡 → 中間像 → 目鏡 → 眼睛」。物鏡近看突出前三項，目鏡近看突出後三項，中間像為共同項；範圍文字及朗讀標籤同步更新。
- 局部畫面顯示「返回完整成像」。返回後鍵盤焦點移到完整成像標題；鏡頭、上方入口及下方分工卡共用近看狀態。
- 輔助光路預設開啟，近看與返回保留物點及光路偏好。原光學模型、標本及方向保持一致。移除圖內重複的範圍標籤與底部可見狀態段落，以單一標頭交代目前範圍；朗讀狀態保留。
- 在窄畫面將完整視圖的標籤移至右側、目鏡標籤略上移，焦距標示依可用空間移到外側，避免重疊。文字仍為正常比例 HTML，光學位置不因標籤調整而改變。

## 檢查

- 顯微鏡互動檢查8項通過：預設全貌、兩個入口、範圍底色、共同中間像、返回焦點、光路與物點保留、說明卡與鍵盤、備用剖面。圖案方向在比較圖可見並完成排版後量測。
- 單元4.4整合檢查23項通過，涵蓋其他學習區、測驗、導覽、深連結及跨尺寸版面。
- 六種視窗尺寸（1440×900、1366×768、1024×768、760×900、390×844、320×844）、每種全貌及兩個局部共18個畫面檢查通過，無水平溢出、文字裁切、標籤越界、標籤互相重疊或遮住示意框。
- 操作、圖像與比較窗皆位於同一視窗內；320×844時工作區高度約809px。
- 實際檢視桌面全貌／物鏡近看，以及320px手機全貌／物鏡近看，確認層級、字形與方向對照。瀏覽器無頁面錯誤。
