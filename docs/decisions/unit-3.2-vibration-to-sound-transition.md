# 3.2 第一、二區轉場：由振動連結聲波

日期：2026-11-02（臺北）。使用者要求承接3.1已教過的波動與介質，從鋼尺振動銜接聲音如何傳到耳邊；先回答傳遞機制，再由動畫觀察引入彈簧波與縱波，避免答非所問。

- 第二區動畫前，小葵由繩子的振動傳遞，問鋼尺沒碰到耳朵時聲音靠什麼傳來；阿公回答空氣傳遞疏密變化、帶動耳膜，指出空氣是介質。
- 動畫後，小葵觀察空氣前後振動像先前的彈簧波；阿公再說明空氣粒子在原位附近來回振動，疏密變化向外傳，兩個方向平行，因此空氣中的聲波屬於縱波。
- 以「平行」取代「同向」，避免把來回振動誤說成始終與傳播方向相同；不以鋼尺上下振動判斷空氣聲波的波型。
- 兩段動畫後對話取代原重點框；第三區結尾只刪除重複的介質定義，保留抽氣現象、聲音需要介質及無法在真空傳播的說明。
- 第一區及其餘區塊、小測、圖片、物理模型、音效與互動程式保持。
