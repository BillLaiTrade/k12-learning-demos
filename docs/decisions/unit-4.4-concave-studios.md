# 4.4 透鏡外形與第五、六區探究

第五、六區保留各自可直接到達的學習任務。第五區以平行光認識兩次折射、發散與虛焦點；第六區移動圖卡，觀察正立、縮小虛像的位置與大小。兩區不使用模式切換隱藏另一項任務。

主畫面所有透鏡都使用完整旋轉體，將徑向厚度曲線繞光軸旋轉成圓形玻璃鏡片。凸透鏡中間厚、邊緣薄；凹透鏡中間薄、邊緣厚。移除遮擋輪廓的周圍金屬環及上方固定件，採下方托座。材質使用低不透明度玻璃、細緻圓周與實際中央曲面輪廓，避免深色側面形成厚圓柱的錯覺；保留完整鏡片體積。兩個曲面的線都落在實際玻璃表面，不改寫折射方向。第二、五區厚薄標示以投影引線與端點括線指向兩面之間的厚度，並在旋轉、縮放與響應式尺寸變化時更新。第二、五區預設採接近側面的斜視角，保留光源與完整出射段；第四區保留可辨識整段物距圖卡的斜視角；第六區調整為出射側的斜視角，使相機始終位於圖卡移動範圍之外，避免圖卡在中途變成細線。剖面留在第二、五區下方的分步說明，不能用等厚拉伸剖面取代可旋轉的主圖器材，否則從側面會變成棱柱。

第二、五區的主圖與剖面使用同一組玻璃球面、入射點及 Snell 兩次折射；立體鏡片沿光軸的中央光路也與該計算一致。第五區的光源位於虛焦點之外，主軸光直行，其餘兩道實際光向右發散。反向延長線預設開啟，指向入射側虛焦點 F，出射光沒有在 F 實際會聚。切換下方進入／離開玻璃的步驟不移動主相機；上方不另設近看模式。

第三、四、六區使用單一理想薄透鏡，立體外形保留完整圓形與厚薄特徵，代表光路在主平面簡化折轉。圖卡、F、2F 與像的位置保持原模型比例。第四區固定眼位研究放大鏡；第六區固定凹透鏡與眼睛，只移動圖卡，物距為 0.3F 至 3.5F。

凹透鏡對鏡前真實圖卡始終形成正立、縮小的虛像。圖卡向透鏡移近時，虛像跟著靠近透鏡、尺寸增加但仍小於原物，位置在圖卡同側、透鏡與 F 之間。跨 F 不切換像的性質，也不更改光路端點偏好。

第六區的觀看框比較固定眼位的角大小，兩框依同一比例同步縮放；觀察表中的尺寸倍率則是虛像相對原物的幾何倍率。眼睛不移到虛像位置，不加入眼內調節機制。

檢查涵蓋完整圓形的徑向幾何、實際玻璃曲面的射線交點、折射定律、虛焦點與虛像的區別、整段物距的成像方程、鍵盤與觸控、偏好保留、WebGL 備援、桌面與手機版面，以及凸透鏡原有成像與放大鏡功能。
