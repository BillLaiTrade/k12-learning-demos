# 3.3 第七區場景音效：本機驗證

2026-10-31。本輪新環境沒有未提交的前輪音效稿，已先同步 main，保留其他人的 2.3／3.4 更新，以及 3.3 原有十二張場景取景與前六區內容。`preserved-content.json` 核對 48 個既有 3.3 檔案的 Git blob 未變；共用 lesson 音源與第七區介面依本輪要求修改。

## 素材與製作

十二份原作的作者、來源、授權、SHA-256、片段與情境差異見 source/sources.json；完整授權證據見兩份 Commons JSON。所有成品都是可解碼的實錄／授權舞曲，沒有合成噪音或無聲影片冒充。起飛採 PDX Aviation 的 UPS 767-300F 真實起飛錄影，音軌非靜音；source/rejected-candidates.json 記錄 NASA 無音軌、另一全靜音 747、螺旋槳機及小型挖土機候選的排除原因。大型機具改採有明確 CC BY 4.0 授權的 Kleemann 碎石設備。

以相同格式先統一至 -23 LUFS，按每級 2 LU 固定增益安排；施工段瞬間峰值需要整組共同下移 2.6 LU，成品實測 -42.60、-40.60、-38.60、-36.60、-34.60、-32.59、-30.59、-28.60、-26.60、-24.60、-22.60、-20.60 LUFS。最高真峰值 -3.00 dBFS；其餘更低。短耳語等片段的絕對響度閘門會改變低音量積分結果，腳本以最終成品量測校正固定增益，不作動態壓縮、變調或變速。兩次重製的十二 WAV、recordings.json、LICENSE.md 與頁面共十五檔完全相同。

這是相對數位響度階梯，不能宣稱主觀聽感等距、裝置校準或 20～130 dBA 重現；未以模型聽感或現場音響試聽冒充人工聽感驗收。

## 檢查結果

- 前六區、分貝情境帶與單元小測回歸 79 項通過，0 失敗／略過，見 regression-tests.log。
- 音效專項四組全部通過，見 audio-tests.log：獨立 ffmpeg 量測／雜湊／授權、十二實際播放 AudioBuffer 全 PCM 逐值符合各自 WAV、圖片／按鈕／鍵盤重播、自然結束、播放中換場景、停止後切換不自動起音、慢載取消及舊下載遲到隔離、503 重試、離區／隱藏／前六區及小測音源互斥、真實手機點拖。
- 六種寬度 320～1440px 的場景與收合／展開授權清單無水平溢出。已檢視桌機與手機，保留原大圖；長元素全區截圖可能包含瀏覽器當下的 sticky 導覽位置，未為截圖修改正式導覽。
- 新測試第一輪兩項斷言假設不符實際：逐鍵穿越已快取中間場景可能合法起音；原筆電雙欄圖寬也未固定 400px。測試改為 Home→End 隔離慢載票號，圖寬以既有相對欄寬檢查，保留原介面與功能，完整重跑四組通過。
- 腳本最初兩次輸出被成品校驗拒絕（增益單位與短片段閘門差異）；已修正後重新製作，未將失敗輸出用於交付／部署。
