# 3.4 單元小測：這口井有多深？

2026-11-01（Asia/Taipei）。使用者核可`exec-e8d5b0bf-5b0d-4785-8ad0-cb508f600b69.png`示意圖，要求製作並先檢查功能與畫面。取代原海底測深＋室內紀錄選擇題，保留五個學習區及`#quiz`入口。

## 場景與操作

小葵在井口朝乾井底短喊「喂！」，不使用儀器探頭或丟石頭。情境素材獨立生成，沿用共用角色的棕色雙髮髻、奶油白帽T及背包；插畫不含文字／聲波／按鈕，SVG波弧、喊話泡泡和操作區由程式分層呈現。作答前井底不可見、紀錄空白；點小葵或「朝井底喊一聲」才播放並取得紀錄。桌機插畫與右欄等高，手機上下排列，觸控熱區為原生按鈕。

右欄提供喊聲開始、回聲開始、往返時間、題給空氣聲速340公尺／秒及一個井深輸入欄。初題0.40秒；「換一口井」從0.40／0.50／0.60／0.80秒另選一題，不連續重複，清除舊紀錄、答案與解析。同題重喊保留答案草稿、收起解析。

未探測、漏填、非正數、算成總路程、其他錯誤及正確分別回饋。有效答案核對後揭示井底深度與兩段聲路，提供具體計算解析；修改答案收起解析，避免舊核對結果誤導。聲路圖為5倍慢動作，非實際比例，減少動態偏好下呈現靜態圖。

## 聲音、計時與取消

喊聲採第五區已使用的`zh-TW-HsiaoChenNeural`小葵試配女聲（語速+12%、音高+25Hz），素材長0.217秒、峰值不超過0.78。井底回聲用同一AudioBuffer、相同音高與時長，增益0.45，最末共用增益0.65；最短返回0.40秒，喊聲與回聲間留有空隙。網頁只載入本地WAV，不呼叫外部語音服務。

音檔與AudioContext啟用完成才排程，發聲和回聲共用音訊時鐘，視覺紀錄直接讀同一時鐘；從喊聲起始量至回聲起始，不從喊完起算。換題、跨區發聲、背景及pagehide取消舊音源與動畫；載入或啟音失敗不產生虛假紀錄，允許重試。晚完成的舊請求不能發出聲音或填入新題。

## 科學界線

聲源／接收近似井口、乾井底固定，空氣聲速為題給值；忽略溫度梯度、井口與口耳的細小距離及側壁多重反射，只呈現井底主要回聲。實際有水的井可能量到水面；不將本模型當現地測量或保證所有真井都可清楚聽見井底回聲。這些說明放於可展開的情境說明，主要操作維持簡單。
