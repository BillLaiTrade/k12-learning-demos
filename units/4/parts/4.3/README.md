# 4.3 光的折射與視深基本版

使用者於 2026-11-01 核可先完成七區基本版，再逐區優化。教學頁為 `index.html`，不新增依賴。`assets/optics.mjs` 為純幾何模型，`assets/lesson.mjs` 控制互動。

- 六個對話／互動教學區：等距光速、垂直入射、空氣射入、水／玻璃射回、反射與折射光路可逆、視深。
- 最後一區為唯一理解檢核，含三題。未作答、錯誤、全對、修改答案及重設均有對應狀態。
- 動畫初始待命，手動開始。第一區為 100 萬公里比較台，支援暫停／繼續／重新播放，離屏或頁面隱藏時暫停並保留進度；第二區保留隱藏時重設。沒有持續空轉的動畫迴圈。
- 空氣、水與常見透明玻璃代表折射率為 1、4/3、1.5。內部用幾何光學維持方向正確，學生不必計算司乃耳定律。介面反射未畫出，頁尾已說明只畫穿透部分。
- 出射回空氣控制在 0–35°，不延伸到臨界角／全反射。
- 視深以固定硬幣、固定眼睛與兩條進入小瞳孔的折射光求反向延長線交點。實際硬幣座標不變；水位改變時重新計算折射點及視位置。小束光近似局部視位置，不宣稱所有大角度光線聚於同一虛像。
- 共用人物頭像引用根目錄 `shared-assets/characters/`，沒有複製素材。

參考：[OpenStax 折射與視深](https://openstax.org/books/college-physics-2e/pages/25-3-the-law-of-refraction)、[自然科學領域課綱](https://edu.law.moe.gov.tw/LawContent.aspx?id=GL001823)。出版社與版次未指定，沿用已核可的共同概念範圍。

檢查：

```sh
node --test tests/unit-4.3-optics.test.mjs
node --test tests/unit-4.3.test.cjs
```

瀏覽器檢查會自啟本機伺服器，需環境中既有 Playwright 與 `/usr/bin/chromium`。可用 `LESSON_BASE_URL` 指定公開頁，`LESSON_USE_PROXY=1` 使用環境既有 HTTPS 代理。覆蓋動畫、切換介質、角度拖曳／鍵盤、可逆、硬幣固定、光路隱藏、三種測驗結果及手機 390／320 寬度。模型另檢查切向光學方向、互易性及視深光線共線性。

這是可供逐區檢視的基本版，沒有新增外部驗收或最終核可紀錄。

## 第一區 100 萬公里比較台（2026-11-01）

使用者核可固定三介質示意圖後，指定共同路程 100 萬公里並完成實作。`light-speed-bench.png` 是依核可圖產生的無文字寫實底圖；`light-speed-lab.css`／`light-speed-lab.mjs` 控制實際字體、金色光跡、光點、接收器及狀態。純模型 `light-speed-model.mjs` 使用每秒 300,000／225,000／200,000 公里的代表光速，約需 3.33／4.44／5.00 秒，按經過的實際時間播放。使用者暫停或離屏時保留進度，再手動繼續；重新播放清空舊狀態。

模型假設整段為均勻介質、忽略衰減；100 萬公里不是圖上器材的實際尺寸，圖中光跡為示意。素材失敗時可重新載入，其他教學區仍可操作。手機保留場景細節並允許局部水平捲動。相關測試：

```sh
node --test tests/unit-4.3-speed-model.test.mjs tests/unit-4.3-speed-lab.test.cjs tests/unit-4.3-optics.test.mjs tests/unit-4.3.test.cjs tests/unit-4.3-format.test.cjs
```

`SPEED_CAPTURE_DIR` 可保存實際畫面、七種尺寸資料及真實五秒播放觀測；沿用 `LESSON_BASE_URL` 與 `LESSON_USE_PROXY` 公開驗證設定。參見 `docs/decisions/unit-4.3-million-km-speed-desk.md` 及 `docs/reviews/unit-4.3-million-km/review.md`。
