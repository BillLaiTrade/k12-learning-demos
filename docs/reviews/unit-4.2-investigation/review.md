# 4.2 未知樣本調查核對紀錄

日期：2026-10-28。使用者已核可簡化初始示意圖，要求製作後檢查內容、功能、畫面，再推送並提供公開區塊連結。

## 核可圖對照

- `approved-initial.webp`：使用者核可的簡化初始畫面。
- 正式初始畫面保留一瓶未知樣本、空燒杯、右方器材盤、前方取樣暫放托盤與收合筆記，沒有展開的報告表格、三個並列實驗或步驟列。
- 主操作是空杯／「取一份試試」。桌上工具按實際操作才放到中央，從器材盤取走的工具不另留一份相同器材在盤上。
- 沿用既有內側欄與頭像，所有內容都在 `.card-main` 內。手機將器材按鈕移到圖下方，維持可點觸尺寸，不把文字硬縮進照片。
- 結果、取樣切換、紀錄入口隨操作出現。筆記記下觀察後展開，供學生補充自己的想法與填寫推論。

## 科學內容

| 核對項目 | 預期結果 |
| --- | --- |
| 原樣本、沉降後 | 2 g 泥沙、5 g 食鹽、95 g 水，合計 102 g |
| 過濾 | 濾紙留下 2 g 泥沙；濾液含 5 g 食鹽與 95 g 水，合計 100 g |
| 直接蒸發原樣本 | 剩下 7 g 混合殘渣，不能據此單獨秤出食鹽 |
| 蒸發濾液 | 剩下 5 g 白色固體，水移除，泥沙不重新出現 |
| 原濾液濃度 | 5 / 100 × 100% = 5%；或 50,000 ppm，兩者都接受 |
| 成分推論 | 必須引用支持的紀錄；食鹽推論限定在已提供的候選成分，不把白色外觀當化學鑑定 |

不新增蒸餾、層析、稀釋或混液計算。動畫為定性示意，器材圖不是量測照片。

## 功能檢查

命令：

```sh
node --test --test-concurrency=1 \
  tests/unit-4.2-investigation.test.cjs \
  tests/unit-4.2-concentration.test.cjs \
  tests/unit-4.2-ppm.test.cjs \
  tests/unit-4.2-chromatography.test.cjs \
  tests/unit-4.2.test.cjs
```

涵蓋：

- 先直接蒸發／先靜置／先過濾等不同路徑、獨立取樣與切回舊樣本。
- 固體／液體去向、質量守恆、乾燥後不繼續沸騰／不直接過濾。
- 原生鍵盤、真實觸控點擊與 CDP 觸控拖曳、滑鼠拖曳、放在外面、Escape／pointercancel。
- 筆記快照、可編輯補充、避免重複加入、移除與撤下舊評語。
- 無證據／不相符證據／正確證據；相同樣本兩次稱量；百分比與 ppm 等價、錯誤數值與未稱量資料。
- 庫存耗盡後顯式補充、重設確認／取消／未完成動畫取消、背景暫停與繼續。
- 素材載入失敗與重試、不影響前面稱量活動、減少動態。
- 1440、1024、850、768、680、390、320 px 初始／展開版面與內容欄邊界。
- 前面蒸發、層析、自由稱量及 ppm 的既有回歸。

第一輪找出測試把不可見的 `noscript` 當成越欄元素，已修正為只量取可見寬度的元素；並改善透明照片遮淡動態液體、器材接地陰影、初始圖示及盤上器材重複。

最終依上列完整命令執行：**74 項通過、0 失敗**，包含新活動 19、自由稱量 19、ppm 14、層析 13、蒸發 9（均含各外層項目）。已實際檢視初始桌面／手機、過濾結果、加熱中、乾燥固體、稱量與筆記／報告畫面。主要截圖保存如下：

- `implemented-filtered-desktop.webp`：操作後濾液與已記錄的觀察。
- `implemented-notebook-desktop.webp`、`implemented-notebook-mobile.webp`：展開的筆記、成分引用與選填濃度。

另以程式逐字比較前五區，除新增導覽／樣式／腳本／對話框與末尾活動外，原教學區內容保持相同。
