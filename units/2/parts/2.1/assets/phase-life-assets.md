# 2.1 第四區生活場景素材

2026-10-31 依使用者核可的生活場景對照方案製作。背景與紋理由本次影像生成工具產生，非實驗實錄；頁面明示生活情境合成、時間加速及非實際比例。

| 檔案 | 用途 |
| --- | --- |
| phase-life-glass.webp | 固定視角的空玻璃杯與廚房背景；合成蒸發水位及冰飲杯外凝結 |
| phase-life-plate.webp | 空白盤子與廚房背景；合成冰塊融化及留下的液態水 |
| phase-life-cold.webp | 家用冷凍庫與空盒背景；合成凝固、昇華及凝華 |
| phase-life-ice.webp | 透明背景的寫實冰塊；用於融化、凝固、冰飲與昇華 |
| phase-life-frost.webp | 透明背景的寫實霜晶紋理；用於冷表面直接結霜 |

原始生成 PNG 存於工作區 `/workspace/generated_images/`，發布素材轉為 WebP；背景最大寬1100px，冰塊最大邊700px。水面、原水位虛線、水珠、生長前緣及霜晶範圍由SVG合成。生活畫面沒有自己的計時器，依上方粒子實際變態比例更新。

蒸發只轉換48顆示意粒子中的24顆，水面由原位下降一半水深，保留液態水。虛線固定；不畫可見的水蒸氣或白霧。凝結水珠在杯外，杯中冰飲保持；昇華沒有融水，凝華不經液滴。
