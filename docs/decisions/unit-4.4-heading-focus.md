# 單元 4.4 的標題、副標與操作提示分工

日期：2026-11-05

依使用者核可的順序，先修正九區副標，再處理少數主標與重複操作提示；範圍僅限 4.4。

- 主標引出值得探索的疑問。第二、五區改問平行光通過凸、凹透鏡後的方向，不在題目中先說出會聚、發散的結果；同步導覽文字。
- 副標定位科學主題及學習焦點，交代外形、物距、成像或應用的關係，不混入操作步驟、完整解說或待探索的結論。
- 操作方法留在圖與控制項附近。第三區的位置尺提示移到尺下，第四、六區在圖卡位置尺下提供操作提示；第二、五區的旋轉與折射步驟提示集中於主圖與剖面之間。
- 對話保留情境、問題與概念銜接，刪除重複操作口令。第八區的同一遠方圖卡、放鬆調節等比較條件移至控制區說明。
- 第九區的觀察模式提示放在切換按鈕旁，完整成像解說移至互動圖之後。

沿用既有標題排版，允許自然換行；沒有改動光學計算、控制項事件、圖像、鍵盤或觸控互動。第二、五區副標在窄畫面再精簡為「凸／凹透鏡：外形、折射與焦點」，避免只剩一字的第二行。
