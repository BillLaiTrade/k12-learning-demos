# 顯微鏡鏡頭近看

物鏡與目鏡提供不同的局部取景，保留各自理解成像所需的原物／中間像／眼睛。點擊鏡片區域或文字標籤、三步按鈕、返回全貌皆同步；光路與上下端偏好保留。小圖顯示同一模型的完整位置及觀察範圍。

- 五項顯微鏡瀏覽器檢查通過：預設畫面、步驟／光路、點擊與鍵盤近看、返回及偏好保留、備用剖面。
- 原光學兩項檢查通過，原物、中間像與目鏡關係及代表光線連續性不變。
- 一般動畫模式下，實際於 1440×900、1366×768、1024×768、760×900、390×844、320×844 操作物鏡、目鏡與全貌。確認重要標示在圖內、文字無縮放、控制與結果仍在同一視窗高度內、位置小圖成功顯示、無裁切及水平溢出；無瀏覽器錯誤。
- 實際查看桌面兩種近看及手機目鏡畫面，焦距 F 位於中間像外側，原物至中間像的過程保留。主圖標示精簡，沒有新增實體屏幕。
