# 2.2 單元小測：從未知樣本瓶開始取樣

2026-10-29。使用者指出點空燒杯取樣不直覺，要求從「未知樣本 X」開始操作。

- 將原本空燒杯上的操作區改到未知樣本瓶，瓶身與瓶上文字皆可點擊；「取一份」入口固定在瓶下方，後續仍在同一處再次取樣。
- 點瓶後，沿用同一個樣本瓶移近燒杯、傾倒、瓶口流出樣本、接液杯累積液體、樣本瓶回位的連續動畫。空燒杯是接收容器，點它不會建立取樣。
- 取樣中的瓶身提示隱藏、取樣入口停用，防止重複建立樣本；動畫結束後瓶身入口恢復。取完六份時，可從同一瓶身或瓶下入口補充同批樣本，保留既有筆記。
- 原有拖曳替代操作調整為「拖瓶至燒杯」；有效放置區對齊接收燒杯。鍵盤 Enter／Space 與觸控同樣可使用瓶身取樣。
- 初始操作提示、無障礙名稱及重設後焦點一併對齊樣本瓶。過濾、加熱、稱量、自由選用器材及報告評量邏輯沿用。
- 本次不改動液體轉移模型、器材照片與每份教學樣本的科學質量。
