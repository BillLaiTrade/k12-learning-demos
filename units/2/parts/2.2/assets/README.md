# 2.2 聲音示範素材

- `sound-story-opening.png` 為開場情境圖。
- `ruler-suspended-background.png` 是依原教室素材調整的背景圖：只有左側一張桌子，右側為桌外空間，避免把尺的懸空段誤看成搭在另一張桌面上。
- 鋼尺、刻度與夾具由頁面內的 SVG 繪製；固定短段留在桌面，夾具跨過桌緣，長段伸出桌外。刻度供辨認尺身，並非量測互動。
- 振動以固定端位移及斜率皆為零、自由端位移最大的平滑曲線示意，刻度隨尺身彎曲，沒有把整片尺當作剛體旋轉。振幅隨時間衰減；按住停止時立即恢復靜止。
- 畫面刻意放慢並放大彎曲供觀察；它與 Web Audio 合成的彈振聲不是相同播放頻率，不作為實際頻率的量測模型。
- `ruler-clamp-background.png` 和 `steel-ruler-cutout.png` 為保留的舊版素材，現行鋼尺示範不再載入。
