# 4.3 對齊 2.1、2.2 的學習頁格式

日期：2026-11-01。使用者在差異盤點後，要求先依 2.1、2.2 的格式修改 4.3。

採兩頁共用的圖文頁首、完整提問式探索導覽、閱讀位置、編號牌／標題／概念副標題卡頭、卡頭分隔線、人物色帶對話與獨立單元小測。桌機採 2.2 的 1160px 頁寬、250px 側欄及 34px 欄距；窄螢幕沿用 2.1 的固定橫向導覽，760px 以下切換單欄。頁首引用既有 `4.2/assets/optics-lab-opening.png` 作光學情境圖，沒有複製或修改圖片；圖片替代文字描述實際圖像，不將鏡面情境宣稱為折射實驗。補齊分享預覽與 canonical。

仍為六個教學區加一個結尾理解檢核，小測獨立識別且不計入六區閱讀位置。原有 `#s1`–`#s7`、表單與操作元件保留，另外提供 `#unit-quiz` 小測直達入口。手機切換區塊時橫向導覽顯示當前項目，初始深連結在內容就緒後重新對齊。

本次只調整格式及必要的導覽行為。六區互動 DOM 與原三題表單經忽略排版空白後逐項相同；光學模型、動畫／拖曳／鍵盤／視深／測驗判定程式保留。沒有增加新的實驗、小測題型或進階光學內容。仍為第 4 階段製作／修訂，非外部驗收或最終核可。
