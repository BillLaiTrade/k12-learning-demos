# 第六區：桌上實作小測，本機檢查

2026-11-02。依使用者指示，唯一小測改成「先挑桌上物品，再直接操作」；先交代二氧化碳部分溶於水，仍可用排水法收集。桌上12件物品包含雙氧水／二氧化錳兩項混淆物，選對需要的材料與器具後，進入同一張操作桌。沒有選單填答、排步驟或整段播放按鈕。

工具可以拿起後點器材，或拖到器材。清水、鑷子、雙孔塞與固定玻璃管／定長橡皮管、薊頭漏斗、稀鹽酸、玻璃片各觸發短動作；器材位置可直接點選或使用同等的按鈕。學生自己決定裝水、遮口倒置、放入水槽、加料、組裝、排氣、移入出口、撤管和封存的時機，不以唯一背誦順序評分。一塊大理石即可啟動足量反應的教學模擬，仍可逐塊補加；盤中數量與夾持數量同步。

石塊與酸液實際接觸才冒泡；酸液由試藥瓶口流出，經漏斗進入錐形瓶，末端被塞子遮住。液封不足時氣體由漏斗逸出；排氣在水中才有出口氣泡，在空氣中仍能排除原有空氣。出口確實進入倒置瓶口才排出瓶中水；進出均先經瓶口下方，固定玻璃形狀不伸縮，橡皮管420單位定長並由管口上方接入。瓶內氣泡只穿過餘下水柱，不畫在已集氣空間；滿瓶後餘氣由瓶口冒出。

未遮口在水外倒置會流失水，半瓶水或太早收集會留下空氣，不能完成。可撤管、重新裝水再收集，保留反應源；導管尚在瓶口內不能蓋片或搬動瓶子。必須先撤管、在水下蓋片、保持蓋片取出及扶正，才通過檢查。停止倒液會保留已倒入的量，瓶子會動畫收起；跨區、離頁或捲離整個小測時暫停時間，再次操作才恢復，不跳過中間動作。
