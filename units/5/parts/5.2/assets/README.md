- `lesson-layout.css`：沿用 5.1 的側欄、頁首、上方編號／標題／摘要、下方內容與手機版面；套用至六個區塊，不修改 5.1 原檔。
- `heat-transfer.css`：各區基礎 SVG、控制、讀數、小測與窄視窗樣式。
- `heat-transfer.js`：第 3–6 區獨立的開始／暫停、重來、條件切換；保冷水壺的單一結尾小測與導覽標示。第一、二區改由各自的專用模組處理。
- 頭像沿用共用 `dialogue-character-avatars.png`；開場沿用 5.1 已有科學桌插圖，後續可依逐區優化更新。未使用生成頭像或把示意圖按鈕當成互動。

## 簡化模型

1. 水溫以指數曲線接近選定環境，不越過環境溫度；熱箭頭依當前溫差改變方向，同溫時消失。
2. 熱平衡以兩塊相同材質、相同質量、只彼此交換熱的金屬為例，總溫度和保持不變；同溫時無淨熱傳遞。本例中間值不推廣為所有材料或質量的混合溫度。
3. 傳導用穩定步長的定性一維擴散呈現材料溫度帶；金屬與木材的係數只供比較，不當作真實物性值。
4. 對流以閉合流線上的示蹤點呈現循環，水／空氣切換；並非計算流速或完整流體力學。
5. 輻射比較有無遮擋板的直接照射，文字交代遮擋物也可能吸熱與再放熱，不宣稱遮擋使所有熱交換歸零。
6. 保溫示例固定初溫、水量及環境，用定性權重比較三種路徑；兩杯均已加蓋，不模擬融冰或蒸發。更改設計會重來。

所有時間均為教學示意。暫停、重設及切換分別只影響當區，頁面失焦至背景時停止播放。

### 深銅路徑與流光

使用者核可流光示意圖後，以原生 SVG 路徑及三段暖色短光帶取代大面積黃色箭頭。米白描邊包住深銅色線條，兩條短路徑分別跨過 A 杯左壁、B 杯右壁，不連接兩杯；上方顯示「放熱／吸熱」與「水 → 環境／環境 → 水」。路徑略低於讀值的活動範圍，以免低溫時遮住數字。

光帶位置與朝向由同一個水溫模型時鐘計算：放熱朝外、吸熱朝內，暫停／繼續／重來／換環境與液柱同步，同溫時整組移除。接近同溫時光帶減弱，但最低維持六成不透明度，深銅路徑與文字保持清楚；流光僅表示方向，不當作實際熱量刻度或介質運動。依使用者後續要求，系統減少動態時仍以較低速度持續移動，見下節修訂。

兩支精緻玻璃管、刻度、溫度模型、對話、780px 面板及其他區塊沿用。最新同組檢查為 13 項，增加實際移動方向、路徑跨杯壁、光帶暫停／繼續、漸弱及減少動態檢查；核可圖與實作畫面見 review 的 `flow-*.webp`。

### 持續流動修正

使用者回報流光看起來不動，要求持續呈現熱傳遞。程式原先在 `prefers-reduced-motion: reduce` 下固定光帶位置，確實可能產生此現象，未取得使用者裝置設定，不將其當成已確認的個人原因。

移除靜態分支，改以 `flowPhase` 在原播放時鐘累積：一般每秒 .48 圈，減少動態時 .24 圈，保持平穩且沒有閃爍、放大或鏡頭位移；切換設定不回跳。另加入沿深銅路徑移動的短亮帶，使持續流動更明顯。暫停、繼續、重來、切換及同溫停止維持原行為。

最新為 14 項檢查，新增兩種動態偏好下真實時間的畫面像素與亮帶位移確認，並確認暫停後兩張實際畫面相同、繼續後恢復移動、重來歸零。畫面證據見 review 的 `continuous-*.webp`。

## 第二區：接觸與熱平衡（2026-10-29）

使用者核可完整示意稿，並要求移除被誤認為實體棒的深色熱傳底線。正式第二區使用同一份原生 SVG 器材、版型與真實人物頭像，將靜態示意轉為可操作場景。

- `balance-lab.css`：僅第二區的 780px 面板、隔熱盒剖面、鋁塊、接觸式探頭、液晶讀數器及控制列。
- `balance-lab.js`：兩塊靠攏、接觸後傳熱、暫停／繼續、重來、切換初始條件、達到同溫後重新觀察，以及背景暫停。
- `balance-model.mjs`：相同材質及相同質量的鋁塊，忽略與外界熱交換。A 60°C／B 20°C 接觸後逐漸接近 40°C；原本同溫的模式兩塊都為 40°C，不顯示淨熱傳光跡。
- 金屬接觸前保持初溫，接觸動畫約 0.7 秒。接觸後溫差指數縮小；剩餘半溫差小於約 0.05°C 時，以兩塊 40.0°C 收束並移除淨熱傳光跡。時間與速率是教學示意，並非真實實驗參數。
- 光跡直接跨越兩塊金屬的接觸面，沒有實體棒、軌道或深色底線。一般與減少動態設定均保留連續方向運動，減少動態時速度較低；暫停會固定光跡與讀數。
- 兩邊的數位讀數、無障礙說明、冷暖反光、接觸位置及狀態來自同一狀態資料。同溫後兩塊回到相同銀色，並顯示沒有淨熱傳遞；同溫比較的操作後小葵台詞亦會同步更換。
- 原共用腳本只移除第二區舊的色塊呈現與事件，保留第 3–6 區、小測與導覽。第一區與其餘區塊 HTML 的保留雜湊見 `docs/reviews/unit-5.2-card02/`。
