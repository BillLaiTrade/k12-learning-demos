# 第六區核可示意圖：虛線移動範圍與觀看窗配對

2026-11-04。使用者否決實體接頸及A標記後，核可[最後示意圖](../reviews/unit-4.3-depth-dashed/approved-reference.png)，指示依圖修改。這是本輪製作授權，非整單元最終核可。

## 呈現

移除眼睛與觀看窗之間的接頸、連接線及其ResizeObserver／座標計算；不新增A、字母或數字配對標記。改用同款眼睛圖稿、淡金光暈與觀看窗細框，右標題明示「這隻眼睛看到的畫面／與眼睛位置同步」。焦點時觀看窗金框同步加強，ARIA仍對應同一個Canvas。

實體金屬滑軌、端點、支座及陰影移除，改成穿過眼睛中心的灰綠水平細虛線；兩端上方標示靠近／遠離。眼睛下方有左右雙箭頭，預設顯示「↔ 左右拖動」；當真正光路進入眼睛時保留雙箭頭並收起重複文字，讓入眼光線保持可見。完整手勢說明仍在頁首、標題及ARIA。關閉光路後完整操作文字再次顯示。這是操作提示，不是另一條光路。

拖曳仍直接控制原眼睛位置；虛線不攔截滑鼠或觸控、不作為第二套滑桿。44px以上的操作範圍、相對位移、Home／End及方向鍵保持。窄螢幕提示位置保留在圖面內，水位／擋光／視位置標籤調整留白以避開新提示與把手。

上方操作說明採精簡奶油色細金提示，下方加水／放水按鈕與一則學習重點整合在共用台內；桌機並排，手機自然換行。沒有恢復重播／重設，沒有新增操作。詳解、空槽預設、連續加滿／放空、途中反向、手動接管、離屏續播及減少動態保持。

## 保持與驗證

不修改視深模型、固定相機、右圖繪製、實際硬幣／槽體、折射率、照片或其他六區。圖稿由既有向量眼睛共用，核可圖只保存為設計參考，沒有把示意圖當作互動畫面。

既有連接檢查改驗水平虛線、下方雙箭頭、眼睛及觀看窗圖稿／焦點配對、眼睛移動而虛線及觀看窗固定；不再驗已刪除的連接線。九尺寸×三位置27組配對、五水位共135組文字／控制／光路避讓、44px與無橫向溢出保持。功能檢查覆蓋新排版下的加放水、鍵盤、滑鼠、原生觸控及整課導覽／小測。執行結果見[本機檢查](../reviews/unit-4.3-depth-dashed/review.md)。維持第四階段。
