# 2.3準備材料：七件物品的身分與實驗功能

2026-10-31。同步main基準c69d147b；依使用者提供的材料圖，將七件物品本體與名稱做成可點選介紹，不只擺圖。沿用原照片、滿寬版型及五步實驗，無新素材或依賴。

## 行為與內容

- 每件物品為一個原生按鈕，物品本體與標籤共用點選範圍；圖上提示點選、標籤有資訊記號，選取項深綠突出。圖下共用一區，分「這是什麼」「實驗中的作用」，手機直排，不遮器材。
- 預設雙氧水；選擇其他物品會停止可選「看看準備」導覽並保留內容，離開第一步再返回也保留。主動重播仍導覽雙氧水、二氧化錳、集氣瓶，不自動前進實驗步驟。
- 七份文案與百分比範圍見[content.json](content.json)。區分雙氧水提供氧氣／二氧化錳催化且不增加理論總產量，解釋錐形瓶反應、水槽與滿水倒置瓶、導管先排起始混合氣、先撤管再水下蓋片。
- Enter／空白／觸控均可選擇，焦點留按鈕，aria-pressed與aria-controls連到對應介紹；polite region播報。介紹需要時捲入可見區，減少動態偏好改為立即捲動；無JS七份介紹依序可讀。
