# 3.3 活動載入失敗隔離

2026-11-01，使用者指定以桌機、筆電為預設使用情境，暫不處理手機觸控範圍；接著核可操作盤點第6項：活動分開初始化，單一活動載入失敗時其餘仍可使用，失敗區塊顯示「活動載入失敗，請重新整理頁面」。

主控制器不再靜態匯入所有活動。七個學習區與小測各自動態載入模組與依賴，分別捕捉下載、解析、模組執行及初始化例外。區塊以loading／ready／error記錄狀態，等待時顯示「活動載入中…」；完成才開放操作，失敗顯示可見alert並停用按鈕、輸入及自訂滑動控制，也收起無效的波形載入文字。靜態教學、來源連結與導覽仍可閱讀／使用。

沿用原音訊停止、取消與離區管理，不改模型或聲音。小測慢載完成時，其初始化不得停止其他區正在播放的聲音；真正進入小測調整才停止其他聲音。重新整理可重新載入，沒有自動播放。

共用依賴失敗只影響需要它的區塊，例如timbre-model影響音色區及小測，兩處各自顯示錯誤；若共用離區播放管理無法載入，所有依賴區塊都顯示錯誤，避免缺少停止機制時仍啟音。本次不涵蓋主控制器本身缺檔或瀏覽器不執行JavaScript的情況。

桌機1440×900與筆電1366×768故障注入涵蓋八個活動模組、間接／共用依賴、部分初始化後拋例外、慢載與重新整理恢復。其餘盤點項目仍逐一討論決定。
