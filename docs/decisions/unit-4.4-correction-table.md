# 第八區比較表直接切換觀察

依使用者要求，讓「比較未矯正與矯正的成像」表格沿用前面學習區的可操作觀察表方式。

- 點選眼睛狀態或未矯正會聚位置，切換對應眼睛並取下鏡片；點選合適鏡片或矯正結果，切換對應眼睛及預設合適鏡片。正常眼睛的兩種觀察都保持不加鏡片。
- 眼睛名稱、鏡片及結果使用原生按鈕，支援Tab、Enter、Space及觸控。表格保留原四欄內容，補一行點選說明，反白目前眼睛模型，按鈕標示目前符合的觀察條件。
- 上方控制與表格雙向同步；手動選擇另一種鏡片時不誤標合適矯正狀態。切換保留輔助光路開關及追蹤物點，不更動光學模型。
- 窄版矯正結果分成「回到／視網膜上」兩行，按鈕維持至少44px高；鍵盤焦點沿用金色。

檢查：既有第八區瀏覽器檢查加上比較表雙向切換案例，9項全部通過，涵蓋九組眼睛／鏡片、八種尺寸、偏好保留、鍵盤、觸控與WebGL備援。文字分行調整後另以1440、390、320px檢查全部表格條件、內層文字點選、按鈕觸控尺寸與無裁切，並實際檢視截圖。
