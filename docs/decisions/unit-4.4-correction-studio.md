# 第八學習區塊：眼鏡如何幫助清楚成像

依核可示意圖製作，沿用第七區的柔和立體眼球剖面、物點配色、視網膜放大窗及整合操作列。第七區比較正常眼睛的遠近調節；本區固定遠方物體與放鬆調節，比較眼軸模型及眼前鏡片。

- 三種眼睛模型：正常、眼軸較長的近視、眼軸較短的遠視。角膜及水晶體的屈光能力相同。補充區明示實際屈光異常也可能與屈光能力有關，遠視不等同老花。
- 三種鏡片選項：不加鏡片、凹透鏡、凸透鏡。兩種鏡片使用預設適當強度，學生可比較另一種鏡片使失焦增加的結果，無需調整度數。
- 同一模型戴取鏡片不移動眼球、視網膜或水晶體；切換眼睛模型先撤除鏡片，保留光路顯示及物點偏好。重設回正常眼睛、不加鏡片、雙物點及顯示光路。
- 以三段近軸薄透鏡計算眼鏡、角膜、水晶體的連續折射。不同物點分別成像，視網膜上的像維持倒立。失焦寬度與預覽模糊來自同一光學模型。
- 視網膜畫為曲面內襯，計算採局部平面近似；圖卡與眼球未按同一比例繪製。放大窗僅比較清晰度。視網膜後方灰色虛線為假想幾何延伸，不表示光穿過視網膜，亦非虛像。
- 手機完整呈現剖面，不使用橫向捲動；WebGL 不可用時沿用向量剖面與全部操作。

驗證：光學單元測試、九種眼睛與鏡片組合、戴取鏡片模型矩陣不變、八種視窗寬度、鍵盤與手機觸控、WebGL 備援、第七區與整頁回歸；實際截圖檢視後發佈。
