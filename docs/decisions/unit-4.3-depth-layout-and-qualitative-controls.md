# 第六區雙視角版面與相對位置操作

2026-11-04。使用者核可新版雙視角示意圖及後續討論：眼睛增加可見導軌；水位與觀看距離不以公分讀值作為學習重點。此次是第六區製作修訂授權，維持第四階段，非整單元最終驗收。

## 教學層級與控制歸屬

左右採等寬照片場景，桌機並排、窄螢幕上下。標題緊縮為單行；左圖上方集中「顯示光路與輔助線」及「重播光路」，右圖同一高度放可見狀態與同步位置提示。狀態不壓在槽內畫面。下方共用列只有「加水觀察」「重設」及簡短拖曳提示。

保留一則「硬幣沒有移動；改變的是光進入眼睛的方向」結論。實線／虛線圖例在左圖下方，右圖下方依實際遮擋狀態解釋；更詳細的折射與視位置原因維持可展開。沒有重複數字卡片、額外說明列或新的測驗步驟。

## 導軌與相對位置

眼睛沿固定水平軌道移動，兩端有端點及「靠近／遠離」提示；導軌不成為第二套控制，仍直接拖曳眼睛。水面與44px垂直把手維持直接操作。移除水深讀值及距槽前數字；圖內、即時朗讀與ARIA描述改為空槽／水位較低／中等／較高、靠近／中間／遠離。

內部幾何單位與範圍維持，沒有為了去掉數字而改動物理計算。方向鍵、PageUp／PageDown、Home／End、相對拖移無跳位、手機手勢及手動接管示範皆保留。

## 右圖取景與質感

從同一瞳孔重新取景，以槽口遠近緣決定垂直視野，保留少量槽緣與前壁，讓槽內、水平水面與硬幣更容易比較。鏡頭原點等於左圖眼睛；取景只隨觀看位置調整，不隨水位或硬幣出現狀態追蹤。硬幣尺寸、位置、槽壁遮擋及折射交點不變。逐像素逆向光線追跡保持，沒有用固定圖片或閾值貼上硬幣。

沿用前面單元照片，水中焦散降低對比，硬幣附近加入接觸陰影，提高金色硬幣與水色的辨識。沒有新增照片、套件或外部服務。
