# 3.2 煙火測距小測檢視

日期：2026-10-29（Asia/Taipei）。

## 畫面對照

- approved-layout.webp：使用者核可的桌機示意圖。
- desktop-observing.webp：正式頁面在 1440 × 1000 視窗的實際觀察中畫面，時間差仍在計時，單發煙火正在展開。
- desktop-result.webp：實際完成觀察並作答正確後的畫面。
- laptop-ready.webp：1280 × 800 筆電視窗的小測初始畫面。

已逐張檢視：左側夜景、煙火、時間線與操作，右側現場條件、觀察紀錄與估算依示意圖配置；精簡標題與側欄內距，初始小測高度約 705 px，無水平溢出。煙火不是背景上的靜態圖案，每次只發射一發；火星展開後形成受重力影響的垂落尾跡。真實觀察完成後煙火可逐漸消散，時間差保留供計算。

## 功能與計時

- 煙火專用模型／瀏覽器檢查：11 項通過。涵蓋 2,000 組隨機題、氣溫聲速、顯示數值計算、音檔非靜音及削波、真實等待時間、延遲音效、估算回饋、鍵盤、同題重播、新題取消聲音、背景中斷、音效載入失敗與重試。
- 最後一輪碼表實測：顯示 3.00 秒，實際約 3.041 秒；顯示 2.00 秒，實際約 2.047 秒；顯示 6.00 秒，實際約 6.016 秒。差異為瀏覽器畫面更新粒度，沒有加速或放慢傳播時間。
- 音效在等待期間維持靜音，到達時才有實際 Web Audio 訊號。使用者手動按按鈕的反應時間不加入測距。
- 錄音起音原有約 0.061 秒低聲背景，已裁掉；衍生音檔前 20 ms 即有明確爆炸訊號。
- 桌機／筆電 1440、1280、1024 px 均檢查，左右欄正常、沒有整頁水平溢出。

## 既有教學內容

四組既有檢查共 65 項通過，包含鋼尺、鐘與粒子、抽氣鐘罩、介質及溫度聲速。更新其中原本依賴四題選擇題的小測整合檢查，使其對應新的煙火小測。
