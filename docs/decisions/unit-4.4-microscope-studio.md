# 第九區：直立式複式顯微鏡

日期：2026-11-05

依核可示意圖，將原本兩片透鏡的水平展開圖改為直立式顯微鏡剖面。以可縮放的 SVG 材質、玻璃、鏡筒剖面、轉換器、載物臺、玻片、聚光器及底座照明呈現器材構造，保留固定的簡化有限筒長成像配置。

三步依序突出物鏡先成實像、目鏡觀察中間像及完整接力。第一步的右側窗標為中間實像，後兩步改為透過目鏡看到的虛像。中間像是空間中的成像位置，不是鏡筒內的實體屏幕。右側最終圖案仍相對原物倒立，補充說明區分它與視網膜成像。

以既有 microscope() 計算物鏡、中間像與目鏡關係，新光路模組依相同兩透鏡配置求解進入眼睛的代表光線。實線前向光路保持連續，虛線反向延長至同一最終虛像；紅、藍持續代表原物上、下端。輔助光路預設關閉，切步驟保留光路與物點選擇，重設恢復第一步。鏡片以等效薄透鏡近似，不逐面模擬多片鏡組與聚光器，外形及放大圖案不作器材尺寸量測。

副標定位科學內容，操作提示在步驟控制旁；下方兩張概念卡說明與第三區實像、第四區放大鏡的概念關係。沒有改動其他學習區的光學與控制腳本。

驗證見 [審查紀錄](../reviews/unit-4.4-microscope-20261105/review.md)。

顯微鏡改用 `microscope-model.mjs` 的固定視角立體剖面：曲面機身、剖開的鏡筒與目鏡、玻璃鏡片、轉換器、載物臺、玻片、調焦鈕及底座。材質以環境反光與柔和燈光呈現，地面陰影交代位置。主圖定位與代表光線由相同世界座標投影到觀察平面，不為配合外形任意搬移成像位置；立體顯示不可用時沿用精簡的 SVG 剖面與全部操作。

## 圖內字形修正（2026-11-05）

使用者指出縮整主圖後，圖內文字被壓扁。原因是 SVG 為對齊立體投影採用非等比例的畫布縮放，連同文字字形一起改變比例。將三個定位標籤與 F 改成獨立 HTML 文字層，以模型投影百分比定位、正常像素字級呈現；備用剖面則計入 SVG 等比例置中的留白。ResizeObserver 在視窗尺寸改變時重算位置，文字僅平移，沒有字形縮放。

保留同一操作視窗與原成像計算。檢查見 [字形審查](../reviews/unit-4.4-microscope-type-20261105/review.md)。

依使用者要求，在分工說明卡後加入「兩組凸透鏡，接力放大」的結論：簡化模型中物鏡與目鏡皆為凸透鏡，前者形成中間實像，後者像放大鏡一樣觀察；強調依焦距配置原物及中間像的位置，不將顯微鏡說成只要擺兩片不同焦距透鏡即可。另簡短註明實際物鏡與目鏡通常為具有會聚作用的多片鏡組。實際檢查 1440、390、320px 的內容及換行，沒有水平溢出，原有預設光路保持正常。
