# 3.2 聲音示範素材

## 單元小測：煙火測距

- fireworks-night.webp 為依使用者核可示意圖製作的河岸夜景背景，天空未預先畫入煙火；煙火由 fireworks-renderer.mjs 的獨立 Canvas 圖層動態生成。每次只有一發，包含短暫白金爆光、三維球殼投影的不均勻金銀火星、冷卻尾跡、二次碎光、阻力與重力造成的垂落、擴散淡煙與同一煙火的水紋倒影。火星在遠方山脊與岸線漸隱，不會落到近景欄杆。
- firework-burst.wav 第二版以兩份真實煙火 CC0 錄音組合爆響、火花劈啪及回音，不使用泛用爆炸或合成噪音；來源、候選比較、起音裁切及重製命令見 AUDIO-SOURCES.md。
- 新挑戰從 0、10、20、30°C 選取氣溫，只提供聲速近似公式 v＝331＋0.6T（T 為攝氏溫度，v 為公尺／秒），由學生自行計算聲速；現場條件及回饋不代算聲速。不提供「需要計算提示？」入口與展開內容。時間差隨機為 2.00–6.00 秒，以百分之一秒記錄。背景核對同樣使用此公式與觀察時間差計算距離，接受整數四捨五入與約 1% 的估算。
- 亮光與碼表以 Web Audio 輸出時鐘為準，同時預約延遲爆炸聲；實際一秒對應顯示一秒。重播保留同題氣溫、延遲與煙火形狀；重新挑戰才換題，並取消先前預約音效。
- 互動由使用者按「觀察煙火」啟動聲音；切到背景時取消尚未完成的觀察，返回後由使用者重播。音效載入失敗時顯示可重試提示，不把無聲的流程當作已完成觀察。
- 頁面顯示的距離是爆炸點到觀察位置的直線距離，忽略光的傳播時間；這是教學估算，不是地面施放點的水平距離。碼表由系統記錄，未把操作按鈕的反應時間算入答案。

## 前五區素材

- `sound-story-opening.png` 為開場情境圖。
- `ruler-suspended-background.png` 是依原教室素材調整的背景圖：只有左側一張桌子，右側為桌外空間，避免把尺的懸空段誤看成搭在另一張桌面上。
- `ruler-parallel-assembly.png` 為現行透明鋼尺與夾具素材，原始尺身兩條長邊平直且平行；金屬紋理、反光與刻度保留在素材中。刻度供辨認尺身，並非量測互動。
- SVG 將素材分為不動的夾具／固定段，以及隨平滑曲線變形的懸空段；固定端位移及斜率為零，自由端位移最大。刻度與金屬紋理隨尺身彎曲，振幅隨時間衰減；按住停止時立即恢復靜止。
- 可直接點擊懸空尺面撥動，再點一次會重新撥動；觸控、Enter、空白鍵及下方播放按鈕均可操作。透明點擊區隨彎曲更新，背景與夾具不會觸發撥動。
- 尺身長邊依使用者指定，與畫面前方、最靠近觀察者的桌子前緣平行。整把尺面採同一平面投影呈現平放姿態；整組尺與夾具僅等比例縮放及小角度旋轉以對齊桌緣。靜止時懸空段不額外變形，避免夾持處折扭；只有撥動後才加入振動位移。
- 尺面點擊區關閉瀏覽器預設矩形焦點框與觸控高亮；鍵盤焦點僅沿尺身提示，不顯示矩形框。
- `metal-ruler-twang.wav` 為 CC0 金屬尺桌緣彈振實錄，頁面不需顯示署名。音檔已調整響度，固定以 100% 音量播放，不提供頁面音量滑桿，音量由使用者透過系統或裝置調整；連續點尺會從頭重新播放，按住停止會立即暫停並歸零，播放結束時恢復靜止。來源與處理方式見 [聲音來源紀錄](AUDIO-SOURCES.md)。
- 畫面刻意放慢並放大彎曲供觀察；聲音以實錄原速播放，兩者不作為實際頻率的量測模型。
- `ruler-clamp-background.png`、`steel-ruler-cutout.png` 及 `ruler-flat-assembly.png` 為保留的舊版素材，現行鋼尺示範不再載入。

## 第二學習區塊：聲音如何傳播

- 依使用者核可的版面示意圖呈現鐘、空氣疏密變化與耳膜。`sound-bell-ear.png` 是本次產生的透明教學素材；SVG 分別取用鐘與耳部，文字、箭頭、粒子和耳膜振動為獨立圖層。
- `sound-propagation.css` 提供全寬圖解與手機版空氣放大視圖；手機放大區透過 SVG `use` 共用同一組粒子，無第二份動畫時間軸。
- `sound-propagation.js` 使用延遲相位的一維縱波示意。每顆粒子有固定平衡位置，位移不超過 ±22 圖形單位，三列同步形成密部／疏部；相位以每秒 315 圖形單位向右傳播，波長為 240 圖形單位。這是放慢的機制示意，不代表實際聲速、頻率或分子尺度。
- 初始粒子均勻靜止。敲鐘後先由鐘引發振動，再依距離傳到各粒子，約 2 秒後到達耳膜。鐘的示意振動依使用者選定錄音持續約 6 秒，整段於約 8 秒結束；粒子不會隨波一路移到耳朵。
- 橘色粒子有固定原位虛線與水平往返箭頭；密部／疏部標示各自追蹤同一個區域，只向右移動；接近耳朵前以 70 圖形單位的範圍逐漸淡出，離開後不再切換追蹤對象或跳回左側。手機同步位置、透明度與顯示狀態，再次敲鐘會重設標示。耳膜僅在擾動抵達後振動。
- 下方僅提供「敲擊鐘」按鈕；直接點鐘、按鈕及鍵盤 Enter／空白鍵均觸發同一敲擊動作。依使用者最新核可，聽到的聲音對應右側耳朵：`bell-reception-audio.mjs` 在點擊事件解鎖音訊並解碼選定的 `handbell-strike.wav`（BELL 8B，CC0），用 Web Audio 輸出時鐘預約在傳播抵達約 2 秒時播放。鐘聲與耳膜同步開始，約 6 秒錄音播放完成時，耳膜也停止。原速、原音高及 100% 輸出保持；依錄音的平滑衰減外形降低視覺振幅，不用於聲壓量測。
- 連續敲擊取消舊的預約音效及動畫，重新從聲源開始。背景分頁凍結時間並停止音效，返回時依原傳播位置、剩餘等待時間及錄音段落接續；初始不自動開始。音效載入或裝置中斷時顯示重試訊息，不呈現已聽到聲音的假結果。來源與處理方式見 [聲音來源紀錄](AUDIO-SOURCES.md)。
- 瀏覽器操作檢查見 `tests/unit-2.2-sound-propagation.test.cjs`；畫面對照紀錄見 `docs/reviews/unit-2.2-card02/`。

## 第三學習區塊：可操作的真空鐘罩

- `vacuum-tabletop-lab.png` 依最新核可的桌上型分貝儀示意產生乾淨器材底圖；由左至右為分貝儀、完整玻璃鐘罩、電鈴、幫浦、管線與指示表。分貝儀與鐘罩之間保留間距，外殼、底座及接觸陰影直接融入同一張實驗桌；照片內沒有固定讀值、狀態文字、粒子或表針。
- `vacuum-lab.css` 沿用本頁第一區塊的教學卡片版型，提供器材上的原生按鈕點擊區、電鈴開關與下方控制；手機版開關換行，圖上點擊區至少 44×44 CSS 像素。沒有音量或空氣量滑桿。
- `vacuum-lab.js` 將電鈴電源、相對空氣量、抽氣／進氣分開管理。點擊幫浦或抽氣按鈕逐步減少空氣，再次點擊停止；進氣閥／放入空氣逐步恢復，切換方向會取代前一動作。到抽氣下限時只限制空氣量，不自動結束抽氣模式；圖上幫浦與下方按鈕維持啟用及「停止抽氣」狀態，使用者仍可停止、再啟動或改為進氣。
- 空氣範圍 0.02～1 僅供內部定性模型，畫面不顯示百分比或壓力數字。依使用者最新指示，鐘罩內不再繪製代表空氣的藍色粒子，保留透明玻璃的寫實外觀；透過鈴聲、分貝儀及空氣指示觀察抽氣／進氣的變化。
- 電鈴開啟時敲錘持續動作，與空氣量無關。聲音經 Web Audio GainNode 連續調整，滿空氣時增益 1，接近真空時約 0.0133；這是定性聽覺對照，並非實測壓力公式。播放器固定 100%、不改音高；沒有依賴行動瀏覽器可能忽略的 HTMLMediaElement.volume 來調整實驗音量。
- 初始不自動播放，使用者開啟電鈴才建立音訊圖並播放本地 `electric-bell-loop.wav`。同一播放器循環使用；抽氣不重啟聲音、關閉立即停止，快速切換以請求序號避免舊播放承諾干擾新狀態。離開區塊或分頁時停止操作及聲音，空氣量保留，返回不自動開聲。
- 圖下注記區分接近真空與理想真空，保留可能經底座傳遞的微弱振動。來源與音檔處理見 [聲音來源紀錄](AUDIO-SOURCES.md)。
- 瀏覽器檢查：`tests/unit-2.2-vacuum.test.cjs`；核可示意與畫面對照：`docs/reviews/unit-2.2-card03/`。

### 罩外示意分貝儀（2026-10-28 修訂）

- 使用者核可桌上型數位分貝儀，放大尺寸並與鐘罩拉開距離。現行分貝儀整合於場景左側，以 SVG 顯示「分貝儀」、紅色七段數字與 dB 單位；數字與無障礙 output 共用實際音訊 RMS 讀值。已移除右側／圖下的獨立儀表區，手機版也維持同一張實驗桌。
- 音訊路徑為媒體 → GainNode → 聲道分離 → 各聲道 AnalyserNode → 聲道合併 → 輸出。逐聲道取得調整後的波形能量，再合成 RMS，避免立體聲相位差造成單聲道相加抵銷；不改變原有左右聲道。
- 以電鈴錄音雙聲道全段 RMS 作「約 70 dB」示意參考，讀值為 `92.3276669648 + 20 log10(RMS)`。每約 0.1 秒取樣，能量以約 0.16 秒時間常數平滑。這不是校準過的 SPL 或 dBA，不代表使用者喇叭與現場分貝，也不取用麥克風。
- 顯示整數，七段筆畫依讀值更新（顯示範圍 0～99 dB）；關閉電鈴、播放尚未開始或訊號靜音時清為「—」，不將 0 dB 當成無聲。若未來更換電鈴音檔，須重新核對示意參考值。
- 原狀態文字只保留在輔助科技的禮貌通知區，正常畫面不重複顯示，播放錯誤時才顯示提示；分貝數字不作持續語音播報。

- 依使用者指示，電鈴狀態、進氣閥、幫浦上的深綠色說明標籤及指示線維持移除。原生操作按鈕保留無障礙名稱，並依新底圖重校幫浦／進氣閥命中位置、敲錘與表針。
- `vacuum-apparatus.png`、`sound-level-meter.png` 保留為舊版器材素材，現行頁面不再載入。最新核可示意見 `docs/reviews/unit-2.2-card03/approved-tabletop-meter.png`。

- 寫實修訂：移除第三區塊的空氣粒子生成、繪圖群組及專用裁切區，註記改為「振動放大示意」。第二區塊的縱波粒子模型維持其教學用途，兩區呈現方式分開。

## 第五區溫度與進度對照

目前由 `temperature-chamber.mjs` 繪製兩個相同高度的透明空氣腔體，固定比較 0°C 低溫組與 80°C 高溫組。依使用者最新指示移除全部調溫按鈕及控制程式，溫度直接列於組別標題；控溫底座、探棒、電纜與讀值窗維持移除。音叉沿用第四區同一繪圖函式、叉臂與金屬材質。五公里距離依下方尺規解讀，並非實物腔體尺寸。

`temperature-control-unit.png` 為上一版依核可示意產生的 1743×902 RGBA 透明底素材，保留原圖及歷史核可圖 `docs/reviews/unit-2.2-card05/approved-concept.png`。依使用者後續要求，現行頁面已撤下分離的器材照片和獨立溫度計，不再載入此圖；角色維持共用正式頭像。

固定組別以同一聲速模型運作，沒有調溫動畫或切換。`temperature-progress.mjs` 僅在下方保留一條刻度：藍色圓點為 0°C、橘色圓點為 80°C。兩個讀數固定並列於刻度下方，左側 0°C、右側 80°C，僅更新距離數字，圓點、讀數色點及組別標題使用相同配色；不再讓文字跟著標記移動，亦移除上方重複圖例。桌機進度區由 116 px 縮為 84 px。兩組共用現有實時時鐘，空氣聲速以固定組成乾燥空氣的絕對溫度平方根關係近似。五公里首次抵達約為 15.102／13.281 秒，差距約 1.820 秒。既有第五區 review 的 fixed 紀錄保留為前版歷史。
