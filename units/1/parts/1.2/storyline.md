# 1.2 故事線規劃

**狀態：已和使用者確認，後續製作以此版本為準。**

## 與前後單元的連接

- **承接 1.1：**學生已知道，看見物體需要有光進入眼睛；光可能先照到物體，再反射進眼睛。
- **1.2 的焦點：**光遇到表面後如何反射，以及平面鏡如何形成影像。
- **銜接 1.3：**1.2 收束在鏡面反射如何改變光的方向；1.3 可從物體放進水中看起來位置改變的現象開場，探索光進入不同介質後的折射。

## 故事開場

阿公拿出兩面小鏡子，準備和小葵做一支能看見牆角另一側的簡易潛望鏡。桌上還放著一面鏡子和一張白紙。小葵照鏡子時，發現鏡子裡有清楚的自己，白紙上卻沒有，於是開始探索鏡面如何改變光的方向、影像又出現在哪裡。

開場先用客觀敘述交代情境；小葵的好奇和提問從第一個學習區塊開始。

## 學習區塊與核心問題

| 區塊 | 核心問題 | 故事與概念進展 |
| --- | --- | --- |
| 1. 鏡面和其他表面 | 為什麼鏡子能映出清楚的影像，白紙或牆面卻不行？ | 從 1.1 的反射概念往前一步：光照到表面會反射；平滑鏡面的反射方向較整齊，粗糙表面則讓光往不同方向散開。 |
| 2. 光在鏡面上的反射 | 光照到鏡面後，會往哪個方向反射？ | 改變光線照向鏡面的方向，觀察入射光與反射光；引入法線，整理入射角等於反射角的規律。 |
| 3. 影像的位置 | 鏡子裡的影像真的在鏡子後面嗎？它離鏡面多遠？ | 用反射光線及其延長線說明平面鏡中的影像看起來位於鏡後，並探索像距等於物距。 |
| 4. 平面鏡成像特性 | 鏡中的影像和本人有哪些相同或不同？ | 整理影像正立、大小相同，以及影像和物體相對鏡面對稱等特性。 |
| 5. 潛望鏡任務 | 兩面鏡子要怎麼擺，才能讓牆角外的光進入眼睛？ | 將反射規律應用在兩次反射，完成簡易潛望鏡；以本區塊結論收束，不在結尾另加無關的新問題。 |

## 收束與轉場

1.2 的結論聚焦在兩件事：鏡面依照反射規律改變光的方向；平面鏡形成正立、等大、與物體相對鏡面對稱的虛像。接下來的 1.3 從水中的物體看起來位置改變開始，轉向光進入不同介質時的折射。
