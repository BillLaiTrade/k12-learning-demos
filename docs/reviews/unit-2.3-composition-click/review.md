# 第二區主圖色格直接點選

日期：2026-10-30（臺北時間）。使用者要求看比例／看混合時，主圖色格也能點選並產生與右側氣體名稱相同的效果。

- 100格改為具名稱的原生按鈕，主圖由圖片語意改為操作群組；全部資料仍預存，無JavaScript時按鈕停用但保留完整圖。
- 綠格選氮、黃格選氧，與圖例共用選取、突出及說明。主圖與圖例雙向同步，切換排列保留選取，顯示全部清除突出與選取。
- 斜紋格合併氬與其餘少量，點選後同時標示右側兩項與放大圖兩部分，說明合計約1%、氬占全部約0.93%，不把整格當成氬氣。右側仍可分別選氬／其餘。
- 滑鼠與觸控皆可操作；主圖只有一個Tab停點，方向鍵依目前畫面位置移動、Home／End至同列頭尾，Enter／空白選取，Tab直接離開主圖。
- 調整原生按鈕樣式，維持氣體配色、格子大小及混合換位，避免通用hover／pressed樣式覆蓋。沒有新增套件。
