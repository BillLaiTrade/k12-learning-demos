# 船上的獨立測深圖

2026-10-31。使用者釐清上方是看得到真實海床的觀察視角，船上人員只能根據回波資料判斷；要求把累積連線畫在另一個地方。

橘線從海洋場景移至下方「船上的測深圖」。圖中沒有真實海床圖片或地形輪廓；初始空白，收到第一筆顯示A，至少兩個位置才依左右位置連成直線。尚未收到回波的點不進圖，同位置取最新完成值，表格保留每筆紀錄，清除一併刪除。垂直軸為探頭到海底距離，橫向是探測位置；點間標明直線估計，取樣密度越高可觀察更多細節。

本機聲納／模型18項、點船6項通過；新增檢查空圖、單點、等待回波、圖層歸屬、左右排序及清除，並檢視桌機與手機兩筆測深畫面。原圖表說明與橘線保留的歷史紀錄，均以本輪獨立圖為最新決定。仍為第四階段，公開驗證另記。
