# 第四區五項外觀與加料細節修正

2026-11-01，使用者先逐項彙整，再明確要求五項一起修正。本輪以最新公開版本為基礎；其他五區HTML逐段不變（preservation.json），七步流程、玻璃片封存、圖下單鍵、固定說明、器材介紹、背景點按與五點整理維持。

1. 管路造型與擺放：材料頁不再是尖拱加水平長L形，改成較平緩的定長軟管垂落與分開擺放的固定玻璃管。
2. 塞子精度：使用原寫實圖完整頂面與錐形側面，校準瓶口內徑、深度、中心及瓶口前緣遮擋。
3. 材質畫風：玻璃取原玻璃素材，軟管使用新增真實紋理，不再用雙色描邊線充當玻璃或橡皮管；仍保持剛體與定長。
4. 加大理石：瓷碟保持水平留在桌上，錐形瓶先傾斜28度，鑷子夾取五塊石塊、逐塊輕放再沿低側內壁滑入，最後扶正。工具從畫面邊緣連續進出，空碟用完撤走。
5. 加稀鹽酸：瓶身保持在錐形瓶外，按實際素材口部位置計算試藥瓶旋轉與平移，液流由該口流入錐形瓶口；不再從瓶身流出。

新增透明材質／鑷子圖集由image_gen參照既有素材生成，原檔納入；規格、雜湊與取樣方式見assets/README.md，未新增套件。六張無JS代表圖與器材文案同步。
