# 4.5 第三區：正面白幕與直接拖曳手電筒

日期：2026-11-03（臺北）。使用者先要求分析、同意後才實作；接著指定正面觀看、彷彿拿三支手電筒照向同一白幕，核對生成版面示意圖後，確認直接拖曳下方各手電筒調整照射方向，並於本輪明確要求依圖製作、使用正式小葵與阿公圖像。本輪已獲製作與既有提交／部署流程授權。

第三區以正面單一白幕為主，下緣三支手電筒。採Canvas 2D加原生HTML／SVG操作，不新增套件；不沿用側視器材、不加旋轉視角、右上重複預覽、放大視窗或空氣中的色柱。三個光斑沒有拖曳圓點或文字遮擋。正式角色沿用shared-assets/characters/dialogue-character-avatars.png的左右半幅與既有對話CSS，不用生成示意圖中的替代角色，也不修改共用圖檔。

初始三燈開啟、部分重疊，能看到單色、兩色與三色共同區。直接抓下方任何一支手電筒拖動，依抓取時偏移改變該支的白幕落點，SVG燈頭同步轉向，光源基座與抓取區保持分開。完全重疊仍可個別操作；關燈仍能調方向，亮起時使用保留落點。方向鍵等效、Escape或觸控取消回復該次拖曳前狀態。光斑分開／部分重疊／完全重疊只改排列，不自動打開已關閉的燈。畫布固定1000×560且CSS兩軸同倍率，手機不拉伸圓形。

使用650／530／460nm，與第二區波長一致；第三區另外計算各燈的功率配比，與第二區等總入射功率的比較條件不同。以既有CIE1931資料解三個正光源功率，使XYZ相加對應D65白點(0.95047,1,1.08883)。相對功率約2.21418、0.841322、0.631057，固定於全程。每個像素先加總光譜色度／線性貢獻，再以固定曝光與背景轉sRGB及色域裁切，不以三個任意等功率色燈保證混白，不把RGB三通道直接當成三個波長。

以理想光束整形定義幕面圓形足跡、固定半徑180畫面單位、平頂及7%柔邊，移動保持照度分布；此為控制變因教學模型，未冒稱一般裸手電筒斜照時不會變橢圓或不隨距離變暗。器材外觀為操作示意，顏色／亮度受顯示色域限制，沒有宣稱校準照片。限制及光譜混合意義放在摺疊模型說明。

保留兩段引導與小葵觀察，不重複結果框；小葵觀察與無障礙狀態依實際光斑交集及開關更新，避免關燈後仍顯示三色混白。原有其他教學區與唯一小測內容保持，仍為第四階段逐區修訂。檢查包含光譜配比、幕面圓形／平移、交集、分開排列、開關保持、瞄準向量、正式頭像、滑鼠／觸控／鍵盤、取消、七寬度與整頁回歸。
