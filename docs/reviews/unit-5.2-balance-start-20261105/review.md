| 情境 | 預期結果 |
| --- | --- |

| 開始前滑鼠／觸控貼合、鍵盤移動 | 可改位置；不更新溫度、不顯示傳熱流光。 |

| 重來 | 回到60°C／20°C與原始位置，時間0，等待再次開始。 |
| 長時間觀察、分開／再接觸 | 保留原有環境交換、接觸傳熱與最終25°C整體平衡。 |
