# 4.4 局部對齊 4.1 共用格式

使用者限定本輪只處理 4.4；4.2 由另一項工作對齊 4.1。本次以 4.1 現行共用格式為依據，取代原本以 2.2 作為排版參照的測試。

- 頁面上限 1120px，桌面左右至少20px；1100px至761px採205px導覽與24px欄距；760px以下保留單欄、620px頁寬上限及12px左右留白。
- 一般文字採相同中文字型順序、文字色與淺灰綠背景。學習卡原有20px圓角、標頭／正文內距、編號牌與底色保留。
- 九個學習區的頭像改為48px；獨立小測保留原44px頭像。
- 一般按鈕採13px圓角、750字重、44px最低高度與共用留白；一般鍵盤焦點改為金色。實驗專用控制沿用各自樣式與狀態。
- 網頁HTML只有共用CSS快取版本變更，所有正文、DOM、ID及腳本逐字保留；沒有修改光學模型、器材、互動、個別實驗CSS或4.1／4.2頁面。

驗證：更新既有整頁測試的4.1參照，23項全數通過。另以1440、1024、390、320px實際比對共同樣式數值、一般按鈕與金色Tab焦點，檢視頁首、眼睛、平板虛像與窄版首區截圖。
