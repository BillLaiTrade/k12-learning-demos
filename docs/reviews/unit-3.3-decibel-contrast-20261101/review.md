# 第七區加大相對音量差

2026-11-01，使用者回報書房到施工的聲音內容有區別，但音量差不夠明顯。檢查現行 WAV 及播放鏈，確認送出增益為1，舊版每級2 LU，書房到施工16 LU；施工尖峰已達-3 dBFS，限制了平均響度。

沿用所有原作、片段、來源SHA-256與授權；共同 -23 LUFS 基準後改用分段相對響度，主要每級3～4 LU，最高三段約1 LU。四倍過採樣限制突發峰值，關閉自動增益補償，保留邊界淡入淡出，未變速／變調。頁面來源修改告知、衍生授權與重製腳本均更新；前版不作峰值動態處理的限制由本次決策取代。

完整十二場景前後對照見 comparison.json。書房至施工由16 LU拉開至26.89 LU，施工提高7.49 LU，書房僅降低3.4 LU。全組最高真峰值-3.48dBFS，低於舊版-3dBFS；提升的是吵雜段平均響度，並控制突發峰值，沒有削波。這是教學用數位音量安排，不重現圖示dBA，也不保證不同設備的主觀響度或聽感倍數。
