# 四項播放器與重點整理修改整合

2026-11-01，使用者先彙整後一次授權製作。第三／第四區採一致配置：

1. 重點整理維持五項，改短標題與核心原因，減少列距，保持16px內文字級。氧氣催化劑保留加快反應、不增加最終產氧量及不消耗等核心，移除回收程序與含氧元素釐清；第四區保留反應物、接觸即產氣、排氣、向上排空氣與撤管蓋片。
2. 單一播放按鈕由右側移到主圖正下方、畫面說明上方，右側只留步驟。按鈕狀態仍是播放／暫停／繼續／重新播放，沒有第二套控制。
3. 控制列旁固定顯示「點畫面空白處，也可暫停／繼續。」窄版換至按鈕下方，不遮住圖片。原背景直接點擊、器材介紹優先、捲動／選字排除、跨播放器互停保留。
4. 材料頁從一開始就有固定畫面說明，靜態文字無動畫；同一控制列與字幕DOM沿用於每個步驟，不在開始播放時新增說明區。手機輔助近景放到主播放器之後，保留互動，不隔開主圖與播放列。另修正中等寬度第四區因文字而縮窄的容器，填滿可用寬度。

新增共用experiment-player模組／樣式，字幕使用固定宿主並支援材料頁靜態文字；化學模型、動畫時序及器材素材不改。其他四個區塊HTML逐段一致，見preservation.json。

## 驗證與尺寸

新增player檢查1440、1024、768、390、320px兩區八個步驟：只有一個播放鍵、圖片→控制→說明順序、材料頁說明與無字幕動畫、固定提示、五項精簡文字、主圖與控制列相對位置／高度一致、無溢出。原oxygen、co2、canvas-tap、captions、equipment與full涵蓋播放／續播／重播、器材介紹與觸控、背景、字幕閱讀及唯一小測。

本機整合73項中，一個氧氣舊斷言仍要求按鈕在場景外，因此該子項與外層失敗；其餘六套62項通過。依使用者核可的新播放器位置更新該斷言後，氧氣11項另跑全部通過，合計73項不同檢查均完成；兩份原始輸出為integration-tests.tap與oxygen-final.tap，不將首輪失敗稱為通過。早期位置檢查已排除正常捲動，以播放器自身座標比較；五種寬度全部通過。

1440px整理高度：氧氣501.7→311.4px，縮短約38%；二氧化碳560.9→341.0px，縮短約39%。390px分別835.3→609.3px、924.1→638.9px。字級保持，before.json與measurements.json為本輪量測。已目視桌機初始播放器、手機初始說明與桌機精簡整理。
