# 第九區顯微鏡資產

`microscope-studio.mjs/css` 呈現完整成像與兩個局部近看入口。預設及重設顯示整台顯微鏡；近看物鏡或目鏡時，完整關係線保留並突出對應範圍，可返回完整成像。兩個入口、鏡頭標籤及下方分工卡共用切換，保留輔助光路與物點偏好；初次載入與重設均開啟輔助光路。

`microscope-model.mjs` 使用單元既有 Three.js 製作直立式立體剖面，材質環境由程式生成。光路與正常字形的 HTML 標籤依同一相機投影；位置小圖為同模型的全貌快照與取景範圍。模型不可用時，SVG 備用剖面仍支援近看及返回。

`microscope-optics.mjs` 依既有 `optics.mjs` 的兩透鏡配置計算連續代表光線。物鏡近看呈現中間實像，目鏡近看及完整成像呈現目鏡的虛像。同一個中間像示意框持續存在，依觀察範圍標示為物鏡的實像或目鏡觀察的物體；比較圖把物鏡形成的中間像原樣帶入目鏡觀察。光學位置及參數不隨取景變動。

`microscope-specimen.mjs` 共用草履蟲固定玻片的輪廓、單側口溝及內部構造，提供比較窗、中間像放大示意、備用剖面與載物臺材質。物鏡成像整體旋轉180°，目鏡不再翻轉；顏色、構造及大小為教學示意。介面直接使用「中間像」，沒有額外代號或重複結論卡。
