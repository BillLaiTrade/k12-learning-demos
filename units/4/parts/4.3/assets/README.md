寬版在1200×600畫布上，採玻璃內面左右70／915、上下190／494；直立版在660×720畫布上，採59／600、199／609，現行四層的層高皆為內面高度四分之一。兩者以相同尺度映射x、y光學座標，保持真正角度，並非拉伸光路。透明光源以原圖約(550,1280)作出光口中心，映射局部(0,0)後再旋轉及平移；低調發光疊在玻璃口內，照片本身不含光跡。

這些是教學用寫實圖稿，物理計算獨立於圖像；排序、速度數據與光路由原純模型產生。圖稿載入失敗時仍可使用向量備援。
