# 第六區移除重播光路按鈕

2026-11-04。依使用者指示移除「重播光路」。左圖工具列只保留光路／輔助線開關；光路、方向箭頭及視位置依水位與眼睛位置直接完整更新。

一併移除只供重播使用的事件、光線播放進度、部分光線裁切、模式切換、按鈕樣式與說明文字。保留原水位動畫時鐘，持續加滿／放空、途中反向、手動接管、離屏續播及減少動態保持。沒有調整固定鏡頭、物理模型、右側光線追跡或照片。

更新既有預設檢查為按鈕不存在、只剩加水與放水，移除過時的重播專項。第六區瀏覽器專項由15項改14項（含外層），五檔完整組合由31改30項；本輪依範圍執行第六區與格式共19項，不把未重跑的純模型及整課描述為本輪驗證。證據見[本機檢查](../reviews/unit-4.3-depth-no-replay/review.md)。維持第四階段製作修訂，待使用者檢視，非最終核可。
