# 2.3 第二區氣體知識卡：緊湊排版與材質圖示

日期：2026-10-31（臺北時間）。使用者指出現行知識卡有大片多餘空白，要求更精緻的內部圖示與內容呈現。

## 修改

- 上方化學式／名稱／排行與占比改成同一資料列，比例放右側，消除原來集中左側的空白。性質卡收緊padding和段落，不再強制斷行；生活用途標題併入照片說明，仍在性質下方。
- 保留原單元字體、標頭與配色，三種氣體使用相應識別色。沒有加回金線／葉片或整張PPT海報，也未改變第二區切換方式。
- 用五張生成的透明材質插圖取代線條SVG，含玻璃、金屬／盾牌、不可燃標誌、水杯與燃燒木條，具立體光影與材質。氧氣助燃圖的燃料是木條；盾牌只是相對穩定的概念圖，文字仍限定一般條件。圖示為裝飾，輔助閱讀略過，全部科學內容保持HTML。
- 原用途照片、文字、比例及全部互動不變。`preservation.json`核對01／03／04／05整區完全未改，第二區所有文字完全相同；只是知識卡DOM中移動用途標籤及替換圖示。無套件或字型變更。

## 前後比較

`density.json`記錄相同1440px與390px視窗下三氣體的實際卡片尺寸：桌面832px寬，高492.406→352.5px（減28.4%）；手機328px寬，高621.484→484.9px（減22.0%）。不是把內容隱藏，也沒有縮小整張卡片寬度。`before-*`／`after-*`保存對照；`generation.json`保存原圖雜湊、切分格位與輸出大小，原圖未刪除。
