# 第三、四區薊頭漏斗改版：本機檢查

2026-11-02。依使用者明確指示，兩區改用薊頭漏斗，操作、動畫、器材及下方五點整理一併修訂；第六區排水集氣遷移任務同步更新液封安排。沒有改變第三區排水、第四區向上排空氣的既定收集法。

順序：先固體 → 雙孔塞固定漏斗與導管 → 由漏斗加液 → 液面淹過漏斗下端形成液封 → 先排空氣 → 收集與封存。薊頭漏斗為無閥長管，固定長度；先整根提起到瓶口上方，再平移對準後下降。試藥瓶口對準漏斗，並顯示漏斗內流線。新素材來源與雜湊記 assets/README.md。

正常速度各自走完氧氣1→2→3→4→5→6→7、CO2 1→2→3→4→5→6，兩者complete、無頁面錯誤，見realtime.json及材料／加液／完成圖。另以代表畫面檢視實際加液瓶口、漏斗下端和液面、雙孔塞、器材標籤；七種寬度由瀏覽器測試驗證。第1、2、5區HTML逐段不變，見preservation.json。git diff --check通過。
