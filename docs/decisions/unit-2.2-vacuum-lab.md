# 2.2 第三學習區塊：真空鐘罩互動模型

日期：2026-10-28。使用者核可鐘罩實驗示意圖後授權實作，並要求核對畫面與功能再交付。

採用獨立的電鈴電源、相對空氣量、抽氣／進氣三組狀態。幫浦、進氣閥與對應按鈕共用同一動作；再次操作可停在當下，切換方向取代前一動作。電鈴關閉不恢復空氣量，讓學生能分辨聲源與介質的作用。

空氣量為定性模型，畫面只顯示「充足／逐漸減少／接近真空」。以最遠點順序保留均勻分布的粒子，避免剩餘空氣集中在某一側；不宣稱粒子數與聲音增益是實測壓力關係。接近真空保留微弱聲音，以表達底座等固體路徑可能傳遞殘餘振動。

電鈴持續振動與音高均不因抽氣而改變。實錄聲音經 Web Audio GainNode 調整聽到的音量，兼顧行動瀏覽器對媒體音量設定的限制；初始不播放，使用者開啟電鈴才啟動音訊。離開區塊或分頁後停止聲音，保留實驗空氣量。

畫面以核可示意產生的器材底圖配合獨立粒子、敲錘與指針圖層；文字和操作均由 HTML／SVG 呈現。前兩區塊的互動與聲音作回歸檢查。核可圖、各狀態截圖及測試紀錄見 `docs/reviews/unit-2.2-card03/`。


## 罩外音量指示修訂

使用者核可移除重複狀態列，改放場景中的示意分貝儀。新增器材不改變罩內空氣表用途；LCD 讀值以增益調整後、逐聲道取樣的真實音訊 RMS 計算，再加上固定示意參考偏移。避免僅按空氣狀態切換假讀值，也避免立體聲相位抵銷造成錯誤量測。畫面與註記明確標示「示意分貝儀／非現場實測」，不宣稱絕對聲壓校準。

正常狀態列改為僅輔助科技可讀，保留真正播放失敗時的可見提示。關閉或無訊號顯示「—」。新增檢查在空氣量不變時暫停音訊，確保讀值隨訊號消失而清除；並驗證音量增益比例與 dB 下降量一致。
