# 3.2 第08項：敲擊只重播點選組別，其他暫停組保留

日期：2026-11-01（臺北）。使用者選擇 A：第四、五區暫停後點單一音叉，只讓該組從頭開始，其他組維持原暫停進度。

- 各組保留自己的暫停秒數、粒子與到達位置；個別敲擊不讓其他暫停組恢復。
- 原本已在播放的其他組繼續播放，未敲擊的組維持待啟動；同步比較的物理聲速與計時模型維持。
- 個別模式下顯示各組「已暫停」狀態；明確按「繼續觀察」才接續先前暫停的組別。
- 當本次播放組結束但仍有暫停組時，保留「繼續觀察」入口；「同時敲擊」重新開始全部，「回到起點」清除全部進度。

只修改第四、五區共用控制器的播放狀態及快取版本；錄音、聲速、距離、粒子模型、器材圖與其他區塊維持。
