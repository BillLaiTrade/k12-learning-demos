# 2.3 第三輪重審 B1–B9 決策

2026-11-04（臺北時間）。使用者逐項採用 B1–B9，B10、B11 明確不採用；延續討論後統一修改、測試及公開確認的流程。

- B1：製氧示範改為兩段固定形狀與長度的玻璃導管，以固定長度、可彎曲的橡皮管接合。塞端玻璃隨塞子移動，集氣端整段由倒置瓶口下方進出；介紹與八個無 JavaScript 代表畫面一併更新。
- B2：暫停時先立即同步當前畫面說明，固定文字與不透明度；繼續時保留實驗進度。播放中的閱讀停留與淡入淡出、連續播放及原有導覽維持。
- B3：移除第四區誤植且停用的「準備清水」器材；第三區排水集氣及第六區操作桌的清水保留。
- B4：以目前實際氣量、成分、容器內容及封存狀態提示與評分；重新集氣已達條件時立即引導撤管與水下蓋片，不再受已補救的歷史錯誤阻擋。
- B5：排水、漏水與溢流攜帶液體各成分和已反應量；依容器位置與流出位置進入接收容器，否則流到桌面。受錯誤藥品影響的容器要提示清空；允許錯誤操作，不因液體排空就假裝容器已清潔。
- B6：接近水域、出口實際位置、氣泡與觀察共用隨水槽移動及液位變化的透視水域；拖曳預覽仍不改變物量。
- B7：乾淨水槽的水可沿用，水位不足才補足；錯誤藥品或其轉移液已污染時，指出受影響容器與清空方式。
- B8：酸耗盡而石塊仍有剩餘時，先確認塞子、漏斗及導管；尚未裝妥就先引導組裝，再由漏斗加酸。重新裝設後仍需先排除引入的空氣。
- B9：補救提示依目前能執行的下一步排序：先恢復產氣，再準備集氣瓶位置與開口，之後才排氣與集氣；保留錯誤原因，但不在產氣停止或瓶口蓋住時要求持續通氣。

B10 不新增氣密性檢查的教學步驟或文案；B11 不新增驗滿方法的教學文案或動畫。預設觀察紀錄、結論與原播放方式保留。

## 模型及驗證範圍

玻璃與橡皮管使用固定的圖面長度；液位按各容器正規化，轉移時使用相對容量比例（水槽為集氣瓶的八倍液量尺度），不是實測毫升、速率或劑量。混合及溢流採守恆的教學近似，排水收集仍可能含水蒸氣，不以水蒸氣作錯誤判定。

測試涵蓋固定管形與管長、暫停／繼續、無 JavaScript 畫面、重新集氣後撤管封存、液體與已反應量守恆、酸液排入水槽、污染清理、水槽移動／液位與出口判斷、耗盡時的器材前提、封口樣本補救順序；另回歸桌機、鍵盤、原生手機觸控及六區內容。公開版須核對原生 Pages 部署和本輪更新檔案。
