# Part 3.1 本機 3D 與影像素材

本資料夾包含學習頁使用的量測場景程式、鉛筆示意圖及本機 Three.js 檔案。頁面不需連線到 CDN 才能載入程式庫。

## 量測場景

- `pencil-3d-viewer.js` 使用 Three.js 幾何元件建立鉛筆模型，不載入外部 3D 物件檔。
- 鉛筆模型長度設定為約 18.2 cm，供頁面示範刻度、估讀與視差；這是教學模型值，不代表特定市售鉛筆規格。
- `pencil.svg` 是單位換算陣列使用的鉛筆示意圖。
- 質量換算明確假設每支模型鉛筆約 5 g，僅用於教學示範，不代表一般鉛筆的固定質量。
- Three.js 版本：0.186.1。套件授權見 `vendor/three/LICENSE`（MIT）。
- WebGL 場景呈現鉛筆與觀察視角；頁面程式繪製直尺、刻度、投影線與讀值。

## 維護注意

若升級 Three.js，需同步檢查授權、模組相依與量測場景的視角及尺面對齊。若更換鉛筆模型尺寸，需同步確認畫面物件、尺面端點及讀值一致。
