# 3.3第五區波形必須與播放同源

2026-10-31，使用者核可音叉／吉他／排笛三列比較，要求波形不得任意畫出。選擇將最終音訊WAV的PCM解析一次，直接用該陣列建立AudioBuffer，並擷取同一陣列第200–210ms逐點作圖。

不沿用初版固定泛音係數畫樂器波形，不另做美化曲線或逐列自動縮放。所有圖共用10ms與±0.6相對訊號刻度；圖形與核可構想圖的細節不同時，以真實訊號為準。兩份樂器實錄調音至共同440Hz目標，音叉近似純音合成清楚標示。三份全段RMS固定增益近似匹配，保留原始起音／衰減與氣息；不宣稱校準主觀響度、實測振動位移或完整音色特徵。

吉他CC BY 3.0、排管CC BY 4.0來源與修改記錄隨檔提供；排管原錄器材為PVC封底管，非圖片中的竹製排笛。載入失敗保持空圖、可點播放重試，不能補一條示意曲線。自動預載只取資料，AudioContext與播放仍由使用者點擊啟動。

整合測試攔截真正啟動的Buffer，逐值對照WAV及每個圖形取樣；避免只檢查兩份重複實作、或驗證外觀卻沒有核對實際聲音。證據見docs/reviews/unit-3.3-timbre/review.md。
