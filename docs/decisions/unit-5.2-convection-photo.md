# 5.2 第四區：依核可圖改為寫實場景

2026-11-05。使用者核可寫實水槽／房間剖面示意圖，要求依圖開始製作。核可圖原檔及操作畫面保存在[本輪紀錄](../reviews/unit-5.2-convection-photo-20261105/review.md)。本次取代前輪純SVG器材與圓點的呈現，範圍仍為自然對流的水／空氣對照。

- 單一全寬場景搭配「水的流動／空氣的流動」頁籤；兩張無文字、無箭頭背景由image_gen參照核可圖生成，保留清水與透明空氣。素材為教學示意，非實驗實拍。
- 原生SVG繪製循環流線、六組寬尾箭頭及相對冷暖。箭頭沿流路實際移動，不將生成圖片上的箭頭當作動畫。水的遮罩限制在水面下；空氣遮罩排除暖氣機本體。冷暖表示同種流體的相對狀態，非不同粒子或測量數值。
- 控制與狀態放在場景下，單一綠底列呈現當下觀察；既有詳細觀察與示意限制收合，保留閱讀。標頭、開場／結尾對話、其他五區與小測HTML逐字保留，僅更新本區資源版本。
- 保留按開始才運行、停續、重來、換媒介清回起點、背景停止及減少動態下低速移動。照片載入成功前不接受開始，失敗能重試；晚到的另一媒介圖片不重設目前動畫。重試完成也不自動開始。
- 這是定性循環示意，非流體數值模擬或量測。不宣稱固定流路、實際流速、溫度或加熱所需時間；沿用室溫附近、下方持續受熱且向周圍散熱條件。
