# 4.3 介質名稱固定欄位

2026-11-05（臺北）。依[本輪決策](../../decisions/unit-4.3-label-alignment.md)，原程式在判對後只把最快／最慢名稱從中央切到左欄；改為全部名稱一開始即固定於同一名稱欄，保留牌內右側標記。

- 移除data-center-x／data-compact-x與判分時改寫名稱x的兩行；全部狀態沿用固定x。原500字重、字距及所有CSS不變。
- 專項5項通過（四尺寸及外層）：1440×900、1366×768、1280×720、1024×768。每種尺寸實際發射、錯序、正序、確認、重播與換題；比較待機／錯誤／正確／重播中／完成／換題的原x、螢幕水平位置、牌內界線及標記間距，24組狀態全部通過。見tests.txt、alignment.json與前後圖。
- preservation.json確認JS只有固定欄位與刪除條件左移，HTML只有版本變更；原CSS／字型、名牌／材質、光路／角度、模型與判分均保持。沒有重跑無關整課或光學模型。
- 本輪S01／S05／S09／S10／S12／S15／S18／S19／S20以定位與原作答流程檢查；S24本機完成，發布與公開證據補存規劃庫同名目錄。其餘未重新整單元驗收，正式範圍為桌電／筆電。

維持第四階段，非整單元最終核可。
