# 第九區：節點操作與實虛像辨識

日期：2026-11-06

上方五個節點改為原生按鈕：原物／物鏡選取物鏡近看，目鏡／眼睛選取目鏡近看，中間像返回完整成像。上、下入口同步；重複點選同一範圍不退出，點中間像或周圍空白可退出，保留原光路與物點偏好。

關係圖底色改為暖白、選取底色改為淡暖色，避開綠色標本。實像維持綠色實線輪廓，虛像以淡藍填色、虛線輪廓及淡藍虛線徽章辨識；方向、構造與放大關係保留。模型補充交代線型與顏色屬示意。

移除位置小圖與未使用的快照及取景計算。圖例高度貼合兩行文字，比較窗較高時由主圖分配剩餘高度，不把空間留在圖例下。

## 檢查

- 顯微鏡互動10項通過：原有光路、成像方向、上下入口、返回焦點、鍵盤及備用剖面，以及新增四個節點選取、重複點選保持、中間像／空白退出、偏好保留、暖色底、虛像輪廓與圖例高度檢查。
- 六種尺寸（1440×900、1366×768、1024×768、760×900、390×844、320×844）各三個範圍，共18個畫面通過；無橫向溢出、文字裁切、範圍錯位、標籤遮擋或瀏覽器錯誤。
- 圖例高度桌面約44px、手機約38px。1366×768的工作區約720–742px；320×844約812–813px，維持縮整後尺寸。手機上方仍有既有的學習路徑固定列，可正常捲動。
- 人工檢視桌面目鏡近看及320px圖像：實像／虛像配色與輪廓可區分，選取暖色背景清楚，兩框水平對齊，唯一中間像仍在共同範圍。
