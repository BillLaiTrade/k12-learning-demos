# 2.3 待用器材退至桌面後側與器材圖裁切

2026-11-04（臺北時間）。使用者確認：暫時不用的器材不能遮住動畫主要操作，可移到桌面後方；鑷子圖片應只顯示鑷子。此輪落實重審 C2、C3 的畫面修改，其餘盤點項目仍待討論。

- 製氧準備時，漏斗、塞子與未使用的管段移到後側，放在主容器後方繪製；集氣端到位後，組裝步驟再將源端與漏斗移至瓶口。玻璃片與尚未使用的試藥亦退至後側，不增加操作畫面高度。
- 二氧化碳示範使用相同原則；待用漏斗、管線、玻璃片與稀鹽酸避開加入大理石的動線。輪到組裝或倒酸時移至前方，試藥瓶使用完回到後側。
- 器材介紹視窗使用明確的圖集裁切遮罩，避免寬圖框左右留白露出相鄰物品。第四區材料桌的鑷子、漏斗一併修正；第三區漏斗介紹同樣採用裁切遮罩。共用原圖保留。
- 固定形狀與長度的玻璃管、橡皮管長度、反應與播放時間及封存順序維持；停用 JavaScript 的十三個操作代表畫面與近景同步。

驗證包含實際 SVG 像素裁切、待用管線所在範圍與前後層次、移至瓶口後的管長及液封、材料桌視窗高度、桌機／手機／無 JavaScript 畫面，以及既有字幕、完整製氣集氣與小測回歸。完成後依展示站流程推送並確認公開版。
