# 第三區依核可示意圖製作：充氮薯片包裝

日期：2026-10-30（臺北時間）。使用者核可[示意圖](approved-mockup.png)，要求不超出既有格式範圍，完成後回頭對照。

## 示意圖逐項對照

| 核可內容 | 實作對照 |
| --- | --- |
| 左概念欄、右側標題與內容 | 沿用既有lesson格式及寬度，未另加右側分鏡欄。 |
| 小葵／阿公上半部承接 | 空氣已有很多氮氣→比較一般空氣與充氮後氧氣差異；頭像、底色、字體沿用共用對話。 |
| 寫實兩袋比較、兩袋均鼓起 | 同一密封包裝圖集作左右參照，寫實桌面背景；不以鼓起辨識氮氣。 |
| 氧氣單色條 | 左21%為資料；右短條只作氧氣較少的定性示意，無固定殘氧百分比。 |
| 點右袋重播 | 直接點袋子，在原位置呈現原有空氣→充氮並排混合空氣→封口；左袋固定。 |
| 透明氣體與流向 | 動態箭頭標氮氣進入／原有空氣排出，不繪彩色氣體、不表示氮氣消滅氧氣。 |
| 三項性質與收束對話 | 無色無臭、一般條件下相對不易反應、不可燃／不支持一般燃燒；回到減少氧接觸與油脂氧化。 |
| 手機上下比較 | 依內容欄寬度切換；每袋有固定桌面，避免拉長背景讓第一包浮在櫃面。 |
| 不超線 | 1440／1280／1024／800／768／390／320px，初始及播放中逐一檢查主圖、兩袋、說明卡、對話、性質卡及流向標籤均在右側內容欄內。 |

已目視[桌機](desktop.webp)、[筆電](laptop.webp)、[手機](mobile.webp)、[桌機充氮中](flushing-desktop.webp)、[手機充氮中](flushing-mobile.webp)及[封口](sealing-desktop.webp)，與核可圖主內容及操作方向一致。審閱圖右側三張分鏡是動畫狀態，未另列成學生頁面的三張大圖。

## 實作與科學界線

新增`nitrogen.css`／`nitrogen.mjs`及生成桌面、透明密封／開口包裝圖集，照片與程式動態分離。圖集僅以ffmpeg無損轉存WebP保留透明度；沒有新套件。生成素材不是實驗實錄，播放時間和右側氧氣短條不是產率、流量、保存時間或殘氧實測。科學依據採既有教材補核及[RSC氮氣用途](https://periodic-table.rsc.org/element/7/nitrogen)。不新增反應方程式、保存天數／保鮮率、變色或小測。

預設兩袋、比較與性質完整可見，無JavaScript仍可讀。點右包重播取代原時序；Escape、離區及背景暫停，再點繼續；減少動態直接保留完成比較。初次驗證發現播放時新增狀態列導致背景縮放，已改成不占版面的輔助回報；固定左側參照播放前後影像SHA-256相同。
