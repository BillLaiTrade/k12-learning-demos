# 3.1八區改為2.1全寬卡片

日期：2026-10-31（臺北時間）。使用者在3.3更新後，明確要求3.1各學習區塊也採用2.1版型。

八個lesson-card全部移除概念側欄，改為lesson-head橫向編號／原問題標題／概念與提示副標，下方lesson-body使用完整卡片寬度。標頭編號、欄距、內距、字級、圓角及內容內距採2.1規格。整頁探索導覽及結尾任務維持，沒有改動教學內文、模型、控制項、SVG內容或圖片。所有script區塊逐字比較相同，結尾field-task至頁尾亦與製作前相同。

以check.cjs執行7組本機檢查，全部通過：8個卡片及2.1計算樣式對照；六種寬度1024／1280／1440／1920／820／390px的八區上下排列、全寬與無頁面溢出；單次／連續繩波、暫停及振幅；頻率與週期連動；波速參數與傳播進度；結尾任務未完成／正確回饋、自動換算及結果；無pageerror與資源錯誤。這是功能與版型檢查分組，不冒稱完整歷史測試套件。輸出見local-checks.json，桌機／筆電畫面見本目錄。

驗證腳本需既有Playwright／Chromium／Python，本機環境從/workspace/k12-learning-demos服務頁面；UNIT31_URL可指定公開網址。未增加應用程式依賴。仍維持第四階段，非內容最終核可或完整單元驗收；公開驗證另記於規劃repo。
