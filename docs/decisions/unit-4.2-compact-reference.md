# 4.2 緊湊操作區與小型正面參考

日期：2026-11-05。使用者核可緊湊示意圖，但要求刪除「稍向左／稍向右」，盡可能將主要操作與參考放在同一視窗。

- 保持單一自由觀看的3D畫面、原器材／光照／材質、上下左右拖曳及兩燈獨立開關。
- 唯一的「回到正面參考角度」移到主畫面右上方，取代整組三個預設視角。重設兩角度並開啟兩燈，不捲動頁面。
- 主畫面依視窗高度調整，兩燈開關使用緊湊列。下方200px完整參考縮圖搭配短說明，窄容器依比例縮小；不再使用第二個大型卡片、重複觀看位置列或額外分隔說明。
- 固定PNG沿用實際場景擷取；不將生成示意圖作為科學內容或產品素材。共用課程格式、核可對話及其他學習區塊保留。

驗證：第一區專項13項，包含光學幾何／像素、原生拖曳與觸控、按鈕不捲頁、無WebGL備援、六種寬度及五種常見視窗的完整操作區同時可見。較短視窗仍可自然捲動，不縮小觸控目標或限制操作角度。
