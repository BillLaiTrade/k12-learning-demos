# 第六區虛像可辨識度、遠近取景與縮放角度

日期：2026-11-07（Asia/Taipei）。局部修訂，維持第四階段。

## 使用者要求與實作

使用者明確指出是虛像本體太小；另要求點選較遠／中等／較近時，主圖切換合適的觀看尺度，並處理放大後顯得更斜的情況。

主圖按當前器材及F的範圍適配取景，近處拉近，遠處保留完整器材；位置尺連續移動時更新。相機位置保持固定，改由投影倍率縮放，旋轉及手動縮放偏好獨立；預設觀看高度降低。虛像使用原尺寸、位置與顏色，完整顯色並加入淡色輪廓光，位於輔助線之前；未加大虛線或改動光學倍率。

右側兩框仍為固定、相同的觀看尺度；主圖說明明示取景會調整，避免把觀察放大誤認為虛像的幾何倍率。既有局部放大、倍率讀值及關閉／焦點流程保留，另補上圖卡、虛像與凹透鏡的位置參照；位置及圖案尺寸由目前物距、像距與倍率計算。

## 量測與檢查範圍

以同一1440px桌機視窗、相同遠近觀察列量測虛像平面在螢幕上的高度與光軌斜度；另外驗證三個物距的虛像位置與倍率不變、滾輪縮放保留相機位置及方向、右側像素保持。

## 最終本機結果

- 光學模型與第五／六區瀏覽器檢查：20 項通過（section-final.tap）。
- 整頁回歸：23 項通過（integration-final.tap）。
- 新增檢查確認遠→中→近的虛像投影高度逐次增加、手動縮放時相機位置／方向與光軌角度不變、右側固定觀看框像素不變，局部放大位置參照的尺寸比等於光學倍率。
- 同一1440px視窗，虛像平面投影高度：遠15.55→18.92px，中25.27→38.07px，近43.32→68.54px。預設光軌斜度8.80°→4.12°；新縮放前後均為4.12°。
- 初次新增角度檢查將門檻設為4°，實測4.12°後調整為5°；縮放前後角度相等的嚴格檢查維持。整頁舊測試預期第五區反向延長線預設關閉，但目前已核准版本預設開啟，故更新該測試的切換順序；第五區程式未改動。保留先前失敗與最後通過紀錄。
