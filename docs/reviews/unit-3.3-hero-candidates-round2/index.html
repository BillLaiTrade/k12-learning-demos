從這個故事，怎麼走到七個學習區塊？

學習內容由故事接續的問題下方的學習操作
① 響度與振幅同一個聲音，為什麼有時大聲、有時小聲？固定頻率，比較振幅與大小聲。
② 音調與頻率聲音變高，是振動得更快嗎？比較頻率、振動次數與音調。
③ 琴弦的音調同一條琴弦，怎麼彈出不同高低的聲音？以簡化琴弦裝置，一次改變有效弦長或張力。
④ 空氣柱的音調長管和短管，吹起來會一樣嗎？以同類開口管，比較有效空氣柱長短與音調。
⑤ 音色與波形音高相近時，為什麼仍能聽出不同聲源？比較同音高的音色與波形；精確圖形在本區觀察。
⑥ 聽覺範圍只要有振動，我們就都聽得到嗎？延伸到人耳可聽範圍、動物高頻聽覺與超聲波。
⑦ 分貝的辨讀除了說大聲、小聲，還能怎麼描述？認識聲級資料與比較條件。
結尾小測能幫聲音展示台調出指定的聲音嗎？整合頻率、振幅與音色的設定。

首頁先呈現一個自然的聲音故事；聽覺範圍與分貝由後續提問延伸。B04以烏克麗麗與竹笛帶入音色，弦長與空氣柱的變因比較，仍使用③④區的簡化裝置。
