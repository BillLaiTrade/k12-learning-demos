# 3.2 第四、五區：一體音叉振動

日期：2026-11-02（臺北）。使用者認為固定下半部與獨立平移叉臂呈現拼接感，核可改為連續彎曲，並明確要求第五區同步、完成後提供畫面檢視。

- 兩叉臂及U形底部以同一條連續曲線繪製，金屬與高光共用路徑；叉尖反向運動，越近底部幅度越小，握柄交點穩定。
- 水中倒置音叉沿用同樣的連續形變；鋼材彈性接觸層沿右叉臂曲線貼合，保留原接觸位置。
- 第四區三組、第五區兩組與獨立預覽共用同一實作，同步資產版本以避免舊快取。
- 保留8Hz外觀示意、±1.5圖形單位、0.6秒敲槌；聲速、粒子、距離、到達時間、控制、音效及文案保持。外觀振動不是實際音高的量測。
- 舊測試中「叉臂直線平移、不形變」的斷言依核可行為改為連續曲線、底部與握柄保持銜接、反向叉尖、完整接觸高度貼合、暫停與重設。檢查兩區全部五支音叉。

不同物態聲速的常見趨勢仍在討論，未加入本次文案。
