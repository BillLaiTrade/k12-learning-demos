# 3.3 第四區慢載提示與取消

2026-11-01，使用者核可操作盤點第4項：排笛聲音準備時顯示「聲音準備中…」及「取消播放」，讓學生直接取消等待；準備成功後收起，保留原點管子試聽操作。

提示列放在目前管長／頻率下方。從啟動AudioContext到錄音下載／解碼期間維持可見，等待時不啟動吹氣與振動動畫，取消鍵支援鍵盤及觸控。取消沿用原播放請求編號作廢機制，並將焦點移回所選管子；背景下載可完成供快取使用，完成後不得啟動已取消的聲音。音檔、音高與振動模型保持。

播放成功、取消、回到起點、換管播放成功、離開區塊、分頁隱藏或播放其他區塊時收起準備列並清除busy狀態。失敗時收起準備列，沿用可見的錯誤與原管子重試；新一次等待清除舊錯誤。取消鍵只在準備期間出現，不改動其他區塊的播放操作。

驗證包含延遲resume與真正暫緩WAV下載、取消後釋放仍無啟音、重試、換管、重設、離區、背景、其他聲源與手機觸控。其餘盤點項目仍逐一由使用者決定。
