# 第五區主圖標示兩側角度，取消放大

2026-11-03。使用者認為不需放大，且雙向同時發光時一組入射／折射角易混淆；確認比照第三／四區直接標在主圖，沿用空氣側及水側的命名。

- 移除放大入口、視窗、淡化遮罩與對應控制；主圖整合角度扇形、引線及數值。
- 固定標「空氣側」及「水側／玻璃側」，綠／藍固定對應兩側，不因開A或B改用入射／折射名稱。任一燈開啟即顯示，雙燈全關及重設時隱藏；0°不畫不存在的角弧，數值保留0°。
- 共用原可逆幾何與角弧函式，半徑依場景與光源距離限制，標籤字級至少16px、引線連至角弧中點；不拉扁光路、不誇大角度。窄／短畫面預留標籤與介質切換的空間，維持同視窗操作。
- A／B獨立開關、兩端拖曳／方向鍵、0–35°、水／玻璃、保持燈態及載入競態／重試、重設保持；原可逆／共用模型及其他區不變。

更新功能與版面專項驗證兩側中立命名、所有開燈組合、真實弧線角度、16視窗64筆及正常時鐘操作；不保留針對已移除放大的舊假設。維持第四階段製作／修訂，待使用者檢視，非外部驗收或最終核可。
