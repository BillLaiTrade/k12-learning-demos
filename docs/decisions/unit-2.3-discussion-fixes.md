# 2.3 全單元檢視後的修訂決定

2026-11-03，逐項討論後使用者授權實作、測試及公開發布。

- 01：杯子完全浸水並放開即可旋轉，不要求額外隱藏深度。
- 02：維持預設觀察紀錄與結論，跳過操作仍可閱讀；不改為操作解鎖。
- 03：主圖粒子比例接近氮78%、氧21%、少量合計1%，不以增加少量粒子突出。
- 04：現有步驟／連續播放方式及相關文案不修改。
- 05、06：統一錐形瓶、雙孔塞與導管等名稱；杯子明說杯口方向；補列藥匙、鑷子。
- 07、08：以實際氣體量及成分判定集氣；倒液真正流入才更新水與氣體，取消保留實際內容物。
- 09、10：提示反映現象、原因與可行下一步；錯藥須清空，不叫學生混加；加清水屬流程偏差而非必須重做，與成果判定一致。
- 11：大理石有限且隨反應縮小、耗盡，區分補酸與補大理石。
- 12：未製氣／已收集未封口／已封口取出分別提示，補救只處理受影響部分。
- 13：導管出口依實際連接移動；水槽不牽動空氣中的出口，保留先撤管的碰撞限制。
- 14：接近只預覽，放開才執行，取消不改內容；維持寬容接近範圍。
- 15、16：清除舊按鈕、壺嘴等過時文案；觀察區說現象，下方說原因／下一步，避免整段重複。
- 17：成功後繼續模擬及操作，僅影響樣本保存時撤下成功狀態並可重新檢查；重做完全清空。
- 18、19：字幕隨步驟／暫停／重播同步；比對三至六區穿孔與遮擋，修正實際落差。
- 20A、20B：手機依現位置取景、邊緣捲動與提示可見；清除幽靈焦點，Enter／空白取用、方向鍵移動、Enter確認、Esc取消，共用滑鼠規則，不恢復輔助操作區。

反應時間、物量、粒子皆仍為教學示意，不宣稱精確濃度或實測速率。修改不涉及其他單元。
