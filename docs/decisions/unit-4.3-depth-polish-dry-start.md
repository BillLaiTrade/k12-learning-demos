# 第六區材質精修、空槽起始與加水觀察

2026-11-04。使用者要求第六區提高精緻程度、對齊前幾區風格，並由預設看見硬幣改為預設看不見、加水之後看見。本次取代2026-11-03版本「預設水深70、距前側80公分即可看見」的初始條件，不變更教學區與測驗區分工。

## 初始狀態及操作

- 預設及重設：水深0公分、觀看位置距前側130公分（世界x300），硬幣固定槽底；右側沒有硬幣像素，由前側不透光槽壁遮住實際光線。
- 水位範圍由40–100公分擴成0–100公分；無水採純空氣直線傳播，不計算假水面折射。左側不畫水面、法線、虛像或反向延長線；保留硬幣及止於槽壁的光。
- 新增「加水觀察」手動示範，約4.6秒由當前水位加到100公分。觀看位置與硬幣不動，兩幅圖共同更新；全滿再按會由空槽重播。手動調整、重設或重播光路會結束加水；離屏／隱藏保留進度、返回繼續。減少動態偏好直接切到加水後完整畫面。
- 可見結果仍由折射與槽緣交點產生，沒有設定某個水位即切換圖片。靠近後空槽也可能直接看見硬幣，會明示純空氣光路，避免把「無水必定看不到」當成通則。
- 預設不自動播放、沒有作答閘門。上方說明、核心結論與展開內容仍可直接閱讀；初始比較情境為「空槽被擋→加水後出水折射→光進入相同觀看位置」。

## 視覺細節

沿用第三至第五區的oblique-entry-water照片材質：木紋改取無直立玻璃反光的區域，側面槽框以同張照片的黑色金屬／玻璃框及底框裁切呈現，保留動態光路，沒有烘焙文字。硬幣增加邊齒、內圈與浮雕；眼睛加入虹膜、眼瞼及陰影。

右側保留逐像素幾何追跡，提高靜止畫面的解析度，補上面法線明暗、接觸陰影、木紋／深色金屬框、槽緣倒角、固定件、玻璃反光與水線；以較低解析度播放加水，完成回到清晰畫面。相機構圖向下微調，讓槽體底緣與接觸陰影可見；目標區域固定，不追蹤硬幣。外側背襯保持不透光，遮擋條件不因精修而改變。

區塊標題改用淺色銘牌、深綠文字與細綠邊；共用控制列採前面實驗的淺綠器材底座與凹入感，主按鈕加水、次按鈕重播光路。桌面雙欄／手機單欄、鍵盤及拖曳、光路開關、材質失敗重試、文字替代均保留。無新素材、外部依賴或服務。

## 檢查

新增無水的直線／遮擋／固定硬幣模型檢查，濕態驗證擴至1–100公分；瀏覽器新增空槽、加水不移動眼睛、真實幣像素由0變可見、離屏暫停與重設等條件。既有整課、格式、九種尺寸、原生觸控及部分幣面共線保持。證據見docs/reviews/unit-4.3-depth-polish/；維持第四階段，待使用者檢視。
