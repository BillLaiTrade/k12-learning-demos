# 4.5 像素電視：調色與補格使用不同目標

2026-11-04。使用者要求「調出指定顏色」與「修復缺少一格」可使用不同目標色。

第一任務初始仍為橙色；第二任務固定問號位置（第2列第3格）改為紫色：紅光弱、綠光關閉、藍光強。只換這一格的目標，4×4其他15格與第三任務8×8不變，避免做完第一題後直接套用同色就完成第二題。

紫色沿用三段亮度可達組合，統一放在PALETTE.P供第一任務的可選紫色與第二任務引用；初始目標分開，第一任務自由換目標功能保持，不另外限制學生選色或色盤重用。第二任務的目標顏色、名稱、提示、檢查、試調帶回與成功色票共用新資料，重設仍回同一紫色缺格。

HTML loader、loader匯入控制器、控制器匯入模型同步更新版本，避免公開瀏覽器沿用舊橙色目標。原調色、方向提示、色盤與三任務操作架構保持，無新依賴、素材或版面改動。

更新模型與瀏覽器現有檢查：兩個初始目標不同；橙色填入紫色缺格不算完成且提示關閉綠光；真正紫色可完成；紅色草稿提示加入藍光；試調帶回不自動覆寫；紫色成功加入色盤並可再選用；WebGL不可用仍能修復。完整8項模型與35項活動檢查的實際結果及公開部署記於主專案review。
