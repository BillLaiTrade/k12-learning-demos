# 3.2 單元小測：煙火離你多遠？

日期：2026-10-29（Asia/Taipei）。

使用者要求把原本四題文字選擇題改為貼近生活的單一任務，核可煙火測距的桌機示意圖，並要求煙火漂亮、確實有爆炸聲，而且每次時間差可隨機改變。桌機與筆電為主要設計對象。

## 核可設計的實作

- 左側河岸夜景與單發煙火動畫，下方顯示亮光／聲音事件、時間差、觀察與重新挑戰。
- 右側依序呈現現場氣溫與聲速近似公式、觀察紀錄、距離公式與作答。
- 初始按「觀察煙火」；觀察後「再觀察一次」重播相同題目。「重新挑戰」才重新抽取氣溫與時間差。
- 隨機時間差 2.00–6.00 秒；氣溫使用合理的 0、10、20、30°C。依使用者後續指示，聲速由學生以提供的近似公式 v＝331＋0.6T 計算，背景核對也使用相同公式。
- 煙火是獨立 Canvas 動畫，夜景背景沒有預畫爆炸。爆炸聲使用 CC0 真實錄音，依 Web Audio 輸出時鐘延遲播放；碼表與音效共用時鐘。
- 學生以「聲速 × 時間差」估算爆炸點到觀察者的直線距離，忽略光的傳播時間。支援空白、無效數值、錯誤、合理四捨五入與正確答案回饋。
- 新題、重播、背景分頁會取消舊的預約音效；音效載入失敗可重試，不會假裝已聽到爆炸。

## 範圍與檢查

只替換單元小測，前面五個學習區塊與導覽維持。更新既有聲速整合檢查中依賴舊四題選擇題的部分，新增煙火小測的模型、實際計時與音訊檢查。

## 第二版：煙火質感與真實火花尾聲

使用者檢視後認為動畫不夠真實、音效太像單純爆炸，要求重新搜尋煙火專用錄音。

- 重新搜尋並比較單發煙火、煙火劈啪和完整煙火秀錄音。採用 LukaCafuka 的 CC0 現場錄音 Firework Crackle，與原本單發煙火實錄組合；來源、未選理由與完整重製命令均記錄於 AUDIO-SOURCES.md。
- 第一聲爆響起點不變，0.7 秒後加入原速、原音高的真實火花碎裂聲，再自然消退。所有聲音都在亮光之後依題目延遲一起抵達，不加入會混淆計時的升空聲或多發連續爆炸。
- 動畫改以三維球殼投影安排火星，使用不均勻的速度、壽命、粗細及亮度，包含金銀色光點、冷卻微光尾跡、小碎星、受重力影響的垂落與擴散煙霧。
- 倒影來自同一煙火的即時圖層，經水紋切碎；火星在遠處岸線前漸隱，不穿過湖水或近景欄杆。
- 純時間函數繪圖保留相同題目的重播一致性。共用既有真實音訊／畫面時鐘，沒有把動畫速度因子帶入測距延遲。
- 不變更版面、題目模型與前面五個學習區塊。

## 學生自行計算聲速

- 使用者要求不再直接提供算好的聲速，只給現場溫度與公式。
- 現場條件改列 v＝331＋0.6T，明示 T 為攝氏溫度、v 的單位為公尺／秒。
- 計算提示、答錯回饋及答對回饋都不代算聲速；學生先算聲速，再估算距離，無須新增輸入欄位。
- 小測的答案模型改為相同線性近似公式，避免題面與核對公式不一致。0、10、20、30°C 四種題目的聲速與原先四捨五入的值相同，分別為 331、337、343、349 公尺／秒；這些數值只用於背景核對。
- 既有檢查中的舊聲速選擇器與提示文案預期同步更新，本次未執行測試套件。
