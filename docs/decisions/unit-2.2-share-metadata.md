# 單元 2.2：網頁摘要與分享預覽資訊

2026-10-30。依使用者要求補上網頁摘要、Open Graph 與 Twitter 分享卡片資料。

摘要涵蓋過濾、蒸發、濾紙層析、糖水配製、泳池 ppm 比例模型及未知樣本濃度小測，搜尋摘要與兩種分享資料沿用相同文字。分享標題沿用網頁標題「混在一起的東西，怎麼分開？」。

分享圖片使用既有單元封面 `assets/unit-opening-cover.png`（1672×941、PNG），以完整 HTTPS 網址提供，並附上圖片尺寸、格式及替代文字；Twitter 使用大圖卡片。正式網址與 canonical 沿用同章 2.1 的 `index.html` 格式，指向單元 2.2 的公開頁面。

資料直接寫在 HTML 的 head，分享服務不必執行互動程式即可讀取。
