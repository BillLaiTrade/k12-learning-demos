# 4.3 每次載入隨機首題

2026-11-05（臺北時間）。使用者要求四種介質每次載入時隨機，避免每次開啟都得到相同答案。

原因是既有題庫將首題固定為同一排列與40度入射，只有後續換題才洗牌。改為第一題也由全部24種排列洗牌後抽取，入射角同樣隨機採36／40度；每次載入建立新題庫。四種介質的材質、代表折射率與光路一起移動，正確答案仍由本題幾何模型決定，沒有另外打亂答案標籤。

沿用每輪24種排列各一次、跨輪不連續重複的換題規則。重新載入為獨立抽樣，不新增個人識別或持久儲存；同一題重播保留本題與作答，按換題才重抽。六個教學區、物理代表值、角度範圍、素材及作答回饋政策保持。

模型新增首題24種答案×兩種角度的受控亂數檢查，並逐輪核對不重題。瀏覽器以受控亂數反覆實際重新載入六次，從實際光路判讀答案並驗錯誤／正確作答；既有整課與小測測試改依當題光線／角度判讀，不再依賴固定首題。快取版本同步更新頁面、控制器及模型引用。
