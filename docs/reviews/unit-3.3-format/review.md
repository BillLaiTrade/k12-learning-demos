# 3.3 對照單元1.1的格式修正

日期：2026-10-30（臺北時間）。使用者要求先對照1.1並直接修正明顯格式問題。

## 對照與實際修正

| 格式項目 | 原3.3的差異 | 修正結果 |
| --- | --- | --- |
| 整體寬度與側欄 | 1200px頁寬、195px側欄，與1.1比例不同 | 1120px頁寬、桌機250px側欄、34px欄距；字體、紙色、文字色與1.1相同 |
| 教學卡片 | 125px概念欄、沒有學習重點，1100px就變上下排列 | 桌機190px概念欄、28px欄距、26px內距；補齊編號、h3概念、核心學習提示，右欄保留較大的h2問題 |
| 文字與對話 | 題目及文字偏小，頭像與角色姓名格式不同 | 標題字級、44px以上按鈕、人物頭像及對話色彩沿用1.1；操作說明放在人物提問之前，七區教學段落仍在原區 |
| 探索路線 | 只有概念短標、一般捲動不更新目前項目 | 各區完整問題標題、分開的編號與文字；閱讀捲動同步標示，目前小測用金色區隔 |
| 頁首與小測 | 缺圖說、教學內容總標題；小測樣式另成一套 | 頁首圖框／圖說、內容總標題與小測標頭／內距／金色標記對齊1.1 |
| 窄版操作與圖表 | 比較圖文字隨SVG縮小、窄版導覽離開畫面 | 圖表軸標與器材說明改為固定可讀字級；761～1100px概念欄150px、比較依空間直排，手機上下排列、頂部探索導覽固定並預留錨點空間 |
