# 5.2 第六區保溫比較：製作與檢視

2026-11-05。使用者核可示意圖後要求依圖及真空／輻射銜接討論實作。原圖保存在approved-mockup.png；決策見../../decisions/unit-5.2-insulation.md。維持第4階段，待成果檢視。

## 本機

- `local-tests.tap`：保溫／對流／輻射三套34項（含父測試），全過，無跳過。涵蓋新比較、實際路徑／圖表停續、載入錯誤／延遲、鍵盤、觸控／減少動態及既有小測。
- `local-layout.json`：1440、1366、1280、820、760、390、320px兩模式共14組，無水平溢位，完整圖表落在面板內，原生操作至少44px；`local-*.png`為實際完整面板畫面。
- 首次畫面核對發現手機圖表因aspect-ratio搭配min-height向右擴張，已設定明確寬度並加入全圖寬度斷言，最終測試通過。長面板截圖改用同寬的高視窗以完整容納面板，避免固定導覽被截圖拼接到面板中間；標示的原視窗高度仍用於量測。
- `preservation.json`：基準a394ccdc，第一至第五區與小測HTML、小測／導覽JS逐字保留。只替換第六區、增加獨立控制器與素材、抽離舊保溫控制器。
- `sources.json`：四份OpenStax來源HTTP200及實際摘錄。移除氣體傳熱、保留輻射與固體連接是依機制整合，無效能實測主張。工具環境沒有requests套件，改用標準urllib完成來源取得，未新增依賴。

## 視覺與科學核對

桌面兩瓶並排，手機每瓶與標示成組。兩種比較同型、同水量、同初溫、同加蓋條件；反射層比較同為真空，反射層僅位於面向夾層的環形區域。輻射波線跨夾層而非橫穿水；瓶口／底部仍有傳導。曲線同起點、B較慢下降，均朝室溫靠近，且無實測時間／即時溫度；曲線觀察窗結束後路徑仍持續，避免誤解為熱傳停止。
