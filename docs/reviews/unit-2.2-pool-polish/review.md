# 2.2 第五區泳池比例模型：畫面精修

2026-10-29。依使用者要求，改善泳池、食鹽與觀察窗的精緻度。

## 視覺調整

- 池壁及池底磁磚以公尺 UV 對應 25 公分接縫；補上分塊石材池緣、實際厚度、泳道底線與不鏽鋼扶梯。
- 水體保持原尺寸，分開處理吸收色、水面反射、波紋法線與池底光紋。正面以剖視方式保留水深標線；地面使用柔和接觸陰影。
- 深綠色秤量皿細化弧面、釉面反光、薄邊與落地陰影。食鹽顆粒加上封閉削角及輕微色差，單粒幾何以積分正規化為單位體積，避免改變質量。
- 食鹽排列增加固定錯層；顆粒數、密度、總晶體體積、實際皿徑與放大視野維持。份量外形仍是估算。
- 整份食鹽觀察窗改用固定標題列、重量標籤、5 公分尺規與整份放大文字；尺寸標線、份量定位點與容量標籤使用較細的字級和框線。

## 本次人工檢視

- 1440 與 1024 寬度檢視場景和完整第五區：池水、池壁、池緣、食鹽及尺寸標示可辨識，無水平溢出。
- 逐一點選 50／100／200 克：可見份量與結果同步更新，50 克約 0.5 ppm，200 克約 2 ppm。
- 瀏覽器操作未出現頁面 JavaScript 錯誤；容量資料仍為 100,000 公升，主場景／觀察窗的物件比例仍為 1。
- 濃度計算函式未修改。模組語法與差異空白檢查通過；本次未新增或執行測試套件。
