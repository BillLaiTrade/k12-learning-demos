# 第四區排笛自由吹奏

2026-10-31（臺北）。使用者核可排笛示意圖，後明確取消固定參照與兩個播放比較欄，要求自由點管吹奏、製作測試後交付公開網址。核可圖保留作外觀依據；實際畫面依最後指示移除參照，僅保留目前管長／頻率。

## 實作與對照

一組六根同管徑竹製排笛，長度40／35／30／26／23／20cm。點哪根就吹哪根，再點同根可重聽，換管先停舊聲；無固定參照、獨立播放欄或滑桿。原生透明按鈕貼合每根管，鍵盤Enter／Space與手機觸控可用。預設選20cm、外觀模式，無自動播放。切「看管內」時只切開目前選管，保留選管與播放進度。重設停止並回20cm外觀。

保留04全寬卡片、原角色頭像、提問、暖色桌面與竹管質感、編繩、選中標記、直接連到管口／封底的長度箭頭。素材pan-bamboo.png由image_gen依圖生成，原始PNG直接採用，以SVG視窗布局管口／管身／封底及不同長度，非整張示意圖嵌入。管內玻璃、粒子、往返箭頭與尺寸線為獨立圖層。第一至第三區及結尾小測維持，更新導覽標題。

## 物理與聲音

原兩端開口模型改為上開下閉排笛。理想空氣柱基本頻率343/(4L)，40cm為214.375Hz、20cm為428.75Hz，畫面四捨五入214.4／428.8。相同管徑、材質及發聲模式，忽略端點修正，不宣稱數字為實測排笛量測。

粒子沿管軸在原位置附近往返，封底位移零、往管口振幅增加；不是粒子一路流到管底。聲音與動畫共用AudioContext時間；畫面100倍放慢、位移放大，短管頻率為兩倍時動畫亦為兩倍。1.8秒合成管音、70ms起音／180ms收音，共同泛音與增益，RMS>0.45、峰值<0.92；不是排笛實錄，不改其他區增益。停止、重設、切區、離開畫面／頁面、隱藏分頁皆歸位，不自動恢復。播放失敗提供可見重試訊息。
