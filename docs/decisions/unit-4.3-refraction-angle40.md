# 第三／四區統一0–40°，聚焦折射比較

日期：2026-11-03。使用者指出全反射不是本區希望強調的內容，討論後明確指定「第三、四區統一改為0°–40°」。此決策取代前輪0–90°的教學操作範圍。

原規劃以光由快變慢時偏向法線、由慢變快時偏離法線為主。核對教育部自然科學課綱：國中Ka-Ⅳ-8列反射與折射規律；高中PKa-Ⅴa-11明列司乃耳定律、臨界角與全反射。尚未指定課本出版社與版次，不據此斷言所有國中課本都未補充全反射。

兩區滑桿與顯示、光源ARIA範圍、拖曳、方向鍵、Home／End及輸入事件均限制0–40°，預設30°不變。代表水與玻璃射回空氣在40°仍有折射光，維持上下圖解與真實角度關係。移除副標、解析提示、展開說明及頁尾的延伸教學文字，聚焦兩種速度順序的折射比較。

共用純模型的完整角域與物理邊界保護保留，僅操作層限制範圍；不虛構不存在的折射光、不改動其他教學區。既有木紋／水色、金色光束、常駐解析、箱框按鍵、清空氣下半部及第五區雙光源保持。

驗證0–40°雙介質雙向全域折射、40°上限各輸入途徑、無延伸文字、角度與圖解同步、桌機及手機畫面、發射／暫停／續播，以及原第五區與整課回歸。完成原生Pages部署及公開核對後交付，仍屬第四階段修訂。

依據：[教育部自然科學領域課綱](https://edu.law.moe.gov.tw/Download.ashx?FileID=31187&id=GL001823&type=LAW)。
