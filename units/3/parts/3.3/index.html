學習內容 3.3｜波動與聲音｜聲音的特性

不同的聲音，
差別在哪裡？

小葵和阿公正在準備校園的聲音展示。有的聲音比較大，有的比較尖；即使音高相近，不同樂器聽起來也不一樣。我們一起聽、一起看，把這些差別說清楚。

每秒振動次數越多，頻率越高，通常音調也越高。高音不代表比較大聲，也不代表聲音傳得比較快。

03

琴弦的音調

一次改變弦長或張力

同一條琴弦，怎麼彈出不同高低的聲音？

同一條弦，先一次只改變一個條件：縮短有效弦長，或把弦拉緊。

小葵

同一條弦，按在不同位置，或拉得更緊，聲音會有什麼差別？

有效振動的弦長

現在的頻率：220.0 Hz

弦振動放慢、位移放大呈現；聲音以原音高播放。弦的材質與粗細固定，弦音為示意音。

等待操作
阿公

其他條件相同時，較短或較緊的弦，振動頻率通常較高。比較時一次改一個條件，才能看清楚是哪個變化影響音調。

04

空氣柱的音調

比較空氣柱長短

空氣柱長短不同，聲音會怎麼變？

比較兩端開口、構造相同的發聲管，吹奏方式與發聲模式保持相同。

小葵

除了琴弦，管子裡的空氣也能振動。長短不同會怎麼樣？

有效振動的空氣柱

現在的頻率：285.8 Hz

這是同類兩端開口管的簡化示意，不包含改變吹奏方式產生的高音。空氣微動只在吹奏時出現，管音為示意音。

等待操作
阿公

同類管子、相同發聲模式下，有效空氣柱較長，主要振動頻率通常較低；較短則較高。這裡比較的是空氣柱，不是敲擊裝水瓶子的聲音。

除了高低與大小聲，聲音還有不同特色，稱為音色。不同的聲音組成會呈現不同波形；同一樂器換一種演奏方式，音色也可能改變。

這裡比較的是高頻上限，不代表從0 Hz起都能聽見；動物種類與個體也有差異。本區只看頻率資料，不播放極高、極低頻聲音，也不作個人聽力測試。來源：OpenStax《College Physics 2e》17.6。

阿公

人耳能聽到的頻率有範圍。超過人耳可聽範圍的聲波仍然存在；有些動物能聽見人耳聽不到的高頻聲音。

分貝的辨讀

讀懂聲級與比較條件

分貝數字，怎麼幫我們比較聲音大小？

分貝數字幫助我們描述聲音大小；下面是有情境的參考資料，不是現在裝置的量測結果。

小葵

平常說大聲、小聲，和分貝數字有什麼關係？

0 dB不是沒有聲音分貝是和參考基準比較的聲級表示，0不等於沒有振動。

數字不是聽感倍數不能因為60是30的兩倍，就說聽起來一定兩倍大聲。

dBA是依人耳對不同頻率的敏感度加權的聲級，與未加權dB有別。情境數值會隨距離、場地與設備改變；本區不實際重現這些聲級。資料來源：NIDCD；分貝基準說明：OpenStax 17.3。

阿公

在比較條件與量測方式相近時，分貝數值較大，通常代表聲級較高。它不是聽感的線性刻度，也不能只看網頁音量就知道耳邊的真實分貝。
