# 單元3.3：第三輪五張首頁插圖候選

日期：2026-10-30（臺北時間）。

## 使用者要求

使用者希望每張盡可能涵蓋下方較多學習區塊的道具及情境，代表整個單元，要求再製作五張候選。前兩輪分別偏波形儀器與兩類樂器，第三輪改為「校園聲音探索」的整體場景，增加不同聲源、聆聽對象與交談／演出／電影情境。

[第三輪比較頁](index.html)使用C01～C05，不沿用A／B編號。前兩輪保留並提供最新一輪連結。正式首頁及教學內容均未套用或修改。

## 每張的共同設計範圍

| 元素 | 連接的學習內容 | 界線 |
| --- | --- | --- |
| 撥弦／敲擊與聆聽 | ①大小聲與振幅 | 首圖只提供聲源與觀察情境；固定頻率的振幅控制仍在①區操作 |
| 不同尺寸音叉、不同長度發聲器材 | ②音調與頻率 | 音叉是純音／高低音示意的視覺線索，沒有新增獨立音叉實驗 |
| 有琴橋與調整裝置的木製琴弦箱 | ③有效弦長／張力 | 與既有琴弦模型呼應 |
| 不同長度、同類直通開口管 | ④空氣柱 | 不改為敲擊水瓶或封底排笛 |
| 琴弦、管子、音叉及演出樂器 | ⑤音色 | 精確波形與同音高比較仍在⑤區 |
| 小葵／阿公／小狗聆聽、蝙蝠及耳朵圖鑑 | ⑥聽覺範圍 | 小狗是在聽一般聲音，沒有宣稱普通樂音是超聲波；蝙蝠以圖鑑呈現 |
| 聲級計、祖孫交談、舞台及電影活動線索 | ⑦分貝 | 連接既有交談、電影院、音樂會參考資料，不新增噪音／聽力保護教學，也不承諾網頁實際量測 |
| 整個聲音探索展 | 結尾小測 | 呼應協助展示台設定頻率、振幅及音色的任務 |

依使用者最新偏好，第三輪重新納入小型聲級計與聽覺圖鑑；保留演奏／聆聽的故事主體，沒有恢復以波形平板／控制台為主的構圖。圖片採前景道具、中景人物及聆聽對象、背景活動情境的層次，避免每張只代表單一區塊。
