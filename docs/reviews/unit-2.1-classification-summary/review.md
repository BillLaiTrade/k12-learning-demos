# 第八區分類總結改為可直接閱讀的網頁卡片（2026-10-30）

使用者指出，原包含關係圖縮進右側內容欄後，圖片內文字小於正文，不易閱讀；核可改為網頁文字與分類卡片，完成後由使用者確認可讀性。

本次以 `#matter-classification-summary` 取代第八區末尾的整張圖片，保持右側內容欄位置：

- 外層「物質」框包含純物質與混合物兩張卡，沿用共用綠色／中性色系與橘色區別。
- 純物質卡內再包含元素、化合物，搭配純鐵、蒸餾水例子及輔助粒子模型。
- 混合物卡說明兩種或兩種以上物質混合，搭配空氣、土壤例子，保留成分可以是元素、化合物或兩者皆有的既有說明。
- 所有分類、說明及例子均使用網頁文字；內文與例子至少 16px，分類名稱 18px，總結標題 19.2px。較窄內容欄調整卡片排列，不縮小文字。

1440／1280／1024／768／760／390px 本機 Chromium 局部檢查通過：總結中所有文字不小於正文、分類層次正確（元素／化合物只巢狀於純物質）、例子正確、舊圖片節點移除、八個學習區塊保留，總結與右側內容欄邊界對齊，無文字／頁面橫向溢出或 JavaScript pageerror。已目視桌機與筆電畫面，證據見 `desktop.png`、`laptop.png` 及 `check.log`。

來源核對 HTML 變更限於這張總結，所有互動腳本與其他課文內容逐字保留，CSS 調整限總結樣式及其欄位規則；差異與空白檢查通過。本次未重跑全單元功能測試，維持第 4 階段製作／精修，待使用者確認閱讀效果；未完成全單元檢查、外部驗收或最終核可。
