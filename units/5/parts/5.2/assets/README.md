## 簡化模型

1. 水溫以指數曲線接近選定環境，不越過環境溫度；熱箭頭依當前溫差改變方向，同溫時消失。
2. 熱平衡以兩塊相同材質、相同質量的金屬為例，同時考慮彼此及固定 25°C 環境的熱交換。接觸時彼此較快接近，分開仍緩慢變化；兩塊同溫後仍可能一起冷卻，最後與室溫相同才達到整體熱平衡，不再固定以 40°C 作為終點。
3. 傳導用穩定步長的定性一維擴散呈現材料溫度帶；金屬與木材的係數只供比較，不當作真實物性值。
4. 對流以閉合流線上的示蹤點呈現循環，水／空氣切換；並非計算流速或完整流體力學。
5. 輻射比較有無遮擋板的直接照射，文字交代遮擋物也可能吸熱與再放熱，不宣稱遮擋使所有熱交換歸零。
6. 保溫示例固定初溫、水量及環境，用定性權重比較三種路徑；兩杯均已加蓋，不模擬融冰或蒸發。更改設計會重來。

所有時間均為教學示意。暫停、重設及切換分別只影響當區，頁面失焦至背景時停止播放。

## 第二區：環境熱交換（2026-10-29，現行模型）

依使用者核可，固定室溫為 25°C，兩塊在分開及貼合時都會受到環境影響。

- `initialTemperatures`：固定為 A 60°C／B 20°C，依使用者指示移除原本同溫的起始模式及切換功能。
- `advanceBalance`：每塊與室溫交換熱，接觸時彼此交換更強；非接觸的微弱交換以小係數近似。採相同熱容量及對稱環境條件的解析更新，不把兩塊的平均溫度固定在 40°C。
- `balanceState`：提供各自的變化方向、彼此是否接近，以及是否都已接近室溫。這兩個平衡階段分開顯示。
- 第一回進入可視範圍才自動開始，開始後分開也會繼續；重來恢復初溫，暫停會固定整段觀察，切到背景亦會暫停。拖曳會繼續觀察，沒有接觸啟動主按鈕。
- 短光跡只表示較強的直接接觸交換；溫差低於約 0.15°C 時不再畫這部分。兩塊均距室溫小於約 0.05°C 時，收束為 25.0°C 並顯示整體熱平衡。
- 兩塊透過熱交換逐漸接近同溫後，仍可能一起降溫，直到與室溫相同。B 接觸時先升溫，後段可能與 A 一起降溫，標示依當下導數更新。
- 器材、拖曳界限、吸附、指標捕捉、鍵盤操作及正式頭像保留；冷暖反光依與室溫的溫差更新。
- 所有速率及時間是教學示意，不是實際鋁塊與隔熱盒的物性測量，也未解算真實空氣流場或輻射。
