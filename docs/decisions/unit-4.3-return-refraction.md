# 4.3 第四區雙光源射回空氣實驗

日期：2026-11-02。使用者核可第一張 `exec-a5c505f7-7cbf-4ac9-9a5e-6a3f28702989.png` 與第二張 `exec-4199c8a5-1bc9-4bba-a12d-619ba6dbbbd1.png` 後，要求依圖製作，功能與實際畫面核對後才交付。

第四區重點仍為水／代表玻璃射回空氣時偏離法線；參考4.2第六區獨立點擊兩支光源、雙色同路徑與相反箭頭，作為往返比較。第五區的反射／折射可逆整合保持。

- 共用第三區已接受的無文字水槽照片；上方空氣中A發紅光、下方介質中B發藍光。兩燈初始關閉，預設水、下方角度30°；原生按鈕或直接點器材各自開關，四種組合皆可，沒有強制步驟或自動播放。
- 拖動B或使用滑桿／方向鍵調整0–35°，A依同一模型自動對準對應路徑，文字明示自動對準。拖動與點燈有5px門檻，觸控區獨立於小器材外形，維持至少45×45px。放大圖內器材同樣可點、可拖。
- 使用既有代表折射率計算：水30°射回空氣41.8°、玻璃30°對48.6°。反向的入射與折射角色交換，兩角一般不相等；0°不偏折。角度皆從法線量起，沒有新增臨界角、全反射或公式教學。
- 兩條光路共用完全相同中心線，A為紅色較寬外緣、B為藍色細線，箭頭沿線錯開以同時辨識相反方向，不將路徑平移。箭頭由各段傳播向量求得。兩燈同開標示「空氣側／水或玻璃側」及度數，單燈則標示當下「入射角／折射角」。細引線連至各自角弧中點，小角度仍可讀。
- 中央44px原生熱區開啟局部近拍，近拍交界點對齊原M，裁切`350 340 600 460`保留兩支器材。窗寬76%、最高520px，周圍全景淡化，近拍與操作清晰。×／Escape關閉並還原焦點，開關不改光源或角度。760px以下的內容容器將介質切換置於同一全景標題列，避開關閉鈕。
- 水／玻璃同時更新全景、近拍、讀值與光源位置，保持兩燈與放大開關；載入序號避免舊請求覆蓋新選擇。失敗可重試或切換介質，準備期間停用調角與開燈。重設關閉兩燈、角度回30°，保留目前介質與近拍開關。
- 控制維持全景下方兩條緊湊列；手機調整為同區單欄，主要操作不需來回捲動。原解釋移入預設收合內容。沒有持續動畫迴圈，光色只區分方向、不示範色散。

獨立的`return-refraction-model.mjs`／`return-refraction-lab.mjs`／`return-refraction-lab.css`管理新實驗；共用課程腳本僅排除新實驗的舊控制器初始化。其他教學區、第三區、照片及共用光學模型保持，不新增依賴。仍為第四階段修訂，待使用者檢視，非外部驗收或單元最終核可。
