# 第一區塊以圖片觀察為主

2026-10-28。使用者要求減少文字敘述，保留可操作的圖片。本版調整前次「一組主圖＋三句脈絡」：主要文字改為古代觀點／研究線索／現代理解的短標籤，完整說明仍留在深入了解。

## 圖片與操作

- 土：原土樣圖的四個成分標記直接回到主畫面，點選圖上數字或成分圖例皆突出對應位置；支援鍵盤。透明點選範圍擴大，原圖與標記位置不變。詳細說明區不再重複土樣圖與同一組按鈕。
- 氣：三張精修圖在主畫面同時呈現較旺、燃燒、熄滅；點圖可放大觀察火焰與燭芯。原生 dialog 可關閉或按 Esc，關閉後焦點回到原圖片；主畫面不因放大而拉長。氧助燃及二氧化碳範例的界限保留在放大說明與深入內容。
- 水：原分解圖繼續呈現，完整生成／分解圖與觀察操作仍可深入閱讀。
- 火：保留蠟燭燃燒前／中的精修圖，不增加使用者先前已移除的額外按鈕。完整反應與生成物仍位於深入內容。

主畫面三個脈絡以關鍵詞及箭頭表示，例如「水 → 氫 ＋ 氧」「水：化合物」。空氣標籤採「含氮、氧等氣體」，避免把組成說成化學分解。古代陳述均在古代觀點標示下；主畫面保留氣體無色與燭芯細煙的圖像界限，原有研究史與來源不刪除。
