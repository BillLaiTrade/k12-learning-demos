# 第六區加水／放水：每次約兩秒，始終逐漸播放

2026-11-04。使用者指出加水／放水會瞬間完成，要求兩個方向都逐漸播放，約兩秒到達滿槽或空槽。

原因是控制器遇到系統`prefers-reduced-motion: reduce`就直接把水位設到端點，播放途中開啟該偏好也會跳到端點。這使教學所需的水位變化消失；原一般模式全量則約五秒。

移除這兩個跳到端點的分支，改為每次從當前水位連續推進約2000ms到滿槽／空槽，中間不停。水位變化是教學內容，兩種動態偏好都保留逐步播放；原CSS裝飾／焦點轉場仍尊重減少動態。播放中切換偏好不跳位、不重啟。

從中途水位開始也使用約兩秒；同方向重按不重啟，反向由目前位置重新開始約兩秒。直接拖水位／眼睛會接管示範，離屏或隱藏暫停並在回到可見時續播；空／滿停用對應方向，沒有新增重播／重設。

固定鏡頭、折射、槽壁遮擋、眼睛與虛線樣式、加放水按鈕及其他區保持。只改控制器計時／偏好分支與入口快取版本，不改物理模型或右側繪圖。

驗證使用真實瀏覽器時鐘，從實際按鍵／觸控事件計時到端點；逐幀記錄Canvas已繪製的中間水位、同時刻側圖水位／水面高度及像素摘要，確認並非只更新計數或最後一幀。涵蓋兩種動態偏好、加滿／放空、中途水位與播放中切換偏好、原生手機觸控；保留反向／接管／離屏續播與整課檢查。結果見[本機檢查](../reviews/unit-4.3-depth-water-2s/review.md)。維持第四階段，沒有新增最終核可。
