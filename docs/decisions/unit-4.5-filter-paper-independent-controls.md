# 4.5 第五區：光源、色片與紙張三組獨立設定

日期：2026-11-03（臺北）。使用者核可暗色場景、三個並排設定區塊且各組按鈕向下排列的示意圖，明確要求依圖修改第五區。此指示取代先前兩階段鎖定光源／色片的操作方式；維持第四階段。

## 操作與版面

三組皆以原生點選按鈕直接操作：光源白／紅／綠／藍，色片無色／紅／綠／藍，紙張白／紅／綠／藍／黑。三個區塊並排，各組選項直向排列，選中項目以既有深綠底與aria-pressed標示；不採下拉、不保留比較模式、不自動重設其他條件。預設與核可圖一致：白光、綠色色片、白紙。

沿用正式角色、卡頭、上方三欄及右上預覽。三欄改為光源提供、通過色片、紙張反射的光；小葵觀察依三個條件更新。窄版保留三組並排與至少44px按鈕，用短色片名稱避免截字，完整名稱仍由無障礙標籤保留；全卡可自然捲動。

## 光學與呈現

新增filter-paper-model.mjs，沿用既有光源、色片與材料的三通道數值：透射光＝入射光×色片透射率，紙張反射光＝透射光×紙張反射率。分開保留色片吸收與紙張吸收，每色守恆；沒有的入射色光不會在後續出現。黑紙保留少量反射，無色片理想化為全部透射，忽略色片表面反射。

第五區單獨降低場景環境照明及地面亮度，保留器材輪廓與可讀的頁面。接收紙使用霧面、非金屬、無自發光的MeshStandardMaterial與紙紋；聚光照明使用色片透射的光，紙張材質使用所選反射率，避免把反射結果重複乘兩次。紙張以獨立照明場景繪製，只接受所選透射色光及同色弱補光，避免器材的白色補光使紅紙在綠光下仍明亮偏紅；共用深度緩衝保留器材遮擋，教學線在紙張後繪製。照明不受教學光路顯示開關影響。

輔助線分為光源至色片、色片至紙張、紙面向入射側的少量漫反射線；不畫穿過不透明紙張的線。平面備援、接收預覽、三欄及說明共用同一模型，預覽採固定曝光降低過亮光暈。場景及預覽是定性外觀，不是校準照片。核可圖僅作設計證據，不作網頁背景或正式角色素材。沒有新增依賴。

## 驗證範圍

新純模型檢查80種組合、兩段逐色守恆、無新增色光、只換紙張不改透射光、紅光經綠片衰減、無色片及黑紙。瀏覽器專項檢查80種實際點選、三段色條／預覽／實際材質與燈光同步、三組互相獨立、八種視窗按鈕方向／觸控尺寸／器材避讓、手機原生拖曳取消與備援；整課檢查保留其他五區及唯一小測。實際結果與部署證據另存主專案review。
