# 5.3 第一區版面與器材操作優化（2026-11-05）

使用者核可前輪建議，要求依方案製作：器材直接啟動、溫差算式、先定義再對照、整併按鈕與重複文字。限第一區，維持第4階段待成果檢視。

- 旋鈕位置新增44px透明原生按鈕，滑鼠／鍵盤可啟動；啟動、載入／失敗、運行中與完成狀態和主要按鈕同源，運行中禁用以避免重複啟動。
- 指示燈使用程式疊層，運行亮、停熱／中斷熄滅；原器材圖不改。
- 移除無刻度長條；右側為目前水溫－起始水溫＝溫升直式，和LCD共用讀值。
- 完成後先由阿公介紹1cal，再對照1g水／1cal與100g水／100cal。共同條件為水都升高1°C，×100只對水量與熱量。比較表有原生表頭與完整讀屏caption。
- 一個主要按鈕由「開始加熱」轉為「重新觀察」，清除完成內容並從初溫重新啟動；移除獨立重來，失敗時才另顯示重試。完成訊息精簡。
- [保留核對](preservation.json)：第二至第五區及小測逐字相同，原熱量模型、器材圖、開場、導覽及其他控制器保持。
