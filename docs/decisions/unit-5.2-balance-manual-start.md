# 5.2 第二區改為按下開始才更新溫度

2026-11-05。使用者指出還沒按開始，鋁塊已自動朝熱平衡變化，要求明確開始後才進行。本次指示取代此前「首次進入畫面自動開始」與「拖動自動續看」的做法。

- 保留原`balance-pause`控制作為開始／暫停／繼續觀察；初始就顯示「開始觀察」。
- 移除進入畫面的自動開始。滑鼠、觸控或鍵盤只調整兩塊位置；開始前即使貼合，讀值也保持A60°C／B20°C、時間0，且不顯示傳熱流光。
- 按開始才運行原熱交換模型；觀察中拖曳維持原傳熱行為，暫停時拖曳不偷偷續看。
- 重來回到原始溫度／位置、停止並等待再次開始；背景暫停後仍需手動續看。
- 熱容量、室溫25°C、接觸／環境熱交換及平衡終點模型保持。其餘學習區與小測未改內容。
- 第二區外層不再重複使用inline-size容器，避免Chromium窄版重來後把動態文字／儀表留成空白；保留原版面與器材。

驗證見[局部檢查](../reviews/unit-5.2-balance-start-20261105/review.md)。此為開始控制的局部修訂，維持第4階段，非全單元最終核可。
