# 3.2 第五區：固定位置的溫度賽跑讀數

日期：2026-10-29（Asia/Taipei）。

使用者要求兩個距離讀數都放在賽跑刻度下方，位置固定為左側 0°C、右側 80°C，只更新數字，並以相同顏色的進度標記節省高度。

- 藍色 0°C 與橘色 80°C 讀數固定並列，不隨傳播位置左右移動。
- 刻度使用同形的藍、橘圓點，讀數內也有相同色點；組別標題配色同步一致。
- 圓點的水平位置仍由各組真實傳播距離決定。垂直稍微錯開，起點或終點同位置時仍可辨識兩組。
- 移除上方重複的實線／虛線圖例及移動文字；桌機進度區高度由 116 px 改為 84 px。
- 維持原有 5,000 公尺、實時時鐘、0°C／80°C 聲速、單獨或同時敲擊、暫停與重設。
- 實際開啟桌機與筆電頁面，操作同時敲擊後暫停並檢視距離讀數、顏色、位置及畫面。既有檢查的圖例／讀數選擇器同步更新，本次未執行測試套件。
