# 第九區：草履蟲標本與最終成像結論

日期：2026-11-05

## 本次調整

- 用草履蟲固定玻片取代箭頭圖卡，以較圓端與單側口溝辨認上下、左右；原物、中間像及目鏡結果共用相同標本輪廓。目鏡只進一步放大，不將中間像翻回來。
- 移除介面與朗讀標籤中的 A 代號，直接稱為「中間像」，保留同一中間像在兩段的角色銜接。
- 獨立結論區用淡金底及大字強調「上下、左右相反的放大虛像」，以圓端由上變下、口溝由右變左核對；區分目鏡所見與視網膜成像。移除原本重複的補充說明。
- 載物臺的微小標本與備用剖面也使用相同輪廓。紅藍為光路追蹤標記，顏色、尺寸及構造是教學示意，不宣稱為顯微照片。

## 驗證

- 顯微鏡瀏覽器檢查7項通過，包含圖形實際上下與左右位置、同一中間像前後延續、無 A 文字、醒目的虛像結論、預設輔助光路、物點偏好、分段／鏡頭／說明卡切換、鍵盤與備用剖面。
- 光學計算2項通過：原物位於物鏡 F 與 2F 之間，中間像位於目鏡焦距內；連續光路及最終虛像交點維持一致。
- 六種視窗尺寸（1440×900、1366×768、1024×768、760×900、390×844、320×844）、每種三個步驟檢查通過。標籤正常比例、沒有水平溢出，操作與比較窗維持同一視窗。
- 實際查看桌面第一／第二段、窄手機與完整內容截圖，確認標本、口溝方向、直接命名與結論的可讀性。
