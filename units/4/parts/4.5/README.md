## 模型與畫面

- `color-model.mjs`提供同一組條件，給立體場景、平面備援、接收面與解釋共用。
- 第一、二區三角玻璃使用prism-optics.mjs實際兩介面交點與向量折射、N-BK7 Sellmeier及CIE色度；白光380–780nm共401個波長，單色比較各1個波長。白幕局部近看為同一接收面；第二區固定取景，不逐色置中。
- RGB光斑在各像素以線性光強相加，完成後轉為sRGB顯示；沒有用顏料混合或半透明圖層代替。三色光強度固定在可疊成白色的搭配，不能推論日光只有三個波長。
- 色卡反射／色片透射用三通道選擇性響應示意，保留少量交叉響應。紅色色卡在只有綠光照明時很暗，沒有把物體永久染黑。此模型不作實際光譜、照度、色度測量；選色與結果不代表所有現實材料。
- 色片吸收與透射為簡化教學模型，忽略表面反射；色卡為漫反射，不當作鏡面。實際窄頻燈、濾片仍有頻寬，單色比較為理想化。
- 遮光板只切斷指定入眼光路；總覽仍保留器材供比較，不表示觀察者能穿透遮板。視覺以接收光示意，不模擬個別色覺與色適應。
- 輔助光路不是空氣中可見光束。旋轉／縮放與光路開關不改變實驗結果。

## 技術與備援

靜態HTML／CSS／ES modules，可在repo根目錄啟動`python3 -m http.server`。立體器材進入畫面附近才載入，僅在操作或尺寸改變時繪製，不持續自動播放。WebGL或立體模組不可用時，保留同模型平面示意、接收面及操作；主程式未就緒時控制停用並顯示提示，靜態對話仍可讀。

方向鍵可旋轉立體實驗台及移動光斑，三稜鏡另有原生按鈕等效操作；支援觸控拖曳、雙指縮放與減少動態。材料色均附文字名稱。
