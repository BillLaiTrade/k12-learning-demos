# 4.4 透鏡如何形成影像？

依使用者核可的十區腳本製作：九個互動教學區與一個結尾小測。製作前實際分析 1.1、1.2、2.1、2.2 的教學邏輯、器材細節、版面及標題連動，分析與完成檢查記在 [review.md](../../../../docs/reviews/unit-4.4-basic-20261101/review.md)。

## 結構與模型

- `index.html`：可閱讀的逐區內容、共用人物對話、完整提問導覽、九區閱讀位置及獨立小測。
- `assets/lesson.css`：沿用 4.3／2.2 的頁面殼層與卡頭尺寸，再加入本課的工作台、光路、控制與觀察窗；未修改共用或其他單元樣式。
- `assets/optics.mjs`：小孔相似三角形、理想薄透鏡光路、眼睛及兩段眼鏡作用、兩透鏡顯微鏡的純計算。公式用於保持模型正確，學生不必計算。
- `assets/lesson.mjs`：由計算結果更新光路、投影模糊、像的特徵、物距紀錄、調節與矯正，以及導覽和小測。每區可獨立重設。
- `assets/lens-studio-cover.webp`：本課生成的情境插圖，沿用共用人物設定；不作光學幾何證據。共用頭像仍直接引用 `shared-assets/characters`。

同一上下不對稱圖案貫穿 01–06。屏幕不跟隨物體自動對焦，只有清楚成像才可留比較紀錄。焦點邊界不繪製無限值；虛像使用有圖例的輔助延長線，眼睛觀察與屏幕比較分開。放大鏡與凹透鏡的觀察光束實際通過圖中眼睛的瞳孔範圍。

眼睛以等效透鏡表示角膜和水晶體的總作用，固定視網膜，分別追蹤兩個物點；各點各自成像而非整物匯成單點。眼鏡用兩段傳播與折射計算；顯微鏡物鏡焦距60、物距80，形成像距240的中間像，目鏡位於300且焦距100，中間像在目鏡焦距內。距離是製作者的模型參數，不作學生必背數值。

## 執行檢查

在展示庫根目錄執行，沿用既有 Node、Playwright、Chromium，不新增依賴：

```sh
node tests/unit-4.4-optics.test.mjs
CHROMIUM_PATH=/usr/bin/chromium node tests/unit-4.4.test.cjs
```

純模型8項；瀏覽器22個子項加主項，共23項，合計31項。涵蓋九區所有操作、十區格式、唯一小測、實際滑鼠拖曳、鍵盤、原生觸控、七種寬度、標頭不遮擋、初始深連結、有效素材及入口，並與2.2實際計算樣式比較。

`LENS_URL` 可指定公開課程完整網址（不帶hash），`LENS_CAPTURE_DIR` 指定證據目錄。公開測試使用環境提供的 HTTPS 代理；需允許本機 socket 與 Chromium 程序。`#s1`–`#s10` 為十區錨點，`#unit-quiz` 為小測入口別名。

七寬度包括1440、1366、1024、820、760、390、320。窄螢幕完整光路可以在各自圖框左右捲動，不讓頁面本身橫向溢出。觸控由Chromium模擬，不宣稱Safari實機或外部驗收。

本機檢查已全數通過；公開發布與重驗結果另見檢查紀錄。仍為第四階段基本版製作／修訂，沒有新增完整單元外部驗收或最終核可。
