# 第六區直接拖曳操作本機核對

2026-11-04。使用者核可水位垂直操作與眼睛前後直接拖曳，移除原兩條水平滑桿。

- local-integration.tap：全組合28項全過（8模型／20瀏覽器，含外層），保留整課及格式檢查。
- local-final-browser.tap：水位把手、直接拖水面、鍵盤、眼睛相對位移、手機觸控／非控制區捲頁、空槽加水、手動接管及原功能等14項全過。
- final-layout.json：1440／390／320寬度，各含0／1／30／100公分及近／遠位置共15組。標示文字互不重疊，水深讀值中心與實際水面同高。最後調整了距離讀值及小水深媒體名稱：距離移到不遮光線的上方；水層太薄時不放「水」字在空氣裡，保留水面與數值。
- final-*.png為最後布局；其餘原專項畫面及measurements.json保留九尺寸、44px水位／眼睛、兩圖同步與遮擋結果。
- preservation.json：前五區、小測、原有控制／照片、視深純模型及右側繪圖共13筆與前版本相同。

初次接管測試以pointerdown之前讀到的水位作基準，但讀取元素期間示範仍會推進（initial-timing-test.tap）。改為驗證按下後立即停止且水位持續不變；靜止水位的按下不跳位另有獨立驗證，沒有放寬拖曳或停止行為。最後版面另檢查極淺水層的標示，消除「水」與水面字樣擠在一起的情況。

控制器與樣式保持既有材質；水位使用場景中的原生垂直range，眼睛是可聚焦的SVG控制，不保留隱藏水平滑桿。模型、速度、初始空槽不可見與加水可見條件保持。維持第四階段，待使用者檢視，非最終驗收。
