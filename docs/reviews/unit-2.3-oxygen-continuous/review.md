# 第三區氧氣條連續縮短（2026-10-30）

使用者指出氧氣直接跳到短條，未呈現逐漸減少。前次減少動態模式將進度量化成0／0.5／1，造成階段間跳變；本次移除此分支及不再需要的媒體偏好JavaScript監聽，手動重播皆隨充氮排氣逐影格縮短。CSS仍依減少動態偏好停用箭頭流動與圖片淡入淡出。

不更動版面、袋子素材、暫停與重播語意；右側仍為定性短條，不顯示固定殘氧數值。腳本查詢版本更新為continuous-oxygen-1。

## 本機檢查

第三區專項10項通過（browser-tests.log）。連續性回歸在兩種動態偏好下，每200ms共16筆量測實際長度，持續縮短、單次沒有跳到短條，封口後保持最終長度；數據見oxygen-progression.json，其中percent是CSS佔軌道長度百分比，並非氧濃度實測。左右比較、暫停、觸控、減少動態、圖片decode失敗與七種寬度邊界回歸均通過。

整頁9項亦於首次並行檢查通過。新增測試起初在充氣／封口交界的影格取樣造成0.0625px差，已明確推進至封口階段再斷言固定長度；第三區專項重新執行10項全數通過。沒有為了測試修改正式動畫時序。
