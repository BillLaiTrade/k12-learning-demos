# 3.1 第五區：水面波與粒子的運動對應

日期：2026-10-29（Asia/Taipei）。

使用者逐項確認後，同意保留現有水盤、操作與版面，修正水面隆起時追蹤粒子反而下移的問題；一般粒子與追蹤粒子使用一致的運動計算，並保留前後往返。

- 新增同一個區域取樣函式，依位置、深度及傳播延遲計算位移，供水面、一般粒子及橘色追蹤粒子使用。
- SVG 的垂直座標向下增加，故向上位移統一使用負值；近水面粒子的垂直位移與該處水面同相。
- 水平位移保留往返，方向配合向左／向右的傳播：波峰通過時沿傳播方向運動，波谷通過時反向。
- 沿用現有落點、波速、週期、深度衰減及振幅包絡。其他待審查項目不在本次範圍。

## 本次核對

在瀏覽器逐時取樣一般粒子及追蹤粒子，共 4,575 個位置樣本；波峰時水面與追蹤粒子皆向上、波谷時皆向下，並維持前後往返及深度衰減。另核對偏右落點的向左傳播、播放結束歸位、鍵盤重新投入，以及手機觸控／減少動態偏好的對應運動。390px 未觀察到橫向溢出或頁面錯誤。
