# 4.4 第四區：放大鏡的觀察操作

2026-11-03依使用者確認的示意圖，沿用既有Three.js器材、固定眼睛canvas、同尺度原物參照與屏幕光斑模型。

- 保留主圖右側常駐眼睛視角。下方以一把圖卡位置尺取代原圖卡操作卡，距離統一使用F；圖卡範圍仍為0.3F至0.9F，尺末端F只作參照。
- 五列表格可整列點選，第一欄保留無框原生按鈕以支援鍵盤。每列切換圖卡、屏幕及光路條件；手動操作則依實際條件更新選取，不強制吸附或捲動。
- 靠近透鏡／接近焦點兩列分別使用0.3F／0.9F；找虛像、插入屏幕、取下比較使用同一0.6F。後兩列的屏幕位置固定為0.95F，確保可重現比較。
- 開啟反向延長線時，沿用第三區透明原圖案加虛線輪廓的方式標示真正的虛像位置與倍率，沒有實體板或底座。延長線不再於固定世界座標裁斷；0.6F的交點為圖卡側1.5F，正立、線性放大2.5倍。
- 主圖中的線性像高與右欄眼睛所見各依既有模型計算。右欄使用虛像距離與像高決定視角，與未經透鏡的參照採相同畫面尺度，不能直接把線性倍率當作看起來的倍率。
- 插入不透明屏幕呈現散開光斑並遮住眼睛；不表示虛像消失。取下後，同物距恢復完全相同的眼睛畫面。保留屏幕拖移、微調及正面觀看。
- 移除實驗台標題列、旋轉提醒、條件徽章與重複說明卡；完整即時狀態保留給螢幕閱讀器。工具與右欄之外保留取景空間，觀察列／延長線切換才重新取景，旋轉和器材拖曳保留相機距離；縮放沿用第三區0.2至2.2的範圍。

驗證包括實際影像像素、真正光線交點、整列與鍵盤操作、位置尺連動、七寬度、原生觸控、五倍近看及WebGL備援。正式程式沒有測試全域API。
