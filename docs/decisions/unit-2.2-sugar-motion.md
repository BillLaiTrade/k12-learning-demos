# 2.2 第四學習區塊：清楚呈現加糖與減糖

2026-10-30。使用者指出動作像抖動、難以看出加減糖。

- 一般加減糖由 1.1 秒延長至 3.2 秒，分成舀取、提起搬移、停留倒出及回位；加糖不再只移動幾個像素。減少動態偏好下也保留 1.8 秒，呈現完整的重量變化。
- 糖粒由實際旋轉後的湯匙口落向秤盤或來源糖碗；加糖重量在落入秤盤時增加，減糖重量在舀離秤盤時減少。
- 連點依序完成每一匙，拿取器材不直接跳到待完成的重量；重設可清除尚未完成的操作。
- 湯匙動作進行時暫時隱藏遮住糖堆的「− 糖」標籤，完成後恢復；按鈕位置與操作保留。
- 保留每次加減 1 克、原有質量範圍、數字輸入、濃度公式及水的操作。

## 湯匙僅呈現動畫

同日依使用者指示，移除湯匙上的透明按鈕及其點擊、拖曳、鍵盤操作；湯匙繼續由 Canvas 呈現加減糖動畫。糖碗與秤盤的加減糖按鈕維持原位置及操作，電子秤數字輸入、水壺與量杯操作沿用。
