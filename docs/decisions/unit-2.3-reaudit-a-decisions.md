# 2.3 第二輪重審 A1–A12 決策

2026-11-03（臺北時間）。使用者逐項採用，並授權統一實作、測試及公開發布。保留預設觀察紀錄與原有播放方式。

- A1：滿瓶後仍持續更新進出氣體與瓶內成分，以目前樣本評分。
- A2：拖曳只預覽位置；確認才影響移動／漏水／逸散。取消不留下預覽造成的變化，原本反應與集氣時間繼續。
- A3：滑鼠、觸控、鍵盤拖曳皆可用 Esc 取消，清除提示及目標，不依賴目前焦點。
- A4：實際補救後重新判斷氣量、成分及封存；歷史錯誤僅在仍影響目前樣本時參與判斷，不重複要求已完成步驟。
- A5：確認移動後水流出時同步記入空氣，氣體逸散亦同步更新成分與剩餘量。
- A6：出口在空氣／瓶外水中／瓶內的畫面、氣泡、觀察與集氣共用實際位置判斷。
- A7：實際倒液累計、容器有限容量；開口容器滿後仍可倒，超量溢出並提醒。錐形瓶依塞子／漏斗／導管連接處理，淹到導管入口須顯示集氣受影響；停止保留實際液量。
- A8：自動停放避開器材開口、抓取處；雙孔塞與附著漏斗一併考慮空間；拖曳中的器材顯示最前，保留學生自行擺放位置。
- A9：第一區改為「先比較杯子垂直倒扣入水與入水後傾斜的差別，再試著拖動看看。」。
- A10：第三區補列清水及用途；無 JS 版本不寫固定項目數，與一般介面清單一致。
- A11：第四區整組標籤統一「雙孔塞與導管」，零件依實際名稱；稀鹽酸介紹為「濃度較低的鹽酸，外觀無色。」，用途另列。
- A12：補充排水收集仍含水蒸氣；錯誤提示具體指出混入空氣或其他氣體、未達目標；水蒸氣不算操作錯誤。

內部物量、混合與溢流使用守恆的教學近似，沒有宣稱精確流體、濃度、實測速率或劑量。驗證需包含已重現的新邊界，以及正常桌機／鍵盤／原生手機觸控、六區內容和公開版本。
