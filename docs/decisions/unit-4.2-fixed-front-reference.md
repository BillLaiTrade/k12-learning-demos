# 4.2 第一區固定正面參考

日期：2026-11-05。使用者核可版面示意後，要求依「可左右觀看的主畫面＋固定正面參考」實作；卡片與標題沿用既有4.1格式。

- 主畫面初始稍向左，右側參考圖保持正面；主畫面只改左右方位，固定俯仰。三個預設角度與獨立燈光開關保留，兩張圖共用控制。窄版依容器寬度上下排列，觸控垂直滑動可捲頁。
- 相同Three.js場景、器材、材質與燈光，以同一WebGL renderer的兩個viewport渲染，複製至兩個可見Canvas 2D。共享相同的曝光、色彩與色調映射；參考圖由實際燈光狀態產生，不是固定開燈照片。
- 參考只在燈光或尺寸變更時重繪，主畫面轉動時保持正面相機及像素不變。主畫面轉回正面時，以原始畫布像素比較兩者亮度，排除縮圖框線，容許不同解析度造成的取樣差異。
- 平滑鏡面偏離反光方向後可比霧面紙暗；這是本活動要比較的方向差異。沒有隨觀看位置調整材料亮度，沒有新增微觀放大圖、空氣光束或反射箭頭。
- 保留第一區三句已核可對話與第二區起的內容。整頁檢查另發現快速跳區時，舊IntersectionObserver事件可能錯選閱讀路線；改由當下卡片位置決定高亮與進度，保留原導覽、錨點及文字。
