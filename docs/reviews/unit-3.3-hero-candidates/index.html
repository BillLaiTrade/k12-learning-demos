圖中的物件，怎麼連接七個學習區塊？

學習區塊共同的視覺線索接到下方的操作或內容
① 響度與振幅喇叭、旋鈕、波形平板固定頻率，調整振幅並比較大小聲。
② 音調與頻率同一套聲音觀察器材調整頻率，比較同一段時間的振動次數與音調。
③ 琴弦的音調有琴橋和調整裝置的木製琴弦箱一次改變有效弦長或張力，再試聽。
④ 空氣柱的音調同類、不同長度的開口發聲管比較空氣柱長短與音調；延續同類開口管的條件。
⑤ 音色與波形琴弦、管子、喇叭與平板比較相同音高的不同聲音特色與波形。
⑥ 聽覺範圍人物聆聽、狗與蝙蝠資料卡從「聽得到嗎？」延伸到人耳可聽範圍與動物高頻聽覺。
⑦ 分貝的辨讀桌上的聲級計與紀錄本由描述大小聲接到聲級資料的比較；本區仍以參考資料辨讀。
結尾小測整張聲音展示台協助展示台設定指定的頻率、振幅與音色，呼應開場。

圖片用來帶入情境；精確的波形、頻率、聲級與模型關係，仍以學習區塊內的操作圖及數值呈現。
