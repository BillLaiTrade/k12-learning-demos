# 4.4 第四區立體實驗台與常駐眼睛視角

2026-11-02。使用者在分析與數次示意修訂後，明確核可「左側可旋轉立體實驗台、右側常駐眼睛視角」，要求依最終示意製作並檢查功能及畫面後才交付。本輪只更新第四區與對應導覽標題、相關測試及文件，維持第四階段。

第四區標題改為「凸透鏡什麼時候能當放大鏡？」，承接第三區的屏幕實像，圖卡在焦距內形成正立放大虛像。保留共用卡頭、人物、十區順序及唯一小測；器材沿用前三區木質光軌、凸透鏡及發光圖卡風格。無物距拉霸或整體重設。

左側立體圖可拖曳空白處旋轉、滾輪／雙指縮放，圖卡沿軌直接拖曳並保留抓取偏移，提供方向鍵及按鈕微調。鏡片及眼睛固定；圖卡限制於焦距內。旋轉主圖只改查看器材的相機，不改右側固定眼睛的觀看位置或影像。右側常駐圓形觀察畫面，正立圖案隨物距連續更新；下方原物參照使用相同眼睛位置、觀看角度與畫面尺度，沒有將幾何像高倍率當作眼睛看見的倍率，也不將不同影像自動縮放填滿。

沿用既有理想薄透鏡模型，新增magnifier-optics獨立核對虛像位置、像高、固定瞳孔入眼光路、屏幕散開光斑與範圍。焦距100公分、眼睛距離170公分為模型參數；主圖及眼睛畫面共用條件，假設眼睛已調節看清，眼睛調節留到第七區。光路在薄透鏡主平面簡化折轉，未逐面計算玻璃折射、繞射及像差。

圖內金色按鈕顯示輔助實線，另有反向延長線按鈕，開啟延長線時同步顯示實際光路；關閉實線也關閉延長線。可選上端／下端／一起看。虛線不是實際光線，交點超出主圖時提示虛像仍存在，不壓回畫框或悄悄消失。主圖範圍內的虛像位置只作輔助標示，沒有另一張實體圖卡。

「用屏幕試試看」在透鏡與固定眼睛之間插入可拖曳的不透明屏幕；屏幕接到散開光斑，右側同步呈現視線被擋住，取下恢復原來觀察。屏幕前面可正面近看，另有正面小圖；其幾何散開範圍與實際光路一致，源點取樣及光斑邊緣柔化／曝光僅便於觀察，不模擬精確光度。切換保留圖卡及屏幕位置，不自動對焦。

桌機並排、手機上下排列，眼睛視角不需切換或另開視窗。窄版標籤避讓，無600px橫向光路捲動。WebGL失敗時眼睛畫面、原物參照、按鈕移動及屏幕比較仍可操作。沿用4.1既有Three.js，沒有新增套件或服務。最新驗證及交付證據見[交付紀錄](../reviews/unit-4.4-magnifier-3d-20261102/review.md)。
