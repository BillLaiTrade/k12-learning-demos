## 實作

第四區後續依使用者要求改為橫向取景：左舞台3:2、取消固定高度與強制等高，可用內容寬度足夠時約3:1分欄，較窄提前上下排列。眼睛與原物參照保留相同CSS畫面尺度，物理與操作邏輯不變。最新比例、七寬度及公開證據見[寬版交付](../../../../docs/reviews/unit-4.4-magnifier-wide-20261102/review.md)。本輪只跑受影響的立體專項10項；下方37項為前次完整製作紀錄。

- `magnifier-studio.mjs/css`、`magnifier-optics.mjs`：第四區依最後核可示意製作左右雙畫面。左側立體圖可旋轉／縮放、拖曳焦距內圖卡；右側固定眼睛視角依虛像位置與像高更新，原物參照使用相同觀看條件與CSS畫面尺度。主相機／光路開關不改右側像素。圖內輔助實線、反向延長線及分物點追蹤；圖外虛像提示不消失。屏幕插入後接到散開光斑，同時遮擋眼睛；可拖曳、正面近看、取下，保留位置。WebGL失敗仍可操作右側與屏幕比較。無拉霸或整體重設，沿用4.1 Three.js，原專屬模組未改。

- `imaging-studio.mjs/css`、`imaging-optics.mjs`：第三區依核可示意製作立體成像台。圖卡、固定凸透鏡、接收屏幕共享理想薄透鏡條件；拖曳與鍵盤／按鈕微調，無距離拉霸或整體重設。階段切換保留位置及紀錄，改物距不搬屏幕。投影依實際接收面位置連續改變大小與散開，不限制倍率；超出屏幕裁切，超出軌道明確提示。正面看同一屏幕時暫隱藏輔助線。清楚像留下同尺度屏幕影像，相同物距更新、其他紀錄保留，可逐筆刪除。WebGL失敗仍可操作屏幕投影與紀錄。

- `index.html`、`lesson.css`：沿用2.2的頁面殼層、人物及標頭，導覽與可見標題一致。`#s1`–`#s10`及`#unit-quiz`保留為編號入口。
- `parallel-optics.mjs`：空氣→玻璃→空氣的兩球面折射；凸／凹厚薄輪廓、光路及焦點使用同一組幾何。
- `convex-studio.mjs`、`convex-studio.css`：第二區依核可示意改成立體平行光源、凸透鏡、木質光軌與焦點；下方以同一球面資料畫局部剖面，可切換進入／離開兩介面及法線。主圖可轉動／縮放，近看仍是同一片鏡片，沒有位置／視角重設或距離拉霸。沿用4.1既有Three.js，不新增依賴。
- `parallel-lab.mjs`、`parallel-lab.css`：第五區保留完整側視圖及同圖近看，沒有固定600px的手機水平捲動；光路按鈕位於圖內，凹鏡延長線預設關閉。第五區HTML與模組本輪未改。
- `lesson.mjs`、`optics.mjs`：既有理想薄透鏡、眼睛與兩段鏡片、顯微鏡計算。對焦與物距共用狀態；切換眼模型先取下舊鏡片，正常成像不需矯正。`data-lab`與`lab4/5/6/7/8`為沿用的內部模型識別，不等於目前可見區號；勿依內部ID推算小測連結。
- 第一區`pinhole-3d.mjs/css`、`pinhole-optics.mjs`及第一區HTML保持原樣，直接引用4.1既有Three.js，沒有新增套件。仍可旋轉／縮放，屏幕正面與孔口近看均觀察同一器材。
- 封面及人物沿用既有素材；不新增副本或外部服務。
