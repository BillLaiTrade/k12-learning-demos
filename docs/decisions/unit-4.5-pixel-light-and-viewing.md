# 4.5 像素電視：送出的色光、觀看距離與每格獨立設定

2026-11-04（臺北）。使用者核可補強分析：先前色塊像顏料、藍通道畫黑缺乏說明、等號沒有建立觀看距離、填圖進度仍未呈現每格RGB設定，是本輪範圍。

## 三段學習路徑

1. 明說每個子像素控制送出的色光亮度，用「送出」涵蓋RGB教學示意，不把所有真實面板概括成自發光燈。金框只選實際索引9的一格；放大RGB加紅／綠送光圖示，藍光關閉則黑色且沒有送光符號。可見文字明說黑色代表這個通道沒有送出對應色光，其他通道仍可送光。
2. 觀看距離用兩個場景表示：同一螢幕區域、相同RGB設定，眼睛在近／放大觀察及較遠一般距離。遠景距離線較長，能否分辨子像素的觀察窗不同；不用等號或時間箭頭表示兩種觀看。亮度改變的橙→黃例子另列在旁，明說紅藍固定、只調亮綠光，區分兩個變因。
3. 直接列相鄰A／B各自的RGB狀態與合成色。A是實際目標索引9（紅亮、綠弱、藍關，橙色），B是相鄰索引10（紅關、綠關、藍弱，深藍色），各自設定後一起構成完整圖。示例不用數字透露目標配方，以語意狀態說明，銜接控制一格→修復缺格→逐格組圖。

三段採寬版圖文排列，手機依序呈現，保持重要文字可讀；不把複雜圖解擠進三窄欄。仍是理想RGB螢幕示意，附非實際比例／五級與8×8學習簡化說明；不模擬真實面板像素密度、視力或物理光學縮小融合效果。
