# 4.5 兩處偏轉指示與主圖分色辨識

日期：2026-11-04（臺北）。使用者要求入射與出射皆能看清相對各自法線的偏轉，並指出第二區主圖仍像一條粗白線，要求在主圖直接辨識分色。

## 呈現決策

第一區各界面分別延長當地入射方向：入射處延長空氣中的水平入射光，出射處延長玻璃內光線，而非共用一條水平線。綠色弧箭頭從原方向轉到實際折射方向，搭配「入射：偏向法線」與「出射：偏離法線」標示。光路、法線和玻璃使用原模型的真實方向及等軸投影。

第二區取消A區近看，主圖直接繪出可分辨的紅、綠、藍代表光路及名稱。這張教學原理圖放大不同色光的分離程度，圖內明列「色光分離放大示意，非實際角度」，圖說補充不作角度量測、三色只是連續光譜的一部分。各線仍從同一入射點經過兩個玻璃表面，保留紅光偏折較小、藍光較大的定性順序；出射點重新求玻璃面交點，避免浮接。

這項主圖辨識需求取代[前輪決策](unit-4.5-prism-clarity.md)第四項的「圖解也不放大角差／A近看」呈現方式。只有原理示意圖使用放大分離；實驗台、白幕與對位線繼續使用原實際角度、位置、波長、尺寸及光學／顯色計算。不是把放大的圖解數值回寫實驗。

## 範圍與檢查

沿用深綠光學墊及玻璃質感，桌機手機各有構圖。第一區補充預設收合、第二區原理預設展開，無JS仍可閱讀。第三至六區、唯一小測及全部27個非SVG執行素材逐檔與基線相同。無新增依賴。

生成測試4項涵蓋四張SVG重建、均勻比例、法線與界面、原方向與真實弧箭頭端點、代表三色的分離標示／順序／面交點／原始資料。瀏覽器專項8項子測試（含外層9項）涵蓋原生鍵盤收合與器材狀態、五種視窗、四張圖文字邊界、無JS圖解。沿用光學7項與顯色3項回歸。整課35項前輪已過，本輪未重跑未修改的全課操作；不將專項描述為全課回歸。公開驗證結果另存主專案review。
