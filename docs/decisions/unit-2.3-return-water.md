# 2.3 第六區：收回物品、修正鑷子圖示、允許反應瓶加清水

2026-11-02。使用者指出桌上綠框、材料區鑷子圖示消失，要求材料再次點選可收回，並允許把清水倒入反應瓶，即使不是正確製氣步驟。本輪只更新第六區及專屬資產／檢查，維持第四階段。

移除舊的器材已選取／滑過綠框，保留拖近有效位置的金色動作提示。材料區改成「點一下上桌，再點一下收回」，以aria-pressed同步是否在桌上；圖示、勾選與桌上本體一致。已完成時也可收回並回到可操作狀態。手機以同一按鈕的按下／放開直接切換，移動、取消及相容click不重複執行，滑動材料區不會誤取用。

收回液體來源不刪除已倒入的液體；收回容器會清空其內容，介面有明示。夾著大理石的鑷子先放回盤中，蓋上的玻璃片先移開，管口在瓶中時先沿瓶口下方撤管再收回集氣瓶。水槽連同仍在水中的集氣瓶／附著玻璃片一併收回；反應瓶連同已裝上的塞子與漏斗收回，單獨收回塞子也回收已裝漏斗，避免懸空。獨立工具與其他容器／已收集樣本保持。這些收回動作不算完成封存，清除的收集紀錄不能獲判成功。

鑷子圖示問題來自材料圖示尺寸規則同時套到巢狀SVG裁片。尺寸只套用最外層圖示，內層照片保留原裁切尺寸；補淡陰影以看清金屬。沒有刪掉、替換或重生鑷子素材。桌上仍用原本真實器材及動畫。

清水允許由開口反應瓶加入，已裝漏斗則經漏斗加入；封閉瓶口不允許穿塞或穿瓶壁。新增獨立清水量，液面與液封依清水加酸液的總量呈現；清水與大理石本身不反應，不生成CO2。後續有酸且接觸大理石才反應。先加水再放石塊時保持瓶身直立，只有空瓶才傾斜。原縮時、反應物足量模型不模擬精確濃度與反應速率。收回反應瓶可清空重試，唯一小測與前五區不改。
