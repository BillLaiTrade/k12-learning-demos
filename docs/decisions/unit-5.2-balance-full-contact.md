# 5.2 第二區整面接觸

2026-11-05。使用者回報鋁塊無法靠在一起。碰撞模型在正面已相接時停止，原圖的頂面卻向後內縮，產生V形縫隙；畫面與「接觸」語意不一致。

以image_gen修正同一鋁塊素材的投影，改為頂面／正面同寬、連續垂直側邊。兩塊使用同圖同尺寸；不以重疊鋁塊或改寫熱交換規則掩蓋縫隙。SVG裁切與輪廓都對應真正可見邊緣。模型原本的零間距接觸、吸附與邊界保留；貼合時明示「已貼合，待開始」／「已貼合，已暫停」。

回歸增加素材邊緣alpha取樣與可見viewBox投影：舊圖前面接觸仍會在上半部取到透明背景，新圖整個高度左右側邊都不透明，且兩可見側邊相接。滑鼠左右拖曳均驗證，原開始／停續／重來／熱平衡與觸控流程保留。
