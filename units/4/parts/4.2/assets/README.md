# 4.2 圖像與動畫素材

## 蒸發結晶連續動畫（目前使用）

- 依使用者最新要求，四個步驟改為同一段連續動畫，不再切換四張圖片。
- `evaporation-animation.js` 使用專案現有 Three.js 與 RoomEnvironment，將既有 `evaporation-dish.webp` 作為固定器材照片。水是隨進度連續變形的折射幾何體；照片參與透射背景，器材、容器及鏡頭不隨階段變形。
- 受熱過程細分為升溫、細泡上升、持續沸騰、開始析晶、水層變淺及乾燥六個觀察階段。反光邊緣的氣泡在水中上升並消失於水面，稠密水面網格隨沸騰變形，氣泡破裂處會產生擴散的擾動。
- 晶體從示意進度 50% 開始，先在邊緣成核，再逐漸增多、長大；接近乾燥時，氣泡隨水量減少而消失。小晶體採用漸進尺寸曲線，避免都留到末段才突然出現。
- 沸騰與蒸發分開說明：本例加熱至沸騰，但水在未沸騰時也會蒸發。水蒸氣本身不可見，不繪製煙霧或蒸氣線條。
- `evaporation-state.js` 定義 0–1 的連續進度及四個定位點。依使用者要求，完整示意為 12 秒，四步各 3 秒：0–3 秒觀察升溫、3–6 秒沸騰蒸發、6–9 秒晶體析出、9–12 秒保留乾燥鹽晶體。定位按鈕對應 0、3、6、9 秒；最後一步的「下一步」停用，但仍可拖曳至播放終點。
- 示意秒數並非真實蒸發時間；加熱、水量及成核排程為定性教學示意，沒有提供可量測的真實溫度、水量、晶體質量或生長速率。
- 播放／暫停、重播及進度拖曳共用同一個狀態；四步按鈕只定位，手動定位會暫停播放。頁面隱藏時暫停，避免背景繼續推進。
- WebGL 無法啟動時提供明確訊息並停用動畫控制，其他教學區塊仍可使用。
- 操作檢查：`CHROMIUM_PATH=/usr/bin/chromium node --test tests/unit-4.2.test.cjs`。

## 蒸發結晶四步寫實示意（歷史素材）

- 檔案：`evaporation-realistic-stages.png`，1536 × 1024 像素，RGBA。
- 製作：2026-10-27，依使用者要求改善四步水體的真實感，以既有 `evaporation-dish.webp` 為器材參照，使用影像生成工具製作。這是教學示意，並非真實實驗的攝影紀錄。
- 排列：2 × 2 等分圖集，左上為透明鹽水、右上為水位降低、左下為淺水層開始析鹽、右下為乾燥後留下鹽晶體。
- 舊版曾以四個背景圖層選取對應區域並淡入切換；目前的連續動畫不再載入這份圖集，保留以追溯先前的寫實素材製作。
- 教學界線：水蒸氣不可見；最初溶解的鹽沒有可見顆粒，末步沒有液層。圖像不提供可讀取的水量、晶體質量或真實時間資料。
