# 4.3 第一區光速比較台：製作與本機驗證

日期：2026-11-01。核可依據為本目錄 `approved-design.png`，另依使用者決定將共同路程改為 100 萬公里，以模型時間播放。

- 木質桌面、三排透明介質與金屬器材採與核可稿同類細節的寫實素材；無文字底圖與動態光跡分開，並非將設計稿整張當互動畫面。
- 原生同時發光、暫停／繼續、重新播放，固定空氣／水／玻璃，無介質卡片。共同計時與三排到達時間由單一模型同步；到達後光點隱藏，接收器亮起。
- 模型速度為 300,000／225,000／200,000 km/s，路程為 1,000,000 km，時間約為 3.33／4.44／5.00 秒；倍率 1。圖上交代理想路程、代表值、衰減及光跡示意範圍。
- 其他六區（第二至六教學區及結尾小測）的 HTML 完全相同，原控制器移除舊第一區後其餘程式相同，`optics.mjs` 相同，見 `preservation.json`。
- `node --test tests/unit-4.3-speed-model.test.mjs tests/unit-4.3-speed-lab.test.cjs tests/unit-4.3-optics.test.mjs tests/unit-4.3.test.cjs tests/unit-4.3-format.test.cjs`：最終 21 項全過。完整結果見 `local-tests.txt`。
- 包含三個到達界線、相同時間距離比例、暫停續播、快速鍵盤操作、重播清空、離屏暫停、模擬 page-hidden 事件、載入失敗後重試、真實觸控、整頁既有操作與導覽。暫停時實驗桌的實際截圖逐位元相同。
