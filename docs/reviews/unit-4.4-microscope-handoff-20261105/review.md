# 第九區：用同一個 A 中間像連接兩段成像

日期：2026-11-05

依核可示意圖，第一段近看原物、物鏡與中間像，第二段近看同一個中間像、目鏡與眼睛。圖內分別標示「原物 → 物鏡 → A」及「A → 目鏡 → 眼睛」。兩段的取景、當前工作與右側比較對象不同，避免只換文字而看不出分段。

主圖的金色 A 框持續保留同一個圖案，透過引線標示鏡筒內的中間像位置。第一段標為「物鏡形成的實像」，第二段改為「目鏡觀察的物體」。右側將第一段結果 A 原樣帶入第二段的觀察對象；下方用「前一段的像，下一段的物」點出接力關係。主圖內的中間像位置標示不是實體屏幕。

## 檢查

- 成像計算兩項通過：原物位於物鏡 F 與 2F 之間、中間像位於目鏡焦距內；同一光線跨兩鏡連續，反向延長線交於最終虛像。
- 瀏覽器互動七項通過，涵蓋同一 A 的圖案與節點延續、第一段結果等於第二段觀察對象、光路與物點偏好、鏡頭／頂部分段／下方卡片連動、鍵盤操作及立體顯示不可用時的備用剖面。
- 單元4.4整合檢查二十三項通過，涵蓋九個學習區、測驗、導覽、跨尺寸排版、深連結與鍵盤操作。
- 1440×900、1366×768、1024×768、760×900、390×844、320×844 六種視窗、各三種步驟共十八個畫面檢查通過：同一操作視窗可容納控制、主圖與比較窗；沒有水平溢出、標籤越界或字形縮放，瀏覽器沒有頁面錯誤。
- 實際檢視桌面第一／第二段與 320px 手機第一／第二段截圖，確認不同取景、A 引線、焦距標示、光路、比較圖與按鈕均可辨認。

圖案大小是定性比較，不用來量測倍率。兩組薄透鏡的原成像位置、代表光路與最終方向保持不變。輔助光路初次載入及重設仍預設開啟。
