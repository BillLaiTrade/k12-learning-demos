# 5.4第一區：依六項盤點改善辨識與判讀

日期：2026-11-07（Asia/Taipei）。使用者指示依前一輪六項建議優化，延續三段觀察與同一能量模型，維持第4階段。

## 六項對照

1. 冰、水、玻璃：加強冰塊輪廓及水面邊緣；沸騰時顯示固定起點水位虛線與對應標籤。冰塊大部分浸入水中，尺寸仍依剩餘冰量縮小。
2. 溫度讀值：放大立體溫度計及LCD，以較粗深色字顯示；3D可用時隱藏多餘的左上浮動框但保留輔助語意，SVG替代時仍有可讀數字。
3. 曲線判讀：橫軸全程固定0～120kJ；0°C水平線加底色襯線，冰融化／水升溫／水沸騰標籤隨實際觀察出現，不預畫未來段落。
4. 停點標示：前段完成而下一段未播放時標「待開始」，操作中手動暫停才標「已暫停」，避免誤認漏看一段。
5. 文案分工：圖下描述狀態，操作旁提供下一步，發現區整理概念，不在三處重說相同讀值。
6. 科學解釋：最後整理為「持續吸熱，可能使水升溫，也可能讓冰融化或讓水汽化；吸熱不代表溫度一定上升。」刪除已無對應欄位的「質量以讀值為準」；補充交代辨識用配色及固定座標。
