# 4.5 像素電視：可見的調色控制與獨立啟動

2026-11-04（臺北）。使用者回報第二小測不直覺，提供截圖：只有三色名稱及級數，15個按鈕皆缺席，顯示初始「互動尚未載入／啟用JavaScript」提示。

## 問題與修正

既有HTML的級數區是空容器，必須等lesson.mjs匯入並啟動pixel-tv.mjs，才由程式建立按鈕。任何未啟動狀況都會留下空白控制區；失敗提示也沿用初始無JS文字。截圖能證明未初始化，不能單憑截圖斷言是快取、網路或使用者停用JS。

將15個按鈕放進HTML，初始化改綁定現有按鈕。載入前可看見按鈕但不能誤操作。新defer載入器獨立匯入調色模組，不依賴lesson.mjs及其他教學模組；新版本網址避免沿用舊入口。主課程不再載入TV。初始化有ready檢查，避免重複綁定或重設。載入中與錯誤各自顯示清楚提示，8秒等候可提供重載，錯誤立即顯示；無JS獨立提示。重載以重新整理頁面處理，與原本暫存生命週期一致。

## 操作呈現

- 任務先說明具體目的，三步列出看目標／選格→點RGB亮度→檢查／填入。
- 「在這裡調色」面板內有紅、綠、藍各0～4原生按鈕，同時標關閉／弱／中／強／最亮，選取使用各通道色並同步aria-pressed。
- 桌機畫面對照與調色並列，1100px以下依序排列，手機仍保留實際／目標對照。面板內直接顯示目前色塊，任務1即時更新左圖，任務2／3明說按填入才更新所選格。
- 主操作按鈕緊接調色面板；子像素解釋收合，灰色空格說明只在適用任務出現。

三任務進度、試調帶回、模型0～4、125種設定、固定題圖與判定不改；五教學區與第一小測HTML保持，沒有新依賴、圖片或外部服務。沿用已核可三任務，不變更成其他評量。
