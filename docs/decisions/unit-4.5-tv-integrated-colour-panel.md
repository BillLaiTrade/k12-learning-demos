# 4.5 像素電視：調色與填色預覽整合在同一面板

2026-11-04。使用者指出RGB操作在右上、準備色與RGB預覽在左下，相隔太遠，操作不直覺，要求修改位置。

將「這一格的目標／準備填入的顏色」移到調色標題下、RGB按鈕上方；RGB子像素／合成色移到按鈕下；方向回饋、檢查／填入、返回試調及重設也納入同一張tv-tuner面板。左側只保留畫布、目標圖及選格工具，準備色跟隨右側調色器。所有節點仍各一份，不複製預覽或狀態。

預覽、RGB與操作按鈕間用短間距及分隔線，不再放成多張遠離的獨立卡。手機沿用色盤在畫布後、調色器前的順序，目標／準備色在同一列，文字可換行；不設固定高度、不裁切，不使用浮動覆蓋。

只改HTML結構與作用於面板內的CSS；原模型、控制器與載入器完全保持，CSS使用新版本。橙色調色、紫色補格、三段選擇、方向提示、色盤重用、手動填入與三任務狀態均保持；一窗導入及其他學習區不變。

更新既有七視窗檢查，確認預覽、RGB、回饋與按鈕皆在同一面板，左側不留預覽；藍光按鈕到RGB預覽、預覽到回饋、回饋到填入各段空隙不超過16px，色票不跨出面板，按鈕至少44px。完整35項活動回歸核對操作、手機／鍵盤、載入備援、無JS與兩個小測獨立。實際結果與公開截圖存主專案review。
