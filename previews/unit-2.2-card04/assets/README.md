# 材質近照與微觀圖形

- `material-specimens.png`：2026-10-28 使用影像生成工具製作的 1024×1536 原圖，未另行修改像素。三個等高區域依序為空容器中的空氣、透明水體與實心鋼材；窗光、木桌及背景一致。
- 以 SVG viewBox 取用 y=0／512／1024、各高 512 的區域，維持原比例。近照協助辨認材質，不是實際 100 公尺的器材配置，也不作為聲速量測依據。
- 微觀圖形由 `rendering.mjs` 以原生 SVG 繪製：常見氣體分子、水分子及金屬原子具有不同外形與球面光影。水分子兩個氫方向的夾角為 104.5°；簡化球棒與配色不代表真實可見顏色或尺度。
- 各個分子／原子圖形的整體平移，與鋼中彈性連結的伸縮，由 `model.mjs` 的共同振動資料更新。最右端放大區共用同一到達延遲，位移放大五倍。
- 沿用 `shared-assets/characters/dialogue-character-avatars.png` 正式角色，不在預覽另製人物。
