# 3.4 聲波反射與回聲初稿

依使用者核可的6教學＋1小測規劃製作，仍在第四階段供檢視，不代表第五階段整課檢查、完整單元外部驗收或最終核可。

## 檔案與啟動

- `lesson-base.css`：沿用5.2的既有基礎樣式副本；共用頭像相對路徑相同，不改動5.2。
- `echo.css`：本課圖文比較、控制與窄視窗樣式。
- `echo-model.mjs`：往返物理關係、波前位置、反射延遲與結尾小測判讀。
- `echo.mjs`：六區SVG、控制、跨區播放管理、音效及小測。圖文與初始比較不需播放即可閱讀；重來保留目前條件。
- `room-phrase.wav`：自製離線合成語音，來源與產製方式見[音效紀錄](AUDIO-SOURCES.md)。

從展示repo根目錄以Python HTTP server提供靜態內容，再讀取 `units/3/parts/3.4/`。若從 `/workspace` 提供服務，網址前綴為 `/k12-learning-demos/`，與其他課程一致。

## 模型與播放

第一區已依核可示意改為木製反射板與實體器材場景，見下方最新規格。第2–3區維持牆面反射、340m/s；第4區水中1500m/s。聲速是題給近似，非實測。第2–4區動畫放慢8倍、提示音配合動畫，不是實際傳播錄音。公式限近似同位置發射／接收、固定目標、往返同介質；聲納為垂直探頭到海底的距離。

第5區相同650Hz短合成音比較：單次回聲延遲0.65秒、相對增益0.55；密集反射採延遲 `[0,.07,.13,.21,.31,.44,.59,.77,.98,1.22]` 秒，直接聲增益1，其餘為 `0.62*exp(-i*0.22)`。這是教學用的接收事件／路徑示意，不是房間聲學實測。

第6區用同一語音與相同延遲，比較處理前／後；吸音處理後只有反射增益改為 `0.62*exp(-i*0.65)`，直接聲不變。不用整體降低音量冒充吸音。圖中吸音區域對應上下兩條示意反射路徑的接觸面；材料不代表產品或真實係數。兩區圖表表示短音的到達紀錄，非整段語音的振幅波形。

第一區聲音開關預設開啟，須點喇叭或按鈕後才播放；其他區聲音仍預設關閉。Web Audio採同一固定輸出縮放和可調音量，沒有啟用麥克風。跨區播放先暫停舊區，改條件或重來停止該區音效；分頁隱藏／離頁停止，返回不自動播放。減少動態偏好仍允許學生主動播放科學示意，可隨時暫停；沒有自動背景動畫。

聲納距離收合會同時隱藏圖上距離、答案及帶數值的深度控制；可由往返時間推得結果。顯示答案或取消收合即可再讀距離。
