# 4.5 第三區：手電筒質感對齊核可示意

日期：2026-11-03（臺北）。使用者指出已上線的手電筒質感與核可示意圖不相符，附現況截圖。本輪依既有修改／發布授權，重做手電筒呈現，保留正面白幕、混光條件、直接拖曳、開關／排列與正式角色圖像。

原本短筒SVG有明顯輪廓線、綠灰漸層與稀疏橫紋，缺少示意圖的黑色金屬長筒、菱紋握把及真實立體光影。改以既有4.1 Three.js建立車削筒身、較寬燈頭、散熱環、薄紅／綠／藍識別環、幾何菱紋握把、細部尾蓋與橡膠開關；採黑色金屬材質、粗糙度／凹凸紋理、棚燈環境反射、柔和接觸陰影。鏡頭固定從握把尾端朝白幕方向看，不把發光燈面對向學生。沒有新增套件、外部HDR素材或生成角色。

三支各自使用透明立體畫布，與原生手電筒按鈕重疊，沿用原抓取區與事件；朝向依各自落點更新，只在狀態改變時繪製。頁面接近第三區才載入立體模組。桌機／手機的畫框和比例一起調整，器材保持在白幕下緣，不遮住混色區。

載入前及WebGL／立體模組不可用時，使用同一模型直接輸出的三張360×260透明PNG，保留金屬質感，並以小角度旋轉提示瞄準；直接拖曳、方向鍵、取消、燈具開關與白幕計算不依賴立體載入。立體場景可用後替換圖片，初次繪製完成前不隱藏圖片，避免空白。

白幕Canvas2D、mix-optics.mjs、CIE資料、三光源功率配比、七區與判定保持。本輪為外觀及載入／備援擴充，不重跑未改的純光學模型；更新整頁瀏覽器檢查，涵蓋實際立體轉向／畫布可見、載入前後白幕剖面像素保持、同模型圖片備援可操作及既有七寬度／手機／其他區回歸。正式角色素材與對話保持。
