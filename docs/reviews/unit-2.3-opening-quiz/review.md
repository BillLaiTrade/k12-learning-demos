# 2.3 開場插圖與單元小測呈現修訂

日期：2026-10-29。依使用者要求，比對 1.1、1.2 的開場圖片及結尾區塊，再修訂 2.3。

## 比對與修改

- 1.1、1.2 均有開頭情境插圖及獨立「單元小測」。來源是現行 `units/1/parts/1.1/index.html`、`units/1/parts/1.2/index.html`；兩頁沒有名為「單元小冊」的閱讀功能。本輪依實際頁面對照，採用單元小測的呈現慣例。
- 新增 `assets/air-story-opening.webp`（1672×941，233,688 bytes）。以共用頭像及 1.1 核可情境圖作角色、畫風參考，生成花圃旁觀察空杯的情境；對照小葵的雙丸子頭、米白連帽上衣與深色背帶，以及阿公的白髮、圓眼鏡、無鬍子白袍造型。插圖是故事畫面，不作為實驗觀察證據。
- 頁首桌機並排圖文，窄畫面上下排列；圖片有尺寸、替代文字及圖說，以本地 WebP 載入。
- `#s8` 沿用既有整合題與獨立 150→120 mL 示例，改為與 1.1、1.2 一致的問號圖記、金色「單元小測」標籤及獨立標頭。側邊導覽、頁首提示也直接標示單元小測。
- 本輪只改呈現用 HTML、CSS 及開場圖，互動 JS、模型、答案判定與 2.1、2.2 檔案未變更。
