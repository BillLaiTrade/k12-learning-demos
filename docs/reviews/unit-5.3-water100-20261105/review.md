# 5.3 第一區：100 g 水與熱量單位（2026-11-05）

## 指示與範圍

使用者先要求參考完成單元分析第一區與生成示意圖，後續指出直接加熱1g水不夠貼近現實，要求越接近實驗越好；討論改用100g水觀察後，明確指示繼續製作第一區。據此完成可操作網頁；維持第4階段，待成果檢視。

- 保留第一區探索標題；副標改為從100g水升溫認識「卡」。先量取100g水，手動開始20→21°C，到點停止；約5.8秒動畫對應模型約23.3秒，明示加速。
- 以新生成的正常比例燒杯、約100mL水、攪拌加熱器、浸水探針與數位儀表替換原1g放大裝置。圖源與尺寸見素材README；只有器材背景是圖片，溫度與操作由程式驅動。
- 即時LCD、目前溫度、溫升與進度同源。操作前不顯示cal數字／定義；完成後顯示100g水升1°C約100cal，再換算每1g水升1°C約1cal。水吸熱屬模型估算，溫度計沒有被當成熱量計。
- 水與容器為同溫集中熱容量模型：C dT/dt＝P－k(T－20)，分開水吸熱、容器吸熱與環境散熱。20W是有效供熱，非器材額定功率。所選42J/°C容器熱容量與0.5W/°C散熱係數為模型設定，未實測校正；未呈現探針遲滯／停熱餘熱，完成後保留當次讀值。
- 無暫停鍵；重來清除進度與完成說明。換區／失焦／背景停止，重新觀察從20°C開始，不自動續熱。圖片未載入不能開始；失敗可重試，其他區獨立可用。
- [保留核對](preservation.json)：第二至第五區、小測HTML逐字相同，原開場圖、分享資訊、導航與其他控制器保留；未修改其他單元。
