# 第六區直接拖曳水面與眼睛

2026-11-04。使用者先詢問垂直拉水面是否比水平水位滑桿直覺，繼而要求眼睛也能直接前後移動，並授權將兩項更新上線。

## 操作對位

移除下方兩條水平滑桿。水位仍為0–100公分，改在左側槽壁外放置隨水面同高的44px上下把手及水深讀值；空槽時把手留在槽底，可直接開始拉。水面附近44px帶亦可上下拖曳，並使用按下時水深與滑動差值，避免碰到擴大觸控區便跳位。只有操作區攔截手勢，其他圖面仍可捲動手機頁面。

水位把手採可聚焦原生垂直range（writing-mode及方向控制），支援方向鍵、Home／End、螢幕閱讀器與觸控。真正互動元素直接置於場景，沒有藏起第二套水平控制。數字與把手皆跟隨水面高度，光路與右側視野共用原幾何。

眼睛為唯一觀看位置控制點，保留原40–170公分距槽前側範圍；增加「拖曳眼睛」、雙向握柄與即時距離。前後拖曳沿剖面水平軸移動，左為靠近、右為遠離；採相對位移，避免按到偏離眼睛中心的觸控區時跳動。方向鍵微調2公分、PageUp／PageDown調10公分、Home／End到兩端，ARIA更新距離。焦點框只包眼睛本體，避免壓到數字。

水位及眼睛的直接操作開始即停止加水／光路示範，接續目前狀態，不重設硬幣或另一個變因。保留加水觀察、重播光路、重設、光路開關、離屏續播、減少動態及材質重試。起始仍是空槽、距前側130公分看不到硬幣。

## 驗證

在原雙視角專項補入原生垂直把手／水面拖曳、無跳位、鍵盤、手動接管加水、手機拖水位不捲頁、非操作區仍可捲頁，以及單一場景控制與最小觸控範圍。廣泛狀態測試透過公開的鍵盤事件設定眼睛位置，實際滑鼠／鍵盤／原生觸控另行驗證。模型保留原檢查。
