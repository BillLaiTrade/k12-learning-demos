## 科學與聲音

基頻以65cm第5弦A2=110Hz為參照，按格以十二平均律改變有效弦長；第12格為一半，基頻為兩倍。相同長度時基頻隨相對張力平方根變化，張力兩倍不是頻率兩倍。材質、線密度固定的理想弦示意，不教公式推導，也不聲稱包含實際按弦引起的全部張力微變。

按哪邊就撥哪邊，參照音也有動畫。只有琴橋到有效終點的弦段作單一基本模態振動，兩端不動；被按住後通往上弦枕的一段保持直線。畫面頻率共用100倍放慢尺度（110Hz→1.1Hz、220Hz→2.2Hz），位移放大，沒有把時間波形畫成多個行進波。音訊與畫面以同一AudioContext時間取樣，共用起音／指數衰減／收音包絡，長2.4秒。

聲音是新合成的撥弦泛音示意，並非吉他實錄；有明確起音與自然衰減，初段RMS>0.20、峰值<0.95，不削波。兩側相同撥弦模型與初始位移，不宣稱不同頻率主觀響度完全相同。第一區6倍、第二區14倍增益及其他區音訊維持。
