# 2.3 第二區：看比例、看混合與成分放大

日期：2026-10-30（臺北時間）。使用者核可[完整操作示意圖](approved-mockup.png)後指示製作；本次只優化第二學習區塊，維持六教學＋一小測及第4階段逐區修訂。

## 實作

- 簡短小葵／阿公對話帶入空氣是混合物，沿用已統一的對話格式。
- 預設看比例；看混合將同一批100格換位。兩種排列皆為78氮／21氧／1氬與其餘合併格，圖例一直顯示氮約78%、氧約21%、氬約0.93%與其餘少量。
- 放大圖預設可見：氬占大部分，其餘占小部分；氬0.93%的分母是全部乾燥空氣。條形面積為近似示意，不新增推算的精確餘量；不把整格標成氬氣1%。合併格以虛線連到放大圖，切換排列與改變視窗時更新。
- 兩種排列都可選取四項成分；氬／其餘在主圖突出相同的合併格，但在放大圖突出不同部分。移入／聚焦暫時突出，點選／觸控保留選取。切換排列保留選取；顯示全部只取消突出、保留排列。
- 短暫換位動畫，減少動態偏好即時切換；手機由主圖、2×2圖例、放大圖、兩類氣體卡依序排列。
- 分類與必要說明精簡；永久不等於不反應，乾燥仍含二氧化碳。全部知識預存在HTML，無JavaScript時仍可讀，互動按鈕停用。
- 不新增測驗、操作關卡、套件或外部服務。生成示意圖僅為審閱依據，正式格數與文字已校正，不作為科學來源。
