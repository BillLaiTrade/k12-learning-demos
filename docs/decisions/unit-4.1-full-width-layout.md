# 4.1 六區採頂部標頭與滿寬內容

日期：2026-11-01（臺北時間）。使用者指示參照已完成的2.2，移除學習卡片內左欄與垂直分隔線，保留原內容、互動、外側導覽及錨點。

六個學習區塊`card-01`至`card-06`統一採`.lesson-head`、`.lesson-number`、`.lesson-body`：編號置於標頭左側，原主標題與短說明位於右側；整個內容區在標頭下方橫跨卡片寬度。兩段原左欄文案移入副標，不刪除文字，不另留一份主標題。沿用2.2的標頭間距與編號樣式，900px以下縮減內距、700px以下縮小編號，副標可自然換行。

本次不變更外側探索路線、圖像、各活動的內部分欄、模型或操作控制。結尾影子劇場已為滿寬配置，保留原呈現。HTML內互動程式及外部腳本版本不變。

驗證包含六種寬度的逐區幾何、主標題／副標及溢出檢查，與2.2的標頭樣式比對，桌機／觸控操作，以及既有三孔板與影子劇場回歸。舊三孔板測試的相鄰頁入口仍指向改編號前的1.2，本輪改為實際4.2；只更新測試網址，未變更教材分工。
