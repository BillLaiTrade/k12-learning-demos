# 4.5 拖曳取樣框、放大鏡自動跟隨

2026-11-05。依使用者確認的示意與後續修正，拖曳對象改為原圖上的小取樣框。放大鏡只顯示預覽，不再接受拖曳，也不增加點圖換選。

## 操作與呈現

- 兩張圖各有44×44px透明抓取範圍，內側小金框／十字對應實際原圖像素；邊緣抓取保留偏移，按下不跳選，範圍在圖內。鏡面為非互動元素，不阻擋取樣框。
- 鏡面在取樣點旁顯示真正5×5鄰域，中央一格金框；以短線接回原圖取樣位置。鏡身與鏡柄保留在圖內，選擇可避開取樣點的一側，該側仍合適時保持，避免拖曳中來回翻動；原圖與結果圖採相同避讓方向。超出圖像的鄰域留空，右側仍只顯示單一選中色及RGB。
- 拖曳中立即更新兩圖取樣框、鏡面、顏色與RGB，狀態顯示「取樣中」；放開顯示「已選定」。保留快速觀察、方向鍵、Home／End，觸控拖框不捲頁，鏡外維持頁面捲動。
- pointer capture追蹤圖外移動；Escape、取消手勢、遺失捕獲、失焦、隱藏、resize及模式切換還原選取與原RGB草稿。移動經過其他色再回原組仍保留調色。

## 更新量與保留範圍

預建原圖色彩索引，按需快取群組輪廓；未換像素時不重做選取更新，觀察與整圖模式取樣時不重畫未改變的結果圖。真正改RGB或同色組時，仍使用原有RGB模型重繪；不用近似濾鏡。圖片、3842色、同色分組／整圖通道計算、初始第一步、五教學區與第一小測保持，不改其他單元及4.1格式。

像素活動維持獨立載入、重試與無JS靜態預覽，HTML／CSS／loader／模組使用同一tv-sample版本。舊拖鏡面規格由本決策取代，歷史紀錄保留。
