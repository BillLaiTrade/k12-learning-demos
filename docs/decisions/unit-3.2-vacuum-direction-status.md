# 3.2 第05項：鐘罩提示依實際空氣變化方向敘述

日期：2026-11-01（臺北）。使用者選擇 A，修正第三區抽氣、停止及進氣時的輔助提示。

- 將空氣目前的狀態（充足／較少／接近真空）與變化方向分開。
- 抽氣且空氣量仍下降時，描述空氣逐漸減少、鈴聲逐漸變弱；進氣且仍增加時，描述空氣逐漸增加、鈴聲逐漸變清楚。
- 停止抽氣、關閉進氣、抽到下限或恢復充足後，描述空氣量保持不變；鈴聲採清楚／較弱／幾乎聽不見等當下狀態。
- 電鈴關閉時只描述電鈴關閉與空氣狀態，不宣稱聽到鈴聲；音效錯誤仍優先顯示既有錯誤提示。

僅修正既有 aria-live 提示文字及控制器快取版本；器材圖、按鈕、空氣模型、音量、分貝及播放流程保持原設計。第06項音訊輸出中斷處理仍待逐項決定。
