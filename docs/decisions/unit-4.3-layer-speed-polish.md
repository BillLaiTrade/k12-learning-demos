# 4.3 小測材質與器材精修

2026-11-04（臺北時間）。使用者指出小測的精緻程度與已完成的第一區光速比較台差距太大，並提供兩者畫面對照。依同系列木質、厚玻璃與金屬器材的呈現重做，保持三層光速排序的功能。

改用三份專用imagegen圖稿：橫向／直立木質底座與玻璃金屬框，以及透明背景黑金屬光源。以第一區既有比較台為材質參照；沒有把新素材當另一個待核可設計，直接完成實際頁面。圖稿沒有文字、光路、法線、內部介面或速度答案。程式依圖中正面玻璃位置繪製三層色澤、介面與光路；名牌以倒角、螺絲、投影補足實體感。光源圖稿以玻璃出光口作旋轉基準，與模型首段起點對齊。

桌機／手機分別用合適比例的圖稿，圖像可依容器呈現；光學x、y仍等比映射，沒有把角度拉伸來配圖。原純模型、相對速度、動畫、排序、回饋、換題與六個教學區保持。

增加素材預載與狀態：載入時顯示簡短提示，正常後收起；失敗或過久可使用暖色底座與向量器材，排序可繼續，晚到的圖像仍可恢復。新圖留在本機素材目錄，不新增套件或外部服務。原檔來源與幾何錨點見[素材紀錄](https://github.com/BillLaiTrade/k12-learning-demos/blob/main/units/4/parts/4.3/assets/README.md)。
