# 2.3 慢慢傾斜與移除杯口放大（2026-10-29）

## 使用者回饋與修正

- 使用者指出慢慢傾斜看起來像瞬間傾斜，並要求移除放大杯口按鈕、功能及整個區塊。
- 原控制器在減少動態偏好下直接套用終點，在播放中切換為減少動態也會跳到完成；本次移除這兩條跳轉。沒有假定使用者瀏覽器當時的偏好設定。
- 按鈕啟動的傾斜改為約6秒等速連續轉動，入水仍約1.8秒；一般與減少動態模式都保留必要的杯子運動。暫停／繼續、手動拖曳、上提保留角度及重做保留。
- 減少動態時不播放移動氣泡，完成後呈現靜態氣泡；偏好變更不改寫當前角度或強制完成。
- 移除放大按鈕、整個放大區塊、事件、重設／繪圖處理、放大模式與CSS，暫停提示也不再提放大。操作列只保留觀察主按鈕與換乾紙重做，桌機／手機均為兩個按鈕。
- 本次HTML、杯子CSS、控制器與繪圖版本同步至 `cup-lab-4`；模型沿用前輪 `cup-lab-3`，沒有變更氣體模型。
