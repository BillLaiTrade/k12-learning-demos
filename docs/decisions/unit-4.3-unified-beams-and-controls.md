# 4.3 統一光束、嵌入箱體與精簡實驗重點

日期：2026-11-03。使用者要求先逐項記錄三項回饋，明確授權後一次修改。

- 第三、第四區以第三區的金色光暈、金色主線、淺色亮芯，加上第四區方向箭頭。共用光束樣式及箭頭顯示規則；主圖保留原第三區亮度與粗細，近拍按視圖單位換算。箭頭固定在各段36%位置，待光的前緣越過箭頭尖端才出現。
- 第四區由靜態光線改為連續前緣，依第三區共同速率：空氣0.24、水0.18、玻璃0.16示意單位/ms。到達介面的時間依實際路徑長度計算，沿同一入射點折射後加快；共同慢動作不代表真實秒數。新增暫停／繼續，離屏／隱藏暫停、完成停止迴圈、關燈重置，重新開燈重播；調角或切換介質保留完整預覽。第五區雙光源仍採原顯示方式。
- 第三、第四區的水／玻璃選項位置保持，外觀改為貼合底框的金屬底座、固定螺絲、嵌入式按鍵與清楚選中狀態。維持兩選項、原生按鈕及讀屏。固定面板與子元素不使用過場，避免共用減少動態規則使縮放後的繪製短暫落後位置。
- 主重點區只留上下白色的介質轉換與實驗結果／角度，移除光較快／較慢小字、左側波前長文及額外例外段。詳細原因和0°例外移至／保留在可展開說明；第四區也補足波前先進入空氣變快、因而轉向的解釋。介質及即時讀值保持同步。

檢查共64項（含外層），包含新速率、連續界面、箭頭不超前、兩視圖同步／亮度與實際線寬、所有播放狀態與取消、面板手機縮放／選取、上下簡要區塊／展開原因，及原幾何、A／B拖曳、載入競態／重試、格式、整課與小測回歸。不改照片或共用折射模型，不新增依賴。仍為第四階段修訂，待使用者檢視。
