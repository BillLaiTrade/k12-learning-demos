# 3.2 五個學習區塊改為2.1版型

2026-10-31（臺北時間）。使用者要求3.4完成後，也將3.2各學習區改為2.1的橫向標頭與滿寬內容。

- 五區統一為頂部編號徽章、原完整標題、原概念及角色簡介；下方lesson-body包住原card-main，移除橫跨卡片全高的側欄。標頭、內距、底線、字級及手機斷點沿用2.1現行值。
- 原有ID與順序、鋼尺／敲鐘／真空鐘罩／介質與溫度實驗及唯一煙火小測內容保留。原內嵌鋼尺與導覽程式保留；圖片、音訊及物理模型不變。
- 第四、五區控制器原只在實驗主體查找標題。標題移到頂部後，查找先沿用原範圍，缺少時僅補查同一lesson-card，維持各區ID前綴隔離與既有預覽頁相容。頁面更新該模組版本參數，避免舊快取找不到標題。
- 回歸時，以修改前版本重現四個聲速舊子項的失敗：跨區仍應同時播放、舊「分別敲擊」文字及同時啟動兩區的真實秒表。依現行lesson-playback的跨區暫停規則，改驗證暫停保留進度、重設互不清除，以及依序用真實秒表檢查兩區；未修改播放或物理規則。滿寬後的圖像高度隨寬度擴大，檢查改為場景之間保持緊湊留白，原到達時間與速度斷言保留。
- 舊版面檢查改驗五區頂部標頭及滿寬位置。瀏覽器原生media預載的net::ERR_ABORTED不判為資產失敗；HTTP錯誤、其他資源失敗、實際音檔解碼／播放及音訊訊號仍嚴格檢查。

畫面與結果存於`docs/reviews/unit-3.2-full-width/`；本輪仍為第四階段版面修訂，不新增整課驗收或最終核可。
