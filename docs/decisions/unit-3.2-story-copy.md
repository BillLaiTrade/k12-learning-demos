# 3.2 故事線與文案逐項檢視

日期：2026-10-30（Asia/Taipei）。

使用者要求重新從開場到單元小測檢視故事與文案，逐項決定是否修改，不預先改動待討論項目。

## 第 1 項：第一區阿公在操作前引導觀察

- 使用者核可將操作前的結論式說明改為：「我們來撥動鋼尺，再用手按住它，看看聲音和它的動作會怎麼變。」
- 操作後既有的阿公說明保留，讓前後分別負責引導觀察與解釋結果。
- 本項狀態：已製作，待使用者檢視。

## 第 2 項：第二區小葵從生活觀察提問

- 使用者核可將小葵的問題改為：「鐘離我這麼遠，聲音是怎麼傳到我耳朵裡的？」
- 由聽見遠處鐘聲的疑問出發，交由阿公說明空氣傳遞振動。
- 本項狀態：已製作，待使用者檢視。

## 第 3 項：第三區小葵提出沒有空氣時能否聽見的疑問

- 使用者要求不預設小葵已知道抽氣的方法，先提出沒有空氣的情況。
- 核可台詞：「如果電鈴還在振動，可是周圍沒有空氣，我還聽得到鈴聲嗎？」
- 本項狀態：已製作，待使用者檢視。
