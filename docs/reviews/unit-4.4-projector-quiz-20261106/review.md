# 4.4 單元小測：投影機任務審查

日期：2026-11-06

依核可示意圖，以投影機任務取代小測四題文字選擇題。任務、器材、投影與控制同一工作區，提供凸／凹透鏡、圖卡及鏡片位置、180°旋轉、提示與檢查成果。保留小測錨點、導覽與原有單元版式。

成像與判定共用薄透鏡和有限孔徑光路；屏幕未對焦、圖卡方向錯誤、圖案未放大或超出目標框皆不通關。目標框與圖案邊界共用資料，接受多組正確配置。清楚實像保留圖卡原色、上下左右反轉，虛像配置不會顯示牆上的清楚像。

立體鏡片沿用核可的旋轉對稱外形；燈箱、透明圖卡、導軌、底座及投影幕有完整支架。光源外殼微向後避開圖卡視線，光源開口仍覆蓋光軸。標籤為正常比例HTML，手機置於器材下方。模型需要時才載入，失敗時可用相同判定的剖面圖完成任務。

## 檢查

- 四項計算測試與六項瀏覽器情境通過（測試摘要含父測試共11項）：對焦、非唯一解、等大與放大、過大影像、凹透鏡／焦點內、像的門窗方向與原色、提示不移動器材、鍵盤、間距、重設及WebGL備用操作。最後再確認等大不通關、略放大的正確配置可通關。
- 七種視窗（1440×900、1366×768、1280×720、1024×768、760×900、390×844、320×844）各初始／完成兩種狀態，共14個畫面通過；最後收整器材視線後，另確認桌面與320px的四個畫面。沒有橫向溢出、文字裁切、標籤重疊或立體／備用圖重疊。桌面初始主要控制與提交按鈕都在視窗內。手機仍保留既有固定學習路徑列，可正常捲動操作。
- 整頁七項相關情境通過（摘要含父測試8項，15項無關既有情境未重跑）：九教學區與唯一小測、任務通關、與4.1版式一致、1440／390／320px十區導覽、深連結及原生觸控導覽。
- 靜態比對確認前九區HTML逐字相同；lesson.mjs僅移除舊四題處理器，其餘事件與光學程式保留。
- 人工檢視桌面初始、完成畫面及窄手機器材畫面，確認圖卡倒放、投影正立、門窗左右對應、凸透鏡形狀、原色與標籤清楚。瀏覽器無頁面錯誤。
