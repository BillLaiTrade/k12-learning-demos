# 5.3 第三區兩杯水量比較台（2026-11-06）

使用者指示依核可示意圖與改良方案製作第三區。兩杯同規格寫實器材並排、A固定100g、B可選100／200／300g，預設先比相同水量；水位隨質量改變。移除大型曲線，改為共用0～10°C刻度的溫升長條，完成後自動記錄及歸納。單一開始／重新比較、可點與鍵盤旋鈕；無暫停、獨立重來或手動記錄。未完成不寫入，同條件重播不重複增加列，最多三種條件。

新背景依核可示意另製，空杯與空白LCD，水體／探針末段／攪拌子／指針／燈號及數字由程式繪製，原圖與編碼記錄於assets/README.md；不將整張介面圖替代實作。各杯水用同一組前兩區教學參數，分開計算容器吸熱與環境散熱，各吸收1,000cal後獨立停熱。動畫同為50倍，沒有強制同加熱時間；模型熱量非量測值。停熱後保留觀察瞬間，未模擬等候冷卻／餘熱／探針延遲。

## 本機驗證

初跑第三區模型／操作及第一、第二區、共通器材／格式六套共30項（含父測試），27過3失敗：[初跑](local-initial-test.txt)。兩個子項失敗：第三區停熱相隔較短，測試時鐘未暫停，跨次讀值會隨真實測試耗時前進；390px紀錄表仍受高優先度雙欄規則影響而擠字，父項隨之失敗。修正窄版規則優先度並固定測試時鐘後，第三區5子項加父項共6項全過：[最終操作](local-mass-final-test.txt)。其餘模型3項與四套既有21項已於初跑通過，原檔及行為保持，不重複跑無關檢查。

覆蓋100／200／300g端點、能量守恆、各自停止／停後不再攪拌、相同零點／刻度的長條、質量與水位同步、完成前不揭示結論、手動啟動／旋鈕Enter及滑鼠、重播不重複紀錄、切換條件清除當次狀態、換區／背景中斷不自動續熱、減少動態效果、慢載／失敗禁用與重試、其他區／小測代表性回歸。

三桌機1440×900、1366×768、1280×720及390／320px基本適配通過：[版面](layout-local.json)。無頁面橫向溢出，LCD與44px以上旋鈕在場景內，窄版紀錄表不擠字；器材台可左右查看。人工檢視初始、運行、200g完成、300g及窄版，水位／探針／攪拌子位置與讀值合理，長條2倍／1倍比例正確。未宣稱手機優先、實體裝置或跨瀏覽器完整驗收。
