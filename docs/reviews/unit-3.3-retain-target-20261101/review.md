# 小測調整時保留目標波形

2026-11-01，使用者選擇盤點第9項「保留目標波形」。

第一次有效比較後，同題改頻率、振幅、音色或按「繼續調整」時保留目標虛線與圖例，只清除舊對錯、分項建議及回饋動作。更動設定後仍需試聽才能再次比較；首次比較前與換題後目標隱藏。換題清空目標路徑、圖例及揭示狀態，不自動播放。

本機模型、小測專項與整頁回歸三檔30項全過，0失敗／略過，見local-tests.log。涵蓋三種設定改動、繼續調整、成功後再修改不殘留成功結果、重新試聽後產生新建議、自己的波形載入失敗／重試時目標仍保持、兩個換題入口都清空舊目標及原取消／音訊／鍵盤流程。
