# 5.2 合身包覆盆壁（2026-11-07）

使用者認為淺布托盤式畫面不合理。新版以同一玻璃盆穿上合身布套的完整素材取代獨立布圈，沿盆身包到玻璃蓋下，無凸出的托盤底／把手／前側挖空。保留透明蓋，布料正常遮住水位與下方瓶身，露出的瓶蓋仍可拖；點布套或器材鍵取下可看水位。配置切換保留溫度與水量，不自動開始。

## 模型與素材

image_gen原檔與匯出見asset.json及assets README，原圖保留，僅縮圖與WebP編碼。側壁包覆教學面積由40%改85%，其餘公式／熱容量及守恆保持，並非實測商品效能。preservation.json核對六區、水體遮罩／漸層、金屬探頭材質與其他控制器保持。CSS未改。

- model-tests.tap：13項，有限熱源、能量守恆、包覆減少散熱、達標與長時間趨室溫全過。
- local-ui-tests.tap：14項，原操作、停續、載入失敗／重試及鄰區獨立全過；抓取位置改可見瓶蓋。
- check.cjs：1366／390／320px，裝卸／重裝、量杯、滑鼠與實際手機觸控抓瓶蓋全過。before走基準242fc5c8的原檔案，沒有回改目前工作樹。
