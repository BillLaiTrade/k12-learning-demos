# 4.4 第四區立體實驗台與常駐眼睛視角交付

2026-11-02。使用者核可approved-layout.png的最後格式，明確要求功能、相應畫面、示意一致性全部檢查後再交付。[決策](../../decisions/unit-4.4-magnifier-3d.md)記錄本輪設計。維持第四階段修訂，第四區及其導覽改為「凸透鏡什麼時候能當放大鏡？」；其餘九區HTML、共用樣式及舊專屬資產保留，見preservation.json。

左側為可旋轉／縮放的立體器材，圖卡在焦距內直接拖曳，凸透鏡與眼睛固定。右側眼睛視角常駐，依虛像像高與固定眼睛至虛像的距離呈現正立放大圖案；原物參照使用同樣觀察位置、觀看角度及CSS顯示尺度。旋轉、縮放與光路開關不改右側像素，只有物距及屏幕遮擋改變時更新。桌機並排，手機上下，無拉霸或整體重設。

輔助實線、反向延長線與分物點追蹤在主圖內操作。實線進固定瞳孔，虛線沿其反向延伸；圖外交點明確提示虛像仍存在，沒有另一張實體圖卡。屏幕插在透鏡與眼睛之間，前面顯示散開光斑，右側同時呈現視線遮擋；屏幕可拖曳／微調／正面近看，取下恢復同一物距的觀察，不自動對焦。屏幕散開範圍由同一孔徑幾何計算，源點取樣、邊緣柔化與曝光只便於觀察，未模擬精確光度。理想薄透鏡、固定觀看位置、假設眼睛已調節看清等簡化均已在頁面說明。

本機新增模型4項、立體專項10項（含主項）及整課23項，共37項通過。模型核對虛像、固定眼睛視角尺度、瞳孔射線、反向延長線、散開包絡及範圍。專項直接讀取影像像素與CSS尺寸核對正立、連續大小、相同尺度參照、主相機與眼睛分離、光路共線、屏幕遮擋及恢復、相對拖曳、鍵盤微調、七寬度標籤避讓、原生觸控／取消／雙指縮放及WebGL失敗備援。整課確認標題／導覽、九教學區／唯一小測、與2.2共用版型及人物。測試僅攔截模組注入觀察與條件設定，正式程式無測試API。

人工檢視後修正窄版標籤避讓、圖外延長線裁切、光斑取樣紋路與右側畫面穩定性，再補上原物參照的CSS尺寸斷言，最後專項10項重跑全過。結果見local-*.txt，像素與七寬度資料見observer-pixels.json與layout.json。Chromium軟體WebGL與CDP觸控不代表Safari實機驗證。未重跑未變動的前三區專項與其他純模型。
