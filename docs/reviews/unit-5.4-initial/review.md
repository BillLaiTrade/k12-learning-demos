# 5.4 六區＋單元小測：整頁可操作初版

日期：2026-11-06。使用者明確要求先研究1～3成品，依六區及現行規格製作整頁初版，再逐區優化；並更正學生入口名稱為「單元小測」。依規劃庫共通規格v1.3、六區架構及展示庫AGENTS.md。來源基準159a4921，發布前同步遠端main；實際提交與公開結果於下方補記。

## 成品參照與採用方式

讀取九頁1.1、1.2、2.1、2.2、2.3、3.1、3.2、3.3、3.4的標題序列、敘事與操作內容；另讀既有共通規律盤點，並在Chromium以1440×900查看1.2、2.2、3.3的實際版面。不將此次研究稱為對九頁重新完整驗收。

| 參考 | 採用到5.4的方法 |
| --- | --- |
| 1.1：由數字到單位與估讀 | 讀值就近，圖中放大與測量值分清楚，不用放大增加器材精度。 |
| 1.2：隕石的質量／體積／密度 | 同一樣品由外觀走向可比較的數據，固定參照與結果一致。 |

## 教學區與操作

| 錨點 | 問題→操作→證據 |
| --- | --- |
| card-01 | 持續加熱是否持續升溫→開始／停熱／拖動進程→冰量、液態水量、溫度及吸熱曲線同源；蒸乾停止。 |
| card-02 | 反向變態的熱方向→切換四種現象並觀察→同一樣品箭頭與環境條件同步。 |
| card-03 | 固體未熔化也改變大小→試環、80°C加熱、20°C冷卻→真實所選尺寸跨越間隙，冷卻可恢復。 |
| card-04 | 液體、氣體與例外→切換液體／氣體／水例外及溫度→固定量體積、4°C密度最大及結冰膨脹分開。 |
| card-05 | 玻璃也膨脹→比較20／60°C及剖面→同尺度水增量、容量增量與差額。 |
| card-06 | 受熱是否生成新物質→已查證的脫水／水合反應→物質身分與相反能量方向，非只看顏色。 |
| unit-quiz | 單一六觀察點小測→讀條件、選理由、統一核對→狀態／溫度、凝結、氣體、水例外、溫度計及反應能量的遷移。 |

## 測試與實際觀察

- 本機最終21項通過：模型7項、瀏覽器13子項＋外層1項。見local-final.txt；五視窗35組版面見layout-local.json；pageerror／HTTP錯誤為空，見errors-local.json。
- 初次瀏覽器檢查失敗保留local-first.txt：識別到SVG漸層ID與讀值ID重複、漏答焦點選擇器錯誤，以及窄版導覽受共用nowrap影響而溢出；修正後重跑。模型第一次斷言把蒸乾終點仍當100°C，已改為只對尚有液態水階段期待100°C，保留蒸乾null溫度的獨立斷言。
- 另以一般時間、實際點擊觀察加熱0.9秒冰量下降、球80°C停在環上，以及水合放熱，未只靠受控時鐘。opening、heating、solid、water、thermometer、chemistry與mobile截圖保存代表畫面；截圖本身不取代操作證據。
- 未執行其他1～3單元完整回歸，因未修改其程式或資產；未作Firefox／Safari／實體手機或外部驗收。
