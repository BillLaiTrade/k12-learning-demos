# 第七區：眼睛調節

## 2026-11-05：依核可示意補上部位作用與操作先後

使用者核可完整頁面示意，另明確指定「物體遠近／水晶體調節」必須緊接眼球圖，「光進入眼睛後，誰負責什麼？」移到操作區下方。依此整理為眼球及成像窗、整合控制列、自動調節提醒、三部位作用與收合補充；沿用正式人物頭像及同頁標頭，示意圖不當作網頁圖片代替互動。

角膜說明主要會聚作用，水晶體說明再次折射及以厚薄調整會聚程度，視網膜說明接收影像且位置固定。主圖採兩行短標示，完整文字放在圖外。視網膜成像區標記對應右側「成像區放大示意」，右欄只留一個隨清晰狀態變色的狀態列；未對焦的原因與操作提示仍依現有模型更新。

背景改淡、內壁改暖白，水晶體改用柔和玻璃材質並取消點串高光，視網膜收窄為後壁弧形薄帶。這些視覺修訂不改光線端點、光學計算、眼球位置或遠近切換時保留調節的行為；示意圖中的看近處已對焦只是範例，頁面仍由正常看遠開始，讓學生自行改近並調節。窄版控制列與三部位說明依序排列，保持同一閱讀順序。

## 既有模型與範圍

本區以正常眼睛的調節為核心。視網膜、眼球與角膜位置固定；角膜的等效會聚作用固定，水晶體的等效會聚作用隨調節滑桿連續改變。調節滑桿上提供可點選的「清楚像」標記，位置由目前物距所需的會聚作用計算，並對齊原生滑桿把手的有效行程。點選後將水晶體調至該位置，仍可手動拖動比較失焦；切換遠近只移動標記。切換物體遠近保留調節與光路偏好，讓學生觀察改看近處後尚未調節的模糊，以及再看遠方時需要減少會聚作用。這些暫時失焦狀態不代表近視或遠視；矯正留在第八區。

主圖採固定正交視角的立體教材剖面，以半球內壁、具厚度的切面、曲面玻璃與柔和光照呈現體積；不使用血管、肌肉、視神經或寫實組織紋理。水晶體採圓潤的雙凸橢球體，調節時直接改變立體厚度，眼球與視網膜不移動。光路和精簡引線標籤疊在立體模型前方，沿用相同投影座標；顯示立體模型時隱藏向量器材，避免兩層模型疊印。立體顯示不可用時保留向量剖面備援及全部調節操作。視網膜畫成貼附後方內壁的弧形帶，兩個物點以紅、藍各兩條代表光分別成像。實際代表光只畫到視網膜，不讓光線穿過眼球或射入神經。各色落點與放大窗的清晰程度取自同一模型；放大窗統一示意尺寸，只比較清晰程度。

數值模型採兩段近軸等效薄透鏡及固定接收面；主圖眼內光路依次經角膜、水晶體，再到視網膜。計算採視網膜局部平面近似，繪圖將落點映射到後壁的弧形內襯；眼外物距與眼球未按同一比例繪製。這些簡化寫在預設收合的補充區。手動滑桿用來放慢觀察，實際正常眼睛會自動調節。

第七區使用獨立模組與樣式，舊共用眼睛模組只繼續控制第八區。檢查涵蓋兩段等效折射、各物點獨立形成倒立像、連續失焦程度、遠近切換保留調節、固定視網膜、光路偏好、鍵盤與原生觸控、七種寬度完整取景，第八區既有矯正流程、實際立體鏡片厚度、固定接收面與顯示備援。
