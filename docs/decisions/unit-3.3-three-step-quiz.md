# 3.3 單元小測分成三個操作區

2026-11-02，使用者核可三區示意，並要求完成按鈕放在第三區說明下方、靠左，與上一區「聽我的聲音」對齊。

1. 聽目標聲音：提示留意音色、音高及大小聲，保留動態樂器圖與播放。
2. 調整並試聽：將波形、音色切換、頻率、振幅及試聽放在同一區，說明可回到上方重聽目標。各控制旁以音色／音高／大小聲解釋用途。
3. 完成比較：獨立區塊，說明下方放靠左按鈕，結果、差異提示與後續操作都留在此區。

上方只保留任務目標。沿用既有框架、配色及音訊素材，使用小型步驟編號、段落間距及淡背景區分。桌面波形與工具並排，手機依閱讀順序排列，試聽與完成按鈕同樣靠左對齊。

表單包住調整與完成兩區，維持原submit事件與所有功能hook；主程式、小測控制器、配對模型及聲音皆未修改。比較前仍須聽過目標及目前設定；保留目標波形、再調整、換題、載入失敗重試及播放取消規則。

本輪三區版面取代歷史的「整個小測及結果塞入一個視窗」要求，允許自然向下閱讀。既有測試改驗各區順序、間距、按鈕對齊、表單歸屬、結果位於完成區且可捲動看見，以及八種寬度無溢出。首次結果檢查遇到瀏覽器定位的0.34px邊界差異，確認顯示正常後，採1px邊界容差；檢查範圍保持。
