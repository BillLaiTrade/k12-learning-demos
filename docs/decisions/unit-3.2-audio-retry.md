# 3.2 第02項：音檔失敗後重新載入

2026-11-01，使用者逐項檢視盤點後採用第02項建議：鋼尺與真空鐘罩重試時重新載入音檔，保留目前實驗條件，失敗提示到播放成功後才清除。

鋼尺在先前播放失敗或原生媒體錯誤後呼叫`load()`，再於同一使用者事件內提出`play()`；一般再次撥尺不重新載入。鐘罩沿用原音訊節點、增益與分析器，失敗後同樣重新載入媒體，保留空氣量、抽氣／進氣模式及儀表位置。錯誤訊息只由目前有效的播放成功要求清除；關閉、離開或取消中的舊要求不清除。

新增`tests/unit-3.2-audio-retry.test.cjs`，以實際攔截音檔請求驗證失敗、連線恢復、等待期間提示、重複失敗、取消、抽氣中重試及390px觸控／鍵盤／減少動態。可指定`AUDIO_RETRY_URL`及`AUDIO_RETRY_ARTIFACT_DIR`重跑公開頁及保存截圖。檢查結果與部署證據記於規劃repo的`docs/reviews/unit-3.2-audio-retry-20261101/review.md`。

本輪只處理第02項，維持原版面、錄音、波動及音量模型；第03項起仍待使用者逐項決定。
