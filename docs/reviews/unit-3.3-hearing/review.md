# 3.3第六區：持續純音頻率探索

日期：2026-10-31。使用者核可approved-mockup.png，明確要求先持續播放、點擊／拖動彩色頻率帶即可切換音高、播放／暫停單鍵，以及自行記錄聽得到的大約兩端；製作完成後先驗證功能與畫面，再提供公開連結。仍為第四階段待實際檢視，非醫療聽力檢查或教材外部驗收。

## 核心與呈現

認識聽覺有概略頻率範圍、個體差異與裝置條件；聽不到不等於沒有聲波。20～20000Hz探索是數位訊號與學生主觀回報，不能證明喇叭實際聲壓或學生真實聽力界線。

配置依核可圖：上方共用小葵對話，左側木喇叭／室內桌景，右側頻率與播放／暫停鍵、下方彩色頻率帶，再接兩個手動紀錄欄、限制小註、阿公對話與收起的動物補充。沿用全寬2.1卡片樣式及現行角色。既有圖片原樣引用，未做圖片後製；沒有把示意圖整張貼到頁面。

初始1000Hz、暫停、兩端空白；截圖中的80／8000Hz是透過操作留下的例子，不自動假設學生聽見。紀錄可改寫，反向區間拒絕並提示、保留既有值；暫停／導航保留，重設清空並回1000Hz。只存本頁記憶體，不儲存學生資料。

## 聲音與操作

- 同一AudioContext，sine OscillatorNode接固定增益0.06；40ms起音，35ms平順調頻，25ms淡出後30ms停止，不反覆重播短音。
- 開始／暫停一鍵切換；喇叭圖也可點播。未播放時調頻不會起音，播放中調頻維持同一個振盪器。沒有自動增大高低頻音量或診斷分數。
- 20～20000Hz以對數位置配置：20在0%、100約23.3%、1000約56.6%、10000約90%、20000在100%；彩色條只代表操作位置，不是光譜或FFT強度。為防擠字，10000Hz刻度錯行排列。
- 滑鼠／觸控pointer capture連續拖曳、超界箝制，方向鍵／PageUp／PageDown／Home／End可用。觸控按鈕使用pointerup及相容click去重，修正拖動後立即點暫停可能漏點的問題；不新增第二個可見播放鍵。
- 與其他區共用唯一活動來源、停止規則及取消票號；跨區／完全離開視窗／隱藏／重設停止，等待resume可取消，失敗可重試。超過裝置Nyquist頻率時明示不支援，不假裝有輸出。
- 保留先調小音量、設備／音量／環境限制與非聽力檢查；動物高頻上限、次聲與超聲界線收於補充。未重新加入噪音或聽力保護章節。

75項通過（含外層），0失敗／略過。第六區11項：以瀏覽器OfflineAudioContext實際render的20／80／1000／8000／16000／20000Hz訊號核對頻率、數位振幅與頭尾，另測調頻到2000Hz、起音10ms就停止；即時頁面攔截真正OscillatorNode確認超過1.3秒仍播放、調頻不重啟及頻率讀值。接近Nyquist時瀏覽器處理可能自然降低輸出，不以強行補償假裝響度校準。

另確認兩端改寫／防反向／重設、暫停保留、跨區來源互斥、離開／隱藏／等待resume取消、失敗重試、知識文字、8種寬度320–1920px，以及真實手機拖曳後立即暫停、重新播放、紀錄／重設／點喇叭每次只起音一次。前五區動畫／音訊／波形與唯一結尾小測回歸正常。

初測發現的淡出排程與手機拖動後漏點已修正並包含於通過檢查；離開測試改為確實捲出整個區塊，避免把仍部分可見誤判為完全離開。已檢視hearing-1440.png、hearing-1024.png、hearing-390.png及hearing-playing.png，確認同核可圖的排列、連續播放狀態與紀錄；手機頻率帶放到圖片／頻率顯示之後，保留可用觸控面積。公開驗證另記於規劃repo。
