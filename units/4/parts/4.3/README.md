# 4.3 光的折射與視深基本版

使用者於 2026-11-01 核可先完成七區基本版，再逐區優化。教學頁為 `index.html`，不新增依賴。`assets/optics.mjs` 為純幾何模型，`assets/lesson.mjs` 控制互動。

- 六個對話／互動教學區：等距光速、垂直入射、空氣射入、水／玻璃射回、反射與折射光路可逆、視深。
- 最後一區為唯一理解檢核，含三題。未作答、錯誤、全對、修改答案及重設均有對應狀態。
- 動畫初始待命，手動開始。第一區為 100 萬公里比較台，完成後可再按同時發光；第二區為三組連續光束，完成後可再按同時發射。兩區皆可暫停／繼續，離屏或頁面隱藏時保留進度並暫停。沒有持續空轉的動畫迴圈。
- 空氣、水與常見透明玻璃代表折射率為 1、4/3、1.5。內部用幾何光學維持方向正確，學生不必計算司乃耳定律。介面反射未畫出，頁尾已說明只畫穿透部分。
- 出射回空氣控制在 0–35°，不延伸到臨界角／全反射。
- 視深以固定硬幣、固定眼睛與兩條進入小瞳孔的折射光求反向延長線交點。實際硬幣座標不變；水位改變時重新計算折射點及視位置。小束光近似局部視位置，不宣稱所有大角度光線聚於同一虛像。
- 共用人物頭像引用根目錄 `shared-assets/characters/`，沒有複製素材。

參考：[OpenStax 折射與視深](https://openstax.org/books/college-physics-2e/pages/25-3-the-law-of-refraction)、[自然科學領域課綱](https://edu.law.moe.gov.tw/LawContent.aspx?id=GL001823)。出版社與版次未指定，沿用已核可的共同概念範圍。
