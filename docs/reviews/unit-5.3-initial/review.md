# 5.3 初稿檢視紀錄

日期：2026-11-04。製作範圍為 5.3 與單元入口／課綱頁的 5.3 連結；沒有編修 5.2。

## 頁面內容

五區依序為熱量單位、吸收熱量與升溫、水的質量與升溫、不同物質的比熱、生活應用。三組實驗都可操作、暫停、重來與記錄；各有自己的條件、曲線與狀態。最後以四題暖暖水袋情境小測檢核。

開場以共用頭像及 5.1 場景參考生成新圖，確認小葵雙丸子頭與白色連帽衣、阿公白髮圓眼鏡與無鬍子的老人造型。HTML 對話引用共用頭像。格式沿用目前 5.2 的側欄與左右欄卡片。

## 內容限制與後續檢視

本次是可操作的初稿，不代表使用者已逐區驗收。比熱取常溫近似值；實驗忽略容器吸熱、散熱及相變，熱量是樣品實際吸收量，時間為示意。這些條件已在頁面各實驗旁註明。固體視為均勻溫度，沒有把加熱過程當成導熱實驗。

後續可依使用者檢視逐區精緻化器材與對話；5.4 仍保留原規劃狀態。
