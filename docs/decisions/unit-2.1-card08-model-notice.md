# 2.1 第八區：明確標示理想化模型

日期：2026-10-29（Asia/Taipei）。

使用者核可將原本的灰色小字改為醒目的提醒框，完成後先檢視此項，再討論下一項。

- 原位置改用淡黃色底、琥珀色邊框及提醒圖示，標題明示「理想化模型：頻率與波長可分開設定」。
- 說明公式探索用途，以及繩子變色表示切換到不同波速條件。
- 真實繩子在拉緊程度等條件不變時的限制獨立成行、加粗，與模型說明分隔。
- 本次範圍為第八區提醒框的文字與樣式。

## 檢視後調整

使用者認為黃色提醒框過於搶眼，核可將其調整成融入版面的模型說明：

- 改為淡灰綠底與細邊框，縮小內距。
- 移除警告圖示、粗左框及中間分隔線。
- 保留原有說明內容，僅「理想化模型」與「波速維持不變」加粗，其餘使用一般字重。
- 完成後提供正式頁面，等待使用者確認此項。

## 恢復黃色並壓縮高度

使用者偏好黃色樣式的辨識度，要求減少說明內容及上下高度。

- 恢復淡黃色底、琥珀色邊框及小型提醒圖示。
- 標題縮短為「理想化模型」，以兩句短文保留獨立參數設定、變色意義及真實繩子的限制。
- 上下內距改為 8 px，標題與段落間距均為 3 px；取消分隔線，避免佔用過多高度。
