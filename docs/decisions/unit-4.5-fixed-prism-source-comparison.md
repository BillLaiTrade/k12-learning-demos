# 4.5 第二區：固定器材，比較白光與單色光

日期：2026-11-02（臺北）。使用者核可先前第二區分析並要求製作。第一區辨認色散現象；第二區固定三稜鏡，只換入射光，處理「色光是否由三稜鏡製造」的疑問。其餘學習區與小測內容保持，仍為第四階段逐區修訂。

第一、二區共用precision-prism控制器、30° N-BK7兩介面折射、有限1×5mm狹縫與x=300mm白幕。第二區預設白光、玻璃在光路中、輔助線開啟；移除放入／移開按鈕，並停用3D、平面備援與Home／End的玻璃位移。第一區保留完整滑軌操作。觀看角度及輔助線可調，實驗結果保持。

白光D65採380–780nm、1nm積分；理想紅650／綠530／藍460nm各只有一個波長，同樣經兩面折射與有限孔徑計算。各光源使用相同總入射輻射功率，沿用CIE色度、Fresnel與吸收及固定曝光；未對各色自動調亮，不把顯示亮度當照度測量。一般LED／色片有頻寬，不以此理想化代稱所有實物。單色狹縫像高5mm、寬約1.04mm，依各自波長落在白光色帶的對應位置。

右上常駐白幕正面沿用第一區15×10mm、5mm尺、兩軸同倍率，沒有放大功能或器材浮動標籤。第二區所有光源鎖定白光色帶的同一取景範圍，主圖白幕的框選與預覽一致；不隨光源置中，以保留實際落點差異。

小葵先提出問題、操作後說出方向改變且沒有展成彩色色帶的觀察；阿公再說明白光含不同色光及其偏折差異。移除重複「眼前的發現」框，保留螢幕閱讀器狀態回饋。摺疊模型說明區分觀察與解釋，不宣稱單色比較本身是白光組成的完整實驗證明。不新增第二支稜鏡重組實驗、外部服務或套件。
