# 5.2 六個學習區塊改採 1.1 左右欄格式

日期：2026-10-29。

## 依據與範圍

使用者指出單元 1.1 的學習區塊分成左右兩部分：左欄小標題、右欄大標題。比對 1.1 的實際 HTML 與 CSS 後，將 5.2 六區共同外框由上方標頭改為此結構。

| 左側小標題 | 右側大標題（保留原文） |
| --- | --- |
| 熱往哪裡傳？ | 同樣的兩杯水，在不同環境會怎麼變？ |
| 熱平衡 | 一熱一冷靠在一起，最後會怎樣？ |
| 熱傳導 | 鍋底受熱，把手為什麼也變暖？ |
| 熱對流 | 水和空氣怎麼把熱帶走？ |
| 熱輻射 | 沒有碰到，也能傳熱嗎？ |
| 保溫與保冷 | 怎麼讓熱水慢一點變涼？ |

左側為普通編號、小標題、學習重點，下方不放操作內容；左右以細垂直線分隔。右側依序為大標題、原有簡介、人物對話與原有互動。與 1.1 相同，標題層級各自獨立，沒有將原有大標題直接縮成側標。

## 保留內容

六區原有大標題及簡介僅移動位置。新增左側短標題與學習重點；原本 `.card-main` 中的對話、場景、控制及結論逐字保留，其 SHA-256 見 `preserved-main.json`（比對時移除本次搬入的 h2／簡介）。小測 HTML 保留。

沒有修改任何 JavaScript、熱模型或圖片。第三區補充窄內容欄的排版，將主場景與細節上下排列，避免場景過度縮小。

## 實際格式預覽

本輪檢視實際瀏覽器版面，未新增或重跑互動測試套件。

- 1440px：六區皆為左欄 190px、右欄 782px；小標題 17.28px，大標題 29.6px。
- 1280px：左欄 150px、右欄 690px；維持大小標題層級與垂直分隔線。
- 1024px：保留左右欄，第三區場景與細節上下排，讀數保持在儀器中。
- 較窄內容區依 1.1 的方式收合；本輪預覽各尺寸均未出現整頁橫向溢出，沒有瀏覽器腳本錯誤。
- `card-01-1440.webp` 與 `card-03-1440.webp`：第一、三區完整畫面。
- `card-01-1280.webp` 與 `card-03-1280.webp`：筆電畫面。
- `card-01-1024.webp` 與 `card-03-1024.webp`：較窄桌面畫面。
- 完整六區位置與字級紀錄見 `layout-measurements.jsonl`。
