# 4.3 小測：在光路旁顯示角度

2026-11-04（臺北時間）。依使用者要求，三層光路的弧線旁直接顯示與法線的夾角，讓排序可依數據判斷。

讀值取自繪製同一條光線的geometry.layers.angle，四捨五入至小數點一位，單位為度。統一對照既有「比較光線與法線的夾角」圖例，不將三層混稱入射／折射角，也不新增重複說明。播放完成後一次顯示三筆，重播期間收起、完成再顯示；換題清空並取新題數據，縮放後位置與圖形一起重算。無障礙圖說原已提供相同精度數據。

深綠讀值帶奶油色細描邊，置於弧線右側並避開光路／層界／名牌。沿用桌面與手機等比例投影。物理關係以本題平行介面與同一束光為前提：夾角越大、光速越快。模型、材質、發射／點燈／重播及排序回饋保持。見[檢查](../reviews/unit-4.3-quiz-angles-20261104/review.md)。維持第四階段。
