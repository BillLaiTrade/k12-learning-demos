# 2.2：ppm 獨立為第五學習區塊

2026-10-29。使用者認為第四區內容過多，核可將 ppm 拆成獨立第五區。

- 第四區保留自由稱量糖與水、重量百分濃度公式、配方計算及質量比例，沿用 `#s5`。
- 第五區新增 `#s6`，主標題「溶質很少時，濃度怎麼表示？」；保留一毫克糖與一公升水的份量觀察、放大鏡、質量比、ppm 定義與百分濃度對照。
- 開頭承接相同的質量比例，說明微量時用 ppm 較易閱讀；一公升水仍僅作大小參照，濃度計算的分母仍為溶液總質量。
- ppm 的樣式與分式排版獨立作用於第五區，沿用先前收斂的桌面字級與並排版面。原 `#ppm-lab`、`#ppm-percent-bridge` 錨點保留。
- 左側五項導覽逐字對應右側主標題，進度改為五個學習區塊；單元小測維持獨立項目。既有導覽檢查的預期數量同步更新。
