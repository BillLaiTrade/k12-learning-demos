# 4.3 第一、二區各組器材獨立發射與計時

2026-11-06（臺北）。使用者要求點擊單一組器材即可自行發射、各自計時，保留原本的同步比較。

兩區各三個光源加原生按鈕操作區，對齊現有照片，不更換素材；滑鼠、Enter及空白鍵皆可發射。點擊只讓該組從零開始，其他組保留運行、暫停或完成狀態。在同步播放中點一個光源，其他組接續原進度，改為各組計時；按「同時發光／同時發射」則清空三組、重新同步出發。

各組使用原模型的抵達時間與路徑位置。第一區仍為100萬公里，約3.33／4.44／5.00秒；第二區仍為150萬公里，約5.00／5.83／6.25秒。新增的independent-lane-timers只管理每組未暫停時間，不更動速度、路程、介面或折射模型。獨立播放顯示各組即時計時，抵達後保留到達時間，共同時鐘暫時收起。

暫停控制作用於正在前進的各組；手動繼續接續所有暫停組。離屏／隱藏分頁只自動暫停正在播放的組，返回只續播自動暫停的組，不解開手動暫停。單組點擊始終是重新發射，其他組不受影響。手動發射沿用帶回器材與控制，自動續播不捲動。

第二區獨立播放不使用「空氣先到」等同步結論，也不套用5秒共同停格；收起「比較同一瞬間」步驟。同步發射時恢復原三步與一次共同定格。獨立狀態牌移至名稱牌上方，光源按鈕不覆蓋名稱牌。只在原狀態列補一句點擊提示，沒有增加操作說明面板或手機專項。

第三至六區、唯一四層小測、角色對話、照片與模型保持。新增三項時鐘單元檢查、兩區十四項瀏覽器檢查，並回歸原兩區、格式與整課操作。檢查證據見[本輪紀錄](../reviews/unit-4.3-independent-lanes-20261106/review.md)。維持第四階段，待使用者檢視。
