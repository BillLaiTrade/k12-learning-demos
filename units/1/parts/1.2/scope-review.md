# 1.2 課綱與教材範圍盤點

**用途：**先完整對照課綱要求，再分配到 1.1–1.5，避免遺漏或重複。課綱要求不會因為目前教材資料尚未查全而刪除；出版社補充項目另標示待核對。

## 三版本教材公開架構

115 學年度的三版本課程架構整理，將八上光學主題分別概括為：

- **康軒：**光、影像與顏色；涵蓋光的直進與反射、平面鏡與透鏡成像、折射、色散與顏色。
- **翰林：**光學現象；涵蓋反射定律、折射與透鏡、光與顏色。
- **南一：**光與影像；涵蓋光的直進與反射、折射與透鏡、色光與物體顏色。

三版本的公開總覽都把反射放在八上光學範圍內；總覽並未列出每個 4-2 細項，不能單靠這份總覽判斷曲面鏡要教到多深。

目前可直接核對到的出版社公開細目，以康軒官方教學動畫目錄最清楚：2 上 4-2 列有「光的反射」與「平面鏡之成像」；折射、凸透鏡與凹透鏡成像列在 4-3，透鏡與視力矯正列在 4-4，三原色光列在 4-5。這支持本專案把面鏡反射和平面鏡成像留在 1.2，並把透鏡成像、視力矯正、顏色分到後續段落。這份目錄沒有列出曲面鏡，不足以證明完整課本完全不教曲面鏡；翰林、南一的完整當年度教材細目也無法從公開入口逐項確認。

## 1.1–1.5 單元邊界核對

國家課綱將光學內容分列在 Ka-Ⅳ-6 至 Ka-Ⅳ-11；三版本公開課程架構也都把「直進與反射、折射與透鏡、顏色」放在同一學期的光學範圍。依本專案目前的 1.1–1.5 編排，建議按概念責任切分如下。這是課程設計的分工，不表示出版社都使用相同的課名或章節切法。

| 區塊 | 負責回答 | 對應課綱／專案安排 | 1.2 的邊界 |
| --- | --- | --- | --- |
| 1.1 光與看見、光的直進 | 看見物體需要什麼條件？光如何直進、形成影子、具有多快的速度？ | Ka-Ⅳ-6、Ka-Ⅳ-7；專案 1.1 已涵蓋 | 1.2 可以承接「光照到物體後會反射進眼睛」，不必重講直進實驗、影子成因或光速。 |
| 1.2 光的反射與面鏡 | 光在各種表面如何反射？反射方向如何判定、光路是否可逆？面鏡成像如何隨物距改變？ | Ka-Ⅳ-8 的反射部分；Ka-Ⅳ-9 中面鏡相關應用；課程手冊 8-1、8-2、8-3 面鏡部分 | 必須完整包含反射實驗、各表面遵循反射定律、光路可逆、入射線／法線／反射線與角度關係，以及面鏡成像和物距關係。折射、透鏡、視深、顏色由後續區塊負責。 |
| 1.3 光的折射 | 光進入不同介質時如何折射？為何水中物體看起來位置不同？ | Ka-Ⅳ-8 的折射部分；課程手冊 8-1 折射部分、8-4 | 必須涵蓋折射現象及視深與實際深度差異；光速與介質的關係依本專案安排在本段，並避免重講 1.2 的反射活動。 |
| 1.4 透鏡與光學儀器 | 凸、凹透鏡如何成像？眼睛如何看見？視力如何矯正？常見光學儀器如何運用透鏡？ | Ka-Ⅳ-9 的透鏡、眼睛、眼鏡、顯微鏡等；課程手冊 8-3 透鏡部分、9-1、9-2 | 必須涵蓋凸透鏡與凹透鏡的成像觀察、物距對像大小／正倒立／位置的影響、眼睛與近遠視矯正，以及生活儀器的透鏡應用。面鏡內容由 1.2 承擔。 |
| 1.5 光與顏色 | 白光如何分色？色光照到物體後，為何物體呈現不同顏色？ | Ka-Ⅳ-10、Ka-Ⅳ-11；課程手冊 10-1、11-1 | 必須涵蓋三稜鏡色散、色光與物體顏色實驗、不透明物體表面的吸收／反射，以及透明物體由透射光決定顏色。 |

### 邊界核對結果

- **不重複 1.1：**簡短引用「光進入眼睛才能看見」作為動機即可；1.2 的新問題從光遇到表面之後開始。
- **不搶 1.3：**1.2 研究反射，不以水中物體視位置、介質改變光速或折射角作為活動結論。
- **不搶 1.4：**平面鏡像由反射形成，留在 1.2；透鏡、眼睛和顯微鏡的成像原理留在 1.4。Ka-Ⅳ-9 是跨段落的生活應用要求，不宜當成必須由 1.2 一次教完的清單。
- **不搶 1.5：**1.2 的鏡面反射／漫反射只比較反射光是否規則分布；物體顏色由哪些色光被反射，留在 1.5。
- **應用任務可留在 1.2：**平面鏡潛望鏡能直接檢查反射方向的理解；若加入透鏡、放大或顏色效果，就超出此任務的必要範圍。
- **曲面鏡是教材核對項，不先刪除也不先增列為課綱必教：**課綱和課程手冊沒有明列曲面鏡成像性質；康軒官方公開動畫目錄列出反射與平面鏡成像但未列曲面鏡，翰林、南一當年度完整教材細目仍未能公開逐項核對。故事初稿先不安排曲面鏡成像活動；後續取得三版本可核對資料後，再決定要不要作教材補充，並標清「課綱要求」或「版本補充」，不以教材未公開為由刪減課綱要求。

## 教材與教學資源中反覆出現的細項

公開的 4-2 課程資料與教學資源，反覆出現以下內容：

1. **反射定律與光路圖：**入射線、反射線、法線；入射角等於反射角；角度以法線為基準；光路可逆。
2. **平滑表面與粗糙表面的反射：**鏡面反射與漫反射；兩者都遵守反射定律，但反射光分布不同。
3. **平面鏡成像：**影像看起來位於鏡後，不能投影到屏幕；影像正立、等大，像距與物距相等，並與物體相對鏡面對稱。
4. **凹面鏡、凸面鏡及生活應用：**部分八上 4-2 教材或教學資源將其列在同節，常見例子包括化妝鏡、手電筒反光罩、道路反射鏡。
5. **反射的應用：**潛望鏡、萬花筒等，可用來應用反射規律；課綱沒有規定一定要以潛望鏡作為獨立單元。

## 範圍判斷：目前可先保留與待決項目

### 1.2 必須涵蓋的課綱要求

- 透過觀察或實驗探討光的反射規律，呈現光在任何表面反射均遵守反射定律。
- 能畫出入射線、法線與反射線，並說明入射角和反射角的關係。
- 知道光路可逆。
- 透過面鏡實驗觀察成像情形與物體到面鏡距離的關係。
- 依 Ka-Ⅳ-9 將面鏡光學原理連結到生活實例或儀器。

### 出版社教材細目：保留待核對，不先刪除

- 目前第三方教材整理提到，部分 4-2 會包括凹面鏡、凸面鏡及用途；康軒公開動畫目錄沒有列出這些細目，翰林、南一當年度完整教材亦尚未逐項核實。這代表**教材比對還沒完成**，不是決定刪除曲面鏡。
- 平面鏡影像的距離、正立、等大、虛像、左右相反／鏡面對稱等細目，應按三版本課本與教師手冊確認後列出來源；目前課程手冊明確要求先以實驗觀察面鏡成像情形和物距的關係。
- 潛望鏡、萬花筒等是可用來實踐反射原理的生活應用。需要比對教材要求與教學時間後再決定採用哪個活動，不以活動選擇取代課綱概念。

### 其他課綱要求的區塊分工（不刪除）

- 光的直進與光速（Ka-Ⅳ-6、Ka-Ⅳ-7）：由 1.1 負責。
- 折射規律、視深（Ka-Ⅳ-8、課程手冊 8-4）：由 1.3 負責。
- 凸／凹透鏡成像、眼睛、近視／遠視矯正、生活儀器中的透鏡（Ka-Ⅳ-9、課程手冊 8-3、9-1、9-2）：由 1.4 負責。
- 三稜鏡色散、色光與物體顏色、透明物體的透射色（Ka-Ⅳ-10、Ka-Ⅳ-11、課程手冊 10-1、11-1）：由 1.5 負責。
