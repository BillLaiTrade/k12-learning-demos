# 第五區單光源用角度角色，雙光源用介質側別

2026-11-03。使用者明確修訂上一輪的固定命名：只有兩光源同開才用空氣側／水側，單燈應能辨認入射角與折射角。

- A單開：上方入射角（藍）、下方折射角（綠）。
- B單開：下方入射角（藍）、上方折射角（綠）。
- A／B同開：空氣側（綠）、水／玻璃側（藍），不對一組角度指定單一傳播角色。
- 扇形、弧、引線與數值顏色一起更新；ARIA描述及單燈結果文字使用對應角色。全關仍隱藏；兩側介質位置與滑桿的水／玻璃側參考名稱保持。

只依燈態選擇名稱／顏色，不改角度數值、模型、光路或範圍，不恢復放大。核對兩介質四組狀態、16視窗及正常時鐘畫面。維持第四階段修訂，待使用者檢視，非外部驗收或最終核可。
