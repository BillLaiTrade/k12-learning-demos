# 5.2 第二學習區塊：接觸與熱平衡

## 最新修訂：加入室溫與持續的環境熱交換（2026-10-29）

使用者指出分開的金屬仍會受到環境影響，核可固定 25°C 室溫、分開時緩慢變化、接觸時較快接近，以及區分彼此同溫與整體熱平衡的方案。

- 保留直接拖曳、器材材質與科學桌場景，面板條件列新增「室溫 25°C」。隔熱層改標示為減慢熱交換，移除忽略外界熱交換的條件。
- 第一回進入可視範圍時自動開始，沒有接觸主按鈕；避免學生尚在第一區時，本區讀數已經全部變成室溫。開始後分開仍會持續變化，暫停／繼續可控制整段觀察，重來恢復初溫並重新觀察。
- 相同材質、質量及環境條件下，用兩個等熱容量的集中模型近似。每塊均與固定 25°C 環境交換熱；直接接觸的彼此交換較強，分開時保留小係數近似空氣／輻射等非接觸影響。並非真實空氣流場、輻射或熱傳係數的定量重建。
- 每一步以平均溫度及半溫差的解析解更新：平均溫度接近室溫，溫差在接觸時更快縮小。步長拆分不改變結果，拖動、分開或貼合不重設溫度，也不將兩塊溫度和固定在 80°C。
- 兩塊接近同溫時提示仍會和室內環境交換熱，讀數繼續變化；只有兩塊都接近 25°C 時才收束成 25.0°C 並停止。40°C 不再是終點。
- 原本同溫模式仍以 40°C／40°C 開始，會一起冷卻；兩塊之間沒有直接接觸淨熱傳短光跡。一般模式的 B 在後段也會改為降溫，升降溫文字依當下模型導數更新。
- 短光跡仍只表示直接接觸的傳熱，隨接觸面移動，不增加環境箭頭或連接棒。環境影響由室溫條件、讀數與狀態說明呈現；表面冷暖反光也依各自與室溫的差距更新。
- 更新標題摘要、阿公開場及操作後對話，交代隔熱不能完全隔絕、分開也變化，以及與環境同溫的整體熱平衡；保留現有正式頭像與版型。其他六個區塊 HTML 保留雜湊核對相同。

## 先前修訂：直接拖曳為主要操作（2026-10-29）

使用者指出按鈕不如直接拖曳直覺，核可兩塊金屬可各自拖近及分開，並要求以拖曳為主要操作。本輪移除「讓它們接觸／重新觀察」主按鈕，初始操作列改為拖曳提示與次要的重來按鈕；只有正在接觸且尚未同溫時顯示輔助暫停／繼續控制。

- 兩塊金屬可獨立左右拖曳，接近時小距離吸附，不能重疊穿過彼此，也不能移出隔熱盒。到達碰撞邊界後反向拉動會立即回應，避免滑鼠需先退回超出的距離。
- 按住移動任一塊，與它連接的探頭、接線及讀數器一同移動。探頭說明線及淨熱傳短光跡會追隨實際接觸位置；光跡和標示不會攔截拖曳。
- 接觸後自動開始或接續觀察。拖開停止累積接觸時間，保留當下溫度，光跡消失；再次貼合從原讀數繼續。只有重來或切換模式會回到初溫。
- 達到同溫後，分開再接觸仍維持 40.0°C，不重新播放傳熱。原本同溫模式亦無淨熱傳光跡。
- 本區明示只比較接觸傳熱，沒有把分開後維持讀數推廣為真實情境中的輻射或其他熱交換也歸零。
- 真實滑鼠及觸控使用相同 Pointer Events 與座標換算；滑鼠游標、低調握點及滑過外框提示可拖曳。鍵盤方向鍵移動，End 貼合，Home 分開；取消手勢、重來、切換模式及頁面背景都會清理指標捕捉。
- 材質、背景、正式角色頭像、四則對話與其他六個區塊 HTML 保留。更新的操作列及握點是本輪核可的變更，不宣稱仍與首次按鈕版逐像素相同。

## 概念與操作

- 相同材質與質量的鋁塊，忽略與外界熱交換。此例的 40°C 不推廣為所有物體的平衡溫度，也不加入熱量計算。
- 先按「讓它們接觸」，約 0.7 秒靠攏；接觸前讀數維持初溫，接觸後 A 降溫、B 升溫。模型溫度和固定為 80°C，兩側不越過 40°C。
- 可在靠攏及傳熱階段暫停、繼續；重來恢復當前模式的起點，切換模式會停止並重設。完成後可重新觀察。
- 同溫模式 A／B 初始均為 40°C，接觸後沒有淨熱傳光跡。小葵的操作後發現隨模式改變，避免對同溫情境聲稱一側降溫、另一側升溫。
- 接觸面的短光跡沒有連續底線或連接棒，正常與減少動態設定均會持續移動；暫停固定光跡和讀數，同溫後消失。
- 螢幕閱讀說明與原生按鈕鍵盤操作保留；頁面切入背景時暫停，回來需自行繼續。
