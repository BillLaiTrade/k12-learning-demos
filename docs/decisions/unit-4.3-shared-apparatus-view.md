# 4.3 共同操作畫面、近拍箭頭與緊縮重點

日期：2026-11-03。使用者先記錄五項回饋，明確授權後一次實作。

- 以前第三、第四區只共用光束外觀，仍由不同畫面及裁切繪製，造成光源定位、近拍比例、字體／角弧／標籤不一致。本次兩區共用第三區的完整單光源模板、控制器及樣式，以root與ID前綴隔離狀態；第四區只傳入相反介質順序及對應幾何。第五區雙向互易實驗保持。
- 兩區初始同為30°，相同角度下光源位置、大小與旋轉精確一致。保留第三區0–60°與第四區0–35°的原範圍，後者不延伸至全反射。第四區穿透線與第三區採相同底／側界面結束，出射角大時在右界止步；代表折射率與相對發光速度不變。
- 主圖保留原照片框架，只將第四區內部水／玻璃及空氣表面交換。近拍共用530 480 240 180裁切、同一合成圖、介面柔化、字級、扇形、引線與標籤，不放入器材或額外M。各組SVG資源以實例ID隔離。
- 方向箭頭依近拍可見區間重算位置，上段靠近進入裁切處、下段靠近離開裁切處，避開文字與角弧；在前緣越過箭頭尖端後才顯示。主圖保持原方向箭頭。
- 移除選項的獨立底座、邊框與螺絲，直接於原橫框顯示淺凹按鍵與刻字。觸控範圍44px，視覺面較薄。窄螢幕以實際底框照片延伸操作底部，選項在箱體內、可點且不遮光路。
- 主要重點保留兩個緊縮白色區塊，明確標示各側「光速較快／光速較慢」，以快慢關係解釋偏向／偏離與角度大小，減少重複句和留白。詳細波前原因及0°例外留在展開說明；兩區說明外框也沿用相同樣式。
- 兩區同樣提供發射／重播、暫停／繼續與重設；拖曳及鍵盤調角不誤發光，展開時可用下方滑桿調角。快速切換、錯誤復原及焦點還原保持，首次發光即切換也保留預覽意圖。
