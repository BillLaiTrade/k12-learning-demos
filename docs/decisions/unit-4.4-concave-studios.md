# 4.4 第五、六區：凹透鏡折射與成像

依使用者確認，保留兩個可直接到達的學習區塊，避免把另一項學習任務藏在模式切換後。第五區參考第二區的立體平行光與兩次折射，第六區參考第三、四區的器材、刻度操作與固定眼位觀看。

第五區採用既有 parallelModel 的玻璃球面與 Snell 兩次折射，旋轉生成同樣的實際立體鏡片。光源移到虛焦點之外，鏡片中央薄、邊緣厚；主軸光直行，另外兩道實際光向右發散。反向延長線預設關閉，開啟時只延長兩道非主軸出射光，標示入射側的虛焦點 F 與焦距；出射光沒有在 F 實際會聚。整體、第一表面與第二表面的近看沿用同一器材。文字標籤避開光路與其他標籤。

第六區使用單一理想薄凹透鏡、鏡前真實圖卡與固定眼位，物距為 0.3F 至 3.5F。位置尺與觀察表只移動圖卡，不再切換凸透鏡。負焦距的薄透鏡方程與同一代表光模型計算虛像，圖卡向透鏡移近時，虛像位置靠近透鏡、尺寸增加，但始終正立、小於原物，並位於圖卡同側、透鏡與 F 之間。跨越 F 不切換成像性質或自動關閉某個物點。

立體器材由共用場景新增可選的 concave 鏡片輪廓建立，預設凸透鏡分支維持既有曲面。第五區逐面折射，第六區光路在主平面簡化折轉；兩區的模型說明交代此差別。第六區的虛像位置不應被畫在平行光的虛焦點上。

第六區右側比較採固定眼位的角大小：虛像尺寸除以眼睛到虛像的距離，與直接觀看原物的角大小比較。兩框使用相同的比例同步縮放，確保各物距的圖案可辨識，不單獨放大其中一框；操作畫面、說明及模型註記均交代比較方式。觀察表中的尺寸倍率則是虛像相對原物的幾何倍率。

檢查涵蓋 Snell 定律、實際曲面的射線交點、虛焦點與有限物體虛像的區別、整段物距的成像方程、實際渲染光路、鍵盤與原生觸控、光路偏好保留、兩區狀態隔離、WebGL 備援、桌面與手機版面，以及原有凸透鏡區塊與全單元整合。
