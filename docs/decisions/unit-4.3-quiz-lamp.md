# 4.3 小測：直接點擊照射燈發射

2026-11-04（臺北時間）。依使用者要求，圖中照射燈也能發射光束。

在既有寫實燈圖上疊放透明原生button，依圖像實際變換後範圍定位；寬／窄版切換及換題重建時同步。保持至少44px操作區，不新增可見說明或按鈕圖稿；滑鼠游標、輕微懸停與鍵盤焦點提示可操作性。按Enter／空白或觸控同樣啟動。

與下方發射按鈕共用start流程，發射中一同停用，完成後可重播且保留排序；換題重新待命。無障礙名稱依發射／重播狀態更新，關聯既有SVG；圖像載入失敗仍可操作向量燈。原折射模型、動畫時間、材質與六區內容保持。見[檢查](../reviews/unit-4.3-quiz-lamp-20261104/review.md)。
