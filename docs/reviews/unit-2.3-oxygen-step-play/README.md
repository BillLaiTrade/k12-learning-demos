# 選步立即播放該步動作

依使用者指示，右側後七項點選後重設並立即播放；重選重演，換步取消前項動畫／字卡。認識材料與初次載入保持靜止；後續仍連播至封存，唯一主鍵、空白暫停續播與介紹優先保持。鍵盤與手機同規則。

本機十套共100項（含各外層）通過：連播10、操作11、空白點選10、字卡10、器材9、材料10、物理8、整頁9、性質10、CO2 13。既有專項隨新選步入口調整，無新增測試套件或依賴。連播專項直接核對七操作立即playing、1000ms物理進度、催化劑加入且尚未封口、重選回到初始影格、快速改步與最後停止。其他專項保留桌機／手機、鍵盤、介紹、字卡與跨播放器檢查。
