# 2.3第三區：可暫停的連續播放

日期：2026-11-01。基準ddab9626。依使用者要求在右側實驗步驟增加連播與隨時暫停，保留手動選步。

- 預設不連播；材料頁開始會進入擺放，其他操作接續目前時間，已完成的中間操作進下一項。
- 同一動畫時鐘串接後七項，操作間保留700ms完成畫面。最後封存停留，可重新連播；不自動進第四區。
- 右側／圖內均可暫停及續播；器材介紹、Escape、離區、背景或別的播放器暫停，關閉／返回不自動開始。
- 手動選步／具名下一項取消連播；圖內重播保持單步。自動換步同步單層清單，避免捲動或隱藏焦點。
- 手機控制放在收合選單之外，維持44px操作高度。無JS保留八項代表畫面與材料資料，隱藏不可用連播。

沿用所有模型、器材介紹、素材與其他五區；preserved-content.json保存逐區及未改模組雜湊。未新增套件、外部服務或科學範圍。
