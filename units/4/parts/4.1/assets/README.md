## 月球軌道與平行陽光（2026-11-05後續）

展示地球半徑1.05、月球0.286335，比例0.2727；展示月軌半徑4.25，另畫太陽示意球。光照／遮擋計算獨立採地球半徑1、月球0.2727、地月中心距60.3，避免距離壓縮與放大球體造成每圈假月食。陽光採遠方平行方向，使用太陽角半徑0.00465rad的13個圓盤代表方向近似有限光源遮擋；CPU及兩球著色器使用相同方向。光照為球面漫反射近似，非月壤精密測光模型，也不是日月食預測器。
