# 4.5 第一區：先固定科學條件，再繪製與實作

日期：2026-11-02。使用者指出AI版面構想中的彩色色帶不能當成方向、長寬都精確的科學圖，要求先確定光學條件，盡可能科學精準後才生成示意圖及製作畫面。先前已討論第一區放大器材、白幕正面近看、輔助光路預設關閉及三稜鏡橫向短滑軌。本輪依上述指示實作第一區，未改第2–7區及小測內容。

選定準直D65白光、後置1×5mm矩形孔、60°等邊／50mm邊長／40mm高的直立N-BK7玻璃，在587.5618nm最小偏向位置固定。白幕平面距中心300mm，固定涵蓋移開與放入落點。玻璃沿與入射方向垂直的短滑軌橫移90mm；只對兩個定位狀態呈現實驗結果。

先查公開玻璃與CIE表，以兩介面實際交點／折射、有限狹縫、Fresnel透射及吸收計算，核對公開折射率與解析最小偏向公式，再由模型輸出科學示意圖；沒有繼續用AI構圖決定光譜形狀。計算結果380–780nm包絡約18.05×5mm，400–700nm約14.47×5mm，主圖及同一白幕30×20mm近看兩軸同倍率，5mm比例尺。真實色光在水平面分開，各單色狹縫像仍直立。

光源理想準直，幾何光學忽略繞射、散射及裝調誤差；CIE轉sRGB後有色域裁切，固定曝光可能令亮部飽和。幾何尺寸對應指定模型，顏色及亮度是顯示近似，未宣稱與實驗照片完全相同。詳細來源及係數見`units/4/parts/4.5/assets/spectral-sources.md`。

直接重用既有Three.js，光譜資料本地附來源／授權，不新增應用程式套件或外部服務。第一區採獨立模型，保留後續待逐區檢視的初版；不因第一區修訂把其他區誤記為已驗證同一實物條件。
