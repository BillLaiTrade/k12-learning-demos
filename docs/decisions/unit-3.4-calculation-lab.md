# 3.4第三區：由往返時間推算距離

日期：2026-10-31（臺北時間）。維持第四階段製作／修訂。

使用者核可數字輸入版示意圖 `exec-b91b7f47-6999-42f6-94eb-a45d920dc94a.png`，要求實作後核對功能、畫面並提供公開連結，同時保留單元2.1式橫向標頭、全寬內容、小葵與阿公對話。

## 教學與呈現

- 完整標題與「往返測距：從聲音走過的路程推算距離」置於既有 `lesson-head`；正文先銜接第二區，小葵提問、阿公引導，活動後保留阿公解釋與模型條件。角色使用既有共用頭像。
- 四段順序：去程和回程共4秒 → 每秒340公尺乘4得總路程1,360公尺 → 去回等長，總路程分成兩半 → 1,360÷2得單程680公尺。沒有四個340格子、重複加法、逐段解鎖或新測驗。
- 實驗室沿用第二區乾淨背景與透明木板，原素材不改動。綠色去程向右、橘色回程向左；場景標「要求的反射板距離」，不提前標680。第三段長條各占一半，不提前標單程答案。
- 器材與路徑為示意，距離按輸入計算；圖片不是以公尺實拍的比例尺，固定圖框不隨結果將器材放大／縮小。題給空氣聲速340m/s、固定反射板、同介質、發射與接收近似同位置。

## 數字輸入與互動

- 已知往返時間為原生數字欄，預設4秒、可輸入小數；沒有時間滑桿或2–6秒標示。合理操作範圍0.1–60秒，允許低於2或高於6的數值。
- 有效輸入即更新各段時間、總路程、等長長條的總量、除以二算式及答案。輸入未完成或超界時先保留最後有效條件，停止本區並暫停發聲入口；Enter／離開欄位時回填有效值，超界取界值、空值保留上次有效值。超界輸入中顯示可修正的說明。
- 點喇叭與下方「再發出一次短音」共用重新發聲控制；獨立暫停／繼續保留進度且不重發原音。改時間、重發、跨區、背景／離頁會取消相應舊排程，返回不自動播放。
- 動畫按輸入的真實秒數播放，4秒在約4秒接收，沒有8倍慢動作或「原速」徽章。聲波位置為每段進度，末次接收後留0.16秒讓90ms短音結束，接收計時不加這段餘裕。
- 沿用已驗證650Hz短音，同一緩衝區原音1與返回副本0.45；固定最末增益0.32，音量由裝置調整。無音量滑桿、聲音勾選、重設鍵或成功提示段落。啟音失敗才顯示可重試說明。
