# 3.3 第七區加入十二場景授權錄音

2026-10-31，使用者要求接手中斷的音效開發。新環境沒有前輪未提交音效／來源草稿，先同步兩 repo 最新 main，再保留十二場景大圖、介紹、OSHA 參考條件與情境帶，新增錄音試聽。此要求取代 decibel-explorer 決策中「不播放聲音」的限制；未增加麥克風或聲壓量測。

## 音源與授權

使用真實錄音，逐份保存作者、原作網址、授權、來源 SHA-256、段落、情境差異及修改。安靜書房採 TU Delft 圖書館自習室；自然景點採森林；一般交談採京都方言；舞廳採授權電子／放克舞曲，並非夜店現場。鍋爐為燃氣加熱鍋爐，非大型工業鍋爐房。重型機具改用大型 Kleemann 碎石設備，並非插圖的挖土機。這些差異在頁面可收合清單中告知。

NASA SCA 候選沒有音軌，不使用。另一份 British Airways Boeing 747.ogv 雖有 Vorbis 音軌，但解碼後全靜音（volumedetect 最大／平均皆 -91 dB），也排除。Flight take off.webm 畫面為螺旋槳機，非噴射機，亦不採用。起飛音必須另取可確認非靜音、來源描述確為噴射機起飛的錄影音軌。

原作授權逐檔適用，未重新以網站通用授權覆蓋；如採 CC BY-SA，衍生檔必須沿用同版本相同方式分享。沒有未授權、NC、ND 或不明限制素材。成品授權見 assets/decibel-audio/LICENSE.md，機器可讀資料見 recordings.json；來源 API 證據與 sources.json 在本輪 review/source。

## 響度與播放

先在相同採樣率／單聲道與短邊界淡入淡出後測量，再以固定增益統一為 -23 LUFS 基準；按場景順序安排 -40 至 -18 LUFS，每級 +2 LU。若任何成品真峰值將超過 -3 dBFS，整組共同下移，不削波或單獨壓平其中一段來湊數。重製腳本實際量測每檔成品並檢查響度及峰值。保留來源聲音與自然變化，不變調、不變速、不用合成噪音替代，不依真實 20～130 dBA 比例輸出。LUFS 僅是數位響度安排，不保證不同音色的主觀聽感等距。

點圖片／「播放場景聲音」重新播放目前錄音，停止後換場景保持安靜；播放或準備中換場景只允許最後選取的場景起音。沿用 lesson.mjs 的 AudioContext、activeRoot、source 與取消票號，不能另開一組失去管理的音源。短增益淡入／停止淡出降低切換不連續；離區、其他區起音、分頁隱藏、離頁均停止。下載／解碼快取不代表播放授權，必須在 resume 及 decode 後再核對票號；錯誤清除快取以便重試，不補假聲或回放錯誤場景。

頁面持續區分 OSHA 典型 dBA 參考、所選情境讀值與裝置播放音量，並保留舒適小音量提示。十二張既有插圖的原始 PNG、SVG 取景、前六區模型及單元小測保持。

## 驗證與交付

除原有前六區／小測回歸外，新增專項檢查每份實際播放 AudioBuffer 與成品解碼 PCM 完全一致、實測 LUFS／峰值／雜湊、圖片與按鈕重播、播放中點拖切換、取消／失敗重試／隱藏／離區／跨音源、手機真實觸控及桌機手機版面。測試紀錄、畫面、來源差異與部署確認由本輪 review 彙整。聽感仍會受使用者音響、裝置音量與環境影響，不把自動數位量測當作校準聽感或現場 dBA。

成品實測補充：為施工段峰值保留餘裕，全組共同下移 2.6 LU，最終約 -42.6 至 -20.6 LUFS，最高真峰值 -3.0 dBFS。短片段在低電平的絕對響度閘門會影響積分值，因此基準及成品均以實際輸出反覆量測校正「固定增益」，不改原作動態或用壓縮器補平。兩次重製十五檔雜湊一致。
