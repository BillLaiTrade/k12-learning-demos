# 5.2 第二區依核可實景示意圖實作

2026-11-05。使用者核可精緻版本，要求依示意圖修改並更新公開網站。範圍為第二區器材畫面；最新手動開始規則及熱交換模型保留。

- 改為實景風格隔熱盒、拉絲鋁塊、獨立數位接觸式溫度計。三層image_gen素材參照同一核可圖，兩鋁塊與兩儀表分別共用相同素材／尺寸；不是將整張預覽當成靜態操作區。
- 鋁塊仍由實物滑鼠／觸控拖曳，或原鍵盤方式移動；探頭隨塊、儀器固定、線材端點動態相連。碰撞與貼合由原位置模型決定。LCD七段數字與A／B讀數、流光使用同一溫度／時間狀態。
- 材質不隨60／20°C變成紅藍或發光，避免暗示不實的外觀。照片風格素材為生成示意，不宣稱為實驗實拍。
- 參照核可圖將狀態放在控制旁、同材質／同質量放在場景下；主要開始按鈕綠色，保留重來。窄版提供可讀A／B文字讀數，控制不裁切。
- 必要素材載入／錯誤與可重試狀態清楚，不讓空白器材假裝進行實驗。載入中與錯誤時不啟動模型；重試成功仍等手動開始。
