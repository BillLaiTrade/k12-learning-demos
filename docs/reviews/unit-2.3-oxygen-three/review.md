# 2.3 第四區：參照2.2第二區重做連續3D場景

日期：2026-10-31（臺北時間）。使用者認為前版精緻度與流暢度仍不足，指定先實際看2.2第二學習區，再回來製作。

## 參照與實作

已在瀏覽器播放2.2第二區，觀察實景器材、折射水體、逐影格氣泡／水面與連續四步；當次參照畫面為 `reference-2.2-section2.png`。新氧氣場景沿用既有Three.js、RoomEnvironment與色調映射／柔光技術，建立自己的立體器材、透明水體、氣泡、木條與火焰；沒有挪用蒸發器材照片，也不宣稱兩者是相同裝置。

上方導管在瓶外先排混合氣，外側氣泡可見；導管末端連續移到瓶口後才開始降低瓶內水位。收集完成後先撤管，再平移水下玻璃片。這些過渡共用同一播放時鐘，沒有用四張圖切換。水面法線、各氣泡出生／上升／消失、下方木條與程式火焰均連續更新；暫停、背景、離場與Escape仍由既有控制器管理。

保留滿寬、四步與下方兩組比較、原共用頭像、必要結果預設可見及小測。無JS保留完整SVG；無WebGL時仍可用SVG重播。3D繪圖沿用既有套件與授權，不新增依賴；軟管幾何緩衝區原地更新，停止後不持續自動播放。製氣8.4秒、木條4.6秒為教學時序，非實測時間／產率。

## 驗證

3D專項直接檢查畫布、幾何位置及像素。原氧氣／整頁回歸亦保留；軟體GPU的實際截圖耗時不等於動畫時鐘，測試改為先暫停時鐘、受控推進，再做原有斷言。曾發現舊測試在導管移動期間就要求水位改變，已將取樣移到導管到位後，另以3D專項驗證移管期間水仍滿瓶。

本次為第4階段逐區修訂。沒有對所有使用者裝置保證固定幀率；公開確認與測試結果另附。

本機最終結果：`oxygen-and-three-tests.log`為17項全通過；`page-and-model-tests.log`為11項全通過，合計28項、零失敗／跳過。桌機與390px手機的製氣／木條，以及瓶外排氣／集氣中途畫面已目視確認。曾因環境重啟使最後一組程序中斷，恢復後已重新跑完11項，未把中斷當作通過。
