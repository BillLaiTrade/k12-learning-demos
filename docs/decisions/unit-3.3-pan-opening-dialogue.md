# 3.3 第四區從琴弦銜接管內空氣

2026-11-02，使用者核可以下開場問答，放在排笛操作區前：

- 小葵：「吉他可以調整琴弦的長短和鬆緊，那排笛沒有琴弦，又是怎麼吹出不同高低的音呢？」
- 阿公：「排笛裡振動的是管內的空氣。我們試試長短不同的管子，聽聽音高有什麼變化。」

取代原本只問短管聲音的單句，承接吉他的發現，引出管內空氣及不同管長的比較。下方現有總結、點管吹奏、看管內、重播、重設、錄音與模型保持；沒有新增JS或播放門檻。

回歸檢查首次在「取消等待下載」案例的整區截圖之後，取消鍵已收起而逾時。改為只擷取載入提示並確認仍可見，再沿用原生點擊取消及延遲音訊檢查；未更改產品的播放或停止規則。

同日後續：依使用者核可，在操作區下方、原阿公總結上方新增小葵發現：「我發現，排笛的管子越短，吹出的聲音就越高！」沿用小葵頭像與配色，按「觀察結果→解釋原因」呈現，阿公的科學條件與頻率說明保持。不新增JS或播放門檻。
