# 4.5 第一、二區：觀察色散與比較色光的分工

日期：2026-11-03（臺北）。使用者核對4.3既有折射教學後，確認第一區應以色散為主、第二區透過固定器材比較色光並解釋原因；核可兩區並排示意圖後，要求沿用現有架構製作。並排僅用於檢視，正式網頁仍依序閱讀。

## 教學與課綱

第一區保留白光固定、放入／移開三稜鏡的操作，直接比較白色光斑與連續色帶。主內容補完整色散概念：白光含不同色光，各色偏折不同而分開；下方預設收合「為什麼光會偏向一邊」，以兩個界面及各自的法線承接4.3。補充在目前擺法下整體偏向底邊，玻璃內仍走直線。最後連到第二區的偏折比較。

第二區改題「不同色光，偏折程度一樣嗎？」；沿用固定三稜鏡、白／紅／綠／藍四選項與白光預設。右上預覽上下兩列為固定白光色帶與當前光源，均用原15×10mm區域、420×280畫布及相同倍率；切換不重新置中、不自動調亮。原生details預設展開，說明同一玻璃內各色光速率略不同→折射程度不同→白幕落點不同。代表圖並列紅綠藍，不表示白光僅有三種色光，也不把單色比較當作白光組成的完整實驗證明。

2026-11-03已核對[教育部自然科學領綱](https://edu.law.moe.gov.tw/LawContent.aspx?id=GL001823)附件：Ka-Ⅳ-7光速、Ka-Ⅳ-8反射折射、Ka-Ⅳ-10三稜鏡色散；課綱以國中七至九年級學習階段規範，並非逐年指定。[翰林國中理化「光的色散」](https://www.ehanlin.com.tw/app/keyword/國中/理化/光的色散.html)亦以玻璃內各色光速率差異解釋色散。採國二可理解的定性說明，不加折射率／各色光速計算或公式推導。

## 呈現與架構

沿用既有3D器材、拖曳／鍵盤、固定模型、白幕接收與WebGL備援；不新增依賴。只在precision-prism加入一次繪製的白光參照及當前光源標籤。新增prism-lessons.css，作用限第一、二區；窄版預覽保留右上半區，兩列畫布同寬，3D取景依既有canvas尺寸重算，保留器材與工具避讓。

兩張透明玻璃質感SVG由scripts/build-prism-explanations.mjs讀取既有prism-optics模型產生，採真實30°形狀與兩介面折點，單一比例映射，不用生成式圖片決定光路。第一張法線各自垂直對應表面；第二張保留650／530／460nm的實際微小角差，另以同一兩軸倍率放大出射光局部，讓差異可讀，不改角度或暗示精度提高。文字與原生收合由HTML提供；停用JS仍可閱讀。核可生成圖只作需求與設計證據，不作正式角色或背景素材。光學模型、3D渲染、第三至六區及唯一小測保持。

## 驗證計畫

新增圖解4項，檢查重建一致、均勻比例、法線垂直與交點、真實色光折點／紅藍順序，以及近看的等軸倍率／角度。既有整課回歸增加教學分工與原生收合檢查，保留各色光像素、固定取景／倍率及其他五區、手機與備援；加入白光參照像素不隨切換改變、靜態圖載入與無JS閱讀。測試依新內容更新舊文字與details選擇器，不降低原光學或器材避讓條件。實際結果與部署另存主專案review。
