# 4.5 像素電視觀察室：從配色填圖改為觀察成像

2026-11-04。使用者實際操作後指出猜配方與64格填圖花費時間、缺少概念增量；核可先看像素、只改一格、整圖關色光的示意，進一步要求更細緻多色圖片及關光後仍能逐格查看原本／目前RGB，最後授權依進階示意實作。此決定取代原第二小測的三個配色任務，第一小測與五教學區保持。

## 學習與互動

一開始就是完整海灣圖片，三頁自由切換，沒有目標配方、填入、色盤、完成計數或答對流程。看像素只讀原圖，顯示選取格RGB；改一格只讓當前金框像素套用三通道開關，其餘9215格取原圖，改選時仍只有當前格套用；看整幅圖讓每個像素套用同一通道遮罩。模式保留各自開關，重新整理回到新版核可示意的整圖紅光關閉狀態。

兩張圖點同一座標會選同一個像素，選點金框同步；左右都能在關光後點選。方向鍵、Home／End及3×3放大格可選取，屋頂／牆面／海面／白雲四個快速選點降低精準點擊需求。原本與目前的RGB數值只供讀取，0～255是sRGB圖片資料，非光功率或面板亮度。沒有數字輸入或反覆湊答案。

## 圖片與模型

以image_gen另製完整海灣像素插畫，原始檔為generated_images/exec-34155ff2-2d14-46e6-9038-c79ff3793e4b.png（1254×1254），複製保存pixel-tv-harbour-source.png；未裁切UI示意圖作網頁或結果圖片。scripts/build-pixel-tv-picture.cjs沿用原測試已有pngjs，平均取樣至96×96、每色以8為間隔簡化（近0／255端點保留），得9216像素與3842種顏色。來源PNG、96PNG、紅光關閉PNG與RGB資料模組一併保存，可重建。

新pixel-tv-observer-model.mjs直接處理同一份RGB資料。關閉通道精確設0，其他通道逐值保留；每次從來源重建，還原無累積損失。海面選點原R=0，關紅不變；白雲原255／255／255，關紅為0／255／255。局部與全圖模式分開運作，不疊加造成混淆。3×3的每個子像素與選取格前後數值皆讀同一模型。

## 呈現及備援

延續米白／綠色課程風格、同級小測①②與原錨點。完整圖片及快速選點與RGB檢視相鄰；桌機並列、手機自適應換行，數值保留可讀字級。Canvas2D繪真正像素，SVG只標選點，影像不套CSS濾鏡；無WebGL／新套件。loader仍獨立於課程入口，載入前／失敗／無JS顯示同資料生成的正確靜態原圖、紅光關閉圖與讀值，控制停用；失敗可重新載入。

原pixel-tv-model與舊8×8概念SVG保留歷史，但新觀察室不引用；舊UI／模型測試檔名沿用，內容改為新行為，避免執行失效任務測試。

## 驗證

模型檢查逐位元對照PNG、八種遮罩、單格改動、原圖獨立、四快速點、鄰格、縮放座標／鍵盤、動態說明與非法輸入。活動檢查實際Canvas像素、關光後點兩圖、原本／目前與鄰格一致、還原、模式獨立、七視窗、觸控、無JS／WebGL、獨立載入／失敗重試、重入與第一小測狀態獨立；詳細執行及公開證據存主專案review。
