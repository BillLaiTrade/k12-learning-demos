# 4.4 第三、四區共用凸透鏡實驗台

2026-11-04依使用者要求，一次整合兩區格式及先前待修的焦點光路；第三區以屏幕找像，第四區改用可移動的眼睛比較觀看結果。

- 共用物卡、凸透鏡、木軌、F／2F位置、物卡範圍0.3F～3.5F、接收位置0.5F～5F，以及代表光線。物距、接收位置相同時，兩區的基本光路座標完全相同；眼睛另以金色光線標示實際進入觀察位置的光，不把全部代表光線折到眼睛上。
- 共用橫向舞台、固定右欄、下方雙尺與三欄觀察表。圖卡尺左遠右近；屏幕／眼睛尺左近右遠，與器材世界位置同向。主圖中的器材選取提示使用下方位置尺；滑鼠、鍵盤與觸控沿用相同範圍。
- 表格切換均採共同取景、初始縮放，不依成像條件拉遠；手動移動器材不追隨相機。保留五倍近看、旋轉、縮回全景及視野外真實距離標籤。一般觀察列保留輔助光路偏好，找虛像才主動開啟。
- 物距恰好F時，預設追蹤上端。取樣同一物點通過不同透鏡高度的三束光，出射方向相同且繼續越過眼睛；切下端或一起看仍符合各物點分別平行。紅、藍不同物點的方向不同，不能把不同物點的線誤判為同一會聚束。
- 虛像位置、線性倍率及透明圖案在兩區一致，反向延長線可選擇。屏幕只在實像位置形成清楚圖案；F及F內不冒充屏幕可接到的像。
- 眼睛可跨到2F、3F及5F；物距不變時移動眼睛不改變實像／虛像位置或線性倍率。眼睛在實像之前、會聚位置或距離像小於0.25F時不顯示清楚圖案；越過後顯示倒立實像。最近對焦距離是教學簡化，非個人視力診斷。
- 眼睛與原物參照採相同畫面尺度與固定觀看角度。視角投影倍率為 `1 / (scale × (eye + object − eye × object / f))`，原物參照為 `1 / (scale × (eye + object))`；比較絕對值。F時取有限視角極限，並說明眼睛放鬆觀看像在無窮遠；不把無窮遠的空間距離誤畫成無限大的眼睛圖案。
- 視野與透鏡孔徑如實裁切；不透明屏幕只有在透鏡與眼睛之間才遮擋。眼睛畫面快取包含屏幕位置，移過眼睛後立即更新。

模型仍是理想薄透鏡與軸上觀察，未模擬逐面折射、繞射、像差或逐步眼睛調節。舊測試中固定眼睛、兩區不同器材大小及逐條件縮小取景的假設，由共用幾何、相同光路、可移動眼睛與實際畫面像素檢查取代。
