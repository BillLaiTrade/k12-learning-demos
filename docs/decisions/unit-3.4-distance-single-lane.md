# 3.4第二區喇叭分別播放

日期：2026-10-31（臺北時間）。使用者要求點上方只由上方發聲並接收反射，點下方只由下方進行，不再由任一喇叭啟動兩組。

- 兩個原生喇叭按鈕分別帶near／far範圍，輔助名稱與title說明自身組別；保留既有「一起發出短音」作同步比較，沒有新增模式切換或提示段落。
- 新觀察先取消前次播放與音訊排程，再將所選範圍及時鐘歸零；未選組清回等待，不畫波前、返回路徑、接收燈或時間紀錄。共用暫停按鈕只續播當次範圍，不重新發聲、不意外切成同步。
- 單組只排一個原音及一個相對增益0.45返回副本，固定最末增益0.32；時長與表頭秒數依該組返回時間，上方不等待下方遠牆。同步保留既有共同時鐘、兩組回波及同距合併排程。
- 物理距離、聲速340m/s、8倍慢動作、共同空間尺度、拖牆與改條件清空、跨區／背景停止不變。共用player新增預設無動作的onRestart鉤子，於取消前次播放後選擇新範圍，其餘五區使用原預設。
- 分別對HTML模組入口與distance-lab匯入更新版本參數，避免瀏覽器混用舊控制器。

維持第四階段製作／精修，不新增第五階段、外部驗收或最終核可。
