# 2.2 聲音示範素材

- `sound-story-opening.png` 為開場情境圖。
- `ruler-suspended-background.png` 是依原教室素材調整的背景圖：只有左側一張桌子，右側為桌外空間，避免把尺的懸空段誤看成搭在另一張桌面上。
- `ruler-parallel-assembly.png` 為現行透明鋼尺與夾具素材，原始尺身兩條長邊平直且平行；金屬紋理、反光與刻度保留在素材中。刻度供辨認尺身，並非量測互動。
- SVG 將素材分為不動的夾具／固定段，以及隨平滑曲線變形的懸空段；固定端位移及斜率為零，自由端位移最大。刻度與金屬紋理隨尺身彎曲，振幅隨時間衰減；按住停止時立即恢復靜止。
- 可直接點擊懸空尺面撥動，再點一次會重新撥動；觸控、Enter、空白鍵及下方播放按鈕均可操作。透明點擊區隨彎曲更新，背景與夾具不會觸發撥動。
- 尺身長邊依使用者指定，與畫面前方、最靠近觀察者的桌子前緣平行。整把尺面採同一平面投影呈現平放姿態；整組尺與夾具僅等比例縮放及小角度旋轉以對齊桌緣。靜止時懸空段不額外變形，避免夾持處折扭；只有撥動後才加入振動位移。
- 尺面點擊區關閉瀏覽器預設矩形焦點框與觸控高亮；鍵盤焦點僅沿尺身提示，不顯示矩形框。
- `metal-ruler-twang.wav` 為 CC0 金屬尺桌緣彈振實錄，頁面不需顯示署名。音檔已調整響度，固定以 100% 音量播放，不提供頁面音量滑桿，音量由使用者透過系統或裝置調整；連續點尺會從頭重新播放，按住停止會立即暫停並歸零，播放結束時恢復靜止。來源與處理方式見 [聲音來源紀錄](AUDIO-SOURCES.md)。
- 畫面刻意放慢並放大彎曲供觀察；聲音以實錄原速播放，兩者不作為實際頻率的量測模型。
- `ruler-clamp-background.png`、`steel-ruler-cutout.png` 及 `ruler-flat-assembly.png` 為保留的舊版素材，現行鋼尺示範不再載入。

## 第二學習區塊：聲音如何傳播

- 依使用者核可的版面示意圖呈現鐘、空氣疏密變化與耳膜。`sound-bell-ear.png` 是本次產生的透明教學素材；SVG 分別取用鐘與耳部，文字、箭頭、粒子和耳膜振動為獨立圖層。
- `sound-propagation.css` 提供全寬圖解與手機版空氣放大視圖；手機放大區透過 SVG `use` 共用同一組粒子，無第二份動畫時間軸。
- `sound-propagation.js` 使用延遲相位的一維縱波示意。每顆粒子有固定平衡位置，位移不超過 ±22 圖形單位，三列同步形成密部／疏部；相位以每秒 80 圖形單位向右傳播。這是放慢的機制示意，不代表實際聲速、頻率或分子尺度。
- 初始粒子均勻靜止。播放時先由鐘引發振動，再依距離傳到各粒子，約 7.875 秒後到達耳膜。鐘的示意振動持續 9 秒，整段於 16.875 秒結束；粒子不會隨波一路移到耳朵。
- 橘色粒子有固定原位虛線與水平往返箭頭；密部／疏部標示各自追蹤同一個區域，只向右移動；接近耳朵前以 70 圖形單位的範圍逐漸淡出，離開後不再切換追蹤對象或跳回左側。手機同步位置、透明度與顯示狀態，再次敲鐘會重設標示。耳膜僅在擾動抵達後振動。
- 依使用者最新指示，下方僅提供「敲擊鐘」按鈕；直接點鐘、按鈕及鍵盤 Enter／空白鍵均觸發同一敲擊動作，從鐘的振動重新展開傳播。連續敲擊先取消原動畫，不累積多條時間軸；自然結束後可再次敲擊。背景分頁凍結時間，返回後自動接續；初始不自動開始。敲擊時同時播放 `handbell-strike.wav` 手持小鐘實錄 BELL 8B（使用者選定②，CC0；含自然餘音約 6 秒），固定 100% 音量，再敲擊則重新起音；背景分頁停止聲音，返回不自動重敲。來源與處理方式見 [聲音來源紀錄](AUDIO-SOURCES.md)。
- 瀏覽器操作檢查見 `tests/unit-2.2-sound-propagation.test.cjs`；畫面對照紀錄見 `docs/reviews/unit-2.2-card02/`。

## 第三學習區塊：可操作的真空鐘罩

- `vacuum-apparatus.png` 由使用者核可示意圖產生乾淨器材底圖，保留完整玻璃鐘罩、電鈴、幫浦、管線與指示表；移除烘焙文字及粒子，改由獨立圖層呈現。
- `vacuum-lab.css` 提供全寬版面、器材上的原生按鈕點擊區、電鈴開關與下方控制；手機版開關換行，圖上點擊區至少 44×44 CSS 像素。沒有音量或空氣量滑桿。
- `vacuum-lab.js` 將電鈴電源、相對空氣量、抽氣／進氣分開管理。點擊幫浦或抽氣按鈕逐步減少空氣，再次點擊停止；進氣閥／放入空氣逐步恢復，切換方向會取代前一動作。
- 空氣範圍 0.02～1 僅供定性示意，畫面不顯示百分比或壓力數字。84 個候選粒子以均勻分布及最遠點順序安排，保留粒子仍散布全罩自由空間；避開電鈴與機座的實體區域。
- 電鈴開啟時敲錘持續動作，與空氣量無關。聲音經 Web Audio GainNode 連續調整，滿空氣時增益 1，接近真空時約 0.0133；這是定性聽覺對照，並非實測壓力公式。播放器固定 100%、不改音高；沒有依賴行動瀏覽器可能忽略的 HTMLMediaElement.volume 來調整實驗音量。
- 初始不自動播放，使用者開啟電鈴才建立音訊圖並播放本地 `electric-bell-loop.wav`。同一播放器循環使用；抽氣不重啟聲音、關閉立即停止，快速切換以請求序號避免舊播放承諾干擾新狀態。離開區塊或分頁時停止操作及聲音，空氣量保留，返回不自動開聲。
- 圖下注記區分接近真空與理想真空，保留可能經底座傳遞的微弱振動。來源與音檔處理見 [聲音來源紀錄](AUDIO-SOURCES.md)。
- 瀏覽器檢查：`tests/unit-2.2-vacuum.test.cjs`；核可示意與畫面對照：`docs/reviews/unit-2.2-card03/`。

### 罩外示意分貝儀（2026-10-28 修訂）

- 使用者要求移除圖下「電鈴狀態／聽到的鈴聲」整列，改為場景中的示意分貝儀。`sound-level-meter.png` 為本次產生的透明器材素材，以獨立 SVG 放在鐘罩外；LCD 數字與音量條由 HTML 更新，手機版調整尺寸保持可讀。
- 音訊路徑為媒體 → GainNode → 聲道分離 → 各聲道 AnalyserNode → 聲道合併 → 輸出。逐聲道取得調整後的波形能量，再合成 RMS，避免立體聲相位差造成單聲道相加抵銷；不改變原有左右聲道。
- 以電鈴錄音雙聲道全段 RMS 作「約 70 dB」示意參考，讀值為 `92.3276669648 + 20 log10(RMS)`。每約 0.1 秒取樣，能量以約 0.16 秒時間常數平滑。這不是校準過的 SPL 或 dBA，不代表使用者喇叭與現場分貝，也不取用麥克風。
- 顯示整數、同步音量條；關閉電鈴、播放尚未開始或訊號靜音時清為「—」，不將 0 dB 當成無聲。若未來更換電鈴音檔，須重新核對示意參考值。
- 原狀態文字只保留在輔助科技的禮貌通知區，正常畫面不重複顯示，播放錯誤時才顯示提示；分貝數字不作持續語音播報。
