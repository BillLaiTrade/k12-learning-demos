# 4.4 第四區：把放大鏡所見連回第三區的虛像

2026-11-04，依使用者確認的版面與教學範圍修改。主線仍為固定眼位、移動圖卡，比較 F 內與 F 外的觀看結果；圖卡範圍維持 0.1F 至 1.5F。輔助光路預設關閉。

開啟光路時，沿用第三區每個物點的三條代表光、色彩與反向延長線，以共同薄透鏡模型計算；F 內標出圖卡同側的正立放大虛像。移除第四區額外的金色入眼光束，避免兩區呈現不同的光路規則。右側提示所見即為主圖標示的虛像。反向延長線開關置於工具列最後，切換情境保留端點與延長線偏好。

觀察表後只用一句話連結「F 內的正立放大虛像」與放大鏡功能；對照連結會將第三區切到 F 內情境。虛像位置不在目前視野內時沿用既有邊界提示，不能把虛像搬到眼睛那側。

「虛像在另一側，眼睛為什麼看得到？」放在預設收合的原生 details 中，以照鏡子和看放大鏡兩個小圖補充：像的位置與眼睛接到光的位置可以不同。鏡子小圖畫反射光及其反向延長線，放大鏡小圖畫透射光及其反向延長線；眼睛均在實際收到光的位置。沒有加入眼內構造、調節機制或入眼光束放大圖，這些仍留給第七區。

檢查涵蓋兩區代表光的取樣與斜率一致、虛像位置與倍率、跨 F 的光路選擇、補充區鍵盤展開／收合、對照連結，以及桌面與手機版面。

補充圖的視覺修訂：兩圖採相同光學實驗台配色、鏡面與玻璃材質、圖卡和底座；眼睛都放在右側，直接對照虛像與觀察者的位置。實際光線與反向延長線共用圖例，箭頭沿幾何光路計算。照鏡子保持物像等大、到鏡面的距離相等；放大鏡採物距半焦距，虛像維持正立兩倍。圖下注解與結論簡短呈現，桌面並排、手機上下排列；補充區仍預設收合。
