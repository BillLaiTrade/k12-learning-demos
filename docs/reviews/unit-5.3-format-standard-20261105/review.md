# 5.3 共通格式修訂（2026-11-05）

## 範圍與變更

使用者在格式盤點後指示：「對齊區塊版型與導覽連動，再整理標題、副標及分享設定」。依 k12 的共通規格 v1.2 與五點標題／副標規則執行；本輪只做既有 5.3 的局部修訂，維持第 4 階段。

- 五個教學區改為上方標頭、下方完整內容，沿用第五單元既有 `unit-format.css`；移除區塊內的概念側欄。開場放回頁首，教材路徑從開場下方開始。
- `lesson-navigation.js` 直接讀取各區 `h2`，包含結尾小測的六個導覽入口逐字一致；標題的子節點／文字變動由 MutationObserver 同步，無另一份導覽標題文案。保留原錨點；返回開場時回到第一區標示。
- 第二區改為「同一杯水，吸收不同熱量會怎麼變？」；第三區改為「水裝得不一樣多，升溫有什麼不同？」；其餘三區標題保持，五區副標改為科學主題與比較焦點。
- 入口、頁面主標題一致；靜態 title／OG／Twitter 採「同樣加熱，為什麼升溫不一樣？｜5.3 熱量與比熱」。三種摘要一致，補 canonical、分享 URL、開場圖及圖像說明／尺寸。
- 分享圖使用既有 `heat-story-opening.webp`，1672×941，未修改原圖；角色、實驗模型、操作、生活應用、四題小測與答案政策保持。
