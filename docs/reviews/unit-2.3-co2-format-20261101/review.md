# 第四區比照第三區的連續實驗工作區

2026-11-01，使用者明確要求評估資料充足後直接製作。既有材料與科學流程足夠，因此沿用大理石＋稀鹽酸、先排空氣、向上排空氣法，不新增材料、劑量或新依賴。

## 本輪變更

- 沿用第三區桌面背景，六件材料與各操作共用同一組器材、固定鏡頭及同高標題。材料桌面、加藥、接管、集氣及封存皆由同一物件更新，不切換舊背景或照片。稀鹽酸使用既有無標籤開口試藥瓶素材，從材料頁至倒入、放回皆相同；不是將氧氣實驗藥品改稱鹽酸。
- 導管隨附塞器材抬起、旋轉並接合，玻璃片沿抬起路徑移往瓶口；不在最後一刻改成另一張器材圖。液體、石塊、反應氣泡及方向示意沿共享時鐘更新。二氧化碳本身仍無色，箭頭不是氣體顏色。
- 八項操作點選即播，依序自動連播；唯一主鍵、桌面空白暫停／原位置續播、材料與動態器材介紹、鍵盤／手機、跨播放器互停保持。新增動態塞子目標並讓介紹點擊優先，不被誤當空白。
- 使用同一共用字幕元件，在圖下顯示淡黃色「畫面說明」，修正原CO2呼叫與新元件不相容的容器選取；第三區行為保留。
- 材料提示置中淡黃底。實驗下方加入同格式五點整理：反應物、加藥順序、先排空氣、直立／瓶底進氣的向上排空氣法、撤管後蓋片。明確說明大理石非催化劑、接觸即反應、氣體仍會混合；未延伸方程式或第五區檢驗。
- 其他五區HTML逐段一致，雜湊見preservation.json；第三區／第五區與小測均回歸。
