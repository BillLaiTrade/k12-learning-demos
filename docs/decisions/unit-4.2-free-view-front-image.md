# 4.2 恢復自由觀看與下方正面參考圖片

日期：2026-11-05。使用者撤回左右分欄與限制觀看方向的版本，要求上方恢復單一大畫面和原操作自由度，下半部放正面圖片，並可一鍵調到該參考畫面。

- 保留先前材質、受照面及燈光改善，上方恢復原生WebGL單一畫面。水平可完整轉動、不限圈數；上下俯仰恢復原始0.2–1.48弧度範圍，不再鎖定高度。初始正面、兩燈關閉。
- 下方固定PNG由實際場景在正面、兩燈全開時擷取，1119×678，沒有另行調亮或以生成圖片替代。說明清楚標示雙燈條件；上方獨立開關及自由觀看不改變該圖片。
- 新增「回到正面參考角度」：回正面與預設俯仰、取消未完成光照動畫、開啟兩燈，再將主畫面帶回視口；按鈕旁明示同時開燈。既有三個預設角度仍保留燈光狀態。
- 滑鼠與鍵盤使用原生click；觸控以有效抬手辨識補足拖曳後可能被省略的相容click，並排除移動、取消與重複啟動。在畫布中垂直拖曳用於調整角度，畫布外維持頁面捲動。
- 無WebGL時隱藏無法操作的主場景並停用六個控制，下方固定圖片仍能閱讀。保留卡片格式、第一區三句對話及第二區起的內容。

幾何、實際像素、自由轉動、手機原生觸控、對照按鈕及窄版證據見`docs/reviews/unit-4.2-free-view-reference-20261105/`。先前分欄版紀錄保留為歷史。
