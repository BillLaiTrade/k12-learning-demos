# 4.3 介質名牌字型微調

2026-11-05（臺北）。依[本輪決策](../../decisions/unit-4.3-label-type.md)，新增一條只作用於四個介質名稱的CSS，另更新HTML樣式版本。

- 舊設定為650字重並套0.35px淺色描邊；新設定為500、0.04em字距、明確繁體中文無襯線字型與無描邊。
- Chromium字型追蹤確認本機原為NotoSansCJKtc-Bold，現在為NotoSansCJKtc-Regular，沒有換成明體或由瀏覽器合成粗體。其他作業系統依原生字型fallback顯示，不宣稱所有OS逐像素相同。
- 1440、1366、1280、1024px四桌面寬度確認四個名稱仍位於原名牌內；實際發射、排序與判分正確，正確後移位的最快／最慢標記與名稱無重疊。見type-check.json與check.txt、兩張代表截圖。
- preservation.json確認原CSS除新增規則外逐字相同，HTML只變樣式版本；沒有改任何教材、名牌幾何、PNG、光學／控制器或判分程式。低影響字型調整未新增實作對照式測試或重跑無關模型。
- S01／S05／S19／S20為本輪外觀與閱讀檢查；S10／S12／S18以實際正確排序回歸；S24本機完成，發布與公開證據補記規劃庫同名目錄。其餘內容與分享資訊保持，未重做整單元驗收。

維持第四階段，非整單元最終核可。
