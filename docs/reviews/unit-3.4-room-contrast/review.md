# 吸音比較可辨識度修正（2026-11-01）

使用者反映材料前後不易看出差異。原因為切換時清空動畫、無法同時刻比較；原反射強弱僅以透明度線性映射。

修正：材料切換先取消音源並暫停，保留相同波前幾何與時間；沒有發聲前仍保持ready，無自動播放。播放結束保留1.05秒的代表畫面並明示可切換比較。反射波透明度採相對壓力係數平方呈現能量差異，線寬作強弱的輔助視覺編碼。未更動聲速、半徑、材料物理假設或四個音檔；原始發出波、未處理牆面的反射維持相同。

本機新區13項、整課10項瀏覽器通過；波前及音訊純模型檢查也通過。新增實際同一畫面比較：處理表面的透明度低於原20%、線寬低於原50%，未處理表面與原始波的半徑、位置、線寬／透明度完全相同；切回前一條件可逐項恢復。檢查播放、暫停續播、材料取消音源、播放結束定格、九種尺寸與真實手機觸控，並開圖檢視同時刻前後差異。
