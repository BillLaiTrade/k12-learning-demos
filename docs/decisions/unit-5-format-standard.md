# 5.1、5.2 對齊共通格式

2026-11-05。使用者要求先讓5.1與5.2符合最新格式，再推進5.2內容。

## 依據與變更

依規劃庫`docs/product/unit-production-standard.md` v1.1、同日標題／副標五點規則，以及現行4.1的版型。共用樣式集中在`units/5/assets/unit-format.css`，只由5.1與5.2載入，不影響5.3與其他單元。

- 兩頁開場與探索標題放在學習路線前；1120px外殼、桌面導覽250px／間距34px，761–1100px改205px／24px，760px以下改橫向導覽。
- 5.1沿用既有上方標頭；5.2將實際主標題與副標移入上方標頭，移除重複概念側欄。學習內容下方使用完整欄寬，實驗內功能分欄仍保留。
- 同類標頭、正文、對話、48px正式頭像與小測統一。原器材內文字及操作佈局按各活動保留，不強迫整張長卡片塞進一屏。
- 副標改為概念／比較焦點，移除操作指令、完整解釋及待探索結論；必要概念仍在既有正文／對話。主標題及核可教材不重寫。
- 入口對應內頁主標題；title／OG／Twitter採「主標題｜編號 主題」，摘要三處一致，canonical與URL正確；沿用已核可的1672×941開場圖及其WebP資源，提供尺寸、類型與alt。
- 5.2對話移除外層引號，與5.1既有約定一致。

## 保留與檢查邊界

格式提交保留所有JS、模型及素材。5.1四區主體完全一致；5.2六區主體排除移出的標題／副標與外層對話引號後完全一致；script標籤完全一致，見[保留比對](../reviews/unit-5-format-20261105/preservation.json)。5.2後續第四區精修另行記錄，不混稱為純格式變更。

未將已移除的5.1估讀表單／小測平視捷徑或5.2第二區同溫起始模式加回。5.1四區一小測、5.2六區一小測及模型數值、評分政策保留。兩頁維持第4階段，本次格式交付不代表完整成品全部規則通過或外審／最終核可。

首次回歸發現兩處舊文案斷言過時；未修改的origin/main頁面同樣失敗：視差標籤現為「讀取位置」，冷卻提示現為「液柱逐漸下降」。僅更新這兩個斷言，不回改已核可文案、不移除物理或操作測試；前者造成一子項失敗，後者使受控時鐘未恢復並連帶影響兩個後續子項。重跑結果見[本輪檢查](../reviews/unit-5-format-20261105/review.md)。

使用者指出入口與其他單元不同。前次格式對齊漏保留了「保冷水壺小測」及綠色選取樣式；改成固定「單元小測」，字重／分隔間距／24px淡金圓形星號／金色選取對齊現行4.1、4.5及5.3。活動名稱仍保留在右側h2。只在5.2的heat-transfer.css覆寫，更新其快取版本；不改其他Part共用CSS。六區、小測內容及全部腳本保留。本機畫面、七視窗與代表作答流程見`docs/reviews/unit-5.2-quiz-nav-20261105/`。
