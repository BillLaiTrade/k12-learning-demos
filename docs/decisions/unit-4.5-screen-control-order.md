# 4.5 整圖圖片、控制與說明順序

2026-11-05（臺北）。依使用者確認，第三步改為「原圖／調整後圖片 → 三色光選項 → 變化說明 → 還原」，將既有結果說明移到控制區內的選項下方，避免隔開圖片與操作。桌機及手機維持相同順序，沿用既有單一控制元件與狀態。

全保留時只顯示「目前保留全部色光，畫面與原圖相同。」不顯示說明標題、重複原因或大框；任一通道改動後才顯示色光狀態、原因與畫面變化。還原後回到一句提示。全圖三選項、計算模型、前兩步及取樣保持。載入版本tv-flow-20261105。
