# 2.2 檢視清單前五項修訂

2026-10-28；使用者核可「先處理一到五項」。其餘建議仍待核可。

1. 單元小測的過濾與加熱共用 `cup-transfer.js`。杯內液面以容器轉動後的輪廓及水平切面計算；水柱起點由同一張杯子照片的杯口座標變換而來。來源、飛行中、濾紙暫存與接收量分別計算；蒸發皿先空皿接液，再加熱、形成固體。初始大瓶取樣模型及科學質量不變。
2. 第一區以空器材背景、既有透明燒杯與 Canvas 液體／泥沙重建連續過濾。第一次進入畫面播放約 10 秒，完成後保留空來源杯、紙上泥沙與下方濾液；點畫面重播。減少動態偏好初始顯示結果，背景分頁暫停。這是定性過程模型，照片座標不宣稱為量測刻度。
3. 圖上按鈕改為「樣本、濾紙、倒入、濾液」，下方保留唯一的四步流程編號。深入解說標題同步移除第二套編號。
4. ppm 在手機及較窄內容欄將「放大看」放到質量標籤右側；窄幅不顯示手形與長前綴，保留可點入口。1 毫克、1 公升、密度、整份糖模型、分母與公式均不變。
5. 開場改為未溶解泥沙、溶解鹽與混合色素的分離觀察，再自由調配糖水並用濃度表示比例；移除不存在的兩杯比較描述。

## 素材

`filtration-empty.webp` 使用影像生成工具編輯原 `filtration-scene.png`，只移除靜態來源杯與其內容，保留漏斗、濾紙、支架及空接液杯。正式頁不再用固定滿杯照片冒充已倒空的來源。透明杯沿用 `concentration-beaker.webp`，不新增套件或服務。

## 檢查

見 `docs/reviews/unit-4.2-investigation/review.md` 的前五項修訂章節與 `tests/unit-4.2-filtration.test.cjs`。測試中的軟體 2D Canvas 選項只影響雲端 Chromium，網站未限制繪圖加速。瀏覽器先等待 DOM，再明確等待各互動 ready／error；本機 HTTP 請求紀錄不累積在未讀取的 stderr 管線。
