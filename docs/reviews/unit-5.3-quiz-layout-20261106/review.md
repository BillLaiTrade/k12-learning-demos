# 5.3 單元小測版面整理（2026-11-06）

依核可方案，把兩張計算卡與比較題整合成「你的推論」，桌機前兩步並排、第三步整列，以分隔線及1／2／3編號建立順序。公式提示置於面板右上方，精度說明各自靠近輸入。共同條件移入器材框上緣；甲乙固定綠／橘色標，照片、吸熱列及答案一致，換題時顏色跟著甲乙而非材料。

觀察前以「開始觀察」為主要操作；完成後重觀察改為次要、核對推論啟用為主要，重答保持次要。中斷且未完成時重觀察仍為主要。原圖裁切與LCD大小保留，沒有為縮圖壓縮讀值。前五區HTML、分享設定及35個其餘資源逐字保持，含純模型、題庫及判定；見preservation.json。

小測瀏覽器10項通過，涵蓋初始、同源觀察、逐欄提示、重看／重答、16組換題與色標、中斷、失敗重試、減少動態及五尺寸。共通格式7項及模型4項另見local-format-model.log，最後各套合計21項（含父測試）。初跑發現比熱輸入列在窄版不換行，調整為彈性換行並限制網格最小寬度；選項文字保持整詞。初跑與第一次換行後的失敗紀錄保留，最後小測結果見local-quiz.log。

五尺寸無頁面溢出、主要文字16px、LCD至少15px、輸入及按鈕至少44px，器材窄版內部左右查看。桌機初始、觀察完成、正確回饋與390px窄版以獨立真實時間頁面截取實際視窗，已人工檢視；功能測試不混用元素截圖。

維持第4階段待使用者檢視；不是整頁最終驗收。公開發布證據接續記錄於規劃庫同名review。
