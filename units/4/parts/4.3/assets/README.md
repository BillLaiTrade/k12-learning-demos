寬版在1200×600畫布上，採玻璃內面左右70／915、上下190／494；直立版在660×720畫布上，採59／600、199／609，現行四層的層高皆為內面高度四分之一。兩者以相同尺度映射x、y光學座標，保持真正角度，並非拉伸光路。透明光源以原圖約(550,1280)作出光口中心，映射局部(0,0)後再旋轉及平移；低調發光疊在玻璃口內，照片本身不含光跡。

這些是教學用寫實圖稿，物理計算獨立於圖像；排序、速度數據與光路由原純模型產生。圖稿載入失敗時仍可使用向量備援。

## 四種介質與觀看畫面效能（2026-11-05）

兩種固體分別以cool／clear表面完成度綁定n1.78／1.55；原固體照片上疊低透明度冷色／淡暖反光與不同細高光。這是即時SVG呈現，沒有修改或輸出任何PNG，外觀不作未知實物的化學鑑定依據，快慢仍依四筆角度判斷。

`depth-observer-worker.mjs`重用原逐像素追跡與材質計算，`depth-observer-client.mjs`管理最多一個運算與最新預覽／細節請求。互動160px寬預覽，停止後最多1100px（原兩倍顯示寬）細節；兩者的幾何、固定觀看方向、倍率與材質相同。攝影射線方向按解析度快取，最多兩組。worker失敗時主執行緒以176／400px備援，照片失敗仍保留原簡化材質與重試。


## 臨界可見範圍的一致呈現（2026-11-05）

`depthGeometry`從真實硬幣半徑的兩端，求出能越過槽緣的連續可見區間，取代七點抽樣；可見性與解析度無關。部分可見時，代表光線取可見區間內的一點；必要時縮小瞳孔附近的輔助取樣間隔，避免把被擋的光線反向延伸。

`renderObserverPixels`保持原材質、陰影與逐像素追跡；若可見薄邊落在像素中心之間，該像素使用一條已由同一`traceViewRay`驗證到達硬幣的子像素光線。沒有疊硬幣圖示或改變光路、攝影方向／倍率，也沒有改PNG。狀態採共用物理判斷，像素數僅作繪製檢查；預覽與精細畫面必須都有實際可見取樣。
