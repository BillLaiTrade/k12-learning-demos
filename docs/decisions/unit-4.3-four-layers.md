# 4.3 小測：四層介質

2026-11-04（臺北時間）。使用者核可由三層增加為四層，維持目前場景大小。

甲乙丙丁皆為位置名稱。原代表n1.00045（氣）、1.4（液）、1.78（固）保持，增加另一透明固體n1.55；兩種固體沿用玻璃內面圖，不以外觀或物態當成普遍速度排序。36／40度下四筆一位小數角度都不同，最小差仍超過2度；不以幾種常見氣體的細微折射差湊層數。光路仍由同一n sinθ不變量與等比例投影產生。

每輪24種速度排列各一次，跨輪不相鄰重複。四槽移卡／覆蓋／交換／判定擴充，圖說、替代文字、未完成提示及結果都同步。逐段發射、點燈、重播保留答案、換題清空、離屏續播保持。

場景維持既有寬／直立木質底座：內面等分四層、原字級、縮小弧線與向上法線延伸。加寬名牌，將正確結果的最快／最慢放入牌內，避免跨層。桌面四欄；650px以下容器採兩列兩欄並標1～4位，首／末位置另註最快／最慢，卡池兩欄。方向鍵依實際欄數處理上下與左右，維持至少44px觸控區。
