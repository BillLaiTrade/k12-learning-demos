# 4.5 第三區：綠框限於指標拖曳，保留鍵盤焦點

日期：2026-11-03（臺北）。使用者允許拖曳中的綠框，但要求放下或點按開關後、滑鼠移開時不殘留。前版pointerdown為保持方向鍵可用而主動focus，瀏覽器會讓focus-visible繼續顯示，與拖曳框共用同一樣式而留下綠框。

以data-pointer-focus區分指標造成的焦點：pointerdown先標記再focus，保留實際焦點以便之後直接用方向鍵；未拖曳時隱藏指標焦點的outline，原綠框樣式只匹配真正的拖曳或非指標的focus-visible。放開／取消原本已移除data-dragging，因此綠框立即清除，無須等mouseleave或用blur破壞鍵盤操作。既有hover的淡底色維持，不增加框。

一般keydown清除指標標記，Tab、方向鍵及Space／Enter恢復鍵盤焦點提示；blur亦清除標記，避免日後Tab返回仍被隱藏。Escape取消拖曳在切換模式前處理，使取消仍清除拖曳綠框。觸控、擷取遺失、失焦與放開同樣適用。

金色輪廓仍只表示開啟，點按開關、快速比較全開、光束、比例、名稱與科學模型皆保持；不新增可見文字、按鈕或依賴。仍為第四階段。

新增焦點專項5項：三色點按開關後移開、保持實際焦點與金邊；拖曳放開／Escape／pointercancel／擷取遺失／失焦清除及取消回復；鍵盤與Tab返回；手機原生點按及touchEnd／touchCancel。搭配金邊5項與快速比較4項；本輪光束8、版面15、整頁34與純光學未重跑，保留檢查確認其他程式未改。
