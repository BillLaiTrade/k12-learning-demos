# 第二區：反射定律圖的核可版面

日期：2026-11-05。使用者核可科學展覽風格示意，要求套用到第二學習區塊的反射定律說明。

以米白底、深綠標題、右上公式與細分隔線取代藍黃底框和大紅字。入射光及入射角用琥珀色，反射光及反射角用深綠；標籤不再加框。鏡面以分層銀藍漸層、亮邊與輕微底緣陰影呈現厚度；角度扇形維持低透明度。手機改為上下排列標題、提示與公式，放大圖內標示並調整位置。

實際網站使用SVG，沒有把生成圖當作光路背景。入射點與鏡面上緣、法線交於同一座標；三角函數計算入射／反射方向，原生SVG圓弧依相同角度繪製。入射箭頭沿完整光路放在接觸點前，避免被入射點圓標遮住。初始HTML就是精確30°，無JavaScript或WebGL時仍可讀。

下方雷射器材、光學模型、20°–90°範圍、拖曳／鍵盤、讀值及第六區接收角度的事件維持原樣。只有上方SVG的座標、視覺及響應式標示更新；第一區與第三區以後不變。原核可圖、實際畫面及檢查見`docs/reviews/unit-4.2-law-exhibit-20261105/`。
