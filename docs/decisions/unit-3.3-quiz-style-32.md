# 3.3 單元小測樣式對齊3.2

2026-11-03，使用者比較3.1／3.2／3.3後，核可「按照3.2來」，修改3.3單元小測的外觀。

- 外框、淡米黃標頭、問號徽章、並列的小測標籤與標題採3.2的配色、字級及圓角。
- 三區改白底、淡綠小標，控制卡採淡綠標頭及白底；編號保留但降低視覺強度。
- 主按鈕統一深綠底、圓角及字級；保留175px等寬、至少44px高與同一右邊界。換題改為標頭右上角的文字操作。
- 保留聽目標→調整並試聽→完成比較三區、緊湊間距、桌面完成區同列及手機自然換行。結果仍在第三區展開。
- HTML僅更新CSS查詢版本；不改文字、結構、JS、配對、錄音、音訊模型或七區教材。

既有小測專項改以實際3.2頁面比對外框與標頭樣式，另核對小標配色及字級。小測與整頁本機26項通過，保留八種寬度、配對、回饋、聲音與波形一致、換題、重試、鍵盤及觸控回歸。公開版於部署後另行驗證並記錄於規劃庫。
