# 4.5 第三區：操作區依視窗高度收斂

日期：2026-11-03（臺北）。使用者指出第三區整體太高，需要上下捲動才能使用全部操作，希望盡量不超過一個視窗。本輪依已授權的修改／提交／部署流程調整版面，不改混光、器材材質或學習內容。

原版在1366×768下，第三區整卡約1322px、操作區約843px；白幕跟隨整欄寬度放大，下方再疊加手電筒、兩組按鈕、提示及狀態，造成操作分散於不同視窗位置。先量測，再改成僅第三區生效的緊湊版面。

桌機將兩段引導並排，保留正式角色與對話順序；標頭、內距及提示收緊。白幕／手電筒和控制面板左右並排，兩組控制改為緊湊排列。場景高度按100svh、導覽列保留區與敘事空間計算，設合理上下限。白幕用容器寬高計算可容納的等比例畫布，保留1000×560比例與實際畫布邊界，沒有拉伸光斑；手電筒也保持原圖框比例與金屬模型。

手機改成上方場景、下方兩列按鈕，觸控尺寸至少44px；短視窗再限制場景高度。操作提示簡化為「拖曳手電筒調整照射位置，方向鍵可微調。」；重複三燈開關狀態列改為螢幕閱讀器可讀，視覺狀態仍由各開關清楚顯示。原生控制群組補上名稱，沒有新增操作步驟。

一般筆電及較大手機可容納整卡；較矮手機優先讓白幕、三燈和六按鈕同時可操作，不用在操作項之間反覆捲動。完整敘事／模型說明仍留在正常文件流，展開說明可自然延伸，不固定整卡高度、不裁掉內容，也不加內部捲軸。

新增13組視窗專項驗證，涵蓋筆電、平板、手機與矮橫向視窗：檢查整卡可容納的情境、對齊操作區後全部控制在視窗內、點按所有按鈕及拖曳不改頁面捲動位置、光斑同倍率、44px觸控範圍及說明可展開。專項以同模型圖片備援隔離CSS量測，真立體由整頁回歸檢查。純光學與立體模組、正式角色、其他教學區及小測保持，未改模型不重跑純模型檢查。
