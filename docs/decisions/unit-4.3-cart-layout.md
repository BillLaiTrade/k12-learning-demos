# 4.3 第二、三區小車說明精簡與雙欄排版

2026-11-05（臺北）。使用者提供兩區截圖，要求分析重複文字與排版後選A：保留兩個說明區及雙欄，不合併或更動學習順序。

左欄為完整動畫與同列的即時狀態／播放按鈕；右欄只說關鍵原因及一句光學對應。垂直例聚焦兩輪同時變慢而直行，斜射例聚焦一輪先變慢、暫時不同速而轉向；角度大小與0°例外由原主實驗交代。兩區的「小車為類比，不代表光受到摩擦」移到相同底部位置，第三區仍保留固定斜射類比與主圖設定獨立的短註。

兩區圖框擴充上緣留白，車輪運動、交界位置與計算軌跡保持。第一張圖直接標法線，圖內標籤保持至少12px螢幕字級並避開輪子；地面字樣放在不干擾行進的位置。右文對齊圖頂部，消除原本因整個左欄置中造成的大面積上方留白。播放中、暫停與完成的按鈕使用短狀態名稱。

以data-compact-cart限定新版樣式與文字於第二、三區。第四區雖沿用同一播放模組，維持原文案、構圖與互動；其他學習區、角色對話、四層小測與物理模型不變，不新增素材、依賴或手機排版工作。

新增tests/unit-4.3-cart-layout.test.cjs，檢查四桌面尺寸、七個動畫時刻的雙輪完整可見、標籤可讀且不遮輪、雙欄對齊與圖下同列控制。另沿用垂直、斜射、加速小車、原互動與格式回歸，確認兩輪同時／先後變速、轉向、重播及中斷邏輯保持。維持第四階段，非最終核可。
