# Part 1.1 互動素材與模型

## 第三區：三片小孔板通光（2026-10-29）

- `aperture-3d.js` 保留原有三板拖曳、選板、高度滑桿、重設位置／視角及場景外觀；通光改由 `aperture-optics.mjs` 計算。
- 模型沿用燈前出光點 x=-4、光軸 y=1.28、屏幕 x=4.265 及既有半徑0.15的光斑範圍。將小光源至此圓形光斑視作窄角直線光束，光斑內採均勻光量分布作幾何模型；不模擬整個燈具的輻射分布、衍射或散射。
- 孔板實際開口為高0.36、寬0.42，厚0.12。板片幾何與光線計算共用相同孔口／板厚常數。每條候選光線由光源直達屏幕；在每片板前、後兩面的交點都必須位於孔內。
- 孔口限制換算至屏幕的光束截面後逐片取交集，以圓形光斑剩餘面積的解析積分求相對通光量。板只在x／y移動，水平孔寬在全部行程都大於光束，因此可用垂直帶形截面精確求此模型的通光比例。沒有以最大偏移量估亮度，也沒有20%以下直接當無光的門檻。
- 按光源至屏幕的實際前後順序處理。每片指示燈顯示已經穿過前方板、也穿過本片的光；前面完全擋光時，後方指示燈會熄滅並說明沒有光束到達。
- 亮點及外暈只在通光量大於零時顯示；沿用原亮度／尺寸的教學示意來表示相對通光量，未把光點當成精確的截面形狀或照度計。
- 檢查：`tests/unit-1.1-aperture.test.cjs`；操作畫面、模型依據與紀錄見 `docs/reviews/unit-1.1-card03/`。該次修訂未修改其餘區塊與單元小冊。

## 單元小冊：少量吸附並保留前後距離（2026-10-29）

- `shadow-theatre-optics.mjs` 共用舞台光源(-0.8,3.05,3.5)、屏幕z=-1.25與原目標深度0.42；切紙平面與屏幕平行，因此由同一點光源投影為等比例縮放及平移。
- 完成判定比較投影大小與屏幕位置：線性大小誤差不超過4%、投影錨點距離不超過0.12舞台單位。此容錯讓尺軌、鍵盤與滾輪可以找到合格位置，不要求唯一的0.42座標。
- 兩項都接近才吸附，僅用學生目前z反算對齊影子所需的x／y。吸附不寫入z、不縮放道具；偏大、偏小或位置不合時保留原狀並提供簡短回饋。
- 拖曳放開、方向鍵、尺軌與滾輪使用相同判定；尺軌拖動中只更新影子，放開後才吸附，滾輪仍按學生指定的方向調整前後步幅。重設舞台仍還原原始三個道具位置。
- 模型用切紙中間平面近似投影，未做逐像素輪廓比對；現有實體厚度、斜向照光及柔邊陰影可能造成些微輪廓差異，透過有限容錯維持可操作性。
- 完成後按鈕顯示「演出完成」並停用，下方提示按上方「重設舞台」重新挑戰；重設還原道具、進度、描邊與操作狀態。


## 單元小冊：扁平尺軌控制器（2026-10-29）

- 依最後示意及使用者的方向修正：左端光源、右端屏幕。控制器高78px，保留刻度、綠色指針滑塊、目前道具名稱及讀值，取代兩個前後按鈕。
- 0–10為相對位置刻度，不是長度單位。左端0對應原本靠近光源的移動上限z=2.95，右端10對應靠近屏幕的下限z=-0.9；沒有改變道具可移動的物理範圍。
- 原生range支援滑鼠、觸控與鍵盤；0.01的刻度步幅提供連續調整。刻度線與數字對齊原生滑塊中心行程，左右兩端小圖示及文字同列，手機不增加額外堆疊高度。
- 選取道具及其他操作後同步尺軌讀值，只更新控制器，不將刻度四捨五入值回寫道具z。原有滾輪與舞台Ctrl方向鍵仍同步尺軌。
- 拖動途中不吸附、不隱藏尺軌；原生change事件提交後才檢查大小與位置，通過時仍只微調x／y並保留學生的z。
- 最後核可示意與實際畫面、檢查紀錄見 `docs/reviews/unit-1.1-shadow-theatre/` 的 `ruler-*` 檔案。

## 第三區與單元小冊：立體畫面無法載入（2026-10-29）

- `scene-loader.js` 分別載入三孔板與影子劇場，捕捉場景／依賴檔案下載失敗、初始化例外及 WebGL context lost。
- 失敗時在原畫面位置顯示「立體畫面未能載入，請重新整理頁面後再試。」，停用該活動的按鈕、滑桿與畫布互動，並移除失效畫布的鍵盤焦點。
- 原本的高度、通光與任務操作提示改為不可操作狀態，不把載入失敗當成光被擋住或挑戰完成。各場景獨立載入，其他學習區仍可使用；劇場沿用接近視窗才初始化的流程。
