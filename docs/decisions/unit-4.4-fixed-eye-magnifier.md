# 4.4 第四區：固定眼位探究放大鏡

2026-11-04依使用者確認的探究順序，第四區改成固定眼睛與透鏡，只逐漸向外移動圖卡。先前可移動眼睛的設計撤回；第三區仍保留移動屏幕尋找實像。

## 教學主線

開場提出「人在原地，只把圖卡往外推，什麼位置能正立地看得更大」，不先揭露F內結論。觀察表收斂為0.3F、0.9F、F、1.5F四列，全程固定同一眼位、觀看角度及追蹤上端物點。一般列保留輔助光路開關偏好。

眼位採透鏡另一側1.5F，沿用先前能完整觀看F條件的眼位，並將它固定於所有條件。模型與操作均不接受移眼；右側標示固定眼位，移除眼睛位置尺和移遠眼睛的比較。物距仍可自由跨越F至3.5F。旋轉／五倍近看僅改主相機。

同一物點的出射束由發散、發散減少、平行到會聚。F內右側與同眼位的未經透鏡原物採相同尺度比較，顯示正立與相對放大程度；恰好F時眼睛留在原位放鬆觀看，角度有限。F外仍有倒立實像；在本次固定眼位及物距範圍，眼睛位於會聚點前、會聚點上或離像過近，不能清楚對焦。不得描述成沒有成像，也不引導學生移眼追像。

虛像在空間中的位置不是眼睛的目的地。透明虛像、反向延長線與屏幕比較移入主表後的「進一步探索」，預設不在主畫面疊加虛像。開啟後仍保持眼位及右側像素不變，並說明不用走到虛像的位置。

## 光路遮擋

移除第四區會聚點上的實像浮動標籤，距離放在圖下狀態。兩區其他影像標籤依目前相機投影，避開代表光路、入眼光及反向延長線；也避開虛像圖案。窄畫面或放大後沒有空位時隱藏浮動標籤，真實距離仍保留在圖下說明，不拿文字蓋住光線。
