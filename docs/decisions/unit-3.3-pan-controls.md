# 3.3 第四區移除重設並突出點奏提示

2026-11-02，使用者要求移除排笛「回到起點」，並在合適位置說明點擊可吹奏。

- 移除按鈕、事件監聽與未使用的排笛重設介面；初次載入仍預設外觀及20cm管。
- 將原圖內小提示移至視角切換下方、排笛圖上方，改為「點選任一根管子，就能吹奏。」桌面與手機皆置中。
- 保留自由點奏、原管長與音高、內外觀切換、等待下載時取消、離開停止及失敗重試。
- 更新主程式、排笛模組與樣式查詢版本，避免舊快取程式綁定已移除按鈕。

既有排笛專項與整頁檢查共24項本機通過。檢查不再操作已刪除的控制；改以重新載入建立專項初始情境，整頁直接點選短管比較音高。七種寬度與兩視角核對提示位置、控制列置中、無溢出及原點奏目標對齊。科學模型、錄音與素材未變更，未新增完整單元外部驗收。
