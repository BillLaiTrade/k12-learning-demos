# 第一區：沿完整反射光路連續前進

日期：2026-11-05。使用者指出播放只像兩段出現，要求參考後續光路呈現。

參考4.2潛望鏡把多段反射光路繪為完整折線，以及4.3光束實驗用移動前端呈現行進的方式。原第一區的線條伸展與500毫秒接觸停頓拆開了行進感；減少動態時更成為整條線的階段切換。

改為每道光一條`起點→入射點→反射終點`折線，三層短尾跡沿整條路徑移動，接觸前後沿路徑速度相同，轉向時同一段亮光跨越兩側。沒有接觸暫停或固定閃光；底下的完整方向圖淡化保留作為路徑參考。六道光同步，光學幾何不變。

以18個瀏覽器原生stroke-dashoffset效果播放，不逐幀重建SVG、不使用濾鏡。一般單次3400毫秒，減少動態單次4200毫秒且光暈較淡；只有手動啟動，兩種設定都能看見完整行進。Esc、偏好變更與離頁可結束播放；重播清除舊效果。移除三階段提示，保留原版面、材質圖、光學模型及主實驗。

檢查實際SVG像素和原生時間軸，在反射前／跨越表面／反射後取樣。以實際dash位置證明轉向前後速度相同、同一亮光同時跨在兩側；重播只保留18個有效路徑效果，實際播放沒有幾何／樣式逐幀DOM改寫。其他回歸沿用第一區專項。
