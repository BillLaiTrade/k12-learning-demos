# 2.3 材料桌留白與三排配置

2026-11-04（臺北時間）。使用者指出十件物品放回材料桌後仍擁擠，本輪調整辨識材料的排列與留白。

材料共用同一張桌面，依四個瓶類、兩組較寬器材（水槽與雙孔塞／導管）、四件固體與工具分成三排。水槽與導管各跨兩欄，名稱統一放在各物品下方；手機保留完整點選範圍及名稱間距。沒有新增下方補充列。

材料圖採原有素材的獨立裁切，玻璃、塞子與橡皮管完整保留，避免取到鄰近器材。材料辨識的畫面與操作用的共用幾何分開；實驗的管長、反應、收集、播放時間及操作步驟維持。無JavaScript也呈現同一個材料桌。

導管介紹改用材料桌同一組完整器材圖，給予相符的檢視範圍；複製時重命名遮罩與裁切ID，確保介紹視窗不受隱藏面板影響。

必要驗證：七種畫面寬度、十個名稱無重疊與正確介紹、物品本體點選、介紹預覽實際繪出、手機原生觸控、無JavaScript、原有實驗畫面與播放器字幕；發布後核對原生Pages及公開檔案。
