# 4.5 第五區：精簡為三組獨立下拉選單

日期：2026-11-03。使用者檢視直向按鈕後指出同一視窗容不下操作元件，明確要求改回下拉選單。本決策取代前輪「不採下拉、選項直向排列」的介面規格，三組獨立條件與光學模型保持。

光源顏色、透明色片、紙張顏色各使用有明確label的原生select，三個區塊並排；選項數量分別為4／4／5，預設白光＋綠色色片＋白紙。改變一組只更新該組，保留另外兩組。全名顯示，不新增確認按鈕；支援原生鍵盤、手機選單及焦點提示，最小操作高度44px。載入前或停用JavaScript時沿用fieldset停用狀態。

只改第五區HTML、控制事件、選單樣式與快取版本。不改暗色實驗台、紙張照明、透射／反射計算、預覽及角色觀察；其他區與小測保持。低高度手機仍可自然捲動，不承諾整卡於所有視窗完全放下。

沿用第五六區瀏覽器專項，改以實際select change檢查80種組合、獨立狀態、三段色條／像素／實際3D材質與燈光；八種視窗確認三選單並排、控制區低於110px、無溢出及44px高度，另驗證原生鍵盤、手機情境、拖曳取消及第六區備援。整課測試同步選擇器以供後續執行。實際執行結果及部署證據保存在主專案review。
