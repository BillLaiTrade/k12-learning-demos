# 第四區改用授權排管實錄

2026-10-31（臺北）。使用者確認目前合成音不是真實排笛錄音後，明確要求採用有授權錄音、製作各管聲音。本輪以mrshoes的“panflute scale octave and a half”（Freesound 278175、CC BY 4.0）替換所有六管振盪器合成音。

## 來源與授權

來源：https://freesound.org/people/mrshoes/sounds/278175/ 。公開HQ MP3：https://cdn.freesound.org/previews/278/278175_5038472-hq.mp3 。作品頁明示CC BY 4.0，允許改作與再發布，來源說明與授權連結存source/source-evidence.json，未修改原MP3存source/mrshoes-278175-hq.mp3。作者描述以一端封閉的3/4英吋PVC管、水位改變音階錄製；不是竹排笛實錄，頁面及素材授權檔均明示來源，沒有聲稱為六根畫面竹管各別現場錄音。

各管由實錄擷取單音、Rubber Band保時長調音至理想頻率、混成單聲道、20ms淡入／140ms淡出及音量調整，無振盪器或循環拼接。每檔1.8秒、22050Hz單聲道16bit WAV。各檔目標、原音段落、調音比例、測得頻率、RMS、峰值與SHA-256見assets/pan-audio/recordings.json；測得頻率誤差小於0.1Hz，初段RMS約0.33～0.38、峰值約0.63～0.76，未削波。處理程式scripts/prepare-pan-recordings.py及原檔可重製六檔。

衍生六檔同採CC BY 4.0；頁面可見作者、來源、授權連結與「剪輯調音」告知，LICENSE.md與manifest隨檔發布，不暗示作者背書。實錄與理想化動畫分開：基頻維持原教學目標，實錄含吹氣質感與自然細微變化；畫面位移幅度改由播放緩衝區20ms區間RMS驅動，保留共同100倍放慢與封底節點。

## 播放與驗證

每管只在點擊後載入本地錄音，解碼後依AudioContext快取。載入後再次核對播放請求與分頁狀態，換管、重設、離場取消舊請求；下載失敗移除快取以供重試。沒有以舊合成音默默替代。其他區聲音維持。

本機整合54項及模型／實際WAV3項，共57項通過（含外層），0失敗、0略過。音高測試改用實際Buffer自相關估測，避免吹氣雜音令零交越計數誤判。檢查PCM音量／時長／餘裕／雜湊、六管音高、快速重播、自然結束與RMS連動、兩視角／七種寬度、手機觸控；新增真正延遲下載後重設不會起音、下載503可重試。前三區與小測回歸通過。已檢視署名後桌機畫面，公開確認另記規劃repo。仍為第四階段，非教材外部驗收。
