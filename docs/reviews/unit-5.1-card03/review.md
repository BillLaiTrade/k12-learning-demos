## 示意圖與實作對照

| 核可項目 | 實作與檢查 |
| --- | --- |
| 前後人物對話 | 沿用核可圖四句對話與位置；頭像改用專案既有 `dialogue-character-avatars.png`，與第二區相同，未使用示意圖生成的角色。 |
| 溫度計左、讀數與操作右 | 桌機使用兩欄，左側玻璃雙刻度溫度計，右側標題、同步讀數、代入公式、滑桿及四個重要溫度按鈕；配色與圓角沿用核可圖。手機改為溫度計在上、操作在下。 |
| 一根液柱、兩套刻度 | 攝氏 0–100°C 共 101 條每度刻線；華氏 32–212°F 共 181 條每度刻線。每 1°C 的間距為每 1°F 的 1.8 倍，分別生成，未複製刻線。數字與刻線均位於玻璃管身。 |
| 重要溫度對齊 | 0°C／32°F 與 100°C／212°F 分別同高，25°C／77°F 與 37°C／98.6°F 的液面依同一攝氏狀態換算。華氏刻度依自身每 20°F 標數及兩端參考點，修正示意圖僅列攝氏對應華氏數字的形式。 |
| 正確液面 | 凹液面中央最低點與水平線同高。25°C 位於冰點至沸點全距的 25%，未使用生成圖近似的液面高度。玻璃、刻線、液柱為原生 SVG，可精確定位。 |
| 換算與滑桿 | 初始 25°C＝77°F，代入 °F＝°C × 9/5＋32。滑桿每步 0.5°C；更新液面、水平線、兩種讀數、公式、滑桿填色與按鈕選取。 |
| 四個捷徑 | 冰點 0°C、室內示例 25°C、體溫參考 37°C、沸點 100°C。選取樣式、滑桿與換算一致，自由拖曳離開預設值時解除選取。純水參考點註明標準大氣壓。 |
| 精修 | 第一輪對照後修正數字描邊偏粗、將原生深色滑桿換成核可圖的綠色填色與白邊控制點，再放大刻字以改善窄視窗閱讀。 |
