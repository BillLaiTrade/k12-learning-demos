# 5.3 熱量與比熱：第一版教學頁

依使用者指示開始製作 5.3，沿用 `units/5/curriculum.html` 已歸納的 Bb-Ⅳ-2、Bb-Ⅳ-3 範圍。這是供逐區檢視的可操作初稿，尚未經使用者逐區核可。

## 教學內容

1. 熱量與溫度不同；量取 100 g 水，用燒杯、加熱攪拌器與數位溫度探針觀察 20→21°C。完成後先介紹 1 g 水升高 1°C 約需 1 cal，再比較100g水約需100cal；固定同一溫升，水量與熱量同步×100。kcal、J 保留可展開補充。
2. 固定 100 g 水、初溫 20°C，依序觀察累計吸熱500／1,000／2,000cal，各段自動停止與記錄，水溫25／30／40°C、溫升5／10／20°C；同步繪製吸熱量—溫升圖，完成後歸納正比關係。
3. 固定水的種類、初溫20°C、各吸收1,000cal，A杯固定100g，B杯預設200g，可自由輸入100～350g（含小數），水位由程式按質量呈現；溫升長條共用0～10°C刻度，完成才自動記錄與歸納。
4. 固定各 100 g、初溫 20°C、各吸收 500 cal，比較水與鋁／鐵／銅。先以水的近似關係預測，再用水與固體金屬實驗檢驗；兩份完成後引入比熱及 Q＝mcΔT。
5. 三個生活情境：500g水袋50→40°C的放熱觀察、海陸白天／夜晚定性比較、可點鍋身／鍋底的比熱與導熱辨別。水袋觀察完成才顯示計算與同條件水／鋁比較。
6. 結尾小測：簡單水升溫、質量倍數、由升溫判斷比熱、選擇公平比較條件。

## 模型與科學限制

- 使用 cal、g、°C；水比熱近似 1 cal/(g·°C)，鋁 0.22、鐵 0.11、銅 0.093。常溫附近參考值，並非任意溫度下的精確常數。
- 教學區間無相變；所有樣品初溫固定 20°C。最高為銅吸收 500 cal 後約 73.8°C，未到水沸騰。
- 第四區計入的是「樣品實際吸收熱量」，忽略容器吸熱與環境散熱，固體視為均勻溫度。相同動畫時間並不代表真實功率或加熱效率相同；頁面明確說明此假設。第一至第三區採包含容器與散熱的集中熱容量模型。
- 舊SVG實驗控制器保留但第二至第四區不初始化；新版第四區採寫實器材背景，固體金屬、接觸探針末端、讀值與燈號由程式疊層。
- 第二區曲線橫軸為吸收熱量，非時間。第四區以共用刻度溫升長條比較；換物質重設兩份讀值並收起歸納，不保留跨材質紀錄。
- 生活應用交代質量、熱量及其他熱傳條件；不把比熱等同導熱能力，不宣稱只靠比熱就可預測真實升降溫速度。

### 第一區 100 g 水模型（2026-11-05）

水的熱容量為 100×4.184 J/°C，容器熱容量設定 42 J/°C；水與容器視為同溫。有效供熱 20 W，向 20°C 環境散熱係數 0.5 W/°C。以 C dT/dt＝P－k(T－20) 更新同一溫度，將總供熱分到水、容器及散熱；水到 21°C 吸熱 418.4 J＝100 cal。供熱總量較大，沒有把它直接當成水吸熱。上述是教學設定，不宣稱圖片中的真實器材具備這些校正參數。

模型約23.3秒到21°C，動畫加速4倍約5.8秒，未把加速當成真實功率。完成後保留讀值，未繼續模擬冷卻、探針遲滯與停熱餘熱。熱量是依模型換算，溫度計只提供水溫；頁面有可見說明及收合條件。第二至第五區及小測保持，第一區僅以100g回到1g的單位參照，不提前展開比熱計算教學。
