# 4.2 圖像與動畫素材

## 蒸發結晶連續動畫（目前使用）

- 四個步驟共用連續變化的場景，點選步驟後連續播放至結束，不再切換四張圖片。
- `evaporation-animation.js` 使用專案現有 Three.js 與 RoomEnvironment，將既有 `evaporation-dish.webp` 作為固定器材照片。水是隨進度連續變形的折射幾何體；照片參與透射背景，器材、容器及鏡頭不隨階段變形。
- 受熱過程細分為升溫、細泡上升、持續沸騰、開始析晶、水層變淺及乾燥六個觀察階段。反光邊緣的氣泡在水中上升並消失於水面，稠密水面網格隨沸騰變形，氣泡破裂處會產生擴散的擾動。
- 晶體從第三階段（4.5 秒）開始，先在邊緣成核，再逐漸增多、長大；接近乾燥時，氣泡隨水量減少而消失。小晶體採用漸進尺寸曲線，避免都留到末段才突然出現。
- 沸騰與蒸發分開說明：本例加熱至沸騰，但水在未沸騰時也會蒸發。水蒸氣本身不可見，不繪製煙霧或蒸氣線條。
- `evaporation-state.js` 定義 0–1 的連續進度及四個片段。第一步 1.5 秒，後三步各 3 秒，合計 10.5 秒：0–1.5 秒觀察升溫、1.5–4.5 秒沸騰蒸發、4.5–7.5 秒晶體析出、7.5–10.5 秒保留乾燥鹽晶體。
- 示意秒數並非真實蒸發時間；加熱、水量及成核排程為定性教學示意，沒有提供可量測的真實溫度、水量、晶體質量或生長速率。
- 依使用者最新要求，移除進度條、百分比及上一步／播放／重播／下一步控制列。點選上方步驟立即從該步驟起點連續播放至第四步結束；點擊圖片則從目前步驟重新播放至結束。選取標示、觀察文字及圖片按鈕標籤隨進度自動推進，僅在整段結束時停止。
- 圖片使用有標籤的原生按鈕，支援 Enter、Space 與觸控。切換步驟或重複點擊時取消舊播放；頁面隱藏時暫停。動畫載入完成前與 WebGL 失敗時停用這五個按鈕。
- WebGL 無法啟動時提供明確訊息並停用動畫控制，其他教學區塊仍可使用。
- 操作檢查：`CHROMIUM_PATH=/usr/bin/chromium node --test tests/unit-4.2.test.cjs`。

## 濾紙層析互動實驗（目前使用）

- `chromatography-workbench.webp` 是依使用者核可的完整頁面示意圖製作的空實驗桌背景；2026-10-27 以影像生成工具由核可場景移除可移動濾紙，保留托盤、兩張備用濾紙、燒杯、透明溶劑、鉛筆及空夾具。這是生成教學素材，不是實驗實錄。
- `chromatography.js` 以 Canvas 2D 在同一背景上連續繪製獨立濾紙、固定紙纖維、潤濕區、原墨點及暈染色帶。未新增套件或外部服務；固定器材不隨動畫變形。
- `chromatography-state.js` 為定性示意模型。綠色樣本示意藍／黃色帶，深色樣本示意藍／紫／粉色帶；顏色、數量與相對移動位置是教學參數，未宣稱為某品牌筆的實測成分、色素鑑定或精確保留數據。不同樣本結果不必相同；未分出多條色帶也不能證明純物質。
- 溶劑由濾紙下端向上潤濕；到達鉛筆基線上的墨點後色素才開始展開，各色帶及暈染上緣保持在前緣下方。容器液面固定，潤濕區使用中性灰米色，不將透明溶劑畫成綠色。完整展開示意為 16 秒，不代表真實實驗時間。
- 2026-10-28 依使用者回饋放慢並重作暈染：0–4 秒前緣逐漸到達墨點，約 4–9 秒先形成混合色的向上羽狀暈染，後段逐漸解析為色帶；三段觀察期共用同一個連續場景，不新增步驟或提示。
- 2026-10-28 依使用者最新要求縮為 16 秒，將前述節奏等比例壓縮：前緣約 2.67 秒到達墨點、約 2.67–6 秒呈現混合暈染，後段持續分色至 16 秒；原點殘色與拖尾曲線保留。
- 紙纖維色痕以固定紋理的有機顏料筆觸呈現，保留淡淡的原點殘色、混合色暈染與各色拖尾；本例的原點濃度由 1 逐漸降至 0.14，不保留完整原墨滴。殘色與拖尾是本示意樣本的選定特徵，不表示所有真實墨水都必然留下相同殘色；不是物質量或吸光值。
- 點上方墨水按鈕直接以正確位置開始對應樣本的實驗；切換或重點同一樣本會換新濾紙並取消舊播放。點濾紙再點燒杯，或拖曳濾紙放入，使用目前選取樣本。
- 手動放置分三種：底端未碰到液面則不展開；底端接觸溶劑且墨點高於液面才進行正常分離；墨點浸入溶劑時濾紙滑入杯中，墨水散入溶劑而不顯示分離色帶。放到杯外或取消拖曳會返回托盤。
- 正常放置後夾具固定濾紙；不允許直接拖動固定濾紙。點紙或杯內可暫停／繼續，點夾具或右下重做圖示取新濾紙重新操作。頁面隱藏時暫停正常分離。
- 原生按鈕支援鍵盤及觸控；點放可作為拖曳替代，Escape 可取消選取。操作狀態僅供螢幕閱讀器讀取，畫面不增加步驟列、操作文字或側邊提示。載入中停用控制，背景載入失敗時顯示錯誤並保持其他區塊可用。
- 操作與科學關係參考：[Scientific American／Science Buddies, Chromatography: Be a Color Detective](https://www.scientificamerican.com/article/chromatography-be-a-color-detective/)；文中示範非永久性水性筆、紙條、鉛筆與夾具，並明確要求水位低於墨線。本模擬不是該文實驗數據的重製。
- 檢查：`node --test tests/unit-4.2-chromatography.test.cjs tests/unit-4.2.test.cjs`。

## 蒸發結晶四步寫實示意（歷史素材）

- 檔案：`evaporation-realistic-stages.png`，1536 × 1024 像素，RGBA。
- 製作：2026-10-27，依使用者要求改善四步水體的真實感，以既有 `evaporation-dish.webp` 為器材參照，使用影像生成工具製作。這是教學示意，並非真實實驗的攝影紀錄。
- 排列：2 × 2 等分圖集，左上為透明鹽水、右上為水位降低、左下為淺水層開始析鹽、右下為乾燥後留下鹽晶體。
- 舊版曾以四個背景圖層選取對應區域並淡入切換；目前的連續動畫不再載入這份圖集，保留以追溯先前的寫實素材製作。
- 教學界線：水蒸氣不可見；最初溶解的鹽沒有可見顆粒，末步沒有液層。圖像不提供可讀取的水量、晶體質量或真實時間資料。

## 第五區塊：直接稱量與濃度

- `concentration-workbench.webp`：2026-10-28 依核可示意圖，以影像生成工具保留原攝影風格器材位置，移除可動糖匙、水壺、糖量及水量，作為固定底圖。`concentration-tools.webp` 是糖匙與空玻璃水壺的透明圖集。這是教學模擬素材，非實驗攝影紀錄。
- `concentration-renderer.js` 以 Canvas 2D 繪製糖量、水位、持續水流、糖粒與獨立器材；背景、秤及容器維持固定。水壺內的水在世界座標保持水平，不隨器材一起旋轉。
- `concentration-state.js` 計算淨質量、溶液總質量、重量百分濃度及質量比 ppm。糖 0–20 克、水 50–150 克；維持可完全溶解的配方範圍，不增加飽和或稀釋計算。份量卡 0–10 毫克，溶液總質量固定 1,000,000 毫克，溶劑補足餘量。
- `concentration.js` 管理直接操作、按住／放手、拖曳與取消、點秤面輸入、原生鍵盤／觸控、重設與背景停止；場景載入失敗時停用上方操作並顯示錯誤，ppm 仍可使用。沒有新增外部服務或套件。
- 第五區以自由配製與即時計算取代原比較卡、下拉濃度題及拉桿；ppm 份量卡是質量份額模型，不描繪真實微粒。正式人物使用共用素材，不使用生成圖中的替代人物。
- 科學依據、功能與示意圖對照、檢查結果與畫面見 [第五區核對紀錄](../../../../../docs/reviews/unit-4.2-card05/review.md)。
