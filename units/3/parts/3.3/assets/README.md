- 其餘區`model.mjs`的固定泛音係數用於呈現不同波形；不宣稱精確重建特定樂器。音訊為1.6秒，20ms淡入、120ms淡出，依RMS作近似大小聲匹配；不是聲級校準，也不保證不同設備與頻率下主觀響度相等。
- 現行木吉他畫面弦振動以基本頻率的1/100呈現；管內空氣位移以1/100放慢，使用兩端開口管基本模式的往返位移，聲音保持原音高。
- 初版60cm／220Hz琴弦模型由下方木吉他65cm／110Hz模型取代；model.mjs的stringFrequency保留一般關係回歸範例，不再控制第三區。管的模型：同類兩端開口管、空氣聲速343m/s，基本頻率依 `343/(2L)` 計算；忽略端點修正，學生不需運算這些公式。
- 相對振幅、圖形振幅、系統音量及真實耳邊聲級必須分開理解；第七區dBA資料不是網頁聲音輸出讀值。第六區依後續核可改為20～20000Hz固定低增益的持續純音探索，不播放範圍外的次聲／超聲，也不作聽力診斷；第七區仍不重現高聲級情境。

- [教育部自然科學課綱](https://edu.law.moe.gov.tw/LawContent.aspx?id=GL001823)，Ka-Ⅳ-5與附錄。

- [OpenStax 17.3 Sound Intensity and Sound Level](https://openstax.org/books/college-physics-2e/pages/17-3-sound-intensity-and-sound-level)：聲級、參考基準與分貝非線性關係。
- [NIDCD Noise-Induced Hearing Loss](https://www.nidcd.nih.gov/health/noise-induced-hearing-loss)：生活情境的平均聲級參考，一般交談60～70dBA、電影院74～104dBA、音樂會94～110dBA。本頁僅引用資料，沒有新增噪音／聽力保護課程。

## 2026-10-31第六區頻率探索台（現行）

使用者核可持續播放／暫停、彩色可點拖頻率帶與手動記錄兩端的示意圖。hearing-experiment.mjs管理20～20000Hz對數位置、1000Hz預設、滑鼠／pointer capture觸控／方向鍵與Home、End／PageUp、PageDown；顏色是操作提示，不是光的頻譜或多頻聲音分析。縮圖引用既有pitch-speaker.png與pitch-room-background.png，沒有生成新圖片。兩端初始空白、按各自按鈕記錄目前頻率，可改寫、保留至本頁重設或重新載入；反向區間會提示並保留原紀錄。紀錄僅在本頁記憶體，不傳送或保存到外部。

hearing-audio.mjs使用Web Audio的sine OscillatorNode、共同固定增益0.06、40ms起音、35ms平順調頻、25ms收音及30ms後停止；暫停後從目前頻率建立新純音，播放中調頻維持同一振盪器，不靠反覆短音重播。與其他區共用AudioContext及唯一活動來源；離開／切換區塊／隱藏／重設停止，等待resume也能取消，失敗可重試。來源不支援超過Nyquist的目標時顯示裝置限制，不偷偷改顯示頻率或假裝已輸出。

固定數位增益不是聲壓或主觀響度校準，高頻接近Nyquist時瀏覽器自身處理也可能降低訊號。沒有追著聽不到而自動加大音量。頁面保留裝置／音量／環境限制、非聽力檢查及先調小音量提示；動物上限資料、次聲／超聲界線收在下方補充。觸控按鈕於pointerup處理並略過相容click，避免拖動後首次點擊漏掉或一次起音兩次；鍵盤仍使用原生click。

此節取代初版第六區僅資料展示、不試聽的規格；使用者已核可本次活動，但不因此新增醫療聽力診斷、極端頻率播放或噪音／聽力保護章節。
