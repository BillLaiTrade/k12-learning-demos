# 第四區塊圖形與保留素材

- 現行動畫由正式課程 `units/3/parts/3.2/assets/sound-speed-rendering.mjs` 以原生 SVG 繪製空氣開放區、水槽水體及鋼材剖面；內部分子／原子、彈性連結及表面取樣位移由同一波動模型控制。水的液面是靜態邊界，聲音傳播以水中粒子局部往返呈現。
- 微觀球棒、配色、尺度與金屬連結為放大示意；水分子圖形夾角 104.5°，不代表肉眼可以看到分子。
- `material-specimens.png` 為前輪過渡版本保留的 1024×1536 影像生成原圖，未修改像素。現行頁面不引用、不下載，也不顯示為左側照片。原三聯區域為空容器、水與鋼；歷史近照截圖保留在 review。
- 人物沿用 `shared-assets/characters/dialogue-character-avatars.png` 正式角色。

正式課程與獨立入口共用 `assets/sound-speed*` 的模型、控制、材質與區塊樣式。此目錄僅保留前輪相片來源紀錄。

聲源採敲擊音叉：敲槌退開後只讓外形固定的叉臂快速反向微移，叉臂路徑不變形，柄與基座固定。水中叉臂浸入水體，鋼材由右叉臂經薄接觸層連到端面，左叉臂自由；圖形為耦合放大示意，音叉外觀與微觀粒子追蹤節奏分別為示意，均不代表音高或改變傳播計時。
