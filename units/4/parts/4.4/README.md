## 實作

- `index.html`、`lesson.css`：沿用2.2的頁面殼層、人物及標頭，導覽與可見標題一致。`#s1`–`#s10`及`#unit-quiz`保留為編號入口。
- `parallel-optics.mjs`：空氣→玻璃→空氣的兩球面折射；凸／凹厚薄輪廓、光路及焦點使用同一組幾何。
- `parallel-lab.mjs`、`parallel-lab.css`：第二、第五區完整側視圖及同圖近看，沒有固定600px的手機水平捲動；光路按鈕位於圖內，凹鏡延長線預設關閉。這一輪未把兩區改成3D模型。
- `lesson.mjs`、`optics.mjs`：既有理想薄透鏡、眼睛與兩段鏡片、顯微鏡計算。對焦與物距共用狀態；切換眼模型先取下舊鏡片，正常成像不需矯正。`data-lab`與`lab4/5/6/7/8`為沿用的內部模型識別，不等於目前可見區號；勿依內部ID推算小測連結。
- 第一區`pinhole-3d.mjs/css`、`pinhole-optics.mjs`及第一區HTML保持原樣，直接引用4.1既有Three.js，沒有新增套件。仍可旋轉／縮放，屏幕正面與孔口近看均觀察同一器材。
- 封面及人物沿用既有素材；不新增副本或外部服務。
