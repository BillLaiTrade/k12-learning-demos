# 單元 2.2：共用調查筆記本

依使用者核可方向，所有取樣共用一組手動填寫的質量與計算紀錄。實驗桌一次只呈現目前這一份樣本，不顯示 A、B 等取樣切換。點「＋ 再取一份」直接取代桌上的舊樣本，從原樣本狀態重新操作，筆記本答案保持不變。先前的實際稱量仍保留供核對補量資料。

依使用者後續指示，移除來源選單，學生只需自行填寫數字。不自動填入任何質量或計算答案。

核對以整次調查中實際完成的稱量為依據，允許濾液與晶體來自不同取樣，無須學生指定來源。本活動每份樣本均為同樣份量與組成的均勻取樣，因此能用新取樣補做漏掉的稱量。仍拒絕未稱量、讀值不符、過濾前液體冒充濾液、含泥沙的乾燥殘渣，以及錯誤代入和濃度答案。保留一次指出一項問題和成功回饋完整帶入畫面。

移除筆記本標題旁的單一取樣標籤，各筆質量僅保留數字欄位。重設清除全部取樣、共用紀錄；取消重設則全部保留。
