# 第九區：共同框住中間像

日期：2026-11-06

採用核可的實線／虛線交疊框線，移除示意圖上「中間像，同時在兩個範圍內」及下方「兩個框共同包含」兩句說明。關係線維持單一橫列與唯一中間像：實線框住原物、物鏡、中間像，虛線框住中間像、目鏡、眼睛，兩框上下錯開。共用區域以淡紋理輔助辨識，不增加第三個框。

區段名稱保留原生近看操作，沒有節點小框或獨立的按鈕列。近看時兩個完整框線都保留，選取狀態以名稱底線、框線粗細及目前範圍表示；可返回完整成像，原有光路偏好及下方卡片連動保留。

## 檢查

- 顯微鏡互動8項通過，包含五個節點的實際邊界：左三項位於實線框內、右三項位於虛線框內，唯一中間像同時位於兩框內；兩框的上下位置確實錯開，線型分別是實線與虛線。
- 1440×900、1366×768、1024×768、760×900、390×844、320×844六種視窗，各檢查全貌與兩個近看範圍，共18個畫面通過。無文字裁切、水平溢出、標籤越界、字形縮放或圖內標籤互相遮擋；控制與比較圖維持同一視窗。
- 人工檢視桌面與320px手機的關係圖，確認兩個完整框線及共同區域可辨認，上下兩句說明不存在。
- 互動檢查亦涵蓋返回焦點、光路與物點、同一中間像延續、鍵盤及SVG備用畫面。瀏覽器無頁面錯誤。
