# 第六區眼睛與視野窗本機檢查

2026-11-04。依[核可精修圖](approved-reference.png)實作眼睛、金屬導軌、淡金托框與兩條視角連線。右圖改名「這隻眼睛看到的畫面」，標題共用同一眼睛圖稿，底部常駐對應說明並保留物理狀態說明。

## 已執行

- [初輪21項](local-initial-tests.tap)全部通過：第六區15項、格式5項及整課1項（含外層）。涵蓋持續加放水、途中反向、手動接管、離屏續播、原生觸控、光路隱藏、減少動態、材質重試、無JS及小測。
- 隨後縮薄托框並微調導軌標籤，以[4項補驗](local-final-layout.tap)確認起始畫面、焦點／連線及九尺寸；這些補驗全過，其他情境未再重跑。
- [最終九尺寸量測](measurements.json)含近／中／遠共27組：兩線起點落在眼睛框，終點貼合觀看窗；曲線不越界、不蓋文字，眼睛框不壓字。連線無箭頭且不攔截事件，隱藏實際光路仍保留連結。
- 鍵盤Home／End及拖曳時線的起點跟隨眼睛、終點留在視野框；焦點時同步加強。兩個主要控制點至少44px，眼睛與視野有ARIA對應，連線及標題小圖示不增加焦點。
- 桌機連線沿眼睛高度空白處到兩圖留白再展開；手機沿卡片右側外緣接到下方視野窗，避開圖面／標籤。
- [11筆保留核對](preservation.json)：第1–5及第7區HTML、原課程／光學控制、固定鏡頭模型、右側繪圖及照片保持。沒有把示意圖當作操作背景，也沒有改動瞳孔／相機原點、折射率或槽壁遮擋。

最終畫面以[桌機](desktop-eye-view.png)、[390px](390-eye-view.png)、[320px](320-eye-view.png)及最終量測為準。目錄內其他水位／遮擋操作畫面屬初輪檢查；局部框線／標籤微調不改其功能結果。

向量圖在本地depth-eye-art.mjs中，共用於主眼睛與標題。實作以留白路徑及窄螢幕外緣連線維持可讀性，與核可圖的連結概念相同。公開結果另存規劃庫，維持第四階段，待使用者檢視。
