# 第六區水的三態恢復橫向並排（2026-10-30）

使用者指出統一 1.1 版型後，第六區冰、水、水蒸氣圖片變成直排，核可恢復三張橫向並排。原因是既有容器寬度 620px 以下切換單欄的規則，被縮窄的內容欄觸發。

本次移除這一組的單欄容器查詢覆寫，沿用三等寬欄位、正方形圖片及原有間距；保留整體背景、版心、卡片外框、圖片、對話、文案、放大鏡大小與互動腳本。未套用先前尚未核可的第六至第七區銜接提案。

1440／1280／1024px 本機 Chromium 局部檢查通過：三張圖片同列、等寬、由左至右排列且位於內容卡內，圖片載入正常；三個放大鏡均可用方向鍵及滑鼠拖曳移動，粒子模型存在，無頁面橫向溢出或 JavaScript pageerror，背景仍為統一後的 `#f4f7f1`。結果見 `check.log`，已目視桌機及筆電畫面 `desktop.png`、`laptop.png`。

來源核對 `</style>` 後的課文 HTML 及互動腳本逐字保留，差異及空白檢查通過。本次未重跑全單元功能測試，維持第 4 階段製作／精修，尚未完成全單元檢查、外部驗收或最終核可。
