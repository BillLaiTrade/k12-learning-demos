# 海底地形查核與模型取捨

查核：2026-10-31（臺北時間）。使用者要求更接近常見海底形態，納入海溝與不同深度，而非規律起伏山丘。

## 已讀取的資料

1. Smithsonian Ocean，[The Deep Sea](https://ocean.si.edu/ecosystems/deep-sea/deep-sea)，本文Seafloor Habitats、Abyssal Plain及Hadalpelagic段落。大陸棚是沿岸、較淺的陸地延伸，大陸坡往深海下降；深海平原較平坦，本文列約3,000–6,000m。海溝屬極深區域，hadal範圍由約6,000m到近11,000m。水深約200m後陽光大幅減弱，約1,000m已無陽光。
2. NOAA Ocean Exploration，[What is a seamount?](https://oceanexplorer.noaa.gov/ocean-fact/seamounts/)，從舊公開URL導向此現行頁並確認內容。海山是從海床隆起的水下山體，通常有較陡側坡，常源自火山；文中以相對周圍海床至少約1,000m的起伏作分類條件，也說明可能有平頂等形態。

部分舊NOAA海溝／深海平原URL回404；舊大陸棚URL雖回200但正文是Page Not Found，均未當作已查證來源。地形查核以成功讀取的上述兩頁為準。

## 本次模型

- 多地形的教學組合剖面，並非某個真實海域的測量線，也不暗示所有海域都具備這些地形。
- 淺棚約150–195m，經大陸坡下降到約4,500m的較寬平原；孤立海山峰頂3,000m，相對平原高1,500m。海溝最深8,250m，兩側較陡，右側接另一側坡面。
- 數值是便於操作的示意條件，不是來源中的實測資料，也不是全部海溝或平原的固定深度。橫向距離壓縮；不教真實坡角或板塊機制。
- 固定節點以連續平滑插值銜接，並保留小尺度固定細節；深度、海床輪廓、聲路、測點與表格都來自同一模型。保留原2／4／6秒代表條件，並擴展到0.2–11秒，不加速度倍率。
- 可聽聲音仍為合成提示音，聲速題給1,500m/s；深海的可見剖面屬視覺化，不冒稱陽光能照到海溝。日光束只留於上層，波紋限制在水體內，避免穿入岩層。
- 圖上與下方提供五種地形名稱／短特徵，沿用自由拖船、每次發聲才建立A/B/C…測點，沒有預設測點或強制路線。
