# 4.3 第二區：垂直入射雙槽實驗與可折疊類比

日期：2026-11-01。使用者先要求研究國外教材與實驗，檢視多版示意圖，指出光路上的圓點／間距可能誤導，改採連續光束；接著要求以「發射」呈現穿越過程，並將「為什麼變慢，卻沒有轉向？」預設收合。最後明確核可製作第二區，要求驗證操作與畫面後才交付。

## 最終設計

- 固定空氣→水、空氣→常見透明玻璃並排，寫實木桌與器材風格沿最後示意圖；介面高度、入射高度與圖面距離比例一致。
- 初始不發光；按「同時發射」才從共同時刻向下延伸連續光路。沒有移動光球、等時間位置點、間距括號、到達秒數或材料切換。
- 光束前緣跨越介面後，水中示意速度為空氣的 3/4，玻璃為 2/3，光路始終沿法線、垂直介面。使用共同示意時間，不將桌上器材的播放時間當作實際光速；只畫穿透部分。
- 可暫停／繼續；完成後原「同時發射」可重新開始。離開實驗畫面或頁籤隱藏時暫停並保留進度，需手動繼續。圖片未就緒時停用發射，失敗可重試。
- 三個步驟標示發射、跨越介面與直線通過；法線與光路重合，底部標示法線。所有文字、狀態與光束均為實際 HTML/SVG。
- 預設收合原生 details 解說；展開後觀看同一台雙輪小車沿直線跨越不同地面，兩輪同時變慢、無轉向。收合、離屏或頁籤隱藏即停止；有減少動態偏好時等待手動播放。明示「小車為類比，不代表光受到摩擦」。
- 實驗桌在窄內容欄局部橫向捲動以維持標籤可讀性，按鈕、解說與下一區連結保留在頁寬內。桌機類比圖文並排，窄欄改上下排列。
