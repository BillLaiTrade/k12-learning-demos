# 第六區：沿用反射實驗觀察光路可逆

2026-10-27，使用者核可依參照第二區實際雷射畫面生成的示意圖製作；要求沿用原做法、確認操作及畫面後公開交付。

## 實際共用的內容

`assets/laser-bench.js` 是從第二區原 `laser-reflection.js` 原樣抽出的木桌材質、照明、鏡面、雷射機構、量角器、法線與角度標記。第二區與第六區均呼叫 `createLaserBench`。第六區的 B 端為相同機構的另一個實例；兩側受光不同，金屬外殼的明暗會不同。

`assets/planar-reflection.mjs` 為兩區共用的平面鏡光路計算。反射面座標改為實際鏡面 mesh 的前表面（x=1.9325），使 M 確實落在表面；第二區其餘既有角度、拖曳、讀值、材質與版面保留。第二區原先的 90° 邊界顯示沿用舊行為；第六區只使用有正常入射的 20°–60°，並以 20°／60°限制承接的初始角度。

第六區初次互動前可承接第二區角度。開始設定或記錄後獨立操作；原區塊再改角度不會破壞第六區已記下的比較條件。

## 科學與操作

1. 設定階段：A 發光，B 位於反射光路上；支援實際拖曳 A、鍵盤及滑桿。
2. 記錄階段：鎖定角度、鏡面和 M。關閉 A，只保留灰色的第一次光路紀錄。
3. 反向階段：B 朝 M 發出另一道光，重新計算與鏡面交點及反射方向，再沿 B→M、M→A 分段顯示。灰色與藍色中心線使用同一座標；藍色是第二次描線的區別色，頁面說明兩次分別發光。
4. 完成後可重播；任意時刻重設會取消舊動畫，恢復可設定狀態。減少動態偏好直接呈現結果。切到背景會完成當次示意，避免回來時殘留半條路徑。
5. WebGL 不可用時，以同一幾何顯示 SVG 光路，仍可記錄、反射與重設。

內容核對：[OpenStax Physics 16.1 Reflection](https://openstax.org/books/physics/pages/16-1-reflection)，2026-10-27 讀取，用於入射角／反射角相對法線及反射規律的依據。可逆性以反射的法向分量反轉、切向分量保持直接驗證；不是把原路徑陣列倒序就宣稱光學驗證完成。

逐一計算 20°–60° 的 41 組光路。每組均檢查 M 位於實際反射面、入射與反射兩角相等、反向起點為 B、經過相同 M、終點回 A，誤差小於 1e-12。反向過程保留鏡面及器材位置，不把物體自動倒轉或影像倒播當成原理。
