# 5.4第一區：依核可示意圖改為分段加熱觀察

日期：2026-11-07（Asia/Taipei）。使用者指示依示意圖修改第一學習區塊；本輪不重排其餘五區或小測。

## 變更與核對

- [核可示意圖](approved-mockup.png)：上方對話、三步觀察狀態、左器材／右曲線，以及一組開始／暫停與重新觀察按鈕。
- 原先從0°C冰水到蒸乾的約32秒連播，改為融冰14秒、液態升溫18秒、部分沸騰16秒的三段加速觀察，每段自動停下；使用同一能量模型，各段動畫時間不代表真實加熱時間或固定供熱功率。
- 初始清楚標為準備觀察，不顯示已在融冰的結論；曲線只畫至已觀察的吸熱量，發現隨操作出現，重做會清空。
- 立體玻璃杯、加熱器、夾具、浸水探針、連接線與數位表由既有本地Three.js繪製；沿用4.1既有vendor，不修改該庫或新增外部服務。螢幕的可讀文字與輔助語意同步更新。
- 水沸騰時約維持100°C且水量減少；第三段觀察到20g水汽化、仍有80g液態水時停止，探針保持浸水。低於沸點時不畫沸騰氣泡，也不把白霧當水蒸氣。
- 橫軸是累計吸熱量（kJ），沸騰段由60延伸至120kJ，所有觀察仍使用相同物理尺度；沒有把分段動畫時長當作橫軸。
- WebGL不可用時使用同狀態SVG替代，控制與曲線繼續可用；無JS保留初始圖與正文、控制停用。
