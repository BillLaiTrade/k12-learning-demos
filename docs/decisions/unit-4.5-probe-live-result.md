# 4.5 自由試光即時色光結果

2026-11-05（臺北）。依核可圖，在自由試光白幕／器材下方新增「目前觀察到的色光」，以兩盞燈的色光標籤、箭頭、結果色塊及簡短說明，連結燈色與看到的結果。原桌機左右工作區及六題挑戰保持，不增加作答或數字控制。

每次原白幕完成繪製後，依同一組燈色、開關與實際光斑位置更新。開啟兩燈且有重疊時，色名沿既有RGB混光分類，結果色塊直接讀取同次白幕緩衝區的重疊像素；部分重疊的文字明確區分未重疊處。相同色光仍呈原色。完全重疊、分開、單燈與全關各自說明，關閉的光源標籤會註記關閉；全關說無色光，不把白幕底色誤稱為照明色。

位置用原白幕1000×560與半徑180的同軸比例判斷，不依快速比較按鈕推測。手動拖曳、方向鍵、開關、換色、重現本題、取消拖曳及分頁切回都同步；幾何邊緣尚無共同光斑像素時，提示邊緣接近，不捏造可見混色。結果依既有footprint與繪圖像素，沒有改光學、曝光、軟邊、紙面或相機模型。新區塊只讀狀態，與六題答案／驗證獨立。

結果以單一polite狀態區通知，重複文字不反覆寫入；舊隱藏燈具狀態保留文字但取消第二個live通知。沒有JavaScript時隱藏即時結果，保留原靜態備援。沿用原格式、圖片及依賴，載入版本probe-result-20261105；示意圖僅供設計參考，不嵌入頁面。
