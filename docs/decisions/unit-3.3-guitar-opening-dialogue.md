# 3.3 第三區從頻率進入樂器操作

2026-11-02，使用者核可在吉他操作區前安排以下對話：

- 小葵：「那演奏樂器的時候，要怎麼調整振動的頻率，奏出不同高低的音呢？」
- 阿公：「我們先用吉他試試看。改變按弦的位置，或調整琴弦的鬆緊，一次只改一個條件，看看頻率會怎麼變。」

原本`.guitar-question`會在初始化、切換模式與調整數值時被改寫。新開場問答涵蓋兩個模式，移除這項舊問句改寫，讓核可台詞固定保留；長短／鬆緊各自的控制、提示及結語仍依模式更新。音訊、琴弦幾何與模型保持，主控制器及吉他模組查詢版本同步更新以載入新內容。

沿用既有吉他專項，補驗初始化、切換長短／鬆緊、修改數值及重設後的兩段台詞與順序，以及原模式結語仍正確切換。
