# 4.3 光的折射與視深基本版

使用者於 2026-11-01 核可先完成七區基本版，再逐區優化。教學頁為 `index.html`，不新增依賴。`assets/optics.mjs` 為純幾何模型，`assets/lesson.mjs` 控制互動。

- 六個對話／互動教學區：等距光速、垂直入射、空氣射入、水／玻璃射回、反射與折射光路可逆、視深。
- 最後一區為唯一理解檢核：光束穿過四層未知透明介質，學生依光線與平行法線的夾角，將甲、乙、丙、丁的光速由快到慢排序。可拖曳、點選或鍵盤操作；先發射再確認，保留修正與自由換題，沒有累積分數。原三題選擇題已由此活動取代。
- 動畫初始待命，手動開始。第一區為 100 萬公里比較台，完成後可再按同時發光；第二區為三組連續光束，完成後可再按同時發射。兩區皆可暫停／繼續，離屏或頁面隱藏時保留進度並暫停。沒有持續空轉的動畫迴圈。
- 空氣、水與常見透明玻璃代表折射率為 1、4/3、1.5。內部用幾何光學維持方向正確，學生不必計算司乃耳定律。折射示意省略部分反射，聚焦快慢介質與偏向／偏離法線的關係。
- 第三／四區入射角皆為0–40°，以單一大場景在發射後直接顯示角度與說明；主學習區不呈現臨界角、全反射與掠射。第五區雙向返回仍維持原0–35°範圍。
- 視深採同步側面光路與第一人稱視野，固定硬幣、可調觀看位置。小瞳孔折射光的反向延長線交點為局部視位置；右側逐像素追跡同一槽體的折射與槽壁遮擋。實際硬幣不移動，不宣稱所有大角度光線聚於同一虛像。
- 共用人物頭像引用根目錄 `shared-assets/characters/`，沒有複製素材。

卡片可拖曳或點選後放入位置；左右鍵移動已放卡片，Delete／Backspace取回，Escape取消。已放卡片可互換，從卡池覆蓋時原卡返回池；拖曳外放／取消不改作答。原生觸控在pointerup處理點選並只抑制同一個相容click，避免拖曳後第一次點選丟失。發射完成前不送出；不完整、錯誤、正確、修改、重播與換題均有對應狀態，回饋在原圖及排序列出現。模型見6項單元檢查，瀏覽器專項14項（含外層），配格式與整課6項共26項。`LAYER_CAPTURE_DIR`保存圖像／九尺寸量測；公開參數沿用`LESSON_BASE_URL`／`LESSON_USE_PROXY`。見`docs/decisions/unit-4.3-layer-speed-quiz.md`及`docs/reviews/unit-4.3-layer-speed-quiz-20261104/review.md`。
