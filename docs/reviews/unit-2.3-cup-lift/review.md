# 2.3 傾斜杯上提突然回正修正（2026-10-29）

## 問題與修正

- 使用者回報杯子傾斜後向上拖，會自行翻正。原模型在深度低於11.5時強制角度歸零；控制器也在較淺位置重新禁止旋轉。
- 模型只對深度及角度各自限值，不再因深度改變而改寫角度。首次垂直入水的限制移由介面執行，完整浸入且放開後持續解鎖，直到換乾紙重做。
- 拖杯身、深度滑桿、往上提按鈕、上下方向鍵與放回水中皆保留角度；較淺處仍可拖杯口轉動。回正須由杯口旋轉、角度控制或明確回正操作決定。
- 杯口任一側露出水面即接通外界空氣，杯內水面與外側水面對齊，濕紙歷史保留。
- HTML與杯子模組相依匯入版本一併更新為 `cup-lab-3`，確保控制器與繪圖使用同一模型。
