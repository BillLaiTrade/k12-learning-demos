# 2.1 故事文案逐項精修

日期：2026-10-29（Asia/Taipei）。

使用者要求逐項討論、決定修改或保留，再依當項指示修改；完成後先供使用者檢視。

## 第一項：開場保留其他器材的探索空間

使用者核可將開場末句由「桌上的彈簧和水盤，也各自出現不同樣子的波」改成「旁邊的桌上，還準備了彈簧和水盤」。

開場先呈現阿公抖動繩子，彈簧與水盤則作為後續探索的器材，避免開場已觀察其他器材傳波，第五區又首次追問不用繩子能否傳波的時序落差。

本次只替換開場末句；其餘故事建議仍待使用者逐項決定。

## 第二項：第一區明確化動作與傳播方向

使用者核可阿公的「傳過來」改為「傳到另一端」，並要求小葵明說阿公抖動的是繩子。

- 小葵：「阿公，你剛剛抖了一下繩子，這個起伏怎麼跑到我這邊了？」
- 阿公：「繩子上的起伏沿著繩子傳到另一端；這種變化的傳遞，就叫做波。」

本項只替換第一區的兩句對話，完成後先由使用者檢視。
