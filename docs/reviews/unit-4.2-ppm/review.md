# 4.2 ppm：實物量級與比例觀察核對

## 內容

已核對質量比 ppm 的定義、兩配方的數字代入、重量百分比對照及總質量包含溶質；1 公升水僅用作大小參照。密度來源、體積計算、模型粒徑選擇、毫米座標、投影、放大尺規及限制見 [比例決策](../../decisions/unit-4.2-ppm-physical-scale.md)。沒有以生成圖中的糖堆判定實際質量，也沒有把特定晶粒顆數當成真實糖的固定標準。

## 功能與版面

點主場景兩個秤量皿、兩張配方卡可切換並放大；倍率與毫米尺規隨視野／螢幕尺寸計算。支援 Enter、Space、觸控、關閉、Escape 及共用重設。上方糖水配方不受兩種 ppm 範例切換影響。正常首頁先顯示同一比例的全景，學生點選後才展開放大。

1–4 區 HTML、第五區上方糖水實驗與重量百分濃度的 HTML 均與前版逐字相同；控制器只移除已被取代的 ppm 份量卡操作。沿用原學習卡欄位及正式人物頭像。

## 2026-10-28：器皿與糖堆質感修訂

使用者指出深色碟仍像平面色塊。主場景改用 `ppm-dish.webp` 的獨立空陶瓷碟影像，呈現厚度、弧形唇緣、釉面細節及接觸陰影；以毫米尺度映射到原本秤量皿位置，未把生成圖中的任何糖量用作質量依據。原主場景深色低細節旋轉碟面撤下，放大區維持深色陶瓷表面並增加微小表面紋理。

糖粒改成封閉、削角且不完全對稱的晶體，仍以幾何積分正規化體積。晶粒旋轉由各粒獨立選取，僅接受包含其全部頂點的安全旋轉；各軸尺度乘積為1。堆積改為錯層、單格內微擾及帶起伏的鬆散錐形，替代固定格點切出的規則半球與垂直柱列。1克／1毫克的晶粒總質量、密度與實心體積、同一毫米座標、相機及尺規倍率維持原定義；空隙不計入糖量，形狀仍是模型。

新增封閉實體、錯層位移、自然旋轉與碟內範圍檢查；既有非重疊檢查包含位置微擾的界限。執行 `node --test tests/unit-4.2-ppm.test.cjs`，本輪11項全部通過、0失敗，包含比例、實際對比像素、公式與互動、320–1440px、WebGL及新碟面素材失敗處理。幾何體積檢查保留Float32渲染誤差容許量，不當作物性資料的實測精度。已檢視實際桌面、手機與兩種放大畫面。
