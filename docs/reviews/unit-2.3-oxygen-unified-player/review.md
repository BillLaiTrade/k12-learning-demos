# 第三區方案A：單一播放鍵

2026-11-01。使用者先要求提案，再明確選擇A：只留右側一顆主播放鍵，取消本步／連播的雙模式。

- 所有步驟先預覽初始畫面，不自動播放；按主鍵從目前操作連續往後。認識材料按播放從擺好集氣位置開始，不自動輪播材料。
- 同一原生按鈕顯示播放／暫停／繼續／重新播放；圖內按鈕DOM及事件移除。舊data-continuous作相同元素的識別別名，不是第二顆按鈕或第二時鐘。
- 手動換步取消播放，等待再次按播放；暫停保留時間及字卡動畫。最後封存停止，重新播放從擺放開始。器材介紹、Escape、背景、離區及其他播放器保持暫停規則。
- 手機同一清單卡在實驗範圍內吸頂，按鈕不複製；overflow:clip避免課程卡成為隱藏捲動容器，步驟標題留出控制卡高度。離開實驗範圍便隨父層移走。清單展開可內部捲動，手機狀態說明供輔助閱讀以免控制卡過高。

本機90項全通過（材料10、器材9、操作11、連播／單鍵10、字卡10、物理8、整頁9、CO2 13、性質10；零失敗／取消／略過）。更新既有套件的選步／開始入口，不新增重複套件；涵蓋唯一按鈕、預覽不動、完整流程／700ms停留／最後停止、精確暫停續播、切步取消、器材及字卡、七寬度、鍵盤、真實觸控、手機捲動時按鈕可見、無JS及跨區／唯一小測。另以桌機與390手機實際預覽，layout.json記錄主圖、近景與註記處按鈕仍在viewport內。已目視單鍵及手機吸頂畫面。
