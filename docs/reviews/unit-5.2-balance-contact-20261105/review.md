# 5.2 鋁塊整面貼合修正

2026-11-05；基準8a3b7f62。[決策](../../decisions/unit-5.2-balance-full-contact.md)。使用者回報無法靠攏，本輪處理頂面V形空隙及貼合狀態可辨識性，不變更熱交換／碰撞模型。

- 新圖修正為頂面與正面同寬的正投影輪廓，SVG使用同寬裁切與矩形焦點範圍，實際圖像填滿顯示邊界。貼合前後取樣見[透明度對照](edge-opacity.json)：原圖上方6筆透明，新圖12筆alpha>=252。
- 回歸驗證左右任一鋁塊滑鼠拖動都可整面貼合，可見viewBox邊界誤差<0.5px，頂面與底部無透明空隙；貼合顯示明確狀態。仍待按開始才更新溫度，貼合後開始可正常傳熱，再拉開不穿越另一塊。
- 首輪新增幾何測試使用nested SVG的boundingBox，包含被裁掉的透明外緣，造成1子項／runner失敗；改為投影實際可見viewBox，保留原0.5px標準與不透明測試，未放寬物理或操作斷言。首輪輸出見[first-run.txt](first-run.txt)，[最終15項全過](final-local.txt)，涵蓋整面接觸、熱交換、手動開始、停續／重來、鍵盤／觸控及載入失敗／重試。
- [七組版面](layout-local.json)包含1440×900、1366×768、1280×720、820×900、760×900、390×844、320×568；狀態文字及控制不裁切。人工核對[整面貼合](contact.png)。
- 另外五個教學區與小測HTML逐字相同，熱交換及碰撞模型逐位元組相同。新圖為生成示意，非實驗實錄，原檔及呈現方式見素材README。
