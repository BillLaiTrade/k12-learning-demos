# 第四區依最新第三區方式更新

2026-11-01（臺北時間）。起始同步展示main `ed76c83c`、規劃main `4653d96`；第三區材料用途最新參考`301441d8`。使用者明確指示依最新第三區開始更新第四區，授權本次呈現／控制修訂。

## 實作

- 第四區改為左側大場景／右側八項單層清單，對齊第三區的標題、綠色選取狀態、單一播放鍵、左右等高與手機可收合固定控制；正常沒有舊下方介紹卡、前後步按鈕或重複的跨區下一步。
- 八項：認識材料、擺好集氣位置、加入大理石、倒入稀鹽酸、塞緊塞子與導管、先排出空氣、向上排空氣集氣、封存二氧化碳。單鍵從材料頁開始會進入擺放並連播到封存；手動選操作立即從該動作的正確前提重播，完成後700ms銜接下項，封存後停止，不自動進第五區。初始不自動播放。
- 六材料本體與名稱開同一原生dialog，只有名稱、沒有ⓘ；介紹含這是什麼／用途及材質縮圖，關閉還原焦點並保留選擇。後七項主圖及手機近景的真實器材外形可點，視窗改顯示本步作用；開啟暫停原時鐘與字卡，關閉不自動續播。
- 第四區自己的`co2-equipment.mjs`處理幾何命中及情境說明，未改第三區器材模組；共用原`oxygen-captions.mjs`的factory，為第四區建立獨立字卡實例，保留閱讀停留、淡出換字及暫停狀態。文字／按鈕仍是HTML，原六材質圖與SVG動態不新增圖片或依賴。
- 連播、暫停／繼續／重新播放、空白畫面點選、選字／拖曳防誤觸、背景／離區／Escape與`air-experiment-play`的co2身分協調沿用第三區互動語意。切操作取消舊時鐘、字卡與介紹，焦點不留在隱藏內容。
- 化學流程保持二氧化碳：先放大理石再倒稀鹽酸，接觸就開始產氣，塞好前少量氣體可散出；先瓶外排起始混合氣，直立瓶以管口靠近底部收集。相同溫壓下密度較空氣大，原有空氣向上離開。先撤管再蓋片並標示，出口暢通，沒有水槽、滿水倒置瓶、水下封口或催化劑套用。
- 模型操作分段起訖物理狀態相接；材料加入、封塞、導管位置與蓋片均來自原獨立物理模型。觀察點隨操作標示，集氣時指出瓶口的空氣離開位置。動畫時間仍只為教學示意，不代表劑量、產率或真實反應速率。
- 無JS仍能依序閱讀八項代表畫面、六份材料介紹、怎麼做／為什麼及提醒；各代表畫面依已完成操作調整，擺放時無材料、只加石塊時無酸、倒酸時塞子仍在旁。材質圖、全景與近景相同物件，無新的動畫時鐘。正常使用則精簡到目前操作及視窗，不堆疊全部說明。
