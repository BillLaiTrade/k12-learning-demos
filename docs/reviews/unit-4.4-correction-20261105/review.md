# 第八區檢視紀錄

已實際開啟 Chromium 操作與檢視截圖，採第七區同款眼球剖面、右側視網膜放大窗及整合控制列。

- 九種眼睛／鏡片組合：正常不加鏡、近視加凹透鏡、遠視加凸透鏡為清楚成像，其餘組合失焦。
- 實際檢查 Three.js 模型矩陣：戴取鏡片不改眼球、視網膜、角膜或水晶體；切模型改變眼軸，外部鏡片可見狀態正確。
- 1440、1366、1280、1024、820、760、390、320 px 的六種代表狀態均無水平捲動、標籤重疊或 SVG 超界。主圖與視網膜影像窗分離，下方控制按鈕至少 44 px 高。
- 看過桌面近視矯正及手機近視矯正、遠視未矯正截圖；修正圖卡文字靠邊與右側說明的斷行。
- 灰虛線只顯示視網膜後的假想延伸；光路的顯示與物點選擇不影響成像結果。
- 鍵盤、手機觸控、補充收合、WebGL 不可用備援均通過；沒有重複 ID、遺失資源或瀏覽器例外。

模型限度：以眼軸差異作代表，並非宣稱近視與遠視只有眼軸長短一種原因。圖卡距離與眼球不按同一比例繪製，弧形視網膜的光學計算採局部平面近似；放大窗只比較清晰程度。

第七區與整頁回歸依序執行，35 項全數通過（見 regression-tests.txt）。

公開頁面最後檢視後補上「物距省略」的斷開光路，避免壓縮物距扭曲鏡片附近的折射方向；九組操作及八種尺寸已重新通過檢查。
