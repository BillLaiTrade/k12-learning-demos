# 3.3第二區：修正主喇叭沒有振動

2026-10-30（臺北時間）。使用者指出播放時上方主喇叭完全不動。定位原因：主喇叭是靜態PNG，之前僅側面放大窗連動；原測試也只驗證放大窗，漏掉主圖。

保留原始喇叭素材與固定箱體，以SVG裁切圖層將正面紙盆與防塵帽獨立呈現，搭配柔性懸邊底色。只讓振膜以軸向位移的放大透視投影起伏，木箱、螺絲及外框不移動、不縮放；圖片檔案沒有被改動。主振膜、側面音圈／振膜、柔性懸邊及波形共用同一音訊時鐘與振動相位，放慢200倍、位移放大，音訊保持原音高。左右使用相同位移幅度，較高頻率只改振動次數。自然完成、調頻、跨區／隱藏停止均歸位，不新增背景微動。

本機整合28項通過、0失敗、0略過（含外層）。新檢查實際擷取主喇叭播放中的6幀，確認至少4張畫面像素不同、位移可見、箱體圖片的螢幕位置及尺寸完全不變；主圖與側面位移一致，停止時回原比例與位置，減少動態偏好下也有教學動作。200Hz左邊與800Hz右邊均檢查，第二區專項現為8項（含外層）；既有音訊、波形、操作與第一區回歸維持通過。

實際畫面與測試見本目錄；公開驗證另記於規劃repo。仍為第四階段，非完整教材最終驗收。
