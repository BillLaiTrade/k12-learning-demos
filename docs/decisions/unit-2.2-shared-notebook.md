# 單元 2.2：共用調查筆記本

依使用者核可方向，所有取樣共用一組手動填寫的質量與計算紀錄。選取 A、B 等容器僅切換實驗桌上的取樣，不切換筆記本答案。

三筆質量各有來源取樣。第一次填寫某筆質量時，來源預設為目前取樣；已有來源不會因切換容器或修改數值而被改寫，學生也可以用來源選單更正。不自動填入任何質量或計算答案。

核對以每筆紀錄所選來源的實際稱量為依據，允許濾液與晶體來自不同取樣。本活動每份樣本均為同樣份量與組成的均勻取樣，因此能用新取樣補做漏掉的稱量。仍拒絕未稱量、來源不符、過濾前液體冒充濾液、含泥沙的乾燥殘渣，以及錯誤代入和濃度答案。保留一次指出一項問題和成功回饋完整帶入畫面。

移除筆記本標題旁的單一取樣標籤，改在各筆質量旁顯示來源。重設清除全部取樣、共用紀錄與來源；取消重設則全部保留。
