# 多種海底地形修訂

2026-10-31，使用者直接要求查核並製作較自然、多深度的海底地形；仍為第四階段。

取代單一正弦盆地，改為大陸棚、大陸坡、深海平原、獨立海山及狹深海溝的組合剖面。研究與數值取捨見research.md；頁尾加入成功查核的來源連結。`sonar-terrain.mjs`統一管理地形與投影；圖像材質沿用，沒有用圖片猜測深度。

本機16項通過，0失敗／跳過，包含地形形態與深度邊界、原2／4／6秒、淺棚0.2秒與深溝11秒的實時計時、素材／圖形／表格一致、滑鼠／手機／鍵盤、暫停、清除、跨區／背景、音訊失敗重試及七種寬度。最後的標籤避讓與水體波紋裁切另外由公開測試與畫面確認。其他教學區保留。

本機與公開證據分開保存，尚未增加外部驗收或最終核可。

首次公開13項功能通過後，人工截圖發現A與「海山」名稱重疊；後續將深水測點字母放在水側、地形名稱裁切在海床內，淺棚字母保留在下方以避開船體，並補圖層／標示位置回歸。以最後公開重測與截圖確認交付。
