# 4.5 第三步整圖調色

2026-11-05（臺北）。依使用者要求，第三步專注整幅圖的色光調整，取消可見放大鏡、取樣框、像素座標、選中色／原始像素RGB及快速取樣選單。改名「3 整圖調色」，不再沿用前兩步的單像素工作台。

## 呈現與操作

上方簡短交代觀察焦點，原圖／調整後圖片並排放大，下方以紅、綠、藍三張控制卡呈現整圖強度。桌機橫排三卡、窄容器改直排，保留44px以上操作。每卡仍可輸入0～255整數，原有0／128／255按鈕在此步顯示「關閉／約半／保留」；255表示保留該通道原圖數值，沒有把所有像素設成255。即時說明哪些色光關閉／減弱／保留，提供「還原整幅圖」。

只重用現有兩張canvas與唯一RGB編輯器，沒有重製圖像或新增模型。第三步影像只供比較與頁面捲動，關閉取樣入口及鍵盤選像素事件，選取保留供返回前兩步。離開時還原節點位置、取樣能力、原按鈕詞義與獨立草稿；第一／二步的可見工作區及同色精確分組保持。初始仍進第一步。

## 科學與範圍

沿用原圖RGB乘以通道控制值／255後取整數的既有模型，0關閉、255保留原值，128約保留一半。不新增濾鏡近似、猜色題目或裝置依賴。五個學習區與第一小測保持，沒有更動4.4。使用同一tv-whole載入版本，獨立載入、重試及無JS第一步預覽維持。

活動檢查改為第三步無取樣、控制在兩圖下方，保留前兩步拖曳與5×5鏡面檢查；核對整圖逐像素結果、還原、控制詞義、無法誤改選取、返回草稿、七尺寸與實際觸控操作，並沿用4.1格式檢查。
