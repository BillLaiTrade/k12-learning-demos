# 3.3第一／二區示範音量提高

2026-10-31（臺北時間）。使用者表示第一區音叉與第二區喇叭幾乎聽不到，要求提高音量。

只在lesson.mjs建立最終AudioBuffer前，對forkKey或pitchKey的訊號施加固定6倍增益（約+15.56dB數位訊號增益，不是主觀聽感6倍）。每次播放重新產生資料，不累積增益；不新增音量滑桿、不改模型相對振幅或波形。音叉輕／重比例7:3、440Hz與衰減包絡，喇叭固定相對振幅與各頻率、動畫及停止規則均保持。其餘五區及小測輸出不變。

量測實際送進AudioBufferSource的資料（直連AudioContext.destination）：輕敲峰值0.23198／RMS0.14550，較重敲0.54128／0.33949，第二區200Hz及400Hz均為峰值0.39000／RMS0.27577；所有樣本有限且絕對值小於1，未削波。第五區純音峰值0.065維持原有輸出。RMS採起音後0.1～0.3秒視窗，不是硬體聲級校準；詳見levels.json。

整合回歸28項通過、0失敗、0略過（含外層）。既有前兩區瀏覽器測試新增最終播放緩衝區的峰值／RMS下限及餘裕斷言，保留頻率、振幅比例、圖形及其他操作檢查；不是只檢查未放大的模型原始資料。公開驗證另記於規劃repo。實體裝置上的聽感仍由使用者檢視，沒有把數位峰值當成耳邊分貝。
