# Part 3.1 本機 3D 與影像素材

本資料夾收納兩個候選頁共用的量測場景程式、蘋果影像，以及本機執行 WebGL 場景所需的 Three.js 檔案。頁面不需連線到 CDN 才能載入程式庫。

## 量測場景

- 長度測量使用同一支鉛筆；`apple-3d-viewer.js` 以 Three.js 幾何元件建立鉛筆模型，不載入外部 3D 物件檔。
- 鉛筆模型長度設定為約 18.2 cm，供頁面示範刻度、估讀與視差；這是教學模型值，不代表特定市售鉛筆規格。
- Three.js 版本：0.186.1。套件授權見 `vendor/three/LICENSE`（MIT）。
- WebGL 場景負責呈現鉛筆與觀察視角；兩個頁面的教學程式繪製直尺、刻度、投影線與讀值。
- `models/food_apple_01/` 保留原始掃描模型及其 CC0 1.0 授權來源資料，目前兩個候選頁的 3D 長度量測場景不載入此模型。

## 蘋果影像

- `apple-hero.webp` 是中型蘋果參照圖，供質量任務及單位換算的逐顆數量呈現使用。
- 參照質量採 USDA FoodData Central 中型蘋果約 182 g；數量示範明確假設每顆模型蘋果皆為 182 g。

## 維護注意

若升級 Three.js，需同步檢查授權、模組相依與兩個候選頁的視角及尺面對齊。若更換鉛筆模型尺寸，需同步確認畫面物件、尺面端點及讀值一致。
