# 第九區：水平對齊與節點圖像

日期：2026-11-06

兩個實線／虛線框改為同一上下邊界，名稱連接線等長。原物、物鏡、中間像、目鏡、眼睛五個節點各自加入圖像：草履蟲、凸透鏡、倒立中間實像、凸透鏡及倒立放大的最終虛像。唯一中間像仍位於兩框共同範圍。

標本圖像共用相同輪廓，實像與虛像均相對原物旋轉180°，虛像維持中間像的方向。凸透鏡圖示呈現中間厚、兩端薄。虛像採清楚圖案與虛線字樣標籤區分；模型補充交代虛像不必然較淡或模糊，圖案大小屬定性示意。

新增節點圖像後縮整主圖與桌面比較窗，維持單一操作工作區；短畫面的目鏡標籤上移，圖像及光路位置仍由相同模型投影。原光學參數、預設輔助光路與切換方式保留。

## 檢查

- 顯微鏡互動8項通過，包含框線上下邊緣相同、兩個凸透鏡圖示、原物與兩個像的方向、唯一中間像位於兩框內、區段切換、返回焦點、光路偏好、鍵盤與備用剖面。
- 六種視窗（1440×900、1366×768、1024×768、760×900、390×844、320×844）及每種三個觀察範圍，共18個畫面通過。沒有水平溢出、文字裁切、標籤越界、字形縮放或圖內遮擋。
- 320×844工作區高度約817px；1366×768局部工作區約742px。
- 人工檢視桌面及320px手機的流程圖，確認五個圖像、實像／虛像標籤、凸透鏡形狀及框線共同範圍清楚。瀏覽器無頁面錯誤。
