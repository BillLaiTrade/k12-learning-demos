# 第三區工具單列與清楚像大小趨勢

日期：2026-11-04

## 修改

- 工具順序為輔助光路、一起看、上端、下端、反向延長線；DOM與鍵盤順序一致，按鈕維持同一列。窄螢幕使用工具列內的橫向捲動，避免換行或遮住屏幕面板。
- 成像表新增「圖卡向透鏡移動」，2F外、剛好2F、F與2F間均標示變大；無窮遠物點、F、F內留白。
- 明確限定比較條件：圖卡仍在F外，並重新移動屏幕找到清楚像。保留無窮遠物點在F形成點像、F內形成虛像的既有說明，不將留白誤寫成完全沒有成像。

## 驗證

既有第三／四區瀏覽器回歸11項全數通過，含七種寬度及原有點選、刻度、光路偏好。

另確認1440、820、390、320px的五個按鈕同列、反向延長線最後，窄螢幕可捲至最後一個按鈕，整頁無水平溢出；結果見[位置紀錄](layout.json)。

以既有薄透鏡模型核對：3F→2.5F的清楚像倍率由0.500增至0.667；2F→1.75F由1.000增至1.333；1.75F→1.5F由1.333增至2.000。三者清楚像都變大，屏幕均需移遠重新對焦。
