# 5.2 第四區漸進對流（2026-11-07）

使用者核可「緩慢起流、逐漸加快、最後大致穩定」。水與空氣都以原觀察時鐘積分平滑速度，8觀察秒由15%示意初速增至原穩定速度，之後不再加速；穩定一圈仍12觀察秒。這是定性動畫，沒有當作流體實際速度或固定起流秒數。

原狀態位置顯示開始形成／逐漸增強／大致穩定循環；箭頭位置連續，保留顏色、路線與對比。暫停凍結速度進程及位置，繼續接續，重來／換流體重新建立，器具仍可開始或繼續。解說3／6／12觀察秒的揭露節點保持。
