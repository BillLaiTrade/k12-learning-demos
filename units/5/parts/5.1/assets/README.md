# 5.1 素材與第一區塊故事插圖

## 2026-10-27：第一學習區塊

使用者核可以精緻的連續情境插圖講述手感的限制，本輪只修改 `#card-01`。

- `touch-story-before.webp`：小葵兩隻手分別接觸冷水與溫水，中間的室溫水尚未碰觸。
- `touch-story-after.webp`：相同人物、視角、桌面與水杯配置，兩隻手改放入中央同一杯室溫水。
- 兩幅圖以既有 `temperature-story-opening.webp` 的角色與畫風為參照生成；第二幅以第一幅編修，維持場景連續性。原始圖為 1536 × 1024 PNG，交付以 WebP 編碼，尺寸及構圖保持不變。圖片不含文字，水杯標示、對話與說明均由 HTML 提供。
- 阿公為無鬍子的白髮、圓眼鏡角色；小葵的衣著與浣熊背包延續既有設定。對話頭像繼續引用根目錄共用素材。
- 冷熱感受採「可能」的定性說明，不宣稱每個人感受一致，不把感覺變成溫度讀值。此區不加入假想的觸覺操作、評分或測量數值。
- 教學順序為先前接觸不同 → 同一杯水可能感覺不同 → 手感不能代替測量 → 引出下一區的溫度計原理。

- 依使用者回饋改為桌機左右雙格漫畫，縮小插圖與間距；窄視窗以小幅直向兩格呈現，保留原圖與對話。
- 再依回饋將每格改為左圖右文的小漫畫，插圖寬度約為前版一半，縮短說明並保留先後情境與感覺差異。
- 最新依使用者指示移除第一區全部補充段落、人物對話及結論，僅保留兩個步驟標題和兩幅圖片；替代文字保留場景描述，小幅圖片尺寸維持約 195px 寬。
- 更正前次過度精簡：恢復每格小葵與阿公的共用頭像對話，保留兩個步驟標題，移除額外敘述與結論。桌機插圖寬度由約 193px 增至約 390px，面積約四倍；窄視窗直向閱讀。
- 依最新更正對齊 3.1／3.2：前段小葵／阿公對話 → 兩幅故事圖 → 後段小葵／阿公對話。四句既有對話逐字保留，移出圖框；兩圖改為全寬直向排列，每幅桌機實測 796px 寬，是先前 193px 小圖的約四倍寬度，圖片不裁切。
- 最新三項修正：桌機每幅縮至全寬版一半寬，窄視窗保留可讀尺寸；第一幕小葵驚訝、阿公鼓勵微笑，第二幕小葵困惑、阿公抬眉解釋；圖上依杯子位置標示「冰水／室溫水／溫水」，並以粗框標出正在接觸的水杯。照片只改人物表情，既有四句對話與其前後位置保持不變；本故事沒有使用熱水，因此不將溫水誤標成熱水。

## 第二區塊：加冰塊／加熱水觀察

- `water-lab-apparatus.webp` 依使用者核可的安全配置圖製作器材底圖，尺寸 1642 × 958；支架、夾具、透明液泡、水面與杯底的間距保持固定。原圖沒有紅液柱與冰塊，兩者由程式連續繪製。
- `water-lab.css` 只作用於 `#card-02`；`water-lab.js` 控制冰塊、電熱板、主圖液柱、右側放大窗和狀態；`water-lab-state.mjs` 保存有界的定性冷暖模型。
- 主圖與放大窗各有 0–60°C 等距刻度：每 1°C 一細格、每 5°C 中線、每 10°C 長線與數字，並標示 °C。刻線及凹形液面中央最低點共用校準公式；保留 5–60°C 的水溫觀察範圍。
- 刻線與數字整合於玻璃管身範圍，主圖和放大窗均為左側刻度、中央毛細管；紅色液柱只佔細管，外層玻璃及其反光另外呈現。放大窗與主圖沿用相同的橫向構造比例，另以文字說明每小格 1°C。
- 5–60°C 是示意模型範圍，初始 22°C；不以動畫時間推論真實加熱功率或融冰時間。融冰期間不開啟電熱板，熱源只對燒杯中的水作用。
- 核可圖、實作截圖、功能與版面檢查紀錄位於 `docs/reviews/unit-5.1-card02/`。

## 第三區塊：攝氏與華氏雙刻度

- `dual-scale.css` 僅影響 `#card-03`，`dual-scale.js` 以原生 SVG／JavaScript 繪製玻璃、單一毛細管液柱與兩套獨立刻度。前後對話沿用共用 `dialogue-character-avatars.png`。
- 攝氏範圍 −40–100°C、每 1°C 一格；華氏 −40–212°F、每 1°F 一格，兩者每度的實際間距比為 1.8，不能複製同一套刻線。華氏以每 40°F 與重要參考點標數，避免延伸量程後 32°F／40°F 的數字重疊。
- 降溫／升溫按鈕每步 1°C，滑鼠及觸控長按可連續調整，釋放、取消或頁面失焦即停止。數字輸入搭配攝氏／華氏單位，按設定或 Enter 才套用；五個捷徑為 −40／0／25／37／100°C。液柱、水平線、兩種讀數、通式、代入式及選取狀態同步更新。37°C 是體溫參考，25°C 是室內示例。
- 本區介紹溫標對應與換算，保留內部溫度精度，四捨五入顯示時用 ≈，不將控制步長或換算小數位視為實體儀器的精度。核可示意圖、實作截圖及檢查紀錄見 `docs/reviews/unit-5.1-card03/`。

- 第三區綠色水平線可直接拖曳，右側圓形端點及透明擴大命中區支援滑鼠／觸控。指標座標透過 SVG 螢幕矩陣轉換，抓取時保留偏移避免跳動，捕獲指標以支援拖出圖外；限於 −40–100°C、顯示步長 0.1°C。放開、取消、失去捕獲、頁面隱藏或視窗失焦時停止拖曳。可聚焦並以方向鍵、PageUp／PageDown、Home／End 操作。

## 第四區：視差、估讀與記錄

- 原第四／第五區合併為 `#measurement`，保留 `#card-04` 作舊連結錨點。前三區與結尾小測內容保留，移除舊的放入／等待動畫及獨立溫度滑桿。
- `parallax-model.js`：固定 37.5°C 液柱、每度的世界座標及觀察者透視投影。前方刻度與後方細管具有不同深度；眼睛位置只改變攝影機，不改變液柱世界座標。
- `parallax-reading.js`：每次拖曳皆重新投影玻璃倒角、細管、凹液面、刻線與數字，使用原生 SVG，不新增套件或 WebGL 需求。刻線僅 34–41°C 的原有 1°C 分度，玻璃反光採漸層；未逐一模擬玻璃折射，前後距離及視角為教學放大。
- `measurement-scene.css`：雙面板、觀看位置捷徑、估讀欄、手機配置；保留小測原放大窗樣式。拖曳眼睛可用滑鼠、觸控及鍵盤，上下限鉗制且同高吸附。
- 學生自行輸入紀錄；參考可顯示／隱藏，無教學區評分。頭像繼續引用共用原素材。外觀與功能紀錄見 `docs/reviews/unit-5.1-card04/`。
