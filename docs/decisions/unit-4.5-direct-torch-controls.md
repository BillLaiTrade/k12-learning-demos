# 4.5 第三區：精簡手電筒區與直接點按開關

日期：2026-11-03（臺北）。使用者先要求下方手電筒區高度縮到原來的一半，接著要求移除獨立燈具開關，改為預設開燈、直接點手電筒切換，並把保留的快速比較放在區塊下半部。本輪合併完成這兩項要求。

將手電筒圖框與名稱／開關狀態並排，圖框維持18:13，縮減留白及高度，不拉伸模型。桌機木紋區約130→68px，390px手機約99→48px；窄螢幕仍保留至少44px的整支器材觸控區。三支燈初始均開啟，名稱旁顯示「開／關」，aria-pressed與完整無障礙標籤同步。金屬材質及正式角色素材保持。

移除右側開關按鈕與多餘欄位，場景使用可用寬度，保留光斑分開／部分重疊／完全重疊三按鈕，改成場景下方一列。桌機預留這列高度，手機隨內容自然收斂；維持白幕等比例、同視窗可操作與說明自然展開。

原生button點按或Enter／Space切換開關；方向鍵微調，拖動超過原有4px門檻才移動落點並顯示柔光束。拖曳結束或取消後的相容click被略過，避免誤關燈；下一次新點按與鍵盤操作仍正常。取消／Escape／失焦回復原落點與開關，放開即隱藏光束；關燈仍可調方向。快速比較只調排列，保留各燈開關。

對話與提示改為說明點按開關、拖曳瞄準；移除套用到器材上的通用綠色按鈕選取背景，保持木紋台面與器材可辨識。mix-optics、柔光束計算、torch-studio、PNG與其他學習區／小測保持。不新增依賴或外部服務，仍為第四階段。

檢查使用既有專項：13種視窗與下方比較列、44px觸控、8組前後高度；真立體柔光束、點按／Enter／Space、拖曳與取消不誤切換、手機原生觸控與再次點按，以及整頁回歸。純光學未改，不重跑既有模型測試。
