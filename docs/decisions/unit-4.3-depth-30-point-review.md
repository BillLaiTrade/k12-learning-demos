# 第六區：依三十項畫面盤點逐項整理

2026-11-04。使用者要求將前輪列出的30項畫面問題全部修改，檢查後再交付。範圍限第六學習區，不改前五區、小測、折射率、硬幣位置、槽體或操作範圍。維持第4階段，沒有新增最終核可。

## 呈現決策

兩圖整合為同一個淺色觀察台，移除各自完整的深綠卡頭及獨立工具列。眼睛托框採橢圓香檳金，虹膜朝水槽方向偏移；同一眼睛圖稿顯示在右標題。桌機使用從托框延伸的淡金視野面與無箭頭邊線，於兩圖留白展開；窄版沿共用觀察台外緣接到下方視野，不遮標籤及操作。

右圖標題保留「這隻眼睛看到的畫面」，移除下方重複的歸屬說明；右圖下方改用狀態加原因。左圖指出前側槽壁及真正的擋光點；右圖只有實際繪出前壁且空間足夠時，才在那面壁上標示同名標籤，避免靠近時把槽底誤標為前壁。

側圖座標仍採均一縮放，沒有拉伸水槽內外的光線；硬幣、槽體及眼睛維持同一世界。側圖放大及左移、幣面放大，水位手把與眼睛提示就近。寬版水位控制靠近槽壁，窄版移至右側留白，保持44px並避開說明。

右圖一次調整固定構圖為俯角32°、垂直視野50°，以減少桌面留白、提高槽體占比；在所有水位與觀看位置均採同一方向及倍率，只平移眼睛原點，不依物體自動縮放。近至遠的槽緣及幣像仍應單調縮小，所有可見幣面仍應落在視窗內。靜止畫面採2倍解析度（上限1100px），播放採較低解析度；提高槽內環境光、降低桌面材質對比，不改光線追跡與遮擋。

## 三十項對照

| 原編號 | 問題 | 修改與核對方式 |
| --- | --- | --- |
| 1 | 左右像兩張獨立卡片 | 共用外框／底色，移除各自卡框與陰影，標題採同一層級。 |
| 2 | 兩條金線像接線 | 連線之間加入極淡視野面，從眼睛托框延伸，沒有箭頭或流光。 |
| 3 | 連線貼右框像裝飾 | 在共用留白展開，終點明確接至視野窗上下緣；保留右窗金框配對。 |
| 4 | 轉折生硬 | 桌機使用曲線展開視野面，窄版貼外緣銜接，不穿圖中文字。 |
| 5 | 金線與光路混淆 | 視野框改為低飽和香檳灰金，真正光路保持亮黃及方向箭頭；UI連線不隨光路開關消失。 |
| 6 | 眼睛沒有朝向水槽 | 虹膜朝左下方偏移，眼睛仍是拖曳觀看位置的唯一控制點。 |
| 7 | 右標題圖示太小 | 放大共用眼睛圖示，搭配明確標題，沒有再增加重複歸屬句。 |
| 8 | 細節縮小後不清楚 | 保留向量虹膜／高光，減少外框厚重感及木紋干擾；最小觸控範圍44px。 |
| 9 | 眼睛像一般按鈕 | 改為橢圓托框，搭配金屬滑軌、左右拖曳游標及就近提示。 |
| 10 | 左側水槽太小 | 側圖均一放大、向左配置，工作台向觀察區分配空間，維持光線角度。 |
| 11 | 左圖留白失衡 | 移除上方控制空列，在原留白中安排槽壁、擋光及水位說明。 |
| 12 | 硬幣太小 | 側圖幣面加大並保留刻紋，位置固定；右圖使用較集中且固定的構圖。 |
| 13 | 右側水槽偏小 | 靜態收緊視野並調整俯角，所有操作仍用同一鏡頭，無自動追蹤／變焦。 |
| 14 | 兩圖水槽不易對應 | 共用觀察台、同一座水槽副標及同名「前側槽壁」，沿用同套照片材質。 |
| 15 | 前後壁對應不清 | 左圖標出前側槽壁，右圖從實際前壁像素範圍定位標籤，前壁離屏時隱藏標籤。 |
| 16 | 槽內過暗 | 提高材質環境光，保留表面法線、接觸陰影及底／壁差異。 |
| 17 | 槽口鋸齒 | 提升靜止畫布解析度至約2倍，CSS呈現等比例，不拉伸投影。 |
| 18 | 木紋搶焦點 | 側圖增加淡色材質襯底，右圖降低桌面對比；保留原木桌風格。 |
| 19 | 工具列吃高度 | 光路開關移至左圖下方圖例，狀態整合進右圖下方原因，不獨占頂部一列。 |
| 20 | 軌道不明顯 | 加深軌道凹槽、增加金屬邊緣與端點，保持44px眼睛觸控範圍。 |
| 21 | 靠近／遠離缺對象 | 開始說明及輔助閱讀明確指向水槽，圖面提示「拖曳眼睛」並緊貼軌道。 |
| 22 | 空槽不知道怎麼調水 | 空槽保留水位軌道與把手，「拉動水位／拉水位」貼控制旁，水面也可拖曳。 |
| 23 | 水位軌道像法線 | 控制軌採青綠寬槽與白色把手，法線改為灰色虛線。 |
| 24 | 手勢提示離操作遠 | 眼睛及水位提示直接放入場景；完整鍵盤／手勢說明保留給輔助閱讀。 |
| 25 | 擋光點不清楚 | 真正阻擋位置加入小型截停標記與「光被擋住」，可見時移除。 |
| 26 | 兩圖因果分離 | 右圖原因依真實狀態說明槽壁擋光、直接越緣或出水折射越緣；對應左側擋光點。 |
| 27 | 說明重複且分散 | 頂部只說先加水比較，標題交代視野歸屬，右下說當前原因，底部保留一句概念。 |
| 28 | 圖例抽象 | 改用「光真正走的路」及「沿入眼方向往回找位置」，細節於既有展開說明解釋。 |
| 29 | 字體／對比不一致 | 教學標籤統一奶油底及深綠文字，去掉木紋上文字的厚描邊；檢查縮放後字體下限。 |
| 30 | 元素搶注意力 | 降低卡框、背景、UI連線及標題色帶強度，將亮黃留給真實光路，青綠留給水位控制。 |

## 驗證要求

保留持續加滿／放空、重按不重啟、途中反向、手動接管、離屏續播、原生觸控、鍵盤、光路開關、減少動態與材質重試。新增同名槽壁、擋光標記及原因隨真實狀態更新的核對。版面擴至9尺寸×5水位×3觀看位置共135組，核對文字互不重疊、水位控制不蓋文字、眼睛框不壓字、連線不遮文字、端點配對、不越界、無橫向溢出。鏡頭另驗證可見幣面不被裁切及遠離單調縮小。
