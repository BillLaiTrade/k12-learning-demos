# 共用人物素材

- `dialogue-character-avatars.png` 是所有單元共用的小葵與阿公對話頭像，左半為小葵，右半為阿公。
- 阿公依確認的人物設定呈現為無鬍子；頭像圖維持 2:1 橫幅，頁面以 CSS 背景定位裁切左右半幅。
- 各單元請直接引用此檔，不要在單元自己的 `assets/` 資料夾建立重複副本。

## 小葵的造型核對

- 棕髮雙丸子頭、自然散髮與瀏海、棕色眼睛，穿白色／米白色連帽上衣；可見背包時使用深色背帶。
- 新製情境圖須對照本目錄共用頭像與既有核可角色素材。單馬尾、襯衫與綠色背帶並非目前小葵的造型。
- 2026-10-28 使用者指出潛望鏡情境人物不符；該圖已依共用頭像及 1.2 既有側臉素材修正。版型示意圖不能取代正式人物參考。
