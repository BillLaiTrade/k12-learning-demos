# 第六區較大圖卡與虛像局部放大

日期：2026-11-06（Asia/Taipei）

圖卡寬高加大 1.3 倍，虛像與原物上的紅、藍追蹤點同步採新尺寸。焦距、物距範圍及眼位沿用原設定。兩個比較框使用相同固定尺度，視野一次調整為 34 度，使最近位置的較大圖案完整顯示，距離變化仍呈現近大遠小。

主圖虛像、虛像位置標籤及右側「放大虛像」均可開啟局部放大。使用原紅箭頭與藍色圓點，標示局部放大示意及虛像相對原物的幾何高度比例。支援關閉按鈕、Esc、點擊背景與關閉後焦點返回；拖曳仍觸發位置尺引導，觸控與 WebGL 備用畫面亦可開啟。

- 瀏覽器測試 14/14 通過，含三個入口、三個代表物距、放大窗內圖案辨識、成像狀態保留、鍵盤關閉、手機原生觸控與 WebGL 備用畫面。
- 既有五種尺寸、七個物距共 35 組取景平衡檢查通過，圖卡、透鏡、眼睛及 F 留在主圖範圍內。
- 固定尺度下，原物與鏡內影像近大遠小；最近位置原物圖案低於觀看框高九成，鏡內影像仍正立縮小。
- 光學測試通過，另驗證紅、藍物點高度與原圖案位置一致。其他區塊 HTML 保留。
- 已人工檢視桌面主圖與桌面、手機放大窗。首次瀏覽器檢查因初始化逾時中止；診斷確認無頁面例外後，完整重跑通過。
