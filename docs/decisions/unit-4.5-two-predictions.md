# 4.5 雙色光挑戰依光路作兩項預測

2026-11-06（臺北）。使用者核可兩步示意後，明確要求移除「你的判斷依據」區塊，其餘依示意更新。

作答卡改為「你的預測」：先以原生選單回答「到達紙張的是什麼光？」，再以八個色票預測「紙張看起來是什麼顏色？」，最後統一檢查並開燈。保留既有黃光／青光／洋紅光等混合後色名，不在選項直接列出組成。條件沿用場景上方既有光源／色片／紙張列，避免在作答卡重複。

移除反射情況選單，不新增「哪些光被反射」的重複作答。每題只保存、驗證到達色光與紙面顏色；漏答依這個順序聚焦，不開燈、不揭露結果。兩項均作答後可開燈，正誤分別回饋；改答清除本題舊結果。既有驗證後收合的完整光路解釋保留，反射比例僅供解釋，不列作答或判定條件。

保留自由試光／六題挑戰分頁、逐題保存、換組規則、三原色燈具、3D與備援、全部光學計算、五學習區及像素電視。僅更動作答HTML、局部CSS、表單狀態與判定欄位；不新增依賴。桌機維持左場景右作答，較窄畫面自然直排。

模型驗證涵蓋72題只答兩項即可完成、缺項與錯答分別判斷、舊反射值不影響新判定；瀏覽器驗證DOM／鍵盤順序、各種漏答、六題保存／換組、開燈／改答、九視窗、備援與第二小冊獨立。詳細已執行結果記於主專案本輪review。維持第4階段待使用者檢視。
