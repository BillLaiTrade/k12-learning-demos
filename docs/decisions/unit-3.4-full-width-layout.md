# 3.4 統一為2.1的橫向標頭與滿寬內容

2026-10-31（臺北時間）。使用者要求3.4格式比照2.1，避免區塊左側標示佔用整欄、留下大片空白。

- 六個教學區塊統一為頂部橫向標頭：編號徽章、原完整h2標題、原概念與角色簡介；下方lesson-body包住原card-main，內容使用整個區塊寬度。
- 標頭與內容的留白、底線、圓角、徽章和字級沿用2.1現行值；900px及700px以下縮小留白與編號。刪除3.4一般卡片及第一、二區的舊左右分欄規則，避免特定區塊或斷點恢復舊格式。
- 六組互動區HTML逐字保留，所有原有ID與順序不變，JS、模型、圖片、音訊及唯一小測皆未修改。原區塊標題仍與導覽對應；頁面層級的探索路線維持。
- 本決策更新先前第一、二區核可圖的左右欄外框格式；既有互動呈現與教學內容延續。仍為第四階段，未新增外部驗收或最終核可。

本機檢查46項通過，含六區1440–320px標頭／主體位置、內容寬度、連結跳轉，以及發聲、拖牆、暫停、鍵盤、觸控與小測。畫面及完整結果見`docs/reviews/unit-3.4-full-width/`。
