# 1.2 故事線規劃

**狀態：故事方向與六個學習區塊已確認。**區塊依 [課綱與教材範圍盤點](scope-review.md) 及[單元 1 課綱覆蓋對照表](../../curriculum-map.md)編排；凹面鏡和凸面鏡列為本課程要學生認識的內容，並與平面鏡的生活應用分成兩個區塊。

## 與前後單元的連接

- **承接 1.1：**學生已知道，看見物體需要有光進入眼睛；光可能先照到物體，再反射進眼睛。
- **1.2 的焦點：**光遇到表面後如何反射，以及平面鏡如何形成影像。
- **銜接 1.3：**1.2 收束在鏡面反射如何改變光的方向；1.3 可從物體放進水中看起來位置改變的現象開場，探索光進入不同介質後的折射。

## 故事開場

阿公拿出兩面小鏡子，準備和小葵做一支能看見牆角另一側的簡易潛望鏡。桌上還放著一面鏡子和一張白紙。小葵照鏡子時，發現鏡子裡有清楚的自己，白紙上卻沒有，於是開始探索鏡面如何改變光的方向、影像又出現在哪裡。

開場先用客觀敘述交代情境；小葵的好奇和提問從第一個學習區塊開始。

## 學習區塊與核心問題

| 區塊 | 核心問題 | 故事與概念進展 |
| --- | --- | --- |
| 1. 不同表面的反射 | 為什麼鏡子能映出清楚的影像，白紙或牆面卻不行？ | 觀察光照到各種表面都會反射；比較平滑表面的鏡面反射與粗糙表面的漫反射，並說明兩者均遵守反射定律。 |
| 2. 反射方向的規律 | 光照到表面後會往哪個方向反射？光路可以反過來嗎？ | 透過實驗改變入射角，畫出入射線、法線、反射線，整理入射角等於反射角，並觀察光路可逆。 |
| 3. 物體和面鏡的距離 | 物體移近或遠離面鏡時，像的位置如何改變？ | 以面鏡實驗觀察物距與像位置的關係，探究像距等於物距。 |
| 4. 平面鏡成像特性 | 鏡中的影像和物體有哪些相同或不同？ | 整理像的方向、大小及相對鏡面的位置特性；物距與像距的相等關係已在第 3 區塊處理，這裡不重複教。教材版本對像的其他細目仍需核對。 |
| 5. 認識凹面鏡和凸面鏡 | 凹面鏡和凸面鏡會怎麼改變反射光？ | 比較反射面的彎曲方向、平行光反射後的大致分布及常見用途；聚焦基本辨認，不延伸到焦點計算。 |
| 6. 面鏡的生活應用 | 兩面平面鏡要怎麼擺，才能讓牆角外的光進入眼睛？ | 將反射規律應用於兩面平面鏡，完成簡易潛望鏡；以面鏡應用收束，不延伸到透鏡原理。 |

## 收束與轉場

1.2 的結論聚焦在反射規律和面鏡成像：光在表面反射時遵守反射定律，光路可逆；面鏡成像位置與物距相關，平面鏡中的像具有可觀察的方向、大小與位置特性。接下來的 1.3 從水中的物體看起來位置改變開始，轉向光進入不同介質時的折射。
