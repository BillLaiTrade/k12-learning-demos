## 核可圖對照

- 保留既有概念欄、題目、小葵提問、阿公收束及專案共用頭像，沒有使用示意圖內重繪的人物副本。
- 左右同款木製喇叭、側面振膜放大窗、暖木桌、同高播放按鈕與同時間窗波形；右側400Hz起、減／加各100Hz，限制200～800Hz。左側固定200Hz。
- 點喇叭或各自播放按鈕，可自由左／左／右重播，僅一側發聲；沒有集中式依序播放按鈕、滑桿、頻率快選或獨立慢動作按鈕。
- 發聲2秒，該側振膜及波形同步放慢200倍，描繪模型中的10毫秒；原音高不變。振膜在結束／中斷時回到平衡位置，紀錄保留；重播從左重畫。調頻停止播放並更新右圖，保留左側既有紀錄，不自動發聲。
- 核可圖的每週期括線保留；為筆電可讀性，週期文字改放圖下固定字級。實際網頁保留全站既有字體及卡片比例，不把整張示意圖當作不可操作的圖片。

## 科學與音訊

使用相同純音合成及相對振幅0.50，僅改頻率；200／400／800Hz在10毫秒分別為2／4／8次振動。所有動畫採同一放慢倍率、位移幅度一致；橫軸是時間，不是空間傳播路徑。圖中保留共同尺度及未播放時可見的淡色完整參照。固定訊號振幅不宣稱主觀響度相同，音調高不代表聲速較快。無新測驗及進階內容。
