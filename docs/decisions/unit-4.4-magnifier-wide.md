# 4.4 第四區改為橫向實驗台比例

2026-11-02。使用者指出左側寬型器材卻被放在近直式的畫面，高度大於寬度，要求調整長寬比例。沿用已核可的立體實驗台與常駐眼睛視角，維持第四階段。

移除左側固定560px高度及左右強制等高；立體舞台以3:2橫向比例獨立取景。可用內容寬度至少720px時，左右欄約3:1分配，眼睛欄至少180px；常見1440px頁面下左舞台約605×403px，原約544×570px。依內容寬度切換，而非僅按視窗判斷，較窄時提前上下排列，避免中尺寸側欄再壓窄實驗台。極窄畫面保留300／320／360px最低高度，確保觸控按鈕及標籤仍可操作。

右側保留同尺度的眼睛畫面與原物參照，參照說明改為側置疊放於既有畫面空白處，縮減文字留白；兩張canvas的CSS寬度仍相同。3D canvas隨舞台實際尺寸更新相機取景。物距、焦距、眼睛位置、光路、像的計算及拖曳邏輯保持，只縮短右側一行提示文字。

沿用既有專項測試，增加實際舞台寬高比與依內容寬度的排列斷言；檢查七寬度、按鈕／標籤、器材完整取景、旋轉／縮放、圖卡拖曳、右側像素不變、屏幕比較及觸控。純光學模型、其他九區及共用版型不變，不重跑無關模型或整課專項。最新結果見[交付紀錄](../reviews/unit-4.4-magnifier-wide-20261102/review.md)。
