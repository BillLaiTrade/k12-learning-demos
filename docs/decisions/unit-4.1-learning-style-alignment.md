# 4.1 六個學習區的共用視覺格式

日期：2026-11-04（臺北）。使用者核可先統一六區卡片外觀，再統一頁寬、副標、頭像與一般按鈕；沿用前一輪已完成的小測格式。

第一步將頁面背景、文字及共用色彩對齊第三單元，六區採20px圓角、淺白底、灰綠邊框與同一陰影；手機保持20px圓角。此步製作提交為`fb38b049`。

第二步以3.3共用配置為基準：頁寬上限1120px，桌機導覽250px、欄距34px；1100px以下為205px／24px，760px以下改單欄，頁寬上限620px、兩側至少12px。六區副標改為一般段落自然換行，兩段既有短語以CSS分號區隔，文字節點保留。六區角色頭像48px，小測頭像維持原尺寸。重設位置／視角按鈕統一白底、13px圓角、750字重及至少44px高度，鍵盤焦點採共用金色外框；大型光源開關、孔板選取、遮擋開關與計時按鈕保留各自配置。

全部正文HTML、教學文字、圖片、控制項、ID、實驗內部分欄及腳本逐字保留；沒有更動光學模型、拖曳、通光、計時與小測判定。既有標頭字級與留白已一致，沿用原設定。頁寬縮減會連帶改變畫布可用寬度，需確認3D場景取景及桌機／手機操作。無新增套件或服務。

維持第四階段製作／修訂。驗證與公開結果記於規劃儲存庫`docs/reviews/unit-4.1-learning-style-20261104/`。
