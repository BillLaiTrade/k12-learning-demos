# 4.2：ppm 以實物量級及等比例模型引入

- 日期：2026-10-28（臺北時間）。
- 核可依據：本輪使用者已確認觀察區與概念區兩張示意圖，要求按核可版型修改正式頁面，完成檢查後推送供檢視。

## 教學與畫面

目前只以同一實驗桌上的 **1 公升水與1毫克糖** 引入微量概念。1克糖、第二個糖碟、1／1,000ppm比較卡皆已依使用者最新核可移除。放大鏡完整呈現同一份1毫克糖，初始即顯示並連回原尺寸糖碟，也可拖放、點碟或用鍵盤操作；整杯水與原糖量保持可見。

從實物大小差距帶出微量時ppm較易閱讀，沿用同一濃度概念。共用質量比分式分支連到兩種表示係數，再用同一份溶液的大字0.0001%＝1ppm呈現等價關係；輔助計算以1,000,000毫克的溶液總質量為分母，1ppm定義置於下方。

1公升水是大小參照，不直接當成1公斤溶液。定義中的1公斤包含糖；不新增混合或稀釋計算，也不把任何體積比直接當作質量ppm。下方ppm固定為1毫克的引入案例，與上方自由配糖水分開。

## 比例的可核對依據

- 蔗糖密度取近室溫的約 **1.59 g/cm³＝1.59 mg/mm³**。來源為 [PubChem CID 5988 的 Density 資料](https://pubchem.ncbi.nlm.nih.gov/rest/pug_view/data/compound/5988/JSON?heading=Density)，2026-10-28 讀取 HTTP 200；該頁引用 CAMEO Chemicals／USCG，資料列為 1.59（68°F，約20°C）。原始引用：[CAMEO Sucrose](https://cameochemicals.noaa.gov/chemical/12695)。
- 因此，1 毫克糖的實心體積約為 **0.62893 mm³**。密度為近似物性值，並非特定品牌糖的實測校正。
- 糖由可積分體積的 3D 晶粒構成。每一模型晶粒選定為 0.1 毫克，以幾何積分將基礎形體正規化為單位體積，再以質量／密度縮放；晶粒各軸變形保留尺度乘積為 1。1 毫克使用 10 個晶粒，總實心體積符合前式。
- 晶粒放置於 0.6 毫米格距的非重疊位置；測試核對各頂點的變形、旋轉後界限。晶粒之間空隙不算糖的體積。這是粒徑與形狀的選定模型，**不表示真實每顆糖固定為0.1毫克或1毫克，也不宣稱實物已秤量拍攝**。
- 水是半徑 55 毫米、液柱高度 `1,000,000/(π×55²)` 毫米的圓柱，體積恰為 **1,000,000 mm³＝1公升**。杯壁照片只提供玻璃質感；水與糖本體以同一毫米座標建立。
- 主視角為寬 360 毫米的正交投影，不靠景深縮小遠處物件。目前這一份糖使用18毫米寬的完整視野，沿用原幾何及原始尺寸。5毫米尺度依視野寬計算 CSS 像素，放大倍率則依實際主畫面與放大框寬計算，手機不另改糖粒質量或加設最低可見尺寸。

## 素材、功能與限制

- 沿用既有 Three.js、RoomEnvironment、正式共用頭像與學習卡版型，未新增套件或外部服務。
- `ppm-table.webp` 是使用影像生成工具由既有實驗桌清除器材後製作的背景，不包含糖或水的質量資訊。玻璃外觀重用 `concentration-beaker.webp`。
- 原本份量卡、比較卡被目前的單一實物觀察與靜態代入式取代。保留放大鏡的鍵盤、觸控、Escape 歸位與上方共用重設。
- 比例畫面載入／WebGL 失敗時提供訊息；正式公式、唯一的數值範例仍可閱讀，不阻擋上方配糖水或其他學習區塊。
- 這是依公開物性值建立的等比例視覺模型，不是實驗影片、品牌糖的粒徑資料或計量儀器精度展示。


## 2026-10-28：自然堆積與空碟質感修訂

- 主場景使用新生成的獨立空陶瓷碟 `ppm-dish.webp`，僅作器皿外觀，不包含糖。糖仍由同一套可計算體積的3D模型繪製，沒有使用生成糖堆判定質量。
- 晶粒由二十面體改為封閉削角晶體，仍先積分體積並正規化。各粒安全旋轉與保體積變形、錯層位置及格內微擾讓堆積更自然；粒子保持在各自安全格內，幾何與位置界限一併檢查，確保不重疊。堆積外輪廓改為帶起伏錐形，空隙仍不計入實心糖體積。
- 密度、兩種總質量、一公升水、主視野與放大視野及尺規計算不變。晶粒形狀、固定模型單粒質量與鬆散程度仍屬視覺模型選擇，非真實品牌粒徑資料。


## 2026-10-28：場景內的可拖曳放大鏡（初版，已由下方份量修訂取代）

- 使用者要求以放大鏡呈現，取代點擊後浮出的放大圖。場景載入後即可看見鏡框與握柄；初始停在桌面右上側，未對準糖碟時鏡面透出原場景，不顯示先前的糖粒影像。
- 可拖曳鏡面或握柄，鏡心接近糖碟時依螢幕位置轉換到原毫米座標的局部視野，放手後對準該糖堆。點糖碟或配方卡是移動同一支放大鏡的替代操作，不新增視窗、放大圖片或關閉鈕。
- 兩碟統一採寬3.6毫米的視野與1毫米尺規，方便比較相同模型粒徑；1克糖堆在鏡內只呈現局部，不再自動改成原先的36毫米全堆視野。畫面倍率依鏡面內寬與主場景寬計算，並非實測光學儀器倍率。
- 握柄支援方向鍵移動，Shift＋方向鍵微調，Home或Escape歸位。共用重設恢復1毫克範例與放大鏡初始位置，取消拖曳不留下舊影格排程。
- 整個鏡框、握柄及鏡內標籤限制在場景範圍；手機沿用相同比例，不放大糖的實體模型。背景/WebGL失敗仍保留正式公式與計算。


## 2026-10-28：修正為水與糖的整體份量差距

- 使用者澄清：放大的目的是讓學生感受大量水與微量糖的差距，不能把ppm引入帶成觀察糖晶體形狀或結構。後續呈現須優先保留整杯水、原尺寸糖量及整份糖，不能以局部晶粒特寫取代這項比較。
- 放大鏡仍可拖到糖碟，兩碟改用相同36毫米寬視野；全份1克／1毫克糖都在鏡內，尺寸不按可見度另外調整。1克是一小堆、1毫克仍是小點，螢幕倍率約為3倍，依裝置內寬計算；這個倍率只放大畫面，沒有增加糖量。
- 選取或放手後鏡框返回右上方空位，以細虛線及原尺寸標記連回所選糖碟。整杯水與兩碟原糖量保持可見，避免鏡框把份量對照蓋住。鏡內固定呈現整份糖，不再依鏡心偏移截取晶粒局部。
- 學生文字改為「看清整份糖有多少」，保留質量與ppm公式；移除引向晶粒觀察的提示。1公升水仍只是大小參照，ppm分母仍為包含糖的1公斤溶液總質量。
- 糖的密度、總質量、幾何實心體積與主場景比例不變；科學尺寸模型繼續作為量的依據，並非要教晶體結構或宣稱真實品牌粒徑。未新增套件、服務或影像素材。


## 2026-10-28：最新核可只用1毫克與一大杯水引入

- 使用者確認只對比1毫克糖相對於一大杯水的微小份量，再介紹ppm。依此移除1克模型及其糖碟、按鈕、陰影、數值比較卡，沒有只把它藏起來。
- 1毫克糖碟移至桌面右下方適當位置，尺寸與總質量不變。放大鏡初始顯示完整1毫克量，連回來源；共用重設恢復同一初始觀察。Home／Escape仍可歸位，再以點碟或拖放觀察。
- 提問→百萬分之一→質量定義→正式公式→唯一代入式，是目前學生閱讀順序。移除已無功能的比較選取，沒有加入新的步驟列、題目或量的調整器。
- 前述歷史紀錄中的1克、兩碟及1,000ppm均為歷史呈現，已由本次最新核可取代。


## 2026-10-28：銜接重量百分濃度與ppm

- 使用者要求稍作說明，學生才知道ppm與上方計算為何不同。於ppm定義之後、正式公式之前補上短段落與兩列對照。
- 兩者先算相同的「溶質質量÷溶液總質量」，再分別寫成質量比×100%與質量比×1,000,000。這是同一比例的不同表示方式，不引入新濃度模型。
- 用現有單一案例說明0.0001%＝1ppm，因微量成分用百分濃度時小數位數較多，ppm較容易閱讀。不新增1克範例、比較任務或體積比計算。
- 現有1毫克對照1公升水、放大鏡與質量定義保留。新增區塊提供`#ppm-percent-bridge`錨點，手機可自然換行。


## 2026-10-28：明說ppm沿用既有濃度概念

- 使用者要求介紹時清楚表明：ppm是適合溶質特別少時的表達方法，不是新的濃度概念。
- 圖後的引入先說明仍在表示溶質質量占溶液總質量的比例，再說微量時改用ppm較易閱讀。銜接標題改為「同一個濃度，換一種表示方式」，內文明說「ppm並不是新的濃度概念」。
- 原有兩種表示係數、0.0001%＝1ppm、質量分母及唯一1毫克案例保留；本輪只改介紹文字與對應檢查。

- 核可來源：使用者看過觀察圖及概念圖，要求按照該版型正式製作。圖稿保存於本輪核對紀錄，作版型與閱讀層級依據；生成圖中的糖量不作科學尺寸來源。

- 放大鏡縮為場景寬26%，握柄向右下、完整留在場景內；上方標牌「放大看這一小點／糖量仍是1毫克」。同一份模型的視野由36毫米調為18毫米，使整份糖量更清楚，保留細小5毫米尺規；不截取晶體局部，也不改主場景水與糖的世界尺寸。
- 概念段落以「微量時，ppm更好讀」為標題，同一質量比分式分支連到重量百分濃度與ppm兩卡，再呈現同一份溶液的0.0001%＝1ppm；1ppm是視覺主角，綠色結論說濃度沒有變。原計算保留為輔助小式，撤除重複的大公式面板與長段落。
