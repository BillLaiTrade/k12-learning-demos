# 3.4 F02：側欄換區停下原播放

日期：2026-11-01（臺北時間）。使用者採用全課盤點第二項：點側欄切到另一區時先停止原播放，一般上下捲動則不中斷。F01已完成，F03–F15仍待逐項決策。

原側欄只做同頁錨點導覽，因此換區後舊動畫及聲音仍繼續。共用入口新增側欄click事件委派：接受未被取消、無修飾鍵的一般點擊，解析有效的同頁區塊；只有目標與目前播放器所屬區塊不同時才呼叫既有stopActive。不preventDefault、不攔截hashchange或IntersectionObserver，保留原生導覽與捲動。

第一至五區沿用暫停，保留進度、選擇條件與測點；回來不自動續播，由學生明確按繼續。井深小測沿用既有中斷機制，清除未完成的回聲紀錄並提示重新喊話，答案草稿保留；已完成的小測不受導覽影響。600ms慢啟音期間切換同樣取消舊啟動，不會延遲冒出回聲。

點正在播放的同區連結、普通捲動，以及Ctrl／Meta等另開視窗或分頁的操作不套用本條停止規則；真正分頁隱藏仍由原有背景規則停止。點目標區塊不會自動播放。

HTML只更新echo.mjs快取版本；聲音時序、數字、音檔、獨立控制器、文案及布局保持。測試與證據見tests/README.md及docs/reviews/unit-3.4-navigation/，公開確認另存規劃repo。維持目前製作階段，非完整單元驗收。
