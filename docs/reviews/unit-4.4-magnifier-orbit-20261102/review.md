# 4.4 第四區修正旋轉時自行縮放

2026-11-02。使用者回報未用滾輪，僅拖曳畫面就會忽大忽小。原updateCamera把旋轉與自動取景綁在一起，每次角度改變都重新計算相機距離。新增距離斷言先在舊版重現失敗，同一次滑鼠拖曳使距離由11.38979135變為12.79756956模型單位，見before-regression.txt。

將基準距離計算移至初始化及容器尺寸變動；旋轉更新只改角度並保留縮放倍數。滑鼠拖曳、鍵盤、手機單指旋轉不自動拉近拉遠；滾輪／雙指可明確縮放，縮放後旋轉保留距離。移動器材與屏幕切換亦保留距離，明確的「正面看屏幕」／返回切換保持。不同角度仍有正常透視與遮擋，此修正不強制每個角度占用相同畫面寬度。

本機原立體專項10項全部通過，新增相機距離／FOV不變量、58次水平及上下鍵盤旋轉、縮放後再旋轉、屏幕切換與手機單指／雙指區分；保留右側像素、光學、拖曳、七寬度及備援。rotation-distance.json記錄修正後初始、滑鼠及鍵盤旋轉距離相同，只有滾輪操作才改變距離。舊版先失敗、新版通過的斷言未放寬。

local-studio.txt為本機結果，layout.json與畫面保存七寬度與手機操作。所有區塊HTML、CSS及其他光學資產保持，僅更新第四區相機模組、載入版本與測試，見preservation.json。未重跑未改的純模型、整課或其他區專項。維持第四階段。
