# 3.2 第三學習區塊：真空鐘罩互動模型

日期：2026-10-28。使用者核可鐘罩實驗示意圖後授權實作，並要求核對畫面與功能再交付。

採用獨立的電鈴電源、相對空氣量、抽氣／進氣三組狀態。幫浦、進氣閥與對應按鈕共用同一動作；再次操作可停在當下，切換方向取代前一動作。電鈴關閉不恢復空氣量，讓學生能分辨聲源與介質的作用。

空氣量為定性模型，畫面只顯示「充足／逐漸減少／接近真空」。依最新寫實要求，空氣保持不可見，不再用藍色粒子呈現；聲音增益與空氣指示為定性模型，不宣稱是實測壓力關係。接近真空保留微弱聲音，以表達底座等固體路徑可能傳遞殘餘振動。

電鈴持續振動與音高均不因抽氣而改變。實錄聲音經 Web Audio GainNode 調整聽到的音量，兼顧行動瀏覽器對媒體音量設定的限制；初始不播放，使用者開啟電鈴才啟動音訊。離開區塊或分頁後停止聲音，保留實驗空氣量。

畫面以核可示意產生的器材底圖配合獨立敲錘與指針圖層；文字和操作均由 HTML／SVG 呈現。前兩區塊的互動與聲音作回歸檢查。核可圖、各狀態截圖及測試紀錄見 `docs/reviews/unit-2.2-card03/`。


## 罩外音量指示修訂

使用者核可移除重複狀態列，改放場景中的示意分貝儀。新增器材不改變罩內空氣表用途；LCD 讀值以增益調整後、逐聲道取樣的真實音訊 RMS 計算，再加上固定示意參考偏移。避免僅按空氣狀態切換假讀值，也避免立體聲相位抵銷造成錯誤量測。畫面與註記明確標示「示意分貝儀／非現場實測」，不宣稱絕對聲壓校準。

正常狀態列改為僅輔助科技可讀，保留真正播放失敗時的可見提示。關閉或無訊號顯示「—」。新增檢查在空氣量不變時暫停音訊，確保讀值隨訊號消失而清除；並驗證音量增益比例與 dB 下降量一致。


## 去除標籤並分開儀表版面

使用者要求拿掉深綠色器材解說字，並避免分貝儀塞在幫浦與管線之間。刪除三個說明標籤及指示線，保留器材上的原生點擊區與無障礙名稱。將分貝儀移出照片，與器材圖並列在同一實驗圖框內，手機版置於圖下方；保持音訊與讀值連動。以幾何邊界檢查兩區不重疊，並確認空氣讀值不換行。

## 學習卡片格式統一

依使用者最新指示，第二、第三區塊的外框均使用第一區塊的共用 `.lesson-card`、側欄、提問／說明、雙角色對話、操作列與 `.fact`。參考 1.1、1.2 的內容順序；不再由獨立 CSS 覆寫為滿寬／置中標題。原核可示意仍作器材及互動配置的歷史參考，外框以本次格式指示為準。圖解與分貝儀使用內容欄的容器寬度切換配置，避免有側欄的平板尺寸擠壓操作。


## 改採融入桌面的數位分貝儀

使用者核可最新 `approved-tabletop-meter.png`，指定放大的桌上型數位面板與足夠器材間距。以同一底圖呈現外殼、腳座、桌面接觸陰影，讓分貝儀自然位於鐘罩外的左前方；取代先前獨立右欄及手機下置設計。面板標題「分貝儀」、紅色七段數字與 dB 為 SVG，數字與原無障礙 output 共用音訊 RMS 資料，不固定在圖內。移除舊款儀表與音量條，保留既有聲音模型、操作、教學外框及非現場實測註記。

新底圖為 1918×820，粒子自由空間、敲錘、表針及器材命中區均重新對齊。檢查包含可見數字段落筆畫、器材實際位置命中及場景內的留白，不再以儀表與整張照片不重疊作為要求。


## 移除鐘罩內可見空氣粒子

使用者要求寫實器材盡可能接近真實，指出空氣本身不可見、不需要藍色示意點。因此刪除第三區塊的粒子生成、透明度更新、SVG 群組及專用裁切區，並移除註記中的粒子敘述。保留透明玻璃底圖、敲錘、表針、定性空氣量、實際聲音增益及分貝讀值；第二區塊的縱波粒子模型不在此次修改範圍。

檢查改為初始、抽氣、接近真空、進氣恢復及手機各尺寸均不存在空氣粒子，同時持續驗證音量與讀值連動。


## 抽氣到下限時保留可操作按鈕

依使用者指示，到接近真空的下限時不再自動將抽氣模式切回待命，也不停用圖上幫浦或下方抽氣按鈕。空氣量維持下限；按鈕維持正常色彩、`aria-pressed=true` 與「停止抽氣」，再次操作仍可停止，停下後也可再次啟動而不突破下限。進氣可直接取代抽氣模式，原空氣充足時的進氣限制保留。

聲源關閉且已達抽氣下限時不持續要求動畫影格，但保留操作狀態；電鈴開啟時仍持續更新敲錘與音量讀值。驗證含下限停留、鍵盤停止／再啟動、直接點幫浦、手機觸控與進氣恢復。
