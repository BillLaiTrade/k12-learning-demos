# 3.3 第七區加入十二場景授權錄音

2026-10-31，使用者要求接手中斷的音效開發。新環境沒有前輪未提交音效／來源草稿，先同步兩 repo 最新 main，再保留十二場景大圖、介紹、OSHA 參考條件與情境帶，新增錄音試聽。此要求取代 decibel-explorer 決策中「不播放聲音」的限制；未增加麥克風或聲壓量測。

## 音源與授權

使用真實錄音，逐份保存作者、原作網址、授權、來源 SHA-256、段落、情境差異及修改。安靜書房採 TU Delft 圖書館自習室；自然景點採森林；一般交談採京都方言；舞廳採授權電子／放克舞曲，並非夜店現場。鍋爐為燃氣加熱鍋爐，非大型工業鍋爐房。重型機具改用大型 Kleemann 碎石設備，並非插圖的挖土機。這些差異在頁面可收合清單中告知。

NASA SCA 候選沒有音軌，不使用。另一份 British Airways Boeing 747.ogv 雖有 Vorbis 音軌，但解碼後全靜音（volumedetect 最大／平均皆 -91 dB），也排除。Flight take off.webm 畫面為螺旋槳機，非噴射機，亦不採用。起飛音必須另取可確認非靜音、來源描述確為噴射機起飛的錄影音軌。

原作授權逐檔適用，未重新以網站通用授權覆蓋；如採 CC BY-SA，衍生檔必須沿用同版本相同方式分享。沒有未授權、NC、ND 或不明限制素材。成品授權見 assets/decibel-audio/LICENSE.md，機器可讀資料見 recordings.json；來源 API 證據與 sources.json 在本輪 review/source。

## 響度與播放

先在相同採樣率／單聲道與短邊界淡入淡出後測量，再以固定增益統一為 -23 LUFS 基準；按場景順序安排 -40 至 -18 LUFS，每級 +2 LU。若任何成品真峰值將超過 -3 dBFS，整組共同下移，不削波或單獨壓平其中一段來湊數。重製腳本實際量測每檔成品並檢查響度及峰值。保留來源聲音與自然變化，不變調、不變速、不用合成噪音替代，不依真實 20～130 dBA 比例輸出。LUFS 僅是數位響度安排，不保證不同音色的主觀聽感等距。

點圖片／「播放場景聲音」重新播放目前錄音，停止後換場景保持安靜；播放或準備中換場景只允許最後選取的場景起音。沿用 lesson.mjs 的 AudioContext、activeRoot、source 與取消票號，不能另開一組失去管理的音源。短增益淡入／停止淡出降低切換不連續；離區、其他區起音、分頁隱藏、離頁均停止。下載／解碼快取不代表播放授權，必須在 resume 及 decode 後再核對票號；錯誤清除快取以便重試，不補假聲或回放錯誤場景。

頁面持續區分 OSHA 典型 dBA 參考、所選情境讀值與裝置播放音量，並保留舒適小音量提示。十二張既有插圖的原始 PNG、SVG 取景、前六區模型及單元小測保持。

## 驗證與交付

除原有前六區／小測回歸外，新增專項檢查每份實際播放 AudioBuffer 與成品解碼 PCM 完全一致、實測 LUFS／峰值／雜湊、圖片與按鈕重播、播放中點拖切換、取消／失敗重試／隱藏／離區／跨音源、手機真實觸控及桌機手機版面。測試紀錄、畫面、來源差異與部署確認由本輪 review 彙整。聽感仍會受使用者音響、裝置音量與環境影響，不把自動數位量測當作校準聽感或現場 dBA。

成品實測補充：為施工段峰值保留餘裕，全組共同下移 2.6 LU，最終約 -42.6 至 -20.6 LUFS，最高真峰值 -3.0 dBFS。短片段在低電平的絕對響度閘門會影響積分值，因此基準及成品均以實際輸出反覆量測校正「固定增益」，不改原作動態或用壓縮器補平。兩次重製十五檔雜湊一致。

## 2026-11-01 圖片優先與持續循環

使用者要求場景圖片佔更大版面，降低文字及分貝數字的視覺份量；並要求開始後持續播放，直到按停止，不再播完一段即結束。桌機圖片／文字欄改為 2.3:1，圖片最小高度增至 360px（中型螢幕 310px），分貝主數字上限由 80px 減至 48px，標題與介紹同步縮小。手機維持圖上文下，圖片由 2:1 增高為 16:9，數字改為 37.6px。沿用原始圖片及十二份音檔，不修改像素、錄音、響度階梯或授權。

場景 AudioBufferSourceNode 使用原生 loop，沿用成品已有的淡入／淡出邊界；同一音源循環，不透過 onended 反覆發起播放或增加並行音源。圖片／播放鍵仍可重播，播放中換場景繼續循環；停止後換場景不自動起音。離區、隱藏分頁、換其他區音源及離頁的停止規則保持。測試核對十二來源 loop、實際音訊時鐘跨過短耳語兩個完整週期仍播放／未新建音源，之後手動停止，以及原取消、重試、觸控和整頁小測回歸。

## 2026-11-01 播放控制移入介紹欄

依使用者附圖，將播放／停止按鈕及播放狀態移到右側情境介紹與條件下方。分貝情境帶直接接在場景圖／介紹區塊下緣，共用連接外觀，不再隔著整列播放控制與音量說明。非實際 dBA 的音量說明移至情境帶之後，維持可見。手機仍是圖片、介紹含控制、情境帶的順序；沿用持續循環與停止規則，不改音源或資料。

## 2026-11-01 統一播放入口

使用者核可移除重複播放入口的建議。圖片改為純展示，移除播放圖示、透明點播按鈕與事件；操作只留右側播放／停止。準備中顯示「載入中…」並停用播放鍵，播放中顯示「播放中」並停用，避免重複起音；停止或錯誤後恢復「▶ 播放場景聲音」與可操作狀態。播放中仍可用情境帶切換錄音，停止後換場景保持安靜。原循環、取消、重試、離區／隱藏／跨音源停止規則保持。此決策取代前面圖片點播與播放中按鍵重播的規格。

## 2026-11-01 加大安靜至施工的相對音量差

使用者試聽回報書房至施工雖有不同聲音內容，但音量差不夠明顯。舊版每級2 LU、書房至施工相差16 LU；施工段的尖峰使整組共同下移，平均音量偏低。新版保留來源及片段，先統一 -23 LUFS 基準，再使用教學用分段響度階梯：-46、-43、-40、-37、-33、-29、-25、-22、-19、-18、-17、-16 LUFS。安靜至施工主要每級3～4 LU，最高三段放緩為約1 LU，不依20～130 dBA實際聲壓比例輸出。

新版允許對突發峰值作限制：四倍過採樣、5ms預視、80ms釋放、約-3.5dBFS上限，關閉限制器自動補償增益。只調整數位播放動態，不換素材、不合成噪音、不變速或變調。原有成品邊界淡入淡出保持，來源／作者／授權及修改告知同步更新。此處取代舊版「僅固定增益、不作峰值動態處理」的製作限制。

實測書房-46.00、施工-19.11 LUFS，差26.89 LU；施工平均響度比舊版提高7.49 LU，書房降低3.4 LU。最高段-16.00 LUFS；全組最高真峰值-3.48 dBFS，低於舊版最高-3.00 dBFS，沒有以尖峰或削波製造大聲。數位響度差不等同聽感倍數；仍需使用者在自己的裝置、固定系統音量下試聽。沒有宣稱實際 dBA 校準或人工聽感驗收。

## 2026-11-01 替換不易辨認的列車錄音

使用者回報列車場景不像貨運列車經過。舊版取 Extemporalist 七分鐘環境錄音的296秒起十秒，內容偏一般車輛／環境噪聲。前次以音量高峰選段，未充分驗證聲源辨識度；本輪加入原作者內容說明及獨立YAMNet分類比對，不再以音量高峰代表列車特徵。

改用 felix.blume（Félix Blume）的 CC0「Train passing by in the Wirikuta Desert (Mexico, SLP)」，擷取45～105秒共60秒，保留鳴笛接續輪軌聲的較完整過程。原作者明示列車鳴笛、鐵軌振動及接觸式麥克風，未細分客／貨運；作為聲音示例，不冒稱插圖貨運列車現場或30公尺條件實錄，差異已列於公開來源說明。保留目標-25LUFS，實測-25.00LUFS、真峰值-10.86dBFS，其他十一WAV雜湊不變，維持既有音量階梯與循環／停止操作。

Google YAMNet對舊成品Train平均分數0.0332，新成品0.6429；新開頭十秒Train 0.9125、Train horn 0.7645，後段亦有輪軌／Clickety-clack特徵。這是模型輸出分數，不是正確率或人工聽感驗收；與原作者聲源說明共同用作選段輔助。分析工具與模型只在工作區，不新增網站依賴。來源、授權、擷取／音量修改、成品雜湊及音檔快取版本同步更新，train單獨升至v=3。
