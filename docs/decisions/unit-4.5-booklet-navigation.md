# 4.5 小冊導覽格式統一

2026-11-05依使用者截圖，修正兩個小測入口被一般學習區的綠色樣式覆蓋。以4.1實際booklet-route-link為準：24px金色圓形星號、上分隔線、相同字型／字級／間距，選取狀態為金色邊線與淺米底。兩入口可見文字統一為「單元小測 ①／②」，完整名稱保留在aria-label與title；連結錨點、內容與全部互動程式保持。

原格式比對只檢查一般導覽，參照fixture也漏收4.1的三條小測導覽樣式，因此先前格式通過仍漏掉此差異。本輪補齊原參照規則，擴充既有八種視窗比對：兩入口的未選取／選取狀態、圖標與原深連結操作，另在1366px及390px比對hover與鍵盤焦點。正式4.1及其他單元不修改。

一併補齊桌機斷點的一般導覽選取邊線，避免舊900px樣式把820px側欄四邊都染成綠色；只修正既定4.1格式的CSS覆蓋，不改導覽追蹤邏輯。
