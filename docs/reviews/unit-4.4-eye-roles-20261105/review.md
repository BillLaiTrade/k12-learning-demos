# 第七區：眼睛部位作用與核可版面

日期：2026-11-05（Asia/Taipei）。本輪為4.4第七區局部修訂。

## 依據與範圍

使用者核可[完整頁面示意](approved-layout.png)，另指定操作先於解說。實作順序為眼球與視網膜成像窗 → 物體遠近／水晶體調節 → 自動調節提醒 → 角膜、水晶體、視網膜的作用 → 收合補充。沿用正式小葵／阿公頭像與全頁版型，圖像由原有WebGL／SVG即時產生。

主圖區分背景、眼球內壁與透明水晶體，視網膜採弧形薄帶；新增成像區標記與對應放大窗，右欄保留唯一對焦狀態。角膜的主要會聚、水晶體調節會聚、視網膜固定接收影像各有可直接閱讀的說明。光學計算及圖外其他教學區不變。

## 檢查安排

- 既有眼睛模型5項、共用光學模型8項，涵蓋兩段折射、獨立物點、固定視網膜、遠近調節及第八區矯正、顯微鏡。
- 第七區實際瀏覽器專項：狀態、3D厚度、固定眼球、遠近與清晰度、光路偏好、鍵盤、觸控及WebGL備援；新增操作先後、三部位作用、單一狀態與變色檢查。
- 八種尺寸、四種條件共32組：1440×900、1366×768、1280×720、1024×900、820×1050、760×1050、390×844、320×844。檢查圖與成像窗分開、SVG完整、標籤不互疊、控制緊接主圖、說明在控制下方及無橫向溢出。
- 整頁回歸確認導覽、其他活動、四題小測與素材正常；公開部署與驗證結果於實際完成後記入規劃庫。

命令：`node --test --test-reporter=tap tests/unit-4.4-eye-optics.test.mjs tests/unit-4.4-optics.test.mjs tests/unit-4.4-eye-studio.test.cjs`；整頁另執行`node --test --test-reporter=tap tests/unit-4.4.test.cjs`。公開專項使用`EYE_URL`及獨立`EYE_CAPTURE_DIR`保存證據。

本紀錄不代表完整第五階段檢查或外部驗收。
