# 4.5 第二步：調整前後對照

2026-11-05（臺北）。依使用者核可的示意，只重排像素電視觀察室第二步「改同色像素」。第一、三步的可見版面與既有RGB／分組規則保持。

## 分工與操作

- 左欄「調整前」固定顯示所選原始色的圖片、色塊、RGB數值與三條等寬色光示意；原值為純文字，沒有可編輯欄位。固定是指不隨調色改變；換選另一種原始色時，才更新參考。
- 右欄「調整後」顯示即時圖片、目前色塊、RGB與原有0／128／255按鈕及0～255整數輸入。修改立即預覽，沒有新增套用步驟。僅依原圖相同RGB的一組像素變色，其餘保留。
- 圖片、色塊及RGB逐列對齊；兩側同時標亮有改值的通道，下方只列本次數值變更，未改時明示兩邊相同。還原回原始值並清除差異標示。
- 快速觀察、座標、選取狀態、同色數量及輪廓開關集中在共用工具列；取樣框拖曳、被動5×5鏡面、鍵盤、觸控與取消還原保持。

## 窄版與程式保留

依可用容器寬度，而非僅視窗寬度切換。620px以下仍並排前後圖片與色塊；RGB控制移至下方，每列標原值，避免狹窄按鈕及前後值相隔過遠。標題字型／字級沿4.1共同格式，不修改其他學習區與第一小測。

第二步共用原有canvas、取樣框與唯一一組RGB控制，只在切模式時搬至對照插槽，離開時還原原位置；保留節點、事件與草稿，不複製控制或新增模型。ResizeObserver僅依圖片寬度變化取消取樣拖曳，避免資訊換行誤取消。圖片、精確RGB數值、分組、整圖強度計算及快取保持，載入版本更新為tv-compare-20261105。無JS仍呈現第一步靜態內容，不提供假操作。

驗證沿用活動套件，新增固定參考／即時改色、差異標記、重設、同色換格保留草稿、節點／焦點與跨模式循環，以及各尺寸兩圖與RGB對齊檢查。公開版驗證後同步驗收紀錄。
