# 4.5 第三區：只在拖曳時顯示輔助光路

日期：2026-11-03（臺北）。使用者要求拖動手電筒時呈現燈頭至白幕光斑的輔助光路，清楚看見當前照射方向；停止操作、放下靜置後恢復無輔助線的畫面。本輪依既有修改與發布授權實作，不增加常駐開關或操作步驟。

在原mix-scene內加入絕對定位、忽略指標事件的SVG輔助層，只顯示正在拖曳的一支。拖曳超過原有4px判定門檻後，顯示該色淡光帶、方向虛線／箭頭及當前光斑的細虛線範圍；光斑輪廓依原180幕面單位半徑等比例顯示，範圍裁在同一白幕內。這些是光軸／瞄準示意，不把光帶當作真實空氣中可見光束或實際束寬。

立體模式從實際模型燈頭出口投影連到目前光斑中心，白幕使用實際canvas邊界，涵蓋緊湊版的等比例留白。為避免原本獨立示意鏡頭造成筒身／連線方向偏差，立體朝向依當前版面投影校準，使光軸與筒身軸線共線；大側向角度會適度取景，保留完整燈頭與尾端。器材材質、模型幾何及混光條件保持。

圖片備援沿用既有同模型PNG，採由原攝影機計算的軸心與燈頭中心作旋轉校準，不從圖框或滑鼠指標任意連線。立體／圖片切換或視窗尺寸改變時同步更新端點。只重繪姿態改變的立體器材，避免拖動提示增加無用的GPU繪製。

放開、Escape、pointercancel、失去指標擷取、視窗失焦或頁面隱藏時清除；取消仍回復拖曳前落點。單純點按、聚焦與鍵盤微調不留下提示。關燈時允許繼續瞄準，但只顯示中性虛線與目標範圍，不顯示發光帶，以免將關燈教成仍有照明。

輔助層不佔版面、不擋拖曳，也不增加前輪已收斂的高度。其性質放在既有摺疊模型說明，不新增器材遮擋標籤。原CIE混色、功率配比、光斑計算、燈具開關／快速排列、正式角色與其他區／小測保持，純光學模型不因本輪重跑。

檢查涵蓋實際燈頭投影／光斑端點與軸線共線、三種色光、極端瞄準、放開／取消／失焦清除、關燈、圖片備援、拖曳中尺寸改變及手機原生觸控，並保留13種視窗及整頁回歸。仍為第四階段逐區修訂。
