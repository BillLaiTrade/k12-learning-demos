## 外觀與核可概念核對

- `layout-reference.webp`：前輪討論的區塊示意。沿用上方標題與小解說、前後角色對話、左右觀察面板、三種視線捷徑、估讀及可選參考的順序。
- 依使用者最新補充，右側改為依眼睛位置投影的立體玻璃與刻線；沒有沿用示意圖的固定正面放大窗。原生 SVG 重新計算每一組三維頂點，無新增套件。
- 對話使用既有共用頭像，沒有使用示意圖生成的人物素材。前三區與結尾小測 HTML 已逐字比對不變。
- `desktop-level.webp`／`desktop-high.webp`／`desktop-low.webp`：三種觀看角度。平視時液面在 37／38 中間；俯視看起來偏高，仰視看起來偏低。玻璃邊緣、刻線及數字隨透視改變，液柱的世界座標固定。
- `width-1024.webp`／`width-390.webp`：窄內容欄適應；手機改為上下觀察窗，維持可讀的刻度與可按的按鈕。另檢查 1440、768、600、320px，沒有水平溢出。
- 截圖中發現並修正舊錨點造成的空白／框線，以及放大窗頂端攝氏單位裁切；保存的是修正後畫面。

## 功能檢查

執行：

```sh
CHROMIUM_PATH=/usr/bin/chromium node --test tests/unit-5.1.test.cjs tests/unit-5.1-dual-scale.test.cjs tests/unit-5.1-water-lab.test.cjs
```

本機 32 項通過，0 失敗、0 跳過（含 runner 外層）。

- 實際滑鼠拖曳具有連續中間位置、上限鉗制、放開後停止；取消指標與鍵盤 ↑ ↓、Home 操作通過。
- 390px 的 Chromium 手機環境，透過 CDP 真實觸控拖曳及點按驗證。只在眼睛命中區禁止瀏覽器捲動。
- 三種視角的玻璃與刻線路徑不同，液柱模型固定 37.5°C；34–41 每度恰有一條刻線，沒有更細分度。
- 以攝影機／刻度深度的射線交點檢查視差方向與投影一致；平視液面位於 37／38 中間。
- 空白、超出範圍輸入、有效估讀、Enter 提交、角度紀錄、參考顯示／隱藏通過。教學區不判對錯、不自動填答案。
- 第二區冰塊漂浮／融化、加熱／停止／重設，第三區雙刻度、換算、輸入與綠線拖曳，以及結尾排序、原理、估讀、容許差距與重設全部回歸通過。
- HTML 閉合與 ID 唯一性、既有腳本語法、`git diff --check` 通過。

## 模型界線與交付

玻璃反光以漸層描繪，採幾何透視，未模擬完整折射。刻線面與細管前後距離、眼睛移動角度為教學放大；不能用偏移量推算真實儀器的誤差。放大不提高原工具精度。
