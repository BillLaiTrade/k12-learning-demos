# 2.3 材料桌視窗限制與鑷子整合

2026-11-04（臺北時間）。依使用者要求，第四區鑷子移入材料桌，移除下方「取用工具」列；同時修正第三區留白過多、桌面超出一個視窗及左右比例不協調的問題。

第三、第四區維持材料與名稱分開、直接點選的排列，但桌面使用有限且隨視窗高度調整的空間。材料頁不再沿用長操作說明的標題留位；步驟欄依內容收齊，不拉出大段空白。第四區以三個瓶類、固體與工具、導管及玻璃片三排呈現，鑷子靠近大理石。

第四區材料辨識改用各物品的獨立素材；移除原整張場景的預覽覆蓋與導管額外點選區，八件器材直接透過各自的按鈕開啟介紹。管線仍使用同一雙孔塞、兩段固定玻璃與橡皮管；素材視窗限制在各自範圍，不帶入圖集中的鄰近物品。介紹視窗同步使用正確裁切。

驗證以整個操作區為準：材料桌、播放按鈕、字幕及導覽都要落在視窗高度內，不只檢查材料圖。涵蓋一般桌機、1366×768／1280×720筆電、平板及390／320手機（手機導覽收合）。另驗證十八件材料的名稱、鑷子／導管本體原生觸控、無JS與原有實驗及字幕。未變更反應、集氣或播放時間。
