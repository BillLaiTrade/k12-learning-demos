畫面元素，如何代表七個學習區塊？

學習內容圖片中的聲源、道具或情境下方接續的內容
① 響度與振幅撥弦、敲擊與聆聽同一聲源的大聲與小聲，接到下方固定頻率的振幅比較。
② 音調與頻率不同尺寸音叉、長短不同的發聲器材由聲音高低的差別，接到頻率與振動次數。
③ 琴弦的音調有琴橋與調整裝置的琴弦箱有效弦長、張力與音調。
④ 空氣柱的音調同類、不同長度的直通開口管空氣柱長短與音調。
⑤ 音色與波形琴弦、管子、音叉及演出樂器不同聲源的聲音特色；精確波形留在本區操作。
⑥ 聽覺範圍人物、小狗聆聽，蝙蝠與耳朵圖鑑人耳與動物的聽覺範圍、超聲波。
⑦ 分貝的辨讀聲級計、祖孫交談、舞台與電影活動線索由生活情境延伸聲級資料；對應一般交談、音樂會與電影院的案例。
結尾小測整個校園聲音探索展示協助展示台設定指定的頻率、振幅與音色。

首圖提供故事與觀察線索；精確頻率、振幅、波形及聲級資料，在學習區塊中比較。狗與人是在聆聽一般聲音，圖鑑則帶入蝙蝠的高頻聽覺；聲級計提供分貝的情境線索。
