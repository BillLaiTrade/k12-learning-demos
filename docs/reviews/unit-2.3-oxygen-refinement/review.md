# 2.3第三區氧氣：核可示意圖實作

2026-10-31，沿用main `fd92b333`，僅精修現行第三區氧氣實驗。使用者核可先前生成的修正版示意圖；[核可參考](approved-mockup.png)。

## 實作與圖像界線

維持單元滿寬標頭、問題標題、字體、配色及共用小葵／阿公頭像。材料與瓶外排氣參考常駐，上方四步連續更新水位、導管、氣泡與玻璃片；下方保持兩組木條同步近景，沒有另一條步驟列。必要結果預設及無JS可見，共同起點另註，動態圖說不提前宣告完成。

本輪依示意圖改用六張生成玻璃／木條／材料材質底圖加即時SVG層，停止載入舊WebGL渲染器；不是影片、實驗照片或單純切換整張示意圖。下方兩組共用相同玻璃及木條素材，火焰附在木條尖端。素材約234KiB，無新套件／CDN。手機保留全景，另以同一動態SVG物件放大瓶口和水位。

12.6秒製氣、6.2秒比較皆為教學時序。氧氣無色；水色、箭頭只供辨識。瓶內氣泡限定剩餘水域，導管到位才排水、完全退出才開始蓋片。保留催化劑不增加理論總量、木條為燃料及未復燃不能唯一辨認氣體的說明。底部改為兩項實驗結論；醫療用途留在第二區。
