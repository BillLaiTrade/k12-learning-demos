# 井深小測製作檢查（2026-11-01）

依使用者核可示意圖`exec-e8d5b0bf-5b0d-4785-8ad0-cb508f600b69.png`，完成小葵在井口朝乾井底喊話、回聲紀錄與井深核對。插畫由獨立素材重製、沿用共用角色，波線／泡泡／按鈕分層，非整張示意圖直接貼入頁面。初始井底不可見且無深度答案，核對後才呈現深度與往返聲路。

本機41項通過：井深模型／PCM3項、既有回聲模型4項、小測瀏覽器11項、整課10項、第五區13項（含各外層）。實際AudioContext核對原喊聲與回聲共用緩衝區、增益1／0.45、最末0.65、排程間隔與畫面回聲開始紀錄一致、非靜音且不削波。測試涵蓋答案各狀態、換題與重喊、跨區／背景取消、延遲啟音取消、失敗重試、鍵盤／真實觸控、減少動態與9種寬度。

已檢視桌機初始／核對解析、390px與320px；初版等高裁切導致人物左側被切，已改左側定位並重新檢視，人物與井口清楚可辨。另在實際0.060／0.441秒擷取綠色喊聲與橙色回聲動畫、檢查泡泡和波線位置。五個學習區HTML逐位元組保留，雜湊見preserved-lessons.json。
