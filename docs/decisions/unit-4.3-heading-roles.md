# 4.3 標題、副標與操作提示分工

2026-11-05（臺北）。使用者依[五點統一規則](https://github.com/BillLaiTrade/k12/blob/main/docs/decisions/learning-block-heading-subtitle-rules.md)要求檢查後，核可「按照建議修改」。依序處理第二區大標、第二至五區副標、第三區操作提示／對話及第二區桌面捲動用語。其餘內容保持。

| 區 | 大標 | 副標 |
| --- | --- | --- |
| 1 | 光在不同介質中一樣快嗎？ | 介質與光速：同時出發，比較傳播快慢 |
| 2 | 光正對水面照下去，會轉彎嗎？ | 垂直入射：光速與前進方向的比較 |
| 3 | 光斜著進入，會往哪裡偏？ | 斜射與折射：入射角與折射角的關係 |
| 4 | 光由水或玻璃射回空氣，方向又會怎樣？ | 折射方向：光由水、玻璃進入空氣 |
| 5 | 折射光路能倒著走嗎？ | 反向傳播：正反方向的折射光路比較 |
| 6 | 水底的物體看起來在哪裡？ | 視深：分清楚實際位置與看起來的位置 |

第二區導覽同步新大標。第三區阿公改引導比較交界前後方向與角度；「拖曳光源調整角度；點擊光源發射。」移至實驗圖上方，沒有新增說明面板。第二區改「左右捲動」並同步無障礙區域名稱。

第四區副標不再先說偏離法線；適用條件「斜射且發生折射時」移到圖旁結果圖例，沿用觀察完成後的顯示政策，0°隱藏此斜射條件；原0°方向不偏折與較深入說明保持。不增加全反射、模型、活動、圖片或手機專項，維持第四階段。
