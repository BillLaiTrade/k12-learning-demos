# 4.2 第一區緊湊操作與正面參考

日期：2026-11-05。依使用者核可示意調整，並移除其明確不要的「稍向左／稍向右」。

## 版面與操作

單一自由操作的3D畫面，唯一回正按鈕位於右上方；下方只有兩個燈光開關與小型參考列。原正面預設一併整併，第一區共三個按鈕。主畫面隨視窗高度調整；桌機參考圖200×約122px，手機縮為列寬約三分之一。參考圖、材質、器材、燈光與自由轉動範圍沿用原版本。

回到正面會重設方位與俯仰、開啟兩燈供對照，不再捲動頁面。保留滑鼠、鍵盤及原生觸控操作；WebGL不可用時仍可閱讀參考圖。第一區三句核可對話、第二區起HTML及PNG原檔未變，見preservation.json。

## 檢查

- 第一區專項13項（含外層）通過。光源條件、光錐、四種開關、反光像素、自由方位／俯仰、取消、鍵盤、同一CDP裝置的觸控拖曳與回正均正常。
- 整頁針對性回歸5項（含外層）通過：導覽／標頭、實際燈具點擊／拖曳、第四區及WebGL備援；未變動的分享與延遲潛望鏡素材專項未重跑。
- 三個預設按鈕移除後，側面取樣使用真實滑鼠拖曳至±38°。主畫面與PNG長寬比不同，依各相機投影取樣同一材料位置，亮度容差維持6；沒有重製或另行調亮PNG。
- 六種寬度1440／1024／768／760／390／320沒有橫向溢出、器材裁切或小於44px的按鈕。縮短畫面後改驗材料實際像素寬度（寬版至少130px、其餘至少64px），替代原先佔畫面四分之一的比例假設。
- 五種視窗1440×900／1366×768／1024×768／390×844／320×667可同時容納整個操作區；手機依既有導覽高度留出上緣，使用elementFromPoint確認按鈕沒有被遮住。量測及截圖見viewport.json與viewport-*.png。
