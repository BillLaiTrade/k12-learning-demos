# 4.3 狀態牌、重設按鈕與視深預覽

2026-11-07，依使用者三項連續回饋：第一區右側三張到達狀態牌採與左側相近的暖色斜面及接觸陰影；第三與第四區刪除各自的重設按鈕，發射、再次發射、調角及介質切換保留；第六區拖眼睛時降低水槽邊緣的藍色顆粒。

視深互動畫面先從160px提高至320px的worker預覽，無worker時由176px提高至256px；僅對預覽中的孤立青藍像素作局部平滑，保留相連水面及原射線幾何。停止後仍回到原高解析度，左右兩圖仍消費同一幾何快照。原圖檔、材料、光速、教學內容及其他區域保留。

原直接依賴重設的測試改以實際調角與再次發射檢查，並檢查兩按鈕確實不存在。新增真實鼠標拖曳、連續預覽與孤立藍像素／水面像素檢查；測試量測及截圖見`docs/reviews/unit-4.3-desk-controls-depth-20261107/`。正式使用範圍為桌機／筆電；未新增手機版面設計。
