## 參考與串接原則

- 1.1以小葵、阿公、鉛筆、直尺與紀錄本帶入量測，後續反覆操作同一支鉛筆與刻度；1.2延續同一顆隕石，加入量筒、電子秤及紀錄，串接體積、質量與密度。
- 3.3依相同方式使用固定的一張聲音展示桌：琴弦箱連第③區，長短不同的同類開口管連第④區，喇叭／旋鈕／平板連第①②⑤區及結尾聲音設定任務。
- 人物聆聽與狗／蝙蝠資料卡連第⑥區；聲級計與紀錄本提供第⑦區分貝辨讀的情境線索。這不新增實際量測功能，不擴張為噪音或聽力保護課程。
- 首圖負責故事及器材辨識，精確的波形、頻率與模型仍在各學習區的互動圖中呈現。生圖內平板曲線不作為定量讀圖題。
