# 第六區眼睛與觀看窗的同高接頸

2026-11-04。使用者認為兩區的連接仍不自然。前版將上、下邊線拉到整張右圖的上下角，長度差距大，像繞到框邊的接線；本輪集中修正這個關係。

桌機改成眼睛托框向右伸出的窄幅金色接頸，在眼睛高度直接接入觀看窗左邊的小開口；開口與觀看窗四周由同一條圓角輪廓連續繪製，沒有直穿接頸的左邊框線，也沒有拉向底角的長邊。上下邊只輕微展開約4px，長度接近直線距離。接頸使用香檳金明暗與細陰影，沒有箭頭或流光。

接頸隨眼睛前後移動伸縮，觀看窗與世界位置保持。滑軌改放在眼睛下方，補上短支座，避免接頸遮住眼睛右邊的軌道。只移動介面軌道，未移動瞳孔、光路端點或相機。

手機上下排列時，移除沿整個台面外緣繞行的兩條線；右標題的同款眼睛直接以短接頸接入觀看窗上緣，同樣與外框共用連續輪廓。標題仍明確寫「這隻眼睛看到的畫面」，原眼睛控制、ARIA對應及焦點配對保持。

不更動版面尺寸、教學標籤、加放水、物理模型、右側繪圖或材質。沒有新增控制或改動前五區與小測。維持第四階段，非最終核可。

既有連線檢查改驗同高／短路徑、手機標題眼睛到上緣小開口及共用輪廓；保留9尺寸的27組連接、135組標籤與光路避讓、44px及無溢出條件。本機初輪4項、滑軌就位後3項補驗全過；原光學及加放水未因本次介面連接而重跑。見[本機檢查](../reviews/unit-4.3-depth-neck/review.md)。
