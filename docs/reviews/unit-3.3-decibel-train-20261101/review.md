# 列車場景錄音更換

2026-11-01。使用者回報列車聲不易辨認。舊十秒成品內容分類以一般車輛、道路／環境噪聲為主；原七分鐘錄音雖標貨運列車，296～306秒並非辨識度較好的段落。

改用Félix Blume的CC0墨西哥列車經過實錄，作者原文明示Train horn、railway vibration、contact microphone；45～105秒共60秒，鳴笛後接較完整輪軌聲。來源授權與原檔SHA-256見[全站來源檔](../unit-3.3-decibel-audio/source/sources.json)；候選API證據在source/candidate-evidence.json。作者未細分客貨運，公開來源清單明列聲音示例及差異，未把不明車種冒稱插圖貨運列車現場。

YAMNet輔助驗證見old-cues.json／new-cues.json，模型與版本、輸入／成品SHA-256及官方下載URL見classification-method.json。分類分數非人類辨認正確率，未冒稱人工試聽。可在工作區安裝ai-edge-litert 2.3.0，核對官方模型／類別表雜湊後執行：

`python classify-cues.py 音檔 模型tflite 類別csv 輸出json`

分析工具不進入網站依賴或播放流程。舊Train分數0.0332，新平均0.6429，開頭十秒Train 0.9125／Train horn 0.7645，後段有輪軌節奏。另查核兩份明示貨運的影片（俄國輪軌近錄、日本白岡站通過），綜合內容與分類選取鳴笛及輪軌更集中的示例；沒有使用其音軌或改動其授權。

新成品維持-25.00LUFS／真峰值-10.86dBFS，六個十秒窗口約-29.15至-22.59LUFS，保留列車經過的自然變化。其他十一WAV逐一核對雜湊完全不變。播放中的片段變長至60秒，檔案約2.88MB，仍只在選中播放時下載並解碼，沿用載入／取消／重試／循環機制。

本機音效與整頁小測15項全過，0失敗／略過，核對新版PCM、來源授權與雜湊、音量階梯／峰值、單一按鈕、循環、換場景、慢載取消及重試、手機／六寬度及整頁小測。原圖片與分貝參考不變；公開部署與公開新版音檔驗證另存課程repo。
