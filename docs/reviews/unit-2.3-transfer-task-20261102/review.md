# 瓶口動作補正與二氧化碳排水集氣小測

2026-11-02，使用者先要求彙整再修改，最後明確授權全部更新。三項為鑷子／石塊由瓶口進出、試藥瓶由實際瓶口出液，以及把最後小測改成二氧化碳排水集氣的操作遷移。第四區保留向上排空氣法；第三區與第一、二、五區HTML逐段不變，見preservation.json。

## 動作修正

原斜線到瓶頸內的插值沒有經過瓶口上方，退出也可能穿側壁。現在每塊先向上提起、在瓶口上方對齊，再沿瓶頸軸線放入；鑷子由同一路徑退出，才在上方回到水平瓷碟。操作21秒、五個石塊物件守恆。獨立取內壁多邊形檢查所有石塊及鑷子的進出交點，必須在瓶頸中央；沒有只驗證終點。

試藥瓶實際500×810，前版誤用440×440。現在依實際出液邊緣(116,83)換算，瓶身旋轉平移及流線起點共同更新。已目視酸液從傾斜試藥瓶的下側開口流入錐形瓶口。

## 小測

單一小測、三步安排：選兩種材料、決定水量／瓶位／正式出口、調整六個操作先後。裝置預覽即時回應選擇。播放依學生安排執行，遇到有問題的操作停下並給回看連結；可保留安排調整重試，正確時完成水下蓋片及取瓶。按鈕、背景暫停／繼續、鍵盤排序、真實觸控、跨播放器互停及局部重設均可用。

材料需大理石＋稀鹽酸；集氣瓶滿水倒置且瓶口在水下，正式出口在瓶口內。判定依科學前提，接受合理交換的準備／製氣順序。先排氣後收集、先撤管後封口；準備倒置時先遮口，入水後才移開玻璃片。U形玻璃管形狀固定，整組從瓶口下方移入／退出；橡皮管定長。二氧化碳部分溶於水仍可用排水法，滿瓶示意以反應物足量為前提。RSC https://edu.rsc.org/experiments/generating-collecting-and-testing-gases/693.article 明列兩法；未宣稱已取得三版課本的完整步驟。

未新增套件、圖像或外部服務；未啟用JS有靜態裝置圖、可讀材料／步驟與科學說明。原六題小測不再載入，頁面仍只有一個小測、一個form。
