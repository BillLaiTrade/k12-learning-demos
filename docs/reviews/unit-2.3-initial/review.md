# 2.3 空氣：八區可操作初稿

日期：2026-10-29。依使用者「依稿製作可操作網頁初稿」的指示製作。

正式頁面：<https://billlaitrade.github.io/k12-learning-demos/units/2/parts/2.3/>

## 完成範圍

- 七個教學區塊與一個整合小測，使用新編號 2.3 及 `#s1`–`#s8`，第二單元入口已可進入。
- 倒扣杯可用拖曳、鍵盤、按鈕及滑桿操作；垂直浸入允許空氣壓縮，傾斜逸出的空氣在杯口仍浸水時不會自動補回。氣泡只短暫出現，濕紙狀態保留到重設。傾斜時的進水為定性剖面示意，不是流體模擬或精密測量。
- 第02–04區共用鋼絲絨實驗狀態、氣體體積與器材幾何；原始記錄、即時觀察及回看分開。先保存100.0 mL，反應中有水位差時約79.3 mL；延長觀察及對齊內外水面後才記錄79.0 mL。
- 對照維持100.0 mL、不改寫主實驗；回看保留記錄，重做主實驗才清除前後值及比例圖。器材可直接點選用途，也有文字按鈕。
- 乾燥空氣100份圖、已知氣體木條比較、含水氣／只看乾燥部分的比例圖；氣體保持透明，圖表顏色只供分類，二氧化碳不重複計入。
- 小測獨立使用150→120 mL示例，提供空白、計算基準、成分及助燃觀念的回饋；修改後重新判定，清空不影響主實驗。
- 沿用共用人物頭像，器材採SVG，無新增套件、CDN或生成圖片。
