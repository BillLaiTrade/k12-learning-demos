# 4.5 第三區：開啟時的金色輪廓光

日期：2026-11-03（臺北）。使用者先要求開／關差異更明顯並先看提案；比較圖包含金色輪廓光、底部發光墊、整格金框。使用者明確選擇第一項並要求實作。本輪採貼合器材外形的細金邊與柔和金色光暈，保持下方名稱、不新增開／關文字。

使用零尺寸、不接收指標的SVG濾鏡定義，僅在原data-on=true時套用至圖框。從實際顯示的透明圖像取得輪廓，先將alpha低於0.5的接觸陰影排除，再以1.5單位膨脹產生細邊、4單位模糊產生外暈，金色填色後與原圖合成。金屬內部原圖最後繪製，保留材質；關閉時移除金邊／光暈，沿用原淡化。效果靜態、不閃爍，金色只標示操作狀態，不改紅綠藍光束或白幕。

濾鏡在器材圖框而非整顆按鈕或名稱上，沒有矩形金框／光墊。跟隨立體器材姿態或PNG旋轉，自動適用WebGL不可用及失效備援。定義保持在獨立SVG，不依賴拖曳輔助層的顯示狀態，所以靜置時仍有金邊。版面尺寸、觸控範圍、名稱、點按／鍵盤、拖曳／取消與快速比較全開功能保持。

模型、幾何、材質、PNG、正式角色與所有HTML內容保持，只加視覺濾鏡及程式快取標記，不新增套件或資產。仍為第四階段。

新增金邊專項5項：三支真立體靜置、開關／鍵盤／快速比較、拖曳與取消、WebGL失效及手機PNG原生觸控。比較同姿態有／無濾鏡的實際像素，核對輪廓外金色像素、金屬深處近乎不變、四角無矩形框及白幕像素不變；包含小數CSS邊界的截圖對齊。搭配快速比較4項與光束8項。本輪整頁34、版面15及純光學未重跑，透過保留檢查確認未改內容。

並行跑兩組軟體立體渲染時，光束首項點按曾等待逾時；未放寬門檻或改產品事件，改為單獨重跑後8項通過。首次金邊專項的手機截圖因小數位置包絡多1px而尺寸不符，已按實際截圖邊界對齊alpha來源後重驗；這是量測修正，不是放寬金邊判定。
