# 第三區斜入小車連續動畫

2026-11-03。使用者要求第三區三格小車示意比照第二區做成動畫。

- 沿用第二區輪胎／車軸／地面質感與展開播放、完成重播方式，改為單一連續場景及即時階段說明。
- 固定輪距的剛性車軸，輪心先後進入下方地面時各自從100降至55示意單位／秒；僅兩輪速度不同時改變方向。兩輪皆進入後同速沿新方向前進，不在結束後繼續旋轉。此數值僅使類比易看，與水／玻璃的光速比例及實驗角度不聯動。
- 保留法線、行進軌跡與方向箭頭；文案連結波前各處先後變慢，明確保留光不受摩擦的類比限制。
- 一般偏好展開自播；減少動態時手動開始。收合／離屏／文件隱藏停止保留進度；再次播放可繼續，完成可重播，無閒置動畫迴圈。
- 桌機圖文並列，手機單欄，取消三格圖橫向滑動。第二區動畫與第三／四區實驗控制、角度和同視窗配置保持。

驗證使用實際瀏覽器時鐘檢查運動幾何、停止／重播、七寬度與原生觸控，另做實際正常時鐘播放檢視。維持第四階段修訂，待使用者檢視，不代表外部驗收或最終核可。
