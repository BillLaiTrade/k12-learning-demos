# 第三區像大小變化的明確標示

日期：2026-11-04

- 三個F外情境由「變大」改成「實像變大」。
- F內補上「虛像變小」，比較的是虛像線性大小，非屏幕投影或固定眼位的視角。
- 無窮遠物點與F列改為「—」，附簡短說明為不作大小比較；保留無窮遠物點形成點像的正確資訊。
- 表下說明分別交代F外重新對焦的實像及F內的虛像。

依既有薄透鏡模型確認3F→2.5F、2F→1.75F、1.75F→1.5F的實像變大；0.6F→0.5F、0.5F→0.3F的虛像變小。實際瀏覽器讀取新欄依序為「—、實像變大、實像變大、實像變大、—、虛像變小」，手機版目視無截字，未發生頁面錯誤。純文字修改，保留既有工具排序與列點選功能。
