# 2.2 聲音示範素材

- `sound-story-opening.png` 為開場情境圖。
- `ruler-suspended-background.png` 是依原教室素材調整的背景圖：只有左側一張桌子，右側為桌外空間，避免把尺的懸空段誤看成搭在另一張桌面上。
- `ruler-flat-assembly.png` 為參考開場圖姿態產生的透明鋼尺與夾具素材：寬尺面朝上平放，自由端斜向桌外伸出；金屬紋理、反光與刻度保留在素材中。刻度供辨認尺身，並非量測互動。
- SVG 將素材分為不動的夾具／固定段，以及隨平滑曲線變形的懸空段；固定端位移及斜率為零，自由端位移最大。刻度與金屬紋理隨尺身彎曲，振幅隨時間衰減；按住停止時立即恢復靜止。
- 可直接點擊懸空尺面撥動，再點一次會重新撥動；觸控、Enter、空白鍵及下方播放按鈕均可操作。透明點擊區隨彎曲更新，背景與夾具不會觸發撥動。
- 顯示時降低素材向下斜出的投影角度，使尺身更平緩地伸出桌緣。尺面點擊區關閉瀏覽器預設矩形焦點框與觸控高亮；鍵盤焦點僅沿尺身提示，不顯示矩形框。
- 畫面刻意放慢並放大彎曲供觀察；它與 Web Audio 合成的彈振聲不是相同播放頻率，不作為實際頻率的量測模型。
- `ruler-clamp-background.png` 和 `steel-ruler-cutout.png` 為保留的舊版素材，現行鋼尺示範不再載入。
