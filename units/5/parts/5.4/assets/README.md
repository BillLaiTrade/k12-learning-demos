# 5.4 熱對物質的影響：可操作初版

依使用者核可六區及2026-11-06「先製作整頁初版，再逐區優化」指示製作。學生頁統一稱「單元小測」，無逐區評分。

## 檔案與狀態

- `thermal-model.mjs`：融冰／升溫／沸騰的能量分段模型，銅球直徑、水密度近似、固定量近似定壓空氣、玻璃相對膨脹、反應資料及六個整合觀察點。
- `thermal-art.mjs`：本課原創SVG器材、曲線與反應示意；同一狀態生成畫面與讀值。SVG漸層ID與讀值ID隔離。
- `thermal.js`：六區獨立狀態、動畫中斷與續行、導覽直接讀取標題及更名連動、單一小測作答與回饋。
- `thermal.css`：局部器材、版面、控制及手機基本版面；沿用`units/5/assets/unit-format.css`，不修改其他單元。
- `thermal-opening.svg`：由本課器材繪圖程式輸出的原創首圖；PNG是同圖的1240×720分享相容版本，以Chromium擷取SVG，不是實驗照片或生成實錄。
- 共用角色直接引用`shared-assets/characters/dialogue-character-avatars.png`，不建立副本。

## 科學模型與來源

1. 初始50g冰＋50g水約0°C，以冰熔化潛熱334J/g、水比熱4.18J/(g·°C)、汽化潛熱2260J/g的近似值，從累計吸熱量求冰、水、蒸氣量與溫度。學生不計算潛熱，圖表不把播放秒數當真實實驗時間。淨供熱加速；停熱忽略散熱並保留狀態。蒸乾後停止，溫度顯示「—」。冰塊形狀、液面與器材比例示意，不以其量幾何體積。
2. 銅球20°C直徑30mm、線膨脹係數17×10⁻⁶/°C；80°C約30.0306mm，超過室溫環孔30.020mm。右上尺寸差放大圖不是實際變形量。水浴為加速調溫，球在調溫時顯示於水浴內，試通過時移至環。
3. 0～60°C液態水採常壓密度的經驗近似式，100g除以密度得體積；約4°C密度最大。同質量冰採約109mL，另作變態比較。不宣稱100g水在所有溫度都等於100mL。
4. 空氣20°C參考100mL，固定氣體量、近似定外壓，採絕對溫度比例求60°C體積；模型含20個示意粒子，數量不因升溫改變。
5. 水製溫度計以20°C水體積為初始容器容量，代表玻璃體積膨脹係數27×10⁻⁶/°C，細管截面5mm²。水增量－容器容量增量＝細管餘量；三條長條同尺度。液柱差放大顯示，只比穩定狀態，不模擬玻璃先熱的液面暫降。
6. 含水硫酸銅加熱脫水為吸熱，冷卻後無水硫酸銅與少量水水合為放熱。動畫是已知反應的定性呈現，不是色變即證明反應；提供物質身分與能量方向。兩例分開準備，不把前一例的餘熱當反應放熱。

來源：[OpenStax狀態變化](https://openstax.org/books/physics/pages/11-3-phase-change-and-latent-heat)、[OpenStax熱膨脹](https://openstax.org/books/college-physics-2e/pages/13-2-thermal-expansion-of-solids-and-liquids)、[RSC含水硫酸銅反應](https://edu.rsc.org/experiments/a-reversible-reaction-of-hydrated-copperii-sulfate/437.article)。反應及銅膨脹參考值於本輪另作來源核對。水密度經驗近似限本課溫域，不延伸為精密物性表。

## 單元小測初版政策

一個小測、六個觀察點，依序選解釋並保留作答，可返回修改；缺答不往下。最後統一核對，逐點說明理由與是否符合證據，不累計遊戲分數。重新作答清空六項與回饋。此為本輪完整初版中的可檢視設計，後續依使用者逐區意見調整，不宣稱已逐題驗收。
