# 4.5 觀察室：先看合成色，再看 RGB 與同色群組

2026-11-05（臺北）。依使用者累計四項回饋，一次修訂並公開供檢視。

1. HTML、載入前、無JS、初始化及重新整理皆從「1 看像素」開始。初始白雲像素，三色保留原值；不預先進入整圖關紅示例。
2. 原圖／目前圖以同一3×3範圍框、中央一格與放大鏡圖示標位置，取消星狀十字。右側常態顯示有格線的同一3×3局部，中央雙色金框；點圖、鄰格、快速點或方向鍵均更新兩圖與放大區。邊界空格禁用、標記不超出圖面。
3. 局部放大各格呈現真正的合成色，選中白色就是白色；下方再列原本／目前的 RGB 色條、數值與合成色。所有視窗維持上下層次，不再把放大格畫成RGB條紋。名稱為便於閱讀的概略色名，顯色與數值仍用原始資料。
4. 第二步改名「改同色像素」。初次進入自動選白雲，原圖中RGB完全相同的352格整組套用通道開關；包括其他白色位置，雲的陰影因RGB不同不包含。原圖以金色輪廓、文字及數量標範圍；結果圖不加整組覆蓋，方便直接看變色。處理後點圖仍用該位置原始RGB選組，避免遮罩後異色合併。可選其他顏色；換選後先前組回復原圖，只有當前組套開關。全圖模式影響全部9216格；兩模式開關獨立、還原不累積。

保留96×96原圖、3842色、三種通道開關、兩個小測的共同格式、五學習區及第一小測。無新圖片、套件或外部服務；放大、顯色與輪廓由同一RGB資料即時計算。舊單格模式與原先全圖關紅初始狀態為歷史，由本決策取代。

驗證：12項模型檢查（含八種遮罩、每個同色群組、352白色、未選組不動、還原及輪廓邊界）；活動檢查覆蓋初始第一步、實際Canvas像素、兩圖／放大／RGB同步、群組原色選取、七種視窗、觸控、鍵盤、無JS／WebGL、失敗重載及兩個小測狀態獨立。公開後保存本輪結果，舊模型10／活動22不是本輪計數。
