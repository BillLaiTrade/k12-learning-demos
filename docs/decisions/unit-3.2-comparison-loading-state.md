# 3.2 第16項：互動未就緒時提示並停用操作

日期：2026-11-01（臺北）。使用者選擇 A，第4、5區的比較圖與操作尚未初始化完成時顯示提示、停用按鈕，成功完成後才恢復操作。

- 正式頁與獨立預覽都以靜態HTML提供「互動功能尚未載入，請稍候或重新整理後再試。」；停用JavaScript或主程式／相依檔載入失敗時仍可見。
- 初始三個控制按鈕均disabled；比較區維持inert及aria-busy，防止初始化途中生成的部分操作被點擊或鍵盤啟動。提示與靜態教學對話位於inert區域之外，仍可閱讀。
- 各區建立比較圖、綁定操作並完成初始繪製後，才開放按鈕、移除inert／aria-busy並隱藏提示。
- 各區分開處理初始化例外；失敗區保留停用與「互動功能未能載入，請重新整理後再試。」提示，另一區仍可完成初始化。恢復網路後重新整理可重新載入，不新增自動重試。
- 正常初始化後的物理模型、播放／暫停、個別敲擊、結果及小測判分保持；本項未新增靜態代表圖或改動其他區塊的載入方式。

本輪16項盤點均已逐項決定；第07項仍依既有決策暫緩，其餘保留現況事項未宣稱修正。單元維持第4階段，未視為外部驗收或最終核可。
