# 3.3第六區改為裝置上的頻率探索

2026-10-31。原第六區只展示資料、沒有試聽。使用者提出探索自己可聽頻率，再核可持續播放／暫停、彩色頻率帶及手動記錄兩端的示意圖並授權製作；此後續核可取代初版「不播放、不作個人測試」的互動限制，但仍不提供醫療聽力診斷。

採20～20000Hz、1000Hz起始，低固定數位增益的單一正弦振盪器；播放中平順調整同一節點頻率，音量不自動補償。彩色帶是頻率選擇工具，非光學頻譜或音訊FFT，不暗示多個頻率同時播放。手動端點初始空白，不靠是否點播放猜測使用者聽見；只存頁面記憶體，不上傳。

在UI與補充說明分別表明裝置、音量、環境影響及數位訊號不等於已量測聲壓。保留人耳概略20～20000Hz、個體差異、聽不到不代表沒有聲波、動物高頻上限及次聲／超聲定義。測試以實際Web Audio render與即時OscillatorNode核對，不以畫面數字冒稱實體喇叭或學生聽覺已驗證。

版面依使用者核可圖，重用既有木喇叭、背景與共用角色。細節及驗證見docs/reviews/unit-3.3-hearing/review.md。

## 2026-11-01 先試聽目前頻率才能記錄

使用者核可盤點第11項：目前頻率成功播放過後，才開放原低音端／高音端記錄按鈕。實際是否聽到仍由學生確認，不自動記錄，也不增加確認視窗。

初始與重新探索時兩鍵停用，顯示「先播放目前頻率，確認聽得到後再記錄。」成功啟動聲音後解鎖，提示改為「已試聽目前頻率；確認聽得到，再記錄低音端或高音端。」同一頻率暫停後仍可記錄；暫停換頻率即撤銷資格，包括換回先前頻率，須重新播放。播放中調頻成功則開放新頻率記錄，不重啟振盪器。只有實際成功啟動／調頻、且AudioContext為running時標記，準備中、取消、失敗或不支援的頻率不得因此解鎖。

既有低／高端紀錄在調頻、暫停與離區時保留；取消任一端不需重新試聽，不影響另一端或播放，重新探索清除紀錄與資格。原上下限順序檢查、固定增益、平順調頻及裝置限制說明保持。記錄動作本身另檢查資格，避免停用按鈕的合成事件繞過規則。以桌機／筆電為預設。
