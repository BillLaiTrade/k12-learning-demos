# 3.3 第二區以音調現象提問

2026-11-02，使用者指定第二區標題為「同樣是喇叭，聲音為什麼有高有低？」從眼前的喇叭與聲音高低提問，取代先點出「振動得更快」的舊標題。

同步區塊標題與左側探索導覽，錨點仍為 `#card-02`。本輪只確認標題；副標、角色對話及所有模型／播放行為維持。

同日後續，使用者核可小葵台詞為「要讓喇叭更大聲，可以讓它振動的幅度更大。那要讓聲音變高或變低，又要怎麼改變它的振動呢？」以前一區的振幅關係作為已知的提問起點，不用「原來」重做總結，也避免暗示敲得更用力會讓音調更高。僅更換這句對話，標題、副標、其他台詞及互動維持。

接續使用者要求，在小葵提問下方安排阿公直接回答音調與頻率的關係。將原本實驗下方的阿公說明前移，補上每秒振動次數的定義及高／低頻率的雙向關係；阿公說明維持一處。科學註記、圖形、聲音與操作保持。

同日後續精簡：使用者指出前面已教過頻率，核可刪去阿公回答中的「頻率就是每秒振動的次數：」，直接運用既有概念說明振動快慢、頻率與音調高低的關係。回答位置與其餘內容保持。

接續依使用者指示調整敘事順序：前方阿公只說「音調的高低，和振動的頻率有關。我們可以觀察一下它們之間的關聯。」頻率高低與音調的雙向關係移到比較圖下方，改由小葵以「我發現」說出。沿用小葵頭像與對話樣式，按閱讀順序呈現比較後的發現，不新增播放門檻或JS行為。
