# 3.4 F01：啟音後同步開始，保留完整回聲

日期：2026-11-01（臺北時間）。使用者於全課15項盤點後核可第一項修正；其餘項目仍待逐項決定。

原前三區在等待AudioContext.resume時先推進動畫，播放完成又停止全部聲源。首次啟音較慢時，畫面已收到返回聲，真正回聲卻尚未播放就被取消。公開版延遲600ms可重現。第四區原本會等待啟音，前三區改為沿用相同等待／取消規則。

共用播放器準備聲音時保持零或原暫停進度；準備成功後，以同一AudioContext時鐘及單一排程起點驅動波前與聲音，包含40ms輸出準備時間。自然完成等待最後聲源結束；主動暫停、重播、條件改變、其他區起播或背景仍可立即取消。等待中暫停後續播不算另一次發聲。啟音失敗保留原錯誤提示及視覺示範，不改成無提示的假音訊成功。

時序位於第一至四區共用播放器，因此也回歸第四區；第五區及小測各自控制器未改。原數字、聲速、波前速度、音量、提示音、文案、控制與版面保持；HTML只更新echo.mjs快取版本。沒有實作F02的側欄換區暫停，也沒有順帶處理其他待決項目。

新增tests/unit-3.4-audio-start.test.cjs。前三區分別延後600ms後，驗證等待時進度為零、原音及所有回聲最末輸出、相對延遲、接收時刻、聲源自然結束而非提前stop；另測等待中暫停續播、改值／快速重播、跨區起播／背景取消及暫停後延遲續播只排剩餘回聲。舊版8項中7項（含外層）失敗、新版8項通過，保留前後證據；不得把舊版預期失敗描述為新版失敗。
