# 5.4第一區：依七項盤點改善器材與曲線辨識

日期：2026-11-07（Asia/Taipei）。使用者指示依畫面盤點結果開始優化；只修改第一學習區塊，維持第4階段。

## 七項處理

1. 燒杯：補連續側壁輪廓與玻璃反光，杯口、杯身及杯底可連續辨識。
2. 探針：改到冰塊以外的位置，浸水段加深；感測端離杯底約0.16個模型單位，末態仍在水中，不以杯底溫度冒充樣品溫度。
3. 熱傳：移除杯外前方的三支箭頭，改以相機投影的單一箭頭，從加熱盤經杯底指入樣品，標示「熱傳入」；停熱隱藏。SVG替代保留相同方向。
4. 曲線：固定0～120kJ橫軸不變，縱軸下緣延至−10°C，讓0°C線與橫軸分開。新增累計吸熱量讀值及橙色最新線段，與綠色已觀察歷程對照；只畫已觀察資料。
5. 文字：放大座標與階段標籤，移開原點附近的「冰融化」，用短引線指向水平段。
6. 留白：緊縮步驟及圖表邊距、放大器材；保留導線與框邊間距，桌機並排、窄版上下排列。
7. 名稱：三段統一為「觀察融冰／觀察升溫／觀察沸騰」。

## 科學與範圍

仍從50g冰＋50g水、0°C開始；融完16700J、升至100°C共58500J，觀察至103700J停止，保留80g液態水。三段時長、能量模型與停點均未改。累計吸熱量明示為模型計算值，並非器材實測；負溫刻度只是圖表留白，並未觀察到負溫。杯壁、配色、液面與器材比例為辨識用示意，探針浸水且不觸底。
