## 音訊與動畫

第一區是440Hz純音衰減示意，非音叉實錄。輕／重振幅0.30／0.70，長2.4秒，使用相同波形、音高、衰減與播放位置；不同力度只改振幅。音訊、敲擊時刻與動畫共用AudioContext時間，不使用獨立計時器重播。畫面以5Hz放慢，位移放大；不以更快的動畫表現較重敲。

兩叉股照片分段反向彎曲；放大圖的振幅箭頭始終由平衡位置指向單側最大位移，並非峰到峰距離。停止後音叉回靜止，觀察窗保留明示為「此次最大振幅示意」的快照。重設清除紀錄、結論與待播聲音，返回區塊不自動播放，沒有新增背景微動。
