# 第八區：移除令人困惑的斷開光路

使用者指出「物距省略」與圖卡旁的光路跳接不直覺。本次移除斜線、物距省略文字、近距離圖卡模型及光線跳接，改以左上角獨立小框標示遠方圖卡的上端、下端；主光路從左緣連續進入鏡片，並註明來自遠方圖卡。

- 鏡片附近的入射及折射方向保持原光學計算，不把遠方圖卡硬畫在鏡片旁。
- 獨立圖示保留於立體與向量備援畫面；第七區原有的圖卡模型不受影響。
- 九組眼睛及鏡片組合通過。檢查每條光路只有一個起點、沒有跳接；凹透鏡使光束較發散、凸透鏡增加會聚的方向正確。
- 八種尺寸的代表狀態通過邊界、標籤重疊及操作區分離檢查；鍵盤、手機觸控與 WebGL 備援通過。
- 實際檢視桌面近視矯正、390 px 近視矯正、320 px 遠視未矯正截圖，沒有斷裂光線、被遮住的圖卡或水平捲動。
