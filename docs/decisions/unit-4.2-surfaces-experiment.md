# 4.2 第一區：自由觀察主畫面與輔助反射圖解

日期：2026-11-05。使用者核可「自由觀察為主、下方圖解為輔」，要求恢復下午版本並改用光滑／粗糙表面命名。

## 版本與呈現

找回台灣時間15:43的`e9ad9ba4`。現行3D恢復該版的材質、燈具、同條件照射與環境，不用晚間燈頭鏡像／角分布限制。保留後續修正的上下左右自由拖曳與觸控；不恢復已刪除的稍向左／稍向右。主畫面常駐，兩燈獨立、初始關閉，回正只改視角。桌機1.65:1、窄容器1.3:1。

兩片器材與說明統一為「光滑表面／粗糙表面」。圖解使用「鏡面反射／漫反射」作為反射方式，不將第一區當作平面鏡虛像實驗；第三區仍討論真正平面鏡成像。

## 輔助圖解

- 置於主實驗下方，桌機並列兩個較小的表面方向圖，窄容器上下排列。沒有折疊主實驗或正面參考圖片。
- 三條入射光方向一致，每條在不同位置接觸各自局部平面，以`r = d − 2(d·n)n`計算反射向量。平滑表面法向一致，粗糙表面局部方向不同；起伏明示為放大示意。
- 每個接觸點只有一組入射／反射光，端點精確相接，方向與角度關係及不穿過其他表面均可驗證。此區只呈現方向分布，法線與量角留給第二區。
- 完整SVG預設可讀，播放按鈕以兩側同步光點呈現行進順序，可重播；不影響主實驗。減少動態偏好直接保留完整圖解。WebGL不可用時，圖解與其播放仍可用。
