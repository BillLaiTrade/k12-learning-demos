# 4.2 輔助圖解：可見播放與視覺修訂

日期：2026-11-05。使用者指出圖解不夠精緻，按播放沒有可見反應。

## 原因與結果

原先reduce偏好只更新隱藏文字並直接返回；一般模式只移動小光點，完整光路始終相同，效果不易辨認。現在一般模式依序畫出入射光、標示接觸點、畫出反射光；reduce模式則分段顯示線條與接觸位置，沒有光點移動。兩者皆有可見提示、目前階段與完整結束狀態，可重新播放。

播放共2700毫秒（1000入射／500接觸／1200反射），完成後恢復完整圖解。補足3D拖曳後可能省略相容click的有效觸控抬手，保留滑鼠及鍵盤。切換動態偏好時恢復完整光路。

下方說明改為分層標題／可見提示、進度與圖例、表面對照卡、細緻材質及結果列；窄版提示保留固定高度，避免播放時跳動。仍為上方自由實驗的輔助，名稱與反射方向保持一致。
