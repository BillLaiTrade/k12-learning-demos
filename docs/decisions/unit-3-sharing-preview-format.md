# 第三單元分享預覽格式統一

2026-11-04，使用者發現3.1分享卡仍顯示「波的傳播｜波動與聲音」，要求3.1～3.4皆比照3.3的格式。

四頁均採「內容頁主標題｜單元編號 主題」，統一HTML title、Open Graph title及Twitter title；一般摘要與兩種分享摘要亦保持一致。主題沿用各頁原有名稱：波的傳播、聲音的產生與傳播、聲音的特性、聲波反射與回聲。

3.3原本符合，維持原設定；其餘僅修正不一致的標題或摘要。各頁沿用既有分享插圖與替代文字，保留canonical、語系及大圖卡片設定；3.4沿用原有JPEG分享版本，正式頁的WebP圖片不變。沒有重畫、裁切或替換素材，課程body完全保持。

分享平台讀取的是靜態HTML中的分享標籤，不會依入口卡片的JavaScript同步標題；因此本輪更新靜態head。來源檢查已核對四頁主標題、三種標題／摘要、canonical、圖片網址及大圖設定，並確認圖片存在、大小低於5MiB、body與圖片指向未變。部署後以公開網址及兩種分享爬蟲User-Agent核對HTML，並確認圖片可直接讀取。平台已產生的舊分享卡可能仍受自身快取影響，不承諾會立即刷新既有訊息。
