# 3.2 第06項：音效中斷提示與恢復

日期：2026-11-01（臺北）。使用者選擇 A：當電鈴音訊輸出遭系統中斷時，顯示「音效已中斷，請關閉再開啟電鈴。」分貝暫顯「—」，保留空氣量、抽氣／進氣狀態、電源與敲錘動作。

監聽 AudioContext 的非 running 狀態；播放準備完成時亦確認輸出仍可運作。中斷後暫停錄音並保留提示，系統自行恢復輸出時不自動發聲；由使用者操作原電源開關，關閉再開啟。成功播放後才清除提示，恢復真實音訊取樣與分貝顯示，沿用原音訊節點。只有音檔本身失敗才重新載入，單純輸出中斷不重新下載錄音。

原有離開區塊／背景分頁的停止規則維持，關閉或離開後的過時播放完成不會清除提示或自行發聲。器材、空氣與音量模型、錄音、第五項方向提示均維持。
