# 4.5 入眼觀念整合第四、五區，改為五區

日期：2026-11-04（臺北）。使用者認為遮擋視線的結果過於直覺，核可整合方案，把篇幅留給第四、五區探索，不再獨立製作第六學習區塊。

## 教學分工

4.1已教光入眼才能看見，4.4處理眼睛成像。4.5保留色散、色光混合、照明與材料、色片／紙張探索共五區，將「最後哪些光進入眼睛」融入第四、五區的結果。未實作先前第六區雙視角示意，不增加額外遮光活動或重複結論框。

第四區的20種照明／色卡組合，結果說明反射光入眼；不匹配或黑色卡時說明入眼光很少。第五區的80種光源／色片／紙張組合，依序說明色片透射、紙張反射、光進眼睛；眼睛在這個裝置中接收紙張反射光，不把色片透射量直接當作紙張外觀。兩區預覽統一標「眼睛接收的光」，仍是原有定性接收／外觀預覽，非新增第一人稱攝影機。

## 編排與相容

移除第六區卡片及導覽，保留五個教學區與唯一四題小測。第四、五區控制、位置、預設、3D與備援均保留。小測引導改完整光路；色片題改為綠片照白紙再反射入眼，答案索引與計分不變，回看仍指向s4／s5。舊公開#s6以第五區內零高度原生錨點相容，沒有額外編號、卡片或遮光操作。

保留第一至三區逐段內容、光學數值、材質／3D及顯色核心；只修改頁面編排、觀察句、小測文案、載入版本與相容錨點樣式。舊入眼模型工具及場景分支保留相容，頁面不再建立eye實驗；避免無關重構。

## 驗證

既有surface模型3項與filter-paper模型4項增加所有組合入眼文字檢查，守恆／數值要求保持。路徑專項6項（含外層）以第四區20組／第五區80組、五區編排、舊錨點、八視窗、手機／鍵盤、3D與平面備援取代已移除遮光實驗。整課35項同步五區、整合文案與小測，保留原有3D／像素、操作、七寬度、觸控與無JS回歸。以實際執行紀錄為準，公開檢視另存主專案review。
