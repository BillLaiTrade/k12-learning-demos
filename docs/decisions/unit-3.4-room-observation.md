# 3.4 F09：房間反射以視覺觀察提問

2026-11-01（臺北時間）。使用者在七項待決的逐項決策中採用改法：拍手與語音在未加入吸音材料時，統一提問「觀察從四周牆面反射回來的波，哪一面牆的反射波先回到小葵身旁？」。

加入材料後保留「比較加入材料前後，反射回來的波線有什麼變化？每面牆的變化都一樣嗎？」。先觀察牆面反射返回的先後，再比較材料效果，沿用既有視覺為主、聲音輔助的方向。
