# 聲納船隻直接發聲

2026-10-31（臺北時間）。使用者要求點船即可發聲，不限於下方按鈕；依此製作，維持第四階段。

- 點擊／輕觸船隻走同一播放器與聲音流程，與下方發聲按鈕相同；保留獨立暫停、清除與移船按鈕。
- 主指標按下時記錄位置，以7個CSS像素區分手勢。超過門檻後只拖船，移回原位也不視為點擊；垂直拖動、取消或失去捕捉不發聲。門檻內的小抖動不改船位，可作一次點擊。
- 有效pointerup且仍在船隻範圍時發聲一次，攔截緊接的相容click；保留原生鍵盤／輔助操作click。測量與暫停中船隻保持停用，避免多筆或疊音。
- 方向鍵／Home／End只移船，Enter／空白鍵可發聲；更新可讀標籤、tooltip與操作提示。沒有新增聲音選項或控制列。

新增真實滑鼠、原生手機觸控、pointercancel、拖曳回原位、小抖動、Enter／Space及下方按鈕檢查；回歸既有聲納測深與累積輪廓。其他教學區、地形、聲速及時間模型保持。
