# 4.3 單元小測：三層介質光速排序

## 教學與物理

光斜射依序穿過甲、乙、丙，交界水平且互相平行。學生比較每層光線與法線的夾角，排序光速由快到慢；不以每層停留多久代替速度，亦不比較每次轉彎幅度。介質名稱及速度數字不提供答案，畫面不要求折射率公式或角度計算。無障礙圖說在完成發射後提供各層角度，讓讀屏使用者可作等價比較。

內部以同一n sinθ不變量產生所有線段，相對速度為1/n，光前緣時間依真實幾何路程與n計算，以520ms／光學路程單位作教學慢動作。三代表n為1.12／1.4／1.78，以六種排列輪換、36或40度入射，確保斜射、不同光速、可辨角差且無全反射；首題對應核可示意的甲最快、乙最慢，之後每輪六種順序各一次，跨輪不連續重複。顏色只對應甲乙丙，不對應快慢。桌機／手機採同尺度投影，不拉伸角度。

## 操作與回饋

初始待命，手動發射後逐段展開，完整後保留光路與每層法線；重播保留排序，離屏／隱藏暫停續播。減少動態僅減弱光暈，沒有瞬間跳完成。學生可先排序作預測，完整觀察後才確認。

三卡可拖曳、點選放置、鍵盤操作。已放卡片可互換，覆蓋時原卡返回池；外放／取消不改答案。左右鍵搬移已放卡，Delete／Backspace取回，Escape取消。手機直接在觸控pointerup處理點選，僅防止同目標重複click，保留拖曳後接續點選。

缺卡時提示完成位置；錯誤保留答案並在原圖加強角度線、在排序標示需再比較的位置；正確才補圖內最快／最慢與正確順序。修改立即清掉舊判定。自由換題停止前題動畫／拖曳，清空答案與回饋，不自動發光，沒有分數、倒數或題數門檻。
