# 第五區修正：金屬表面可見差異

2026-10-31（臺北時間）。使用者指出左右兩張圖看不出差異。前版確實共用一張底圖、只有氣流標記；未把金屬反應效果畫出來。本輪依此修正，原標題／副標仍待後續討論，不改動。

- 左邊加入高溫氧化變色的生成示意，以柔邊SVG遮罩限制在焊接區附近的金屬表面。原底圖與設備上半部維持一致，右邊保留原金屬表面，表達氬氣減少空氣接觸／氧化。
- 使用藍褐／深灰的高溫氧化色澤，不畫成長期紅鏽、金屬破裂或焊縫損壞。氣體保持無色，箭頭仍為流向標記。明確標示表面差異為教學示意，不作實測品質／效能數據。
- 兩邊增設觀察位置標記與結果文字；左邊變色由同一播放時鐘逐漸出現，重播從相同表面開始，暫停／繼續與氣流同步。預設與無JS時也可見結果。
- `preservation.json` 確認其他六區、原標題及原底圖未變。

`tests.log`：19項全通過，零失敗／跳過（模型1、第五區瀏覽器9、整頁9）。新增直接比較兩個可見畫面金屬區像素的檢查，平均RGB差約33.2（0–255尺度；只用於驗證畫面差異，不是氧化量）。另驗證圖層連續出現／重播清除、像素暫停、鍵盤觸控、七種寬度、減少動態及無JS。已目視桌機與手機差異與播放中途畫面。公開確認另記課程repo。
