# 2.3 套用2.1滿寬卡片版型（2026-10-30）

依使用者指示，六個教學區塊改用2.1現行橫向標頭：上方編號、大標題與副標，下方內容滿寬；移除整區左側概念欄。小測沿用既有獨立橫向標頭，探索路線保留。

標頭的欄寬、編號外觀、字級、間距與窄螢幕規則參照2.1。概念／任務文字合併為副標，問題標題連同原ID移至標頭。原始碼比對六區內文與互動標記（移動的h2以外）完全相同；沒有更動第四區待核可的內容與互動。

## 檢查

- 整頁、第二區成分圖與第三區充氮專項合計31項通過，見browser-tests.log。
- 七種寬度1440／1280／1024／800／768／390／320px，六區標頭均在內容上方，內容本體左右到卡片內緣，不再保留側欄空間，頁面無橫向溢出。
- 杯子預設對照與重設、成分圖兩種排列／點選／放大框、充氮連續縮條、兩種製氣重播及小測回歸通過。
- 桌機第一／三區與手機第四區截圖已人工檢視，內容使用滿寬且仍在卡片內；無JS仍有完整教學證據。

第四區優化提案與示意圖仍待使用者核可，此次版型核可不包含該實作；後續以滿寬格式為準。公開部署證據另記課程repo本次交付紀錄。
