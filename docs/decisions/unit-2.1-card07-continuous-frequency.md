# 2.1 第七區：頻率變化由波源連續傳出

日期：2026-10-29（Asia/Taipei）。

使用者逐項確認後採用 A：保留現有振動，改變頻率時不重設波形；波源從目前位置接續振動，新的頻率變化逐步向右傳，已送出的波繼續前進。

- 波源相位使用分段頻率的時間積分，切換時保存當下相位，避免以新頻率重算先前全部時間而跳位。
- 每個位置依固定波速及距離取用較早的波源相位；既有波形不會因調整控制而瞬間改變。
- 頻率與週期仍互為倒數，沿用原本 1–4 Hz、0.25–1 s、振幅與波速。
- 新頻率形成完整一個波形前，以原有標籤顯示「新波形形成中」，形成後才顯示對應波長，避免標示跨過不同頻率的過渡段。
- 這次僅處理第七區的連續振動與傳遞；其餘待審查項目仍由使用者逐項決定。

## 檢查結果

- 以瀏覽器比對 241 個波形取樣點與獨立計算的延遲相位，誤差低於 0.005 SVG 單位（座標四捨五入）。
- 確認 1 Hz 切至 2 Hz 時波源位置連續，舊波保留，新波由左向右形成；形成完整週期後才顯示波長。
- 確認週期滑桿、鍵盤、連續調整、長時間歷史裁切及手機觸控可正常操作。
- 檢查 320–1440 px 共七種寬度，未發現水平溢出；桌面與手機截圖均已檢視。
