# 4.5 到達紙張的色光以顏色名稱作答

2026-11-05依使用者指示，選項應表示混合後的色光顏色，而非直接給出組成。將「紅、綠光／綠、藍光／紅、藍光／紅、綠、藍光（白光）」改為「黃光／青光／洋紅光／白光」；原紅、綠、藍光保持，欄位文字改為「到達紙張的色光顏色」。使用者可自行到自由試光合成，再返回預測。

只有選項顯示文字與對應欄位標籤變動，保留全部value、原判定、混光／透射／反射公式、六題比較順序、換組與保存。自由試光每支仍僅三原色，小測導覽與其他學習區保持。驗證實際選單七種色名、混合色值作答、自由試光對照及返回保存；更新載入版本mixed-colour-options-20261105。
