# 第四區氧氣視覺精緻度修訂

2026-10-31（臺北時間）。使用者要求先提升第四學習區塊畫面精緻度，其他修正留待後續指示。

- 將原本粗線平面器材重繪為有厚度的玻璃：弧形錐瓶肩部、雙層瓶口、側面反光、瓶底折射、玻璃片厚邊及水槽透視側壁。
- 使用一致的左上柔光與暖色實驗桌，加入器材接觸陰影、水面彎月面、透明液體層次與氣泡高光。二氧化錳以細顆粒呈現，橡皮塞加入表面深淺。
- 兩組集氣瓶加入前後瓶口、玻璃底與柱面反光；木條增加木紋、焦痕與炭化裂紋，火焰改為透明漸層、明亮焰心與局部暖光。
- 四步按鈕及結果框的圓角、邊線、陰影一致化。所有圖像仍為原創SVG，沒有額外依賴或新人物素材。

只有HTML內三幅SVG、氧氣CSS及資源快取版本變更。移除SVG後逐字比對：第四區文字／控制項／頭像與其他區內容均相同；oxygen.mjs與oxygen-model.mjs未變更，動畫時序、流向、水量與火焰狀態沿用。

`tests.log`：沿用氧氣與整頁兩套測試，共18項通過，零失敗／跳過，含七種寬度、兩瓶並列、真正SVG水位／木條座標／火焰透明度、暫停重播、鍵盤／觸控、背景離場、減少動態與無JS。已目視桌機、390px手機、排氣及排水中途畫面，玻璃反光不遮蔽氣泡、液面與比較結果。語法及git diff --check通過。

目前仍為第4階段逐區修訂，等待使用者下一輪具體修正。公開確認另記課程repo。
