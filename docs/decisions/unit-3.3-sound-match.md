## 活動與版面

- 上方淡黃色卡片顯示目標樂器及「聽目標聲音」，作答前隱藏目標波形與數值；下方僅呈現學生目前的波形，不顯示樂器名稱。
- 「換一種波形」循環三種音色，頻率與振幅使用左減、右加的原生按鈕及唯讀檔位顯示。換波形不重設其他兩項，操作不自動發聲；試聽鍵在播放時可停止，再點可重播。所有播放沿用整頁唯一活動音源。
- 現行為45組獨立目標（三音色×五頻率×三振幅），每題三項皆可調，初始三項與目標不同。兩聲都試聽後才完成比較；調整後須重聽自己的最新設定。右上角隨時可換題，不必完成目前這題。
- 提交後在原座標以虛線揭示目標波形，分項回饋音色、音高、振幅／音量。修改即清除過期結果，可繼續調整或隨時換題；不顯示題數進度、不累積分數、沒有結算畫面。換題停止舊播放、取消等待、清除本題設定與回饋，新題不自動出聲。
- 成功條件為音色相同、頻率與振幅選中相同的預設檔位，標準收在操作說明中。
- 米白、墨綠、淡黃色及上下區塊依核可圖；樂器引用第五區既有素材與組合。筆電保留全部核心工具同屏，手機保留可讀大小、上下堆疊。原七個學習區及導覽保留。

## 聲音與波形同源

`sound-match-model.mjs` 接受第五區最終 440Hz PCM，依每份素材全段峰值設定固定 0.6 基準，再以頻率比做線性重取樣至 48kHz、乘振幅增益，產生最終 Float32Array。音訊與繪圖直接共用該結果，不另外手繪樂器波形、不逐圖或逐次調整後自動放大。

頻率固定五檔 220／330／440／550／660Hz；振幅增益固定三檔 0.3／0.6／0.9。共同時間窗為 10ms、縱軸固定 ±0.6；視窗起點為來源 200ms 對應的輸出時間，變頻時仍比較同一段來源附近的音色。播放原有完整起落，重取樣也改變長度，沒有強制循環或時間拉伸。峰值不超過 0.6，並非聲壓或主觀響度校準；不同音色不保證同增益同響度，回饋以振幅設定表述。

吉他為 allan764 CC BY 3.0，排笛聲音示例為 mrshoes CC BY 4.0 的 PVC 排管錄音，音叉為近似純音合成。來源、作者、授權及新增重取樣／增益修改告知收於小測可展開說明及既有素材授權文件。未新增套件或外部服務。
