# 第二區共同振幅尺度

2026-10-31：使用者指出原「振幅相同」短線無法直觀比較。改成左右共用的相對位移尺：−0.50、平衡位置0、+0.50，淡綠背景標示可比較範圍，橘色圓點與振膜即時位置同步。單側箭頭A由0指向+0.50，兩側固定標示相對振幅A=0.50，沒有把峰到峰範圍1.00誤當振幅。數值是模型相對量，不是公尺或實測喇叭位移。

維持原聲音、增益、200～800Hz、左右獨立播放及背景。只改既有放大窗標示，不增加操作。第二區8項檢查通過，包含左右數值一致、單側振幅定義、動態圓點與振膜同相位、停止回0及既有播放／音量／頻率／版面檢查。實際畫面見playing-1440.png。公開確認另記於規劃repo。
