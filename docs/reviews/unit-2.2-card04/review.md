# 第四學習區塊：整合預覽檢視

日期：2026-10-28（Asia/Taipei）。狀態：獨立預覽待使用者核可，正式第四區塊尚未替換。

[開啟完整互動預覽](https://billlaitrade.github.io/k12-learning-demos/previews/unit-2.2-card04/)。

## 回饋落實

- 使用共用正式小葵／阿公頭像；角色不由示意圖重新生成。
- 空氣、水、鋼都以局部粒子位移表達縱向振動傳播，鋼的連結跟隨粒子伸縮。
- 移除橘色追蹤粒子、原位虛線及箭頭；深色只是到達紀錄，不是光束或額外移動物件。
- 最右端放大區明確呈現開始振動的先後，三組距離與時間倍率一致。
- 整合介質比較、空氣溫度、開始／暫停／繼續／再次比較、逐格、回到起點、提示音與教學結果；預測已依最新指示移除。

## 科學與狀態核對

`model.mjs` 以同一振動訊號加上距離／聲速延遲控制所有粒子。檢查固定 y、位移有界、粒子不交叉、完成後回到原位、各組頻率相同，以及鋼中連結與實際粒子位置一致。空氣／水／鋼到達時間分別約 291.5／67.6／16.9 毫秒。

兩個空氣模型的初始排列相同，20°C 參考保持不變；30°C 設定組早約 5.0 毫秒，0°C 設定組晚約 10.6 毫秒，兩組同為 20°C 時完全同步。條件變動後清除舊動畫與結果，沒有為溫差另設誇大的傳播速度。

```sh
CHROMIUM_PATH=/usr/bin/chromium node --test --test-concurrency=1 tests/unit-2.2-card04-preview.test.cjs tests/unit-2.2-vacuum.test.cjs tests/unit-2.2-sound-propagation.test.cjs tests/unit-2.2.test.cjs
```

前一輪整合版本的上述完整命令共 44 項通過：新預覽 17 個模型及瀏覽器檢查（含群組計數），前三區塊 27 項回歸。輸出保存於 `tests.log`；最後版面文字微調後再執行新預覽的 17 項檢查，通過紀錄見 `preview-final.log`。互動測試以凍結時鐘推進，避免讀取時經過的真實時間造成錯判；音訊提示以實際 AudioContext／振盪器檢查。既有分貝儀的筆畫驗證改為同一次取得數字與筆畫，避免量到不同影格；未修改正式課程的行為。

版面涵蓋 320／390／640／768／850／1024／1440px，內容保留在主欄、沒有水平溢出，按鈕／選單／滑桿與點擊區至少 44px；包含手機觸控、鍵盤切換分頁、來源按鈕與滑桿。提示音預設不播放、可停用，背景分頁停止動畫並保留時間。

## 畫面紀錄

- `ready.png`：起始靜止、沒有預先公布勝負或自動播放。
- `material-desktop.png`：鋼已到達，水與空氣仍在傳遞，畫面與記錄一致。
- `material-mobile.png`：手機三組比較與放大區，正式角色及卡片格式。
- `material-result.png`：教學結論、聲速與到達時間保留，粒子回到原位。
- `temperature-desktop.png`／`temperature-mobile.png`：固定參考、可調設定、相同排列及完整比較結果。

預覽是放慢的示意模型，粒子排列與振幅不代表真實分子尺度。提示音不是介質內的原音；瀏覽器／觸控為 Chromium 模擬檢查，不能取代使用者裝置上的實際操作回饋。


## 最新修訂：移除預測，辨認實物與微觀結構

已撤下預測欄、猜測對白、選項與對錯回饋。三種材質的差異改由近照及微觀外形共同呈現，不使用不同底色作為主要區別：氣體為稀疏分子，水為較密集、錯開的彎折分子，鋼為具立體光影與彈性連結的原子排列。所有粒子圖形仍沿水平方向依同一波動資料更新，沒有改成光束或獨立播放的裝飾動畫。

`material-detail.png` 為點開水近照的畫面。近照可使用滑鼠、觸控、Enter 開啟，關閉按鈕與 Escape 均可返回；動畫暫停且時間保留。三張近照以 SVG 取用同一原圖的三個等高區域，沒有拉伸材質。相片載入失敗時有可讀提示，微觀比較仍可操作。

前一輪材質版本共 20 項檢查（含群組計數），涵蓋原模型、控制與新增的材質辨認、水分子夾角、可見圖形位移、彈性連結端點、近照開關／暫停，以及素材失敗與七種視窗寬度。該輪輸出見 `materials-tests.log`；本輪未修改或重跑正式前三區塊，前一輪回歸紀錄保留為歷史。


## 最新修訂：整合比較面板與版面比例

依使用者確認的方向，三張獨立大卡改為單一比較面板，桌面共用「介質／微觀振動／最右端放大」欄位。照片與名稱集中於左側 88px 窄欄，中間保留主要空間給模型，右端觀察直接相接，並把到達時間移到對應粒子下方。三列桌面模型區高度約 440px，減少大片空白及重複標籤。手機採 68×44px 材質小標頭，振動與末端觀察維持同一列。

微觀視窗由 660 改為 456 圖形單位，保留同一 100 公尺距離對應，並以較少、較大的取樣圖形改善閱讀：空氣 16×3、水 16×5、鋼 20×4，共 208 個可見分子／原子中心。取樣數不代表密度量測。靜止圖形不透明度提升至 0.64、已到達為 1；所有組別仍共用同一頻率、脈衝與傳播延遲。

本輪 21 項檢查全部通過（含群組計數），新增版面比例檢查：單一面板、照片位於模型左側、桌面模型寬至少為照片的 3.5 倍、模型高度至少 100px、三列合計低於 470px，以及末端觀察與模型直接相接。既有物理數值、暫停／逐格／重啟、近照、音訊、七種視窗與手機觸控檢查一併通過，輸出為 `layout-tests.log`。上述畫面紀錄已更新為本輪截圖。正式課程保持待核可狀態。
