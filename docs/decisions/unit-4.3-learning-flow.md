# 4.3 第三至第五區學習順序與介質切換

日期：2026-11-03。使用者先集中提出回饋，明確表示開始修改後一次實作。

- 第三區承接光速比較與垂直入射，說明空氣到水／玻璃、光速由快變慢，斜射偏向法線。
- 第四區專注相反速度變化：單一光源由水／玻璃射回空氣、慢變快，斜射偏離法線。保留0–35°範圍、拖曳／鍵盤、重設與局部放大，使用金色光線與無A／B代號的單一器材。
- 第五區接原第四區A紅光／B藍光獨立開關、任一端拖曳及雙向重合比較，呈現光路可逆。單燈分別標入射／折射角色；雙燈標介質兩側角度。滑桿改稱介質側角度，避免角色互換時名稱錯誤。反射對照放在可展開補充，保留原來反向操作。
- 三區介質切換統一為水槽正下方中央的一個原生按鈕，顯示目前水／玻璃；點擊切到另一種。保留aria-pressed（玻璃為true）、下一種提示、快速連按競態防護與失敗重試。
- 兩種速度變化都直接顯示在主要觀察說明，方向結論明示斜射條件；0°速度仍改變但方向不偏折。詳細原因在各自說明中保留，沒有把折射角與入射角說成相等。
- 第四、第五區共用既有控制器，以root／ID前綴區分狀態與SVG定義，不複製光學模型。圖片與幾何完全沿用，焦點、局部背景淡化、角度細引線及小角度呈現保持。
- 第三區狀態列移至角度列後，維持原圖全寬並讓1440×650等低高度視窗主要操作同屏；手機切換在圖下方第一列，避免擠在器材邊框。

驗證為兩個模型、第三／五區既有回歸、新增第四區與分區狀態及置中位置、全課格式／功能，共51項（含外層）。另以桌機／手機實際截圖核對單燈、雙燈、水／玻璃及0°／35°。維持第四階段修訂，等待使用者檢視。
