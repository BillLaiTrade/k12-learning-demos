# 4.4 單元小測：完成一台投影機

日期：2026-11-06

現有四題文字選擇題改為使用者核可的投影機任務。學生選擇凸／凹透鏡，調整透明圖卡與鏡片位置，旋轉圖卡，讓牆上的圖案清楚、放大、正立且位於目標範圍內，再檢查成果。主圖、投影與控制項整合在同一工作區；標頭以任務名稱與科學主題分工，操作位於控制項附近。

使用同一幅具有單側門窗的小房子，旋轉與薄透鏡成像皆改變上下及左右。圖卡與牆上的成像由相同圖案生成，清楚成像時不改色。投影大小由幕上光線截距決定，清晰度由有限孔徑在幕上的擴散量判定；虛像配置不會被當成牆上的清楚實像。原物範圍、目標框及通關範圍共用明確邊界，容許多組正確位置。

使用者按檢查成果後才顯示判定；調整配置會清除舊結果。提示依目前問題提供觀察方向與回看入口，保留學生操作。重新挑戰清除結果、提示與光路開關。原生按鈕與滑桿提供鍵盤及觸控操作，載入失敗時使用相同模型的剖面圖繼續任務。

保留小測錨點及整頁導覽，移除舊四題評分處理器。前九個學習區塊的 HTML、模組與光學參數保留，小測以專屬就緒標記初始化。立體模型按視窗需要載入，材質、器材比例與有限孔徑失焦為教學近似，相關說明置於收合的模型補充。

檢查與截圖見 [投影機單元小測審查](../reviews/unit-4.4-projector-quiz-20261106/review.md)。

## 加入立體視角操作（2026-11-06）

依使用者要求，單元小測由固定鏡頭改為可拖曳操作Three.js相機。支援360°水平環繞、上下轉動、以操作位置為中心的滾輪縮放、Shift／右鍵平移，以及手機單指轉動、雙指縮放平移。相機保留桌面上方的仰角與縮放界限。視角狀態獨立於光學狀態；轉動或縮放會保留圖卡、鏡片、圖案材質與已完成的判定。

在畫面附近提供裝置相應的手勢提示、鍵盤說明及獨立的「重設視角」。Home與重設視角只恢復相機，重新挑戰恢復器材及相機。標籤依相機投影排序及限位，離開視窗的標籤收起；手機標籤順序跟隨觀察方向。無法顯示立體模型時收起相機操作，剖面任務照常運作。

檢查與畫面見 [投影機立體操作審查](../reviews/unit-4.4-projector-orbit-20261106/review.md)。

## 鏡片玻璃體積與名稱（2026-11-06）

使用者指出小測中的鏡片像線框，核可調整玻璃體積、雙凸厚薄與輪廓。只在投影機模型中採用專用透光玻璃材質，保留原旋轉對稱幾何、半徑及厚度曲線；取消金屬外環與深色中央剖面線，以淡色外緣及貼合曲面的短反光辨識玻璃，下方保留小托座。凹透鏡沿用自身中薄邊厚曲線與同一材質，切換器材位置不變。

圖上名稱及無障礙說明隨選擇改為凸透鏡／凹透鏡。沒有更改投影、失焦、通關條件或相機功能；其他教學區仍使用原共享鏡片呈現。檢查與前後畫面見[鏡片外觀修訂紀錄](../reviews/unit-4.4-projector-glass-20261106/review.md)。
