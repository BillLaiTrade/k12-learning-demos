# 第六區眼睛與視野窗的配對

2026-11-04。使用者核可精修示意圖後授權實作：細緻眼睛、淡金托框、兩條細金線連到右側視野窗，明確表達右圖來自該眼睛的觀看位置。核可參考圖保存在本輪檢查目錄；維持第四階段製作修訂，非最終核可。

## 眼睛、導軌與命名

以本地向量圖製作象牙色眼白、綠榛色虹膜紋理、瞳孔、角膜反光、細眼瞼與陰影，搭配薄香檳金托框及金屬導軌。主圖與右圖標題共用同一眼睛圖稿；圖稿獨立於光學模型，主瞳孔仍位於原觀看座標。

右圖標題改為「這隻眼睛看到的畫面」，下緣常駐「這裡呈現的，就是圖中眼睛所見」，並保留可見／遮擋的動態說明。眼睛滑動控制以aria-controls指向觀看畫布，並描述其與視野的關係；小圖示與連線為裝飾，不增加焦點。

## 兩條線與淡金框

兩條細金線從眼睛托框的右上／下緣接出，桌機接到視野畫面的左上／下緣，配合相同金框與極淡底色。連線先沿眼睛高度的空白區伸出，再於兩圖留白展開，避開光路與解說文字。線條無箭頭、沒有流光，與實際黃色光線區分；隱藏光路不隱藏視角配對。

手機上下排列時，兩條線沿卡片右側外緣接到下方視野窗右上／下緣，不穿過圖面或標籤。連線按實際SVG座標及元素框計算，眼睛拖曳／鍵盤／版面縮放時更新，沒有用固定位置圖片。眼睛取得焦點時，連線與視野框同步加強；減少動態關閉過渡。連線忽略滑鼠與觸控，不擋操作。

眼睛與金框收進原圖內，觸控範圍仍至少44px；小螢幕另縮薄托框、微調導軌標籤，避免框緣貼字。固定鏡頭、空槽起始、持續加滿／放空、途中反向、離屏續播、模型與材質保持；沒有恢復重播／重設。

## 驗證

初輪第六區、格式與整課共21項全過。之後只調整小螢幕框線／標籤，以起始畫面、焦點／連線及九尺寸共4項補驗全過；其他功能不無故重跑。九尺寸×近／中／遠共27組，核對端點貼框、曲線不越界、不遮文字、眼睛框不壓字、無箭頭及不攔截事件。既有滑鼠／鍵盤／原生觸控、加放水、減少動態、材質重試與無JS保留。
