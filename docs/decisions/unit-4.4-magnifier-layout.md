# 4.4 第四區：十二項畫面與探究重整

2026-11-04依使用者確認，收斂為固定眼睛、向外推圖卡，回答何時能作放大鏡。先前的大型三判準說明框撤回，內容不再成為第二個主題。

| 項目 | 本輪處理 |
| --- | --- |
| 主體大小 | 固定主要操作區取景；減少長空軌主導畫面，窄畫面採較近取景 |
| 器材辨識 | 預設斜向觀察，能看見圖卡正面；圖卡、透鏡、眼睛加簡短標記 |
| 光路追蹤 | 選取可見代表光，方向與成像位置依薄透鏡方程；箭頭表示延伸 |
| 面板遮擋 | 3D獨立viewport；桌面比較區在旁，手機在下，兩者不重疊 |
| 入眼光 | 金色入眼束與代表光有就近圖例；眼睛符號放大並保持瞳孔對齊 |
| 大小對照 | 透過鏡片與直接看並排、同畫幅同尺度同背景，加入共同對齊線 |
| 圖卡尺 | 距離透鏡為標題，突出0.5F、F、1.5F及主要操作範圍；保留0.3F至3.5F |
| 四步探究 | 初始0.5F、接近F為0.9F、恰好F、F外1.5F；同眼位、同取景比例 |
| 大型文字 | 移除三張分類卡和長說明，不以縮字維持原框 |
| 必要澄清 | 一句動態提醒；兩句概念補充預設收起，不講眼內機制 |
| 補充工具 | 虛像延長線與屏幕比較保留於四步觀察之後，預設收起 |
| 結論與驗收 | 簡述F內、F、F外，逐尺寸檢視卡面、光路、對照與操作 |

初始改0.5F，使預設放大差異較容易直接比較；下限0.3F與跨F探索範圍不變。比較區觀看角度由56度收斂為40度，兩畫面同時改變觀看範圍，不改模型視角倍率；不用把原物縮小或虛像任意放大製造差異。

顯示光線的透鏡高度取樣以可辨認範圍選擇，與第三區依相同薄透鏡方程；實際線性倍率、像距、屏幕投影及眼位保持。F的同色光束仍平行。桌面可見1.5F物距的3F會聚位置；窄畫面若像在視野外，保留正確距離與延伸方向，不為塞入畫面縮小全部器材。手動移動不追相機，切換四列回到該尺寸的共同初始比例，輔助光路保留偏好。

旋轉與五倍近看僅改主相機；原生雙指縮放修正既有缺少clampZoom定義的路徑。可見性檢查包含實際卡面投影寬高、兩區分離、並排比較、手機刻度與光路標記；物理模型與整課操作另行回歸。
