
第九區使用 `microscope-studio.mjs/css` 呈現直立式顯微鏡剖面及觀看窗；`microscope-optics.mjs` 依既有 `optics.mjs` 的兩透鏡配置計算連續代表光線。第一步呈現中間實像，後兩步呈現目鏡的虛像；預設顯示輔助光路。器材外形及圖案放大為示意。

第九區的立體剖面由 `microscope-model.mjs` 使用單元既有 Three.js 製作，材質環境由程式生成，無新增外部圖像素材。光路與三個短標籤依模型投影；模型不可用時仍可操作 SVG 備用剖面。

顯微鏡支援點擊鏡頭或標籤近看，與三步觀察同步；位置小圖為同模型全貌快照及投影範圍。`microscope-model.mjs` 負責取景轉換，`microscope-studio.mjs` 同步光路、HTML 定位與觀察結果。光學參數不隨取景變動；備用 SVG 亦保留近看及返回。

第九區預設近看物鏡成像。主圖持續保留同一個 A 中間像示意框，隨步驟改標為物鏡的實像或目鏡觀察的物體；右側前後比較將第一段的 A 圖案原樣帶入第二段。圖案大小為定性示意，實際成像位置與代表光路仍由相同的兩透鏡模型計算。

第九區以草履蟲固定玻片取代箭頭圖卡。`microscope-specimen.mjs` 共用相同輪廓、單側口溝及內部構造，提供比較窗、中間像放大示意、備用剖面與載物臺材質；方向用整體旋轉180°呈現，同一中間像在目鏡觀察時不再翻轉。介面直接使用「中間像」，並以獨立結論區說明最後看到相對標本上下、左右相反的放大虛像。顏色、構造及大小為教學示意。
