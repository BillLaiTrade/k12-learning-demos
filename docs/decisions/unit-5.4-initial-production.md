# 5.4 整頁初版製作

2026-11-06。使用者已核可六區架構，後續明確要求先研究單元1～3成品、對齊目前頁面規格，製作六區及一個單元小測的可操作初版，再由使用者逐區帶領優化。此指示取代先等第一區示意定案才製作的分輪停點。

另依使用者最新更正，入口與學生介面統一使用「單元小測」；活動主標題描述證據判讀，不以「整合小冊」等名稱替代。

採用現有靜態HTML、CSS及ES modules，沿用第五單元共用格式，不新增依賴或服務。六區內容與範圍依規劃庫六區決策，具體器材／題型形成可檢視初稿。學生可供熱與停熱、比較反向變態、調溫試球環、比較固液氣脹縮與水例外、分解水／玻璃增量，以及觀察含水／無水硫酸銅吸放熱。只有結尾小測判讀理由，不逐區評分。

首圖與器材為原創SVG教學圖，人物沿用共用正式頭像。首圖PNG為相同圖的分享版本。未將原創圖稱為實驗照片或實錄；具體圖像與互動細節仍待逐區回饋。

單元1～3參考方法、模型限制、檢查證據與待優化範圍見[本輪紀錄](../reviews/unit-5.4-initial/review.md)。維持第4階段製作／修訂，非整頁最終核可或外部驗收。
