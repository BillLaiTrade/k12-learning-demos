# 2.3 獨立開場頁首與探索路線位置修正

日期：2026-10-29。使用者指出探索路線應位於標題、圖片下方，並要求參照同單元 2.2 的配置。

## 原因及實作

先前 2.3 將 `.hero` 放在 `main .content`，與左側 `.route` 同屬一列，導致導覽從開場旁邊開始，且開場可用寬度被側欄扣除。前一輪只調整欄寬與切換點，沒有修正這個結構問題。

- 將整個開場移到獨立 `header.masthead`；下方 `main` 才安排探索路線與教學內容。
- 參照現行 `units/2/parts/2.2/index.html`，頁首／教材共用最大1160px容器，圖文欄寬0.9fr／1.1fr、欄距28px、680px以下上下排列。
- 保留開場圖、文字、八區錨點、單元小測與原有互動程式。HTML的CSS連結帶入 `?v=opening-layout-3`，使此次配置更新有獨立資源網址。

## 本輪實際預覽

以本機HTTP與Chromium讀取版面並擷取四種視窗；以下數值四捨五入，均在頁面頂端讀取：

| 視窗寬度 | 開場頁首底部 Y | 探索路線起點 Y | 圖片寬×高 |
| --- | --- | --- | --- |
| 1440px | 586 | 622 | 621×349 |
| 1024px | 532 | 568 | 526×296 |
| 800px | 463 | 499 | 403×227 |
| 390px | 711 | 719 | 364×205 |

四種畫面中探索路線都從完整頁首之後開始，文件寬度與視窗一致，預覽未出現頁面JavaScript錯誤。1440px、1024px及390px時的圖片尺寸與上一輪直接量得的2.2相同。已目視檢視[桌機](desktop.png)、[平板](tablet.png)、[較窄桌面](compact.png)、[手機](mobile.png)。
