# 單元小測：投影機任務

`projector-quiz.mjs/css` 控制4.4最後的單元小測。畫面依核可示意圖整合光源、透明圖卡、鏡片、固定投影幕、鏡片選擇、兩把位置滑桿、180°旋轉及檢查成果。保留 `#s10`、`#unit-quiz`、`#quiz` 與 `#quiz-result`；前九區的標記與光學程式不變。小測使用獨立的 `data-projector-ready`，不改變九個教學區的 `data-ready` 計數。

`projector-optics.mjs` 重用既有 `optics.mjs` 的薄透鏡公式與代表光線。物距為鏡片位置減圖卡位置，屏幕距離為固定幕位置減鏡片位置；有限孔徑的光線在幕上擴散量為 `aperture × abs(1 + s/u − s/f)`。清晰度、牆上圖案大小及通關共用同一組位置，不以預設座標判斷。可用多組距離通關；圖案範圍由實際圖案邊界與繪製目標框的同一組邊界檢查。器材間距下限保護支架，並同步到兩個原生滑桿的有效範圍。

`projector-art.mjs` 以同一棟非對稱小房子產生圖卡與投影材質。圖卡旋轉180°時，投影上下、左右同時對應反轉；清楚成像的原色一致。幕上圖案按代表光線截距縮放，失焦以有限孔徑光斑的高斯近似呈現，凹透鏡或焦點內配置不會顯示牆上的清楚虛像。

`projector-model.mjs` 使用本單元既有 Three.js 與核可的旋轉對稱透鏡模型。凸透鏡中間厚、邊緣薄；凹透鏡中間薄、邊緣厚。鏡片更換不影響器材位置。器材採固定視角，距離以滑桿調整；標籤為原比例 HTML，位置依同一相機投影。模型靠近視窗後才載入，WebGL 不可用時，剖面示意仍使用相同材質、光路與通關判定。

檢查成果後才顯示通關及四項目標；修改器材、鏡片或方向會清除舊結果。提示提供觀察方向及相關學習區連結，不自動移動器材；重新挑戰恢復初始配置並收起提示與結果。支援原生鍵盤及觸控滑桿，輔助光路預設收起。

驗證包含 `tests/unit-4.4-projector-optics.test.mjs`、`tests/unit-4.4-projector-quiz.test.cjs`，及 `LENS_PROJECTOR_RECHECK=1 node --test tests/unit-4.4.test.cjs` 的整頁導覽與版面檢查。
