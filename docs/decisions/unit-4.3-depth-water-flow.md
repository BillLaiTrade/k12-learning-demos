# 第六區持續加水至滿、放水至空

2026-11-04。使用者澄清：按「加水觀察」後應逐漸加滿，按「放水觀察」後應逐漸放完。前輪把「逐步」理解成分段停止，與使用者意圖不同；此次移除段落目標及連按累加。

每次從當前水位持續往滿槽或空槽前進，到端點才停止。全程約5秒，中途不在五分之一等位置停下，也不瞬間跳到滿／空；從中間開始只走剩餘路程，維持相同示意速率。同方向重按不中斷／重播，相反方向從當前水位平順反轉。

兩個按鈕及左圖下緣的拖曳提示保持，不恢復重設。空／滿停用對應方向；水位調整不改眼睛位置、光路開關或固定鏡頭。手動拖曳／鍵盤可接管，離屏／隱藏保留進度、返回續播；減少動態直接顯示滿／空端點，偏好途中改變也完成當前方向的目標。
