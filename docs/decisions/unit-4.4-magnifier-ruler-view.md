# 4.4 第四區：預設大取景與同向刻度尺

2026-11-04依使用者連續三項回饋，合併調整初始比例、尺的移動方向及觀察列取景。

- 初始相機改為接近水平側視，方位−0.04弧度、仰角約8°。1440px檢查時木軌佔可用3D區寬約83%，接近使用者的參考圖。
- 所有觀察列共用取景邊界與目標，包含完整圖卡行程、屏幕及0.6F虛像。取景預留工具列最長文字與追蹤列所需空間，避免加入屏幕按鍵或切換光路時重新縮小。選列回到初始縮放，保留手動旋轉功能。接近F的遠像仍以「視野外」與真實距離標示，不再為它自動縮小器材。
- 原生拉桿改為第三區同式的刻度按鈕、細刻度及「圖卡↔」把手。左端2F、右端透鏡0F，往右拖把手代表物距減少，圖卡在實驗台上也往右。鍵盤左右方向一致；Home／End仍到模型範圍兩端。
- 圖卡仍限0.3F至2F，點透鏡0F刻度移至最近的0.3F。拖曳保留抓取偏移，取消或失去捕捉後停止；模型、眼睛／原物參照與預設光路保持。
