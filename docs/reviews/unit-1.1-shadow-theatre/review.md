# 1.1 單元小冊：少量吸附並保留學生的前後距離

日期：2026-10-29

## 核可範圍

使用者核可「保留少量吸附，但不自動修正前後距離」。本次完成判定同時檢查影子的位置及大小，僅協助少量上下／左右對齊。同步更新既有操作說明及失敗回饋；保留原舞台、三個道具、控制方式、演出與重設流程。「再演一次」的既有行為未納入本次修訂。

## 判定與吸附

原本使用道具到預設3D位置的0.52距離作容錯，通過後直接將z改為0.42。學生只需移動x／y即可被系統修好影子大小。

新增純數學模組 `shadow-theatre-optics.mjs`，與場景共用點光源(-0.8,3.05,3.5)、屏幕z=-1.25與原描邊的參考深度0.42。平行切紙平面的投影比例為光源到屏幕距離除以光源到道具距離。比較投影錨點與描邊錨點的屏幕距離，以及投影線性大小與描邊大小的比例。

- 大小容許相對誤差4%；位置容許0.12舞台單位，約屏幕寬的2.6%。兩項都合格才吸附。
- 以學生當前z反算所需x／y，只寫入x及y，保留z及道具本身大小。吸附修正量不超過位置容錯除以當前投影倍率。
- 原有每次0.16的前後步幅可到達合格位置。實際完成案例為月亮z約0.44、兔子約0.38、樹影約0.34，都未變成0.42。
- 大小不合時回饋偏大／偏小，大小接近而位置仍遠時回饋位置未對齊；不直接告訴學生應往哪個方向移。
- 拖曳放開、方向鍵、前後按鈕及滾輪共用同一判定，避免某種控制方式繞過條件。轉動鏡頭不改變世界投影判定。

這是切紙中間平面的幾何投影判定，未做逐像素輪廓比對。現有道具厚度、柔邊及斜向照明可能讓輪廓有些差異，保留有限容錯供學生操作。

## 檢查與畫面

`tests.log`：23項通過、0失敗（含外層項目），其中新小冊檢查11項及既有孔板回歸12項。

- 數學：三個起始z即使中心對齊仍因大小不合而失敗；分開核對大小／位置、容錯內外邊界、非標準z可完成、既有前後步幅可達標，另以80組獨立射線與屏幕交點核對。
- 實際場景：透過測試載入時插入的觀察入口讀取真正Three.js道具座標、尺度、描邊及狀態，正式程式未暴露全域測試API。三個道具只移x／y均無法通過；只改大小而位置仍遠亦不能通過；符合兩條件後才標示已對準。
- 吸附：逐個道具核對吸附前後z完全相同、道具尺度不變、描邊中心對齊、x／y修正量不超過容錯。
- 操作：滑鼠拖曳、方向鍵、前後按鈕、滾輪、鏡頭轉動、完成及既有重設，另以獨立手機瀏覽器程序做真實觸控拖曳及按鈕，再確認吸附保留z。這是瀏覽器觸控模擬，未量測實體手機效能。
- 版面：320／390／768／1024／1440px無水平溢位，沿用原有版型。
- 回歸：第三區三孔板的幾何通光、亮點及指示燈、拖曳、觸控、重設及其他既有相關操作仍通過。

人工檢視 `wrong-size.png`：影子中心接近描邊，大小不同時三道具仍待定位，描邊仍保留；`placed.png`：學生自行調整大小與位置後三道具才完成；`mobile-touch.png`：手機觸控操作後僅已符合條件的月亮完成，其餘待定位。`initial.png`、`mobile.png` 保存起始與窄螢幕畫面。

早期滾輪檢查在輸入事件處理前讀取了舊值，且滑鼠位置受鏡頭切換影響；檢查改以畫布內穩定位置發出滾輪，等待原生事件更新後核對。沒有為此更改正式程式的滾輪步幅或額外增加UI。


## 更新：扁平尺軌，左光源、右屏幕（2026-10-29）

使用者核可扁平版示意圖，再明確要求將示意中的方向改為「左端光源、右端屏幕」，以對照舞台的前後相對位置。`ruler-approved.png` 保存最後扁平示意；該圖仍是先前左屏幕的方向，實作以最後的方向修正為準。保留既有舞台、道具卡及任務面板。

### 控制器

- 高78px，桌機與手機皆維持緊湊兩行：標題／讀值／提示，以及兩端標示／刻度尺。兩個舊前後按鈕已移除；小燈與屏幕圖示和文字同列。
- 原生range提供0–10相對位置刻度、0.01步幅，綠色防滑指針滑塊沿刻度移動。0在光源端、10在屏幕端，沒有標出答案位置，也沒有將刻度當公分或公尺。
- 左移增加z、靠近光源並放大影子；右移減少z、靠近屏幕並縮小影子。移動範圍沿用z=-0.9至2.95，沒有改變原有投影幾何或容錯。
- 選取／切換道具時同步各自的刻度、名稱及讀值，只更新控制器，不把顯示值的四捨五入回寫道具。畫布方向鍵與原有滾輪也會同步尺軌。
- input即時更新道具與影子，change才提交吸附判定。拖曳經過合格區間時不會立即鎖住或隱藏尺軌；放開後仍依大小／位置兩條件判定，只微調x／y、保留學生的z。
- 操作引導補上先選道具；尺軌僅於選中未完成道具時顯示，沿用原選取流程。原生鍵盤與可及名稱提供目前道具、相對刻度及端點方向。
