# 3.1 第七區：兩種繩波實驗模式

2026-11-01。依使用者核可，保留現有「理想化參數實驗」，新增「真實繩子」切換；沿用既有靜態頁面、SVG 波形與單次振動播放，不新增相依套件。

- 預設為理想化參數實驗，頻率與波長可獨立調整，週期與頻率互為倒數，波速及繩色隨參數改變。原範圍保留：頻率 1–4 Hz、週期 0.25–1 s、波長 4–8 m。
- 真實繩子代表同一條繩子拉緊程度等條件不變，固定波速為 12 m/s，使用固定綠色並隱藏變速色階。調整任一參數時，以 `f = 1/T`、`λ = 12/f = 12T` 同步其他兩個參數；頻率及週期範圍沿用，對應波長為 3–12 m。
- 加減步幅保持頻率 0.5 Hz、週期 0.05 s、波長 1 m；超出範圍時停在端點並停用對應按鈕。真實模式計算保留完整精度，顯示最多三位小數，說明區提醒顯示精度。
- 固定路徑保持 30 m，真實模式波形前端的抵達時間固定為 2.5 s；來源完成一次振動後停止，整個波形離開路徑才完成播放，沿用既有時間及進度語意。
- 各模式分別保留參數，首次進入皆為 2 Hz、0.5 s、6 m。切換會取消正在播放的動畫並重設波形、來源及進度，切回時恢復該模式先前的參數。
- 真實繩子是固定條件的教學示意，不代表理想化模式中能任意獨立改變同一條繩子的頻率及波長。

驗證指令與範圍見 `tests/README.md` 的兩模式專項；涵蓋三向連動、邊界、固定顏色與時間、狀態保存、播放取消、鍵盤／觸控及版面。課程其餘區塊與小葵結論保留。
