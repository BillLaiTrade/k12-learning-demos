# 4.3 小測：讓介質本身呈現氣、液、固差異

2026-11-04（臺北時間）。使用者指出相較第一區，前版只精修外框而三層仍無材質差異，並表示可使用液體、固體或其他氣體。

直接使用第一區原有圖稿的氣體艙、液體焦散、玻璃厚邊／反光，分別貼入三層。PNG原檔不變，SVG以不同視窗引用內面。桌機取較寬區域，窄容器依比例取材質中央，避免器材細節變形。名牌與光線維持獨立繪製。

題目資料將物態與代表折射率綁定：氣體1.00045、液體1.4、透明固體1.78。新增氣體外觀時，代表n取接近1的1.00045，避免將原未指名介質的1.12直接當成一般氣體。六種位置排列時，圖樣／n／光路一起變更，甲乙丙僅為位置名稱。學生可結合前面介質經驗與折射角度判斷；回饋仍依平行法線的夾角，不宣稱所有物態都具有固定光速排序。

示意為薄壁密封分層，略去壁厚度及部分反射，層間主介面互相平行。光紋只表現液體材質，不改動主介面方向或偽造波浪法線。主折射公式、計時方式、排序操作與換題流程保持；材料載入沿用預載／備援處理。六個學習區與原圖片均保持。
