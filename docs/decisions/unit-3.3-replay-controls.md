# 3.3 短音保留再次點擊重播

2026-11-01，操作盤點第7項。使用者選擇「保留重播」：第二到第五區的聲音正在播放時，再點同一個播放控制會停止舊音源，從頭播放同一設定；不改為同鍵停止。

四區原有操作說明補上對應的可見提示，分別說明再點喇叭／播放鍵、同側琴弦／撥弦按鈕、同一根管子、同一樂器／播放鍵可從頭重播。不改按鈕名稱、播放程式、音檔、波形、動畫或第六區／小測／第七區的停止方式。以桌機與筆電為預設，手機範圍仍擱置。

下一個仍需討論的是小測調整時是否保留目標波形與提示（原盤點第9項）；原第8項的本輪最佳紀錄已隨獨立無限單題取消，不再適用。

2026-11-02後續：使用者要求移除第二區標頭的「再點同一個喇叭或播放鍵，可從頭重播。」只刪除該句可見提示，第二區仍可再次點擊重播，第三至第五區提示及所有播放邏輯保持。
