# 2.3 氬氣主標示修訂

日期：2026-10-30（臺北時間）。

使用者指出主圖只列「其他1%」會藏住第三大成分氬氣，要求直接標示。

- 第二區主圖例獨立列氮氣約78%、氧氣約21%、氬氣約0.93%，其餘少量氣體另列，不再將氬氣歸在主圖例的「其他1%」。三個主要成分的含量順序直接可見。
- 100格圖保留78氮／21氧的粗略份額，最後約1格以斜紋合併氬氣及其餘少量，搭配明確圖說；不把末格標成氬氣1%，也不以約數相減宣稱其餘的精確值。資訊放大框的各氣體比例分母都是全部乾燥空氣。
- 氬氣及其餘氣體可分別選取，因100格精度而共同突出合併末格；回饋明確說明合併關係。全部資料預設可見、停用JavaScript仍可讀。
- 第五區與小測提供資料同步改為氬氣獨立標示；不改變六區、一小測、兩種製備或其他學習內容。
- 沿用既有NOAA來源；約1%為氬氣與其餘的合計，不新增固定的「剩餘0.07%」數值。
