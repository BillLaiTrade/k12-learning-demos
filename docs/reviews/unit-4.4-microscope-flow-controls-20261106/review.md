# 第九區：關係線中的近看入口

日期：2026-11-06

將兩個獨立近看按鈕移入關係線的物鏡與目鏡節點，以鏡頭名稱與「如何成像／如何觀察」兩行呈現。原物、中間像、眼睛保留為關係節點；中間像只出現一次。選中鏡頭按鈕以深綠底表示，目前涵蓋的關係範圍以連續淡綠底表示。上方完整成像標題、範圍文字與返回入口保留。

關係線用原生群組容納按鈕，明確指定按鈕名稱與操作提示；保留鍵盤、焦點返回、鏡頭及下方卡片連動、光路與物點偏好。

## 驗證

- 顯微鏡互動檢查8項通過，包括兩個按鈕位於關係線內、群組與按鈕語意、範圍標示、全貌及局部切換、共同中間像、鍵盤、偏好及備用剖面。
- 1440、1366、1024、760、390、320六種視窗寬度與三種觀察範圍檢查通過，確認文字、控制及圖內標籤未裁切、越界或重疊。
- 放大手機節點小字後，再以390與320px確認三種觀察範圍。完整關係線不需橫向捲動，工作區可在同一視窗顯示。
- 人工檢視桌面全貌及物鏡近看、320px手機全貌及物鏡近看，確認鏡頭節點可辨認且選取範圍清楚。
