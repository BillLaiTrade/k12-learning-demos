# 3.2 第09項：統一空氣聲速近似公式

日期：2026-11-01（臺北）。使用者選擇 B，第五區改採與煙火小測相同的近似公式 `v＝331＋0.6T`（T 為攝氏溫度，v 為公尺／秒）。

- 0°C 與80°C的教學聲速分別為331、379m/s；傳到5,000公尺約為15.106、13.193秒，差約1.913秒。
- 既有0°C／80°C分組、5公里距離、實時計時、粒子訊號、暫停、單獨敲擊及重設維持。
- 第四區空氣343m/s、水1480m/s、鋼5900m/s保持；小測的公式、題目氣溫、延遲及答案容差保持。
- 同步更新正式頁的模型／控制器快取版本、獨立預覽頁的舊公式說明及版本，避免新舊算法混用。

本次是依核可取捨統一教學近似方式，不宣稱舊平方根模型錯誤，也不把線性近似當作精確實測值。歷史檢查與舊數值紀錄保留；後續接續第10項夜景圖載入失敗後重試。
