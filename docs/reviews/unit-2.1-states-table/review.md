# 2.1 第二區：三態圖解比較表

日期：2026-10-29。

## 使用者確認的呈現方式

以「圖解＋短標籤」直接呈現九格比較；移除原先選欄、選列、選格後才顯示的下方模型區。所有概念與圖解預設可見，僅在格內保留少量觀察操作。沿用現有第二區標題、角色對話與其餘課程區塊。

- 形狀：固體、液體與氣體皆可更換右側容器；左側保留參照。金屬塊幾何不變；水的量維持 100 mL，以相同剖面填充面積表示等量，容器變窄時水位升高；氣體的不規則粒子示意分布在密閉容器內。
- 體積：固體以同一金屬塊與尺寸線呈現；液體兩杯均直接標示 100 mL；氣體可上下推拉活塞，讀值跟隨可用空間改變。
- 可壓縮性：三態使用同一類密閉活塞示意。固體與完全充水、無氣泡的液體在施力後只作極小位移，標示體積幾乎不變；氣體則可明顯壓縮。氣體的 24 個示意粒子在換容器、改變體積或壓縮時數量保持相同。
- 標示物理性質及「觀察時仍是原來的物質」。器材、粒子和體積數值均為教學示意，並非真實力—體積校正；難壓縮不表示完全不能壓縮。
- 正式實作是原生 HTML 表格、SVG、CSS、JavaScript，沒有新增套件。窄螢幕僅表格內可橫向捲動，列標題固定，並提供滑動提示；鍵盤可操作換容器按鈕及活塞（方向鍵、Home、End），活塞亦支援滑鼠與觸控。
