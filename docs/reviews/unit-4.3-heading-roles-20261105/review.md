# 4.3 標題、副標與操作提示修訂

2026-11-05（臺北）。依[核可決策](../../decisions/unit-4.3-heading-roles.md)完成文字分工。第一／六區及小測標頭保持；第二區大標／導覽改為真正待觀察疑問，第二至五區副標只定位概念／比較關係。

## 檢查

- 六區大標／副標逐一對照決策表，副標未放點擊／拖曳教學、偏離法線或原路返回等待探索結論。文字保持自然換行。
- 第三區阿公只引導觀察；實際操作提示移到實驗圖上方，距離圖緣8px，與光源圖相鄰，不遮器材或控制。第二區桌面捲動用語及區域名稱一致。
- 第四區適用條件由副標移到觀察結果圖例；待機時不預先顯示，水／玻璃各0°與40°下核對條件顯示／隱藏與界線，0°不顯示斜射條件。原控制器依既有data-angle與結果狀態運作，沒有改模型或播放時序。
- 1440×900、1366×768、1280×720、1024×768四桌面尺寸確認六區標頭無裁切、提示緊鄰圖、16組條件狀態均正確，見checks.json／check.txt及代表截圖。
- 必要回歸12項全過：原格式5項與11項決策互動7項，包含發射先回圖、小車中斷／收合、小測重播／無變動保留、四桌面控制可見性及硬幣薄邊預覽／細節／備援一致。只把既有條件斷言改查新的圖旁位置並補0°隱藏檢查，沒有刪除科學條件要求。
- preservation.json確認光學模型、實驗控制器、原實驗CSS、PNG及小測控制器皆相同；lesson.mjs僅增加標題同源導覽UI。課程修改限HTML核可文字／提示位置、共用格式CSS兩條提示／條件樣式及導覽標題綁定，不重跑無關光學模型。
