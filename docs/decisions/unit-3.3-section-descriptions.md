# 3.3 各學習區標頭說明

2026-11-02，使用者核可第三區改為「改變琴弦的長短或鬆緊，聽聽聲音，觀察振動的變化。」並要求確認目前各學習區塊相同位置的說明。範圍為3.3七個學習區，另檢視單元小測；參照3.2、3.4的學習方向簡述，不把標頭當作完整操作說明。

| 區塊 | 決定與現行說明 |
| --- | --- |
| 01 音叉 | 保留「響度與振幅：保持音高相同，比較聲音大小與振動幅度。」已有明確比較條件及觀察方向。 |
| 02 喇叭 | 改為「比較不同音高的聲音，看看喇叭的振動有什麼不同。」先引導觀察，不在標頭指定振動快慢。 |
| 03 琴弦 | 採使用者核可文字，移除與標題重複的同弦說明、已由模式落實的單變因提醒及重播提示。 |
| 04 排笛 | 保留「點選長短不同的管子，聽聲音，也看看管內的振動。」移除標頭重播提示；圖上方點奏提示保持。 |
| 05 音色 | 改為「聆聽相同音高的不同樂器聲，比較它們的波形。」釐清原「同一個音」指相同音高，移除標頭重播提示。 |
| 06 聽覺 | 保留「持續試聽，自由探索高低音，記下這次的聽覺範圍。」與探索及手動紀錄相符。裝置／環境限制說明保持。 |
| 07 分貝 | 改為「比較不同生活場景的參考聲級，認識分貝的讀法。」以觀察內容取代點選方法，操作區已有點選／拖動提示。 |

單元小測屬作答流程說明，保留既有內容與程式管理。不更動標題、導覽、人物對話、操作、音訊、模型、素材或樣式。既有琴弦按鈕與拖曳提示、排笛點奏提示、分貝點選／拖動提示皆保持；重播行為保持，標頭不再重複提示。
