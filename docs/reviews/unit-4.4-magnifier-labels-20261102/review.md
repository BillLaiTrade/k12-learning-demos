# 4.4 第四區移除器材浮動說明

2026-11-02。使用者指出底座上的器材名稱與「可拖曳／固定」標籤太多、影響操作。本輪移除圖卡、凸透鏡、眼睛與屏幕的常駐浮動標籤，底座及拖曳把手完整露出；下方器材按鈕、微調、F焦點標記及僅開啟反向延長線時的虛像提示保留。不新增其他說明或開關。

只有第四區HTML的標籤、模組內標籤定位資料與載入版本更新，橫向比例與其他九區、樣式、光學計算及操作邏輯保持。preservation.json核對其餘九區、既有資產，以及標籤繪製以外的整份程式一致。

本機立體專項10項全部通過，新增確認四種常駐器材標籤不存在、下方圖卡操作仍可見；既有拖曳、旋轉／縮放不改眼睛像素、影像比例、光路、屏幕比較、七寬度、觸控及備援全數保留。人工檢視桌機與手機畫面確認標籤已移除；結果見local-studio.txt與layout.json。未重跑未改的純模型、整課及其他區專項，維持第四階段。
