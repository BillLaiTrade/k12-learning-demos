# 4.2 第一區四項畫面改善

日期：2026-11-05。使用者核可先做四項：放大受照面與平衡取景、減弱桌面亮斑、改善材質辨識、提供三個觀看位置與清楚的開關狀態。第五項表面放大示意不在範圍內。

- 單一3D場景、左右同時比較。放大兩種材料為相同尺寸，使用正交取景保持等大的視覺比較，依器材及標籤範圍適配螢幕。
- 兩光源相對各自受照面的位移相同，距離2.8單位、相同強度與0.12弧度半角；完整光錐落在材料上。木桌粗糙度提高，降低環境補光與曝光，保留淺灰背景。
- 鏡面以平整材質與窄幅高光呈現；紙面以高粗糙度與細微紙紋呈現。初始觀察方向由反射向量對準；換視角時只動相機，反光差異由同一場景的材質光照計算產生。沒有另外畫固定亮斑或為視角切換指定明暗。
- 三個觀看按鈕與拖曳共用相機。初始正面、左右±38°，可回正面；切換保留原點燈狀態。按鈕可鍵盤／觸控操作，至少44px高；自由拖曳時更新觀看狀態，不逐幀重播相同讀屏文字。
- 各光源初始關閉，維持獨立開關；已開啟／已關閉、按鈕顏色、燈頭與指示環發光、可及名稱同步。載入或失敗時停用控制，延續原備援訊息。
