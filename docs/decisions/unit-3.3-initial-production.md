## 七區核心內容與實際呈現

| 區塊／錨點 | 要呈現的核心內容 | 初版呈現與學生操作 | 應觀察到的結果與界線 |
| --- | --- | --- | --- |
| 1／`#card-01` 響度與振幅 | 固定頻率下，振幅改變與大小聲有關；大聲不同於高音。 | 依核可示意圖改為同一支音叉的輕敲／較重敲、放慢振動及單側振幅放大觀察；逐次留下波形與聽感紀錄。 | 頻率同為440Hz；只改變振幅，兩叉股反向運動。兩次皆觀察後顯示音高相同及阿公收束；停止保留紀錄，重設清空。 |
| 2／`#card-02` 音調與頻率 | 相同時間內振動較多次，頻率較高、音調通常較高。 | 依後續核可示意圖改成固定200Hz與右側200～800Hz、100Hz加減；兩個木製喇叭各自播放，振膜與波形放慢同步呈現。 | 圖形週期數與實際聲音頻率同步變化，不宣稱相同振幅在不同頻率必定同樣大聲，不改寫成聲速變快。 |
| 3／`#card-03` 琴弦 | 固定弦性質時，較短或較緊的弦，基本頻率通常較高。 | 有效弦長30～90cm、相對張力0.50～2.00；保留原220Hz試聽及目前琴弦撥動。 | 長度、張力各自可改，數值與合成弦音同步；只有撥動目前琴弦時畫面放慢振動，停止／重設後靜止。 |
| 4／`#card-04` 空氣柱 | 同類、同一發聲模式下，有效空氣柱較長時音調較低。 | 同類兩端開口管，20～80cm長度控制；保留60cm參照，吹奏目前設定時出現短暫空氣微移。 | 長度與基本頻率反向變化；不與敲水瓶混用，也不假裝涵蓋高音超吹、所有開閉管及真實吹奏細節。 |
| 5／`#card-05` 音色與波形 | 相同音高下，波形／聲音組成仍可不同，形成不同音色。 | 440Hz純音、弦音示意、管音示意，三張波形預設並列並可各自試聽。 | 同音高不同波形與聲音特色；波形相對高度統一，音訊RMS近似匹配，保留設備影響說明。不是樂器實錄，不將音色講成永遠不能改變。 |
| 6／`#card-06` 聽覺範圍 | 人耳可聽範圍約20～20000Hz；聽不到不等於沒有聲波。 | 區間圖、18／440／18000／25000Hz觀察選擇、動物高頻上限資料。 | 顯示次聲／人耳概略範圍／超聲分類。動物只比較上限，沒有宣稱從0Hz起皆可聽；本區不播放極端測試音。 |
| 7／`#card-07` 分貝 | 基礎辨讀聲級資料，理解數字有基準、條件與加權方式。 | 一般交談、電影院、音樂會的dBA參考範圍，點選後顯示情境差異；說明0dB及非線性聽感。 | 資料比較不等於裝置量測或實際重現該聲級；不教對數運算、不增加噪音／聽力保護教學。 |

## 一個結尾小測

`#unit-quiz`為一個聲音展示台設定任務：依指定頻率、維持原振幅及音色要求操作，提供原聲／目前設定波形與試聽。可見要求不依賴精細聽力。檢核有未完成、錯誤及正確回饋；修改撤回舊結果、全部重填及換要求均可操作。前七區沒有逐區判分。

## 聲音與動畫的實作界線

- 以Web Audio短音合成，固定頻率、相對振幅與泛音係數，便於獨立比較；示意音非樂器實錄。定義與來源見[素材說明](../../units/3/parts/3.3/assets/README.md)。
- 每次聲音1.6秒並有淡入淡出；同時只播放一組。切換區塊、隱藏分頁、離開畫面／頁面及手動停止，均取消聲音與動畫，返回不自動恢復。
- 琴弦與管內空氣僅在試奏目前設定時出現短暫放慢示意，沒有額外背景粒子微動；教學動作不因「減少動態」偏好而定格。
- 學生介面不用內部製作階段標籤；文件中的「初版」不代表第五階段完整審查或外部驗收。

後續依使用者實際檢視逐區精修，優先維持各區核心概念與變因控制；更換音源或模型時同步更新本紀錄。
