# 3.2 第14項：依公式完整答案判分

日期：2026-11-01（臺北）。使用者要求氣溫與時間差完全代入公式所得的結果就是答案，不再採用約±1%或至少2公尺的估算容差，也不接受另行四捨五入的答案。

- 使用題面公式 v＝331＋0.6T，再以聲速乘上畫面記錄的時間差。四種氣溫的聲速均為整數，時間差為百分之一秒，完整距離最多兩位小數。
- 數值與完整結果相同才判正確；例如10°C、3.01秒須答1014.37公尺，1014、1014.3、1014.4及偏差0.01公尺均不接受。1014.370與1014.37為相同數值，均接受。
- 作答區、輸入欄輔助說明與答錯回饋明示「有小數時完整保留，不用四捨五入」；題面與答對回饋改為計算用語。
- 保留單一距離輸入欄，仍只核對最後答案，未宣稱能驗證學生的計算過程。聲速公式、氣溫／時間差生成、觀察、音訊、圖片重試、重播／換題與其他區塊保持。

計算使用既有百分之一公尺表示法消除程式浮點乘法尾差；判分本身採數值相等，沒有額外誤差範圍。第15項前面核心觀念是否另納入小測仍待逐項決定。
